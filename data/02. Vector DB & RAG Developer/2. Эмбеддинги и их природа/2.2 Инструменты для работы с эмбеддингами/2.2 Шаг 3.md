#### Эмбеддинги OpenAI

OpenAI предоставляет готовую модель эмбеддингов, наиболее известная – `text-embedding-ada-002`. Она возвращает вектор длиной 1536 для каждого текста и обучена на огромном объёме данных. Преимущество OpenAI Embeddings – очень высокое качество без необходимости развертывать какие-либо модели локально. Вы просто делаете запрос к API с вашим текстом – и получаете массив из 1536 чисел. Этот эмбеддинг универсален: его можно использовать для поиска, сравнения текстов, кластеризации, рекомендаций и много другого.

Работать с OpenAI API можно из Python, используя официальный пакет `openai`. Вам понадобится интернет-соединение и ключ API. В нашем курсе упор делается на практику с локальными инструментами, поэтому подробно останавливаться на вызове внешнего API мы не будем. Но важно знать, что такой вариант есть. Многие приложения сейчас комбинируют локальные и облачные эмбеддинги. Например, можно сначала быстро отфильтровать кандидатов локально с помощью недорогой модели, а для более тонкого ранжирования запросить эмбеддинги высокой точности у облачной модели.

Стоит упомянуть, что OpenAI взимает плату за использование своей модели (например, доли цента за несколько сотен или тысяч токенов текста – актуальные тарифы указаны в их документации). Кроме того, отправляя данные внешнему сервису, важно убедиться, что это не нарушает требований безопасности и конфиденциальности, особенно если вы работаете с чувствительной информацией.
