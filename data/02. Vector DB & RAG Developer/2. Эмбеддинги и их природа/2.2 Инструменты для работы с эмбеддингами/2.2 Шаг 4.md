#### Практика получения эмбеддингов (Python 3.10, Ubuntu 22.04)

Давайте суммируем, как на практике можно получить эмбеддинг для текста в типичной среде (например, на Python 3.10 в Ubuntu 22.04). Первый вариант – использовать библиотеку `sentence_transformers`. Предварительно устанавливаем её (`pip install sentence-transformers`). Затем в коде:

*Пример сценария:* вы загружаете предобученную модель, например `all-MiniLM-L6-v2`, и вызываете её метод `encode("ваш текст")`. Результат – список из N чисел (N ≈ 384 для данной модели). Это и есть эмбеддинг.

Второй вариант – OpenAI API: устанавливаем пакет `openai` (`pip install openai`). В коде нужно указать ключ API (`openai.api_key = "ВАШ_КЛЮЧ"`), затем вызвать метод `openai.Embedding.create(input="ваш текст", model="text-embedding-ada-002")`. В ответ придёт структура, из которой можно извлечь сам вектор (список из 1536 чисел). Этот способ требует доступа к интернету и наличия аккаунта OpenAI.

Оба способа в конечном счёте дают эмбеддинги, которые можно сохранять и использовать для поиска. В следующих модулях мы будем работать в основном с эмбеддингами, полученными с помощью моделей вроде Sentence-BERT или OpenAI. Эти эмбеддинги станут основой для векторного поиска и других возможностей, которые мы рассмотрим далее.
