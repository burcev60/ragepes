### Шаг 3. Ингест: чанкинг → эмбеддинги → upsert (мультивектор)

**Цель.** Превратить сырой корпус (JSONL + изображения) в мультивекторные точки индекса: посчитать эмбеддинги для текста/заголовков/картинок/OCR/капшенов и записать всё в коллекцию с именованными векторами.

#### 1) Формат входных данных

Минимально достаточно одного файла `docs.jsonl` и папки с изображениями:

    {"doc_id":"m1","title":"Установка клиента","text":"Чтобы подключиться к базе...", "url":"https://docs.example/install","source":"manual","section":"install","lang":"ru","created_at":"2025-07-10"}
    {"doc_id":"m2","title":"Поиск картинкой","text":"CLIP даёт общее пространство...", "url":"https://docs.example/clip","source":"manual","section":"search","lang":"ru","created_at":"2025-07-11","images":["m2_1.png","m2_2.png"]}

- `text` может быть длинным — будем бить на чанки.
- `images` — относительные пути в каталоге `--images_dir`.
- Доп. поля (если есть): `caption`, `ocr.full_text`, `ocr.spans[]` (см. предыдущий шаг).


#### 2) Чанкинг текста

Чанки нужны, чтобы не «размывать» смысл и улучшать извлечение:

- **Размер:** 300–800 символов; **оверлап:** 40–80 символов.
- **ID-схема:** `point_id = "{doc_id}#p{idx}"`.
- **Префикс заголовка:** полезно добавлять `[title] → текст чанка` при векторизации.


#### 3) Выбор энкодеров

- `text_vector`, `ocr_text_vector`, `caption_vector` → любой *текстовый* энкодер (например, SBERT: `all-MiniLM-L6-v2`).
- `title_vector` → компактный энкодер (например, `paraphrase-MiniLM-L3-v2`).
- `image_vector` → CLIP/SigLIP (визуальный энкодер). Важно: пара «текст↔картинка» должна быть согласованной.


Все эмбеддинги L2-нормируем перед записью; в индексе метрика `Cosine`.

#### 4) Каркас скрипта `ingest_multivector.py`

CLI: `--jsonl docs.jsonl --images_dir images --collection kb_multivector --url http://localhost:6333 --api-key ... --batch 256`

    #!/usr/bin/env python3
    # -*- coding: utf-8 -*-
    import argparse, json, pathlib, itertools, math, os, sys
    from typing import List, Dict, Any, Iterable, Optional

    import numpy as np
    from qdrant_client import QdrantClient
    from qdrant_client.http.models import Distance, VectorParams, PointStruct

    from sentence_transformers import SentenceTransformer

    # ---- опционально CLIP (если не установлен - просто пропустим image_vector) ----
    def try_load_clip():
        try:
            import torch, clip  # pip install git+https://github.com/openai/CLIP.git
            device = "cuda" if torch.cuda.is_available() else "cpu"
            model, preprocess = clip.load("ViT-B/32", device=device)
            return model, preprocess, device
        except Exception:
            return None, None, "cpu"

    def l2_normalize(x: np.ndarray) -> np.ndarray:
        n = np.linalg.norm(x) + 1e-9
        return (x / n).astype("float32")

    def chunk_text(text: str, max_len: int = 700, overlap: int = 80) -> List[str]:
        # простой символьный чанкер с overlap; замените на sentence/paragraph-чункер при желании
        text = " ".join(text.split())
        if len(text) <= max_len:
            return [text]
        chunks, i = [], 0
        while i < len(text):
            j = min(len(text), i + max_len)
            chunks.append(text[i:j])
            i = j - overlap
            if i < 0: i = 0
            if j == len(text): break
        return chunks

    def encode_texts(model: SentenceTransformer, texts: List[str], batch_size: int = 64) -> np.ndarray:
        embs = model.encode(texts, batch_size=batch_size, show_progress_bar=False, normalize_embeddings=False)
        if isinstance(embs, list):
            embs = np.array(embs)
        # L2-нормализация
        embs = np.vstack([l2_normalize(e) for e in embs])
        return embs

    def encode_images(clip_model, preprocess, device, paths: List[pathlib.Path], batch_size: int = 32) -> Optional[np.ndarray]:
        if clip_model is None:  # CLIP не установлен
            return None
        import torch
        from PIL import Image
        all_embs = []
        with torch.no_grad():
            for i in range(0, len(paths), batch_size):
                batch_paths = paths[i:i+batch_size]
                imgs = []
                for p in batch_paths:
                    img = Image.open(p).convert("RGB")
                    imgs.append(preprocess(img))
                imgs = torch.stack(imgs).to(device)
                feats = clip_model.encode_image(imgs)
                feats = feats / (feats.norm(dim=-1, keepdim=True) + 1e-9)
                all_embs.append(feats.cpu().numpy().astype("float32"))
        return np.vstack(all_embs)

    def ensure_collection(client: QdrantClient, name: str):
        existing = {c.name for c in client.get_collections().collections}
        if name in existing:
            return
        client.recreate_collection(
            collection_name=name,
            vectors_config={
                "text_vector":     VectorParams(size=384, distance=Distance.COSINE),
                "title_vector":    VectorParams(size=384, distance=Distance.COSINE),
                "image_vector":    VectorParams(size=512, distance=Distance.COSINE),
                "ocr_text_vector": VectorParams(size=384, distance=Distance.COSINE),
                "caption_vector":  VectorParams(size=384, distance=Distance.COSINE),
            },
            hnsw_config={"m":16, "ef_construct":128},
            optimizers_config={"memmap_threshold": 200000},
        )

    def main():
        ap = argparse.ArgumentParser()
        ap.add_argument("--jsonl", required=True)
        ap.add_argument("--images_dir", default=None)
        ap.add_argument("--collection", default="kb_multivector")
        ap.add_argument("--url", default="http://localhost:6333")
        ap.add_argument("--api-key", default=None)
        ap.add_argument("--batch", type=int, default=256)
        ap.add_argument("--prefix_title", action="store_true", help="добавлять title в начало чанка")
        args = ap.parse_args()

        client = QdrantClient(url=args.url, api_key=args.api_key)
        ensure_collection(client, args.collection)

        # --- энкодеры ---
        txt_enc  = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
        ttl_enc  = SentenceTransformer("sentence-transformers/paraphrase-MiniLM-L3-v2")
        clip_model, clip_preprocess, device = try_load_clip()

        # --- чтение JSONL и подготовка точек ---
        points: List[PointStruct] = []
        img_dir = pathlib.Path(args.images_dir) if args.images_dir else None

        with open(args.jsonl, "r", encoding="utf-8") as f:
            for line in f:
                row = json.loads(line)
                doc_id = row["doc_id"]
                title  = row.get("title", "") or ""
                text   = row.get("text", "") or ""
                images = row.get("images", []) or []
                payload_base = {
                    "doc_id": doc_id,
                    "url": row.get("url"),
                    "source": row.get("source"),
                    "section": row.get("section"),
                    "lang": row.get("lang"),
                    "created_at": row.get("created_at"),
                    "title": title,
                }

                # --- 3.1: текст → чанки → text_vector + title_vector ---
                chunks = chunk_text(text, max_len=700, overlap=80) if text else []
                texts_for_emb = [(f"[{title}] {ck}" if (args.prefix_title and title) else ck) for ck in chunks]
                if texts_for_emb:
                    text_embs = encode_texts(txt_enc, texts_for_emb)
                else:
                    text_embs = np.zeros((0,384), dtype="float32")

                title_vec = None
                if title.strip():
                    title_vec = encode_texts(ttl_enc, [title])[0]  # 384-dim

                for idx, emb in enumerate(text_embs):
                    pid = f"{doc_id}#p{idx}"
                    vecs = {"text_vector": emb}
                    if title_vec is not None:
                        vecs["title_vector"] = title_vec
                    points.append(PointStruct(id=pid, vector=vecs, payload={**payload_base, "chunk_idx": idx}))

                # --- 3.2: изображение → image_vector (если CLIP доступен) ---
                if img_dir and images and clip_model is not None:
                    full_paths = [img_dir / p for p in images]
                    img_embs = encode_images(clip_model, clip_preprocess, device, full_paths)
                    for k, pth in enumerate(full_paths):
                        pid = f"{doc_id}#img{k}"
                        vecs = {"image_vector": img_embs[k]}
                        points.append(PointStruct(id=pid, vector=vecs,
                                                  payload={**payload_base, "image_path": str(pth)}))

                # --- 3.3: OCR/Caption (если есть в JSONL) ---
                if "ocr" in row and isinstance(row["ocr"], dict) and row["ocr"].get("full_text"):
                    ocr_vec = encode_texts(txt_enc, [row["ocr"]["full_text"]])[0]
                    # Частичное обновление существующей точки-картинки или создаём отдельную (привяжем к #img0)
                    pid = f"{doc_id}#img0"
                    points.append(PointStruct(id=pid, vector={"ocr_text_vector": ocr_vec},
                                              payload={**payload_base, "ocr": row["ocr"]}))
                if "caption" in row and isinstance(row["caption"], str) and row["caption"].strip():
                    cap_vec = encode_texts(txt_enc, [row["caption"]])[0]
                    pid = f"{doc_id}#img0"
                    points.append(PointStruct(id=pid, vector={"caption_vector": cap_vec},
                                              payload={**payload_base, "caption": row["caption"]}))

        # --- батчевый upsert ---
        B = max(1, int(args.batch))
        for i in range(0, len(points), B):
            client.upsert(collection_name=args.collection, points=points[i:i+B])

        print(f"Inserted/updated {len(points)} points into '{args.collection}'")

    if __name__ == "__main__":
        main()

- Скрипт *создаёт* коллекцию при отсутствии (см. шаг 2), затем пишет точки батчами.
- Текстовые чанки получают `text_vector` (+ общий `title_vector`); изображения — `image_vector`.
- Если в JSONL есть `ocr.full_text` или `caption`, они пишутся как частичные апдейты в `#img0` (адаптируйте под свой ID).


#### 5) Полезные приёмы

- **Частичный upsert:** можно добавлять новый именованный вектор к уже существующему `point_id` (как выше для OCR/Caption) — не нужно перезаписывать всё.
- **Параллелизм:** при больших коллекциях используйте параллельную кодировку батчей и очередь на upsert.
- **Валидация:** проверяйте, что длина каждого вектора соответствует схеме (384/512 и т.д.), а L2-норма близка к 1.


#### 6) Мини-практика (2–3 минуты)

1. Соберите из 2–3 записей свой `docs.jsonl` и одну картинку в `images/`. Запустите скрипт с `--prefix_title`.
2. Проверьте, что в коллекции появились точки: 2–4 чанка текста с `text_vector` и хотя бы одна точка с `image_vector`. Убедитесь, что `title_vector` присутствует у всех текстовых чанков.


#### Чек-лист готовности

- Входные данные нормализованы (JSONL валиден, пути к картинкам корректны).
- Эмбеддинги считаются и L2-нормируются; метрика индекса — `Cosine`.
- ID-схема соблюдена (`doc_id#p{idx}` / `doc_id#img{idx}`), payload содержит ключевые поля (ACL/секции/язык).
- Батчевый upsert завершился без ошибок; размерности векторов соответствуют схеме коллекции.
