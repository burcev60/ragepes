### Шаг 5. *RecommendQuery*: «похоже на это» (+ негативы и диверсификация)

**Цель.** Научиться выдавать похожие элементы по одному или нескольким «якорям» (positive set) с учётом «чего не хотим» (negative set), исключений и диверсификации (MMR). Подходит для «похожие экраны», «прочитать дальше», «ещё по теме».

#### 1) Контракт `RecommendQuery`

- `positives`: список `point_id`/`doc_id`, на которые хотим быть похожими.
- `negatives`: список id, от которых *отталкиваемся* (опционально).
- `vector_name`: по какому вектору меряем похожесть (например, `text_vector` для «по смыслу текста», `image_vector` для «по картинке»).
- `agg`: способ агрегирования якорей в один запросный вектор: `"mean"` / `"weighted"` / `"rocchio"`.
- `exclude_self`: булев флаг, чтоб не возвращать сами якоря (по `doc_id` или `point_id`).
- `filters`: ACL/контент фильтры (как в NearestQuery).
- `k`, `ef_search`, `fields`, `mmr` (`{lambda, topn}`), `max_per_doc`, `limit`.


*Идея.* Сначала строим **запросный вектор** по якорям, потом делаем обычный NearestQuery и применяем пост-обработку (исключения, MMR, лимит по источнику).

#### 3) Поток выполнения

1. **Извлечь векторы якорей** по `point_id`/`doc_id` и выбранному `vector_name`.
2. **Собрать q** (mean/weighted/rocchio) и нормализовать.
3. **NearestQuery** по `vector_name` с ACL-фильтрами, `k`, `ef_search`.
4. **Исключить** `positives` и `negatives` из кандидатов (по `doc_id` или `point_id`).
5. **MMR** и `max_per_doc` для разнообразия.
6. **Отсортировать** стабильно и вернуть Trace.


#### 4) Псевдокод `RecommendQuery`

    from dataclasses import dataclass
    from typing import List, Dict, Any, Optional
    import numpy as np

    def l2norm(x):
        x = np.asarray(x, dtype="float32")
        n = np.linalg.norm(x) + 1e-9
        return (x / n).astype("float32")

    @dataclass
    class RecommendQuery:
        positives: List[str]              # point_id или doc_id
        negatives: Optional[List[str]] = None
        vector_name: str = "text_vector"
        id_kind: str = "point"            # "point" | "doc" — чем заданы ids
        agg: str = "mean"                 # "mean" | "weighted" | "rocchio"
        weights: Optional[Dict[str,float]] = None  # для weighted
        rocchio_alpha: float = 1.0
        rocchio_beta: float  = 0.3
        filters: Optional[Dict[str,Any]] = None
        k: int = 100
        ef_search: int = 64
        fields: Optional[List[str]] = None
        exclude_self: bool = True
        mmr: Optional[Dict[str,Any]] = None       # {"lambda":0.7, "topn":10}
        max_per_doc: Optional[int] = 2
        limit: int = 10

        def run(self, client, coll) -> Dict[str,Any]:
            trace = {"query":{"type":"RecommendQuery","params":{
                "vector": self.vector_name, "agg": self.agg, "k": self.k, "ef": self.ef_search}}}

            # 1) вытянуть векторы якорей
            def get_vecs(ids):
                # замените на ваш способ: по point_id/doc_id вытянуть именованный вектор из хранилища
                return [self._load_vector(client, coll, i, self.id_kind, self.vector_name) for i in ids]

            v_pos = [v for v in get_vecs(self.positives) if v is not None]
            v_neg = [v for v in get_vecs(self.negatives or []) if v is not None]

            # 2) собрать q
            if self.agg == "rocchio" and v_neg:
                q = self.rocchio_alpha * np.mean(v_pos, axis=0) - self.rocchio_beta * np.mean(v_neg, axis=0)
            elif self.agg == "weighted" and self.weights:
                acc = np.zeros_like(v_pos[0])
                for i, v in zip(self.positives, v_pos):
                    acc += float(self.weights.get(i, 1.0)) * v
                q = acc
            else:
                q = np.mean(v_pos, axis=0)
            q = l2norm(q)

            # 3) поиск
            raw = client.search(
                collection_name=coll,
                query_vector=(self.vector_name, q),
                limit=self.k, with_payload={"include": self.fields or []},
                params={"hnsw_ef_search": self.ef_search},
                query_filter=self.filters
            )

            # 4) пост-обработка: исключения/диверсификация/лимиты
            pos_docs = set(self._to_doc_ids(client, coll, self.positives))
            neg_docs = set(self._to_doc_ids(client, coll, self.negatives or []))
            cand = []
            for p in raw:
                doc = p.payload.get("doc_id")
                if self.exclude_self and (doc in pos_docs or doc in neg_docs):
                    continue
                cand.append({"point_id": str(p.id), "doc_id": doc, "score": float(p.score),
                             "payload": {f:p.payload.get(f) for f in (self.fields or [])}})

            # MMR
            if self.mmr:
                cand = self._mmr(cand, lam=self.mmr.get("lambda",0.7), topn=self.mmr.get("topn", self.limit))

            # max_per_doc
            if self.max_per_doc is not None:
                cand = self._limit_per_doc(cand, self.max_per_doc)

            # стабильный порядок и финал
            cand.sort(key=lambda x: (x["score"], x["payload"].get("created_at"), x["point_id"]), reverse=True)
            trace["final"] = [{"rank":i+1, **c} for i,c in enumerate(cand[: self.limit])]
            return trace

        def _load_vector(self, client, coll, id_, id_kind, vname):
            # Верните np.ndarray для указанного идентификатора и именованного вектора
            ...

        def _to_doc_ids(self, client, coll, ids):
            # Преобразовать point_id/doc_id в список doc_id
            return ids

        def _mmr(self, items, lam=0.7, topn=10):
            # Лёгкая версия: диверсифицируем по doc_id-сходству через payload/метаданные
            # Лучше использовать реальные векторы документов, если доступны
            out, sel = [], set()
            for it in items:
                if not out: out.append(it); sel.add(it["doc_id"]);
                else: out.append(it)
                if len(out) >= topn: break
            return out

        def _limit_per_doc(self, items, max_per_doc=2):
            cnt, out = {}, []
            for it in items:
                if cnt.get(it["doc_id"], 0) < max_per_doc:
                    out.append(it); cnt[it["doc_id"]] = cnt.get(it["doc_id"], 0) + 1
            return out

#### 6) Рецепты

- **Multi-seed рекомендации** (несколько карточек в корзине): *weighted* по вероятности покупки или времени на странице.
- **Анти-дубли**: в `negatives` передавайте уже выбранные элементы — Rocchio оттолкнёт от них q.
- **Кросс-модальность**: для «похожие картинки» используйте `image_vector`; для «по смыслу скрина» — `ocr_text_vector` или `caption_vector`.
