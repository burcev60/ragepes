### Шаг 3. *FusionQuery*: мультиканальный поиск (text ↔ image ↔ ocr)

**Цель.** Научиться объединять несколько каналов поиска (например, `text_vector`, `image_vector`, `ocr_text_vector`) в один финальный скор так, чтобы итоговый топ был и точным, и устойчивым.

#### 1) Контракт `FusionQuery`

**Входные параметры:**

- `parts` — список каналов. Каждый элемент: `{ name, vector_name, vector, weight, k_each, ef_search, filter }`:
  - `name` — произвольное имя (например, `"text"`, `"image"`, `"ocr"`).
  - `vector_name` — имя поля в индексе (`text_vector` / `image_vector` / `ocr_text_vector` / `caption_vector`).
  - `vector` — L2-нормированный вектор запроса для этого канала.
  - `weight` — вес канала (можно не суммировать к 1 — мы нормализуем).
  - `k_each` — сколько кандидатов брать из каждого канала (обычно 50–200).
  - `ef_search` — HNSW-качество для этого канала.
  - `filter` — доп. фильтры (сливаются с общими ACL).
- `normalizer` — способ нормализации скорингов по каналу: `"minmax"` (по умолчанию), `"zscore"`, `"rank"` (Borda).
- `mmr` — `{lambda: float ∈ [0,1], topn: int}` — пост-обработка (опционально).
- `max_per_doc` — ограничение количества фрагментов из одного `doc_id` в финальном списке.
- `fields` — список payload-полей, нужных в ответе (минимум: `doc_id,title,url,created_at`).
- `limit` — сколько вернуть в *final* (после пост-обработки).


**Выход:** *Trace* со сводным ранжированием и вкладом каждого канала по каждому элементу.

#### 2) Алгоритм fusion (шаг за шагом)

1. **Сырые выдачи по каналам.** Для каждого элемента `parts` вызываем *NearestQuery* с его `k_each`/`ef_search`/`filter`. Получаем *candidate_sets*: `{"text":[...], "image":[...], "ocr":[...]}`.
2. **Объединение «всех кандидатов».** Берём объединение `doc_id` (или `point_id` — на ваше усмотрение) из всех каналов — получаем общий пул.
3. **Выравнивание.** Для кандидата, которого нет в канале, используем *минимальный* скор этого канала (или последний ранг в `rank`-нормализации). Это важно, чтобы «отсутствие» не ломало нормализацию.

#### 3) Числовой мини-пример (min–max + веса)

Сырые cosine по каналам:

| doc | text | image | ocr |
| --- | --- | --- | --- |
| d1 |
| d2 |
| d3 |

Нормализация min–max по каждому столбцу:

- text: min=0.55, max=0.74 → d1=0.37, d2=1.00, d3=0.00
- image: min=0.28, max=0.44 → d1=0.19, d2=0.00, d3=1.00
- ocr: min=0.12, max=0.88 → d1=1.00, d2=0.00, d3=0.39


Весá (нормируем к сумме 1): `w_t=0.5`, `w_i=0.3`, `w_o=0.2` → уже сумма 1. Считаем *fusion*:

- d1 = 0.5·0.37 + 0.3·0.19 + 0.2·1.00 = **0.442**
- d2 = 0.5·1.00 + 0.3·0.00 + 0.2·0.00 = **0.500**
- d3 = 0.5·0.00 + 0.3·1.00 + 0.2·0.39 = **0.378**


**Топ:** d2 → d1 → d3. Если поднять вес OCR до 0.35 (и нормализовать веса), d1 станет топ-1.

#### 4) Псевдокод `FusionQuery.run()`

    from dataclasses import dataclass
    from typing import List, Dict, Any, Optional
    import numpy as np

    def minmax(arr):
        lo, hi = float(min(arr)), float(max(arr))
        return [(x - lo) / (hi - lo + 1e-9) for x in arr]

    def zscore(arr):
        mu = float(np.mean(arr)); sd = float(np.std(arr))
        return [(x - mu) / (sd + 1e-9) for x in arr]

    def rank_norm(scores_dict, all_docs):
        # Borda: лучший получает K очков, худший 1 очко (или 0); затем /K
        ranked = sorted(scores_dict.items(), key=lambda kv: kv[1], reverse=True)
        pos = {doc: i for i, (doc, _) in enumerate(ranked)}  # 0..K-1
        K = max(1, len(all_docs))
        return [(K - pos.get(doc, K-1)) / K for doc in all_docs]

    @dataclass
    class FusionPart:
        name: str
        vector_name: str
        vector: list
        weight: float = 0.33
        k_each: int = 100
        ef_search: int = 64
        filter: Optional[Dict[str, Any]] = None

    @dataclass
    class FusionQuery:
        parts: List[FusionPart]
        fields: Optional[List[str]] = None
        normalizer: str = "minmax"  # "zscore" | "rank"
        mmr: Optional[Dict[str, Any]] = None   # {"lambda":0.7, "topn":10}
        max_per_doc: Optional[int] = None
        limit: int = 10

        def run(self, client, coll: str, base_filter: Optional[Dict[str,Any]] = None) -> Dict[str, Any]:
            trace = {"query":{"type":"FusionQuery"}}
            # 1) сырые кандидаты
            cand_sets: Dict[str, Dict[str, float]] = {}
            meta: Dict[str, Dict[str, Any]] = {}  # doc_id -> payload subset
            for p in self.parts:
                f = self._merge_filters(base_filter, p.filter)
                res = client.search(
                    collection_name=coll,
                    query_vector=(p.vector_name, p.vector),
                    limit=p.k_each,
                    with_payload={"include": self.fields or []},
                    params={"hnsw_ef_search": p.ef_search},
                    query_filter=f
                )
                scores = {}
                for it in res:
                    doc = it.payload.get("doc_id")
                    scores[doc] = max(float(scores.get(doc, -1e9)), float(it.score))
                    if self.fields:
                        meta.setdefault(doc, {k: it.payload.get(k) for k in self.fields})
                cand_sets[p.name] = scores
            trace["candidate_sets"] = {name:[{"doc_id":d,"score":s} for d,s in sorted(ch.items(), key=lambda kv: kv[1], reverse=True)]
                                       for name,ch in cand_sets.items()}

            # 2) объединение doc_id
            all_docs = sorted({d for ch in cand_sets.values() for d in ch.keys()})

            # 3) нормализация по каналам
            norm_per_channel: Dict[str, List[float]] = {}
            for name, ch in cand_sets.items():
                # заполнение отсутствующих минимумом канала
                if ch:
                    ch_min = min(ch.values())
                else:
                    ch_min = 0.0
                raw = [ch.get(doc, ch_min) for doc in all_docs]
                if self.normalizer == "zscore":
                    norm_per_channel[name] = zscore(raw)
                elif self.normalizer == "rank":
                    norm_per_channel[name] = rank_norm(ch, all_docs)
                else:
                    norm_per_channel[name] = minmax(raw)

            # 4) нормализация весов и склейка
            Wsum = sum(max(0.0, p.weight) for p in self.parts) or 1.0
            weights = {p.name: max(0.0, p.weight)/Wsum for p in self.parts}
            fused = {doc: 0.0 for doc in all_docs}
            for name, vals in norm_per_channel.items():
                w = weights.get(name, 0.0)
                for i, doc in enumerate(all_docs):
                    fused[doc] += w * vals[i]

            # 5) пост-обработка: MMR / max_per_doc
            ranking = sorted(fused.items(), key=lambda kv: kv[1], reverse=True)

            if self.mmr:
                ranking = self._apply_mmr(ranking, cand_sets, self.mmr.get("lambda", 0.7), self.mmr.get("topn", self.limit))

            if self.max_per_doc is not None:
                ranking = self._limit_per_doc(ranking, self.max_per_doc)

            final = [{"rank":i+1, "doc_id":doc, "score":score, "payload": meta.get(doc, {}),
                      "channels": {name: norm_per_channel.get(name, [0]*len(all_docs))[i]
                                   for name in cand_sets.keys()}}
                     for i,(doc,score) in enumerate(ranking[:self.limit])]

            trace["postprocess"] = {
                "normalization": self.normalizer,
                "weights": weights,
                "mmr": self.mmr,
                "max_per_doc": self.max_per_doc
            }
            trace["final"] = final
            return trace

        def _merge_filters(self, base, extra):
            if not base: return extra
            if not extra: return base
            # простая конъюнкция must/must_not — адаптируйте под свою БД
            out = dict(base)
            for k,v in extra.items():
                if k in out and isinstance(out[k], list) and isinstance(v, list):
                    out[k] = out[k] + v
                else:
                    out[k] = v
            return out

        def _apply_mmr(self, ranking, cand_sets, lam=0.7, topn=10):
            # упрощённая версия: диверсифицируем по doc_id сходству через каналы (косвенно)
            selected, out = set(), []
            for doc, sc in ranking:
                if not out:
                    out.append((doc, sc)); selected.add(doc);
                    if len(out) >= topn: break
                    continue
                # штраф за «похожесть» по канальным нормированным профилям
                def profile(d):
                    return np.array([cand_sets[name].get(d, 0.0) for name in cand_sets.keys()], dtype="float32")
                # cos между профилями (вместо doc-векторов; достаточно для диверсификации)
                def cos(a,b):
                    na = np.linalg.norm(a)+1e-9; nb = np.linalg.norm(b)+1e-9
                    return float((a@b)/(na*nb))
                div = 0.0
                p_doc = profile(doc)
                for d_sel,_ in out:
                    div = max(div, cos(p_doc, profile(d_sel)))
                mmr_score = lam*sc - (1-lam)*div
                out.append((doc, mmr_score))
                out = sorted(out, key=lambda kv: kv[1], reverse=True)
                out = out[:topn]
            # восстановим оригинальные fusion-скоры на выходе
            base = dict(ranking)
            return [(d, base[d]) for d,_ in out]

        def _limit_per_doc(self, ranking, max_per_doc=2):
            taken = {}; out=[]
            for doc, sc in ranking:
                if taken.get(doc, 0) < max_per_doc:
                    out.append((doc, sc))
                    taken[doc] = taken.get(doc, 0) + 1
            return out

*Примечания.* 1) Для настоящего MMR лучше использовать настоящие документные векторы (например, `text_vector`) — здесь приведён «легковесный» суррогат через профили каналов ради простоты. 2) Веса отрицательными не делайте (штрафы — в FormulaQuery).

#### 6) Тюнинг весов и динамическая переоценка

- **Старт по умолчанию:** `text=0.5`, `image=0.3`, `ocr=0.2`.
- **Динамические правила:**
  - Если в запросе есть картинка → увеличьте `w_image` до 0.45–0.6.
  - Если в тексте встречаются «редкие токены» (regexp: `[A-Z_0-9]{4,}`) → поднимите `w_ocr`.
  - Если `ocr.conf` у кандидата низкий → зануляйте вклад OCR для этого кандидата.
- **Обучение весов:** на малом валид-наборе обучите логистическую регрессию/линейную комбинацию по метрике nDCG@10.

#### Чек-лист готовности

- Сырые выдачи получаем по каждому каналу с собственными `k_each`/`ef_search`/`filter`.
- Склеиваем через нормализацию внутри канала и веса, отсутствующие кандидаты корректно заполняются минимумом.
- Пост-обработка: MMR + `max_per_doc`, стабильная сортировка и ограничение `limit` реализованы.
- Трейс возвращает вклад каналов, параметры и финальный топ — пригодно для дебага и оффлайн-оценки.
