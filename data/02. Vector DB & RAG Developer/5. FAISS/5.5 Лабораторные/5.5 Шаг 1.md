## Задача 1. Косинус через IP: доказать эквивалентность и проверить корректность выдачи

### Цель

Показать, что поиск по **косинусной близости** в FAISS корректно реализуется как **поиск по Inner Product** на **L2-нормализованных** векторах, и что результаты совпадают с «ручным» вычислением косинуса.

### Окружение и данные

- Библиотеки: `numpy`, `faiss` (CPU).

- Сгенерируйте синтетические данные:

  - База: `xb` размером `N × d`, где `N ≥ 5000`, `d = 128`, `dtype=float32`, C-contiguous.

  - Запросы: `xq` размером `Q × d`, где `Q ≈ 7–16`, `dtype=float32`, C-contiguous.

- Фиксируйте `np.random.seed(...)` для воспроизводимости.

### Что нужно сделать

1. Реализовать функцию:

  - `l2_normalize(a: np.ndarray) -> np.ndarray`  
Нормирует строки `a` по L2-норме, защищаясь от деления на ноль (эпсилон `1e-12`). Возвращает `float32`, C-contiguous.

2. Получить нормализованные массивы:

  - `xbn = l2_normalize(xb)`, `xqn = l2_normalize(xq)`.

3. Построить индекс FAISS:

  - `IndexFlatIP(d)`; добавить `xbn`; выполнить `search(xqn, k)` для `k=10`.

4. «Ручной» контроль:

  - Для первых **двух** запросов вычислить матрицу косинусов **без FAISS** как `xqn[:2] @ xbn.T`.  
В нормализованном пространстве это и есть косинусная близость.

  - Получить `top-K` индексы «вручную» и сравнить с индексами из FAISS.

5. Проверить монотонность:

  - Для каждой строки `D` из FAISS значения должны **не возрастать** (IP: больше — лучше).

6. Отчёт:

  - Кратко опишите, почему IP на нормализованных векторах эквивалентен косинусу (формула `||x−y||² = 2(1−cosθ)` → максимум IP ⇔ максимум cos).

  - Выведите сводку: формы `D,I`, совпадение top-K на 2 запросах, пример одной строки `D`.

### Критерии зачёта

- `l2_normalize` корректно обрабатывает нулевые нормы (эпсилон).

- `D.shape == (Q, k)` и `I.shape == (Q, k)`.

- Внутри каждой строки `D` выполняется `D[:, j] ≥ D[:, j+1] − 1e−6`.

- `top-K` индексы FAISS полностью совпадают с «ручным» top-K для **первых двух** запросов.

- Код работает за разумное время на CPU (секунды, а не минуты).

### Подсказки

- Убедитесь, что все массивы `float32` и C-contiguous: `np.ascontiguousarray(...)`.

- Для сравнения top-K используйте `np.argsort(-C, axis=1)[:, :k]`.

- Если вдруг попадётся нулевой вектор (маловероятно при `rand`), нормализация с эпсилоном защитит от NaN.
