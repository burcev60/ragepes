## Установка FAISS, типы данных и быстрый стенд

### Цель шага

- Установить FAISS (CPU или GPU) и убедиться, что модуль импортируется.
- Подготовить «рабочий» датасет эмбеддингов `xb ∈ ℝ^{N×d}` и запросов `xq ∈ ℝ^{Q×d}`.
- Проверить ключевые требования FAISS: **float32** и **C-contiguous** память.
- Зафиксировать воспроизводимость (seed) и оценить память.


На выходе: папка `data/` с файлами `xb.npy` и `xq.npy`, готовыми для следующих шагов.

### 1) Установка

#### Вариант A — CPU

    pip install --upgrade pip
    pip install faiss-cpu numpy

#### Вариант B — GPU (если есть CUDA)

    pip install --upgrade pip
    pip install faiss-gpu numpy

*Замечания:*

- Для `faiss-gpu` нужна совместимая CUDA. Если wheel недоступен, попробуйте conda:

    conda install -c conda-forge faiss-gpu cudatoolkit

- На Windows часто проще начать с `faiss-cpu` и вернуться к GPU позже.
- В WSL проверьте, что `pip` и `python` из одного окружения.


### 2) Быстрый sanity-check окружения

Сохраните как `check_env.py` и запустите `python check_env.py`:

    # check_env.py
    import sys, platform

    def line(k, v): print(f"{k:<20}: {v}")

    line("Python", sys.version.split()[0])
    line("Executable", sys.executable)
    line("Platform", platform.platform())

    try:
        import numpy as np
        import faiss

        line("numpy", np.__version__)
        line("faiss", getattr(faiss, "__version__", "unknown"))

        has_gpu = hasattr(faiss, "get_num_gpus")
        ngpu = faiss.get_num_gpus() if has_gpu else 0
        line("FAISS GPUs", ngpu)
    except Exception as e:
        print("Import error:", e)
        raise

**Проверьте:** путь Executable указывает на нужный интерпретатор; `FAISS GPUs` > 0 для GPU-сборки.

### 3) Создаём «рабочую» синтетику (xb, xq)

**Требования FAISS:** `np.float32`, `arr.flags['C_CONTIGUOUS'] == True`, одинаковая размерность `d` у базы и запросов.

Сохраните как `make_data.py` и запустите `python make_data.py`:

    # make_data.py
    import os
    import numpy as np

    # --- параметры стенда ---
    N = 100_000   # количество базовых векторов
    Q = 1_000     # количество запросов
    d = 768       # размерность эмбеддинга
    np.random.seed(42)

    # --- генерация ---
    xb = np.random.rand(N, d).astype('float32')   # база
    xq = np.random.rand(Q, d).astype('float32')   # запросы

    # гарантируем C-contiguous (на всякий случай)
    xb = np.ascontiguousarray(xb, dtype=np.float32)
    xq = np.ascontiguousarray(xq, dtype=np.float32)

    # --- базовые проверки ---
    assert xb.dtype == np.float32 and xq.dtype == np.float32, "Use float32"
    assert xb.flags['C_CONTIGUOUS'] and xq.flags['C_CONTIGUOUS'], "Use C-contiguous arrays"
    assert xb.shape[1] == d and xq.shape[1] == d, "d must match"

    # --- оценка памяти ---
    def human_bytes(b):
        for u in ["B","KB","MB","GB","TB"]:
            if b < 1024: return f"{b:.2f} {u}"
            b /= 1024
        return f"{b:.2f} PB"

    xb_bytes = xb.nbytes
    xq_bytes = xq.nbytes
    print(f"xb: {xb.shape}, {human_bytes(xb_bytes)}")
    print(f"xq: {xq.shape}, {human_bytes(xq_bytes)}")

    # --- сохранение ---
    os.makedirs("data", exist_ok=True)
    np.save("data/xb.npy", xb)
    np.save("data/xq.npy", xq)
    print("Saved to data/xb.npy and data/xq.npy")

*Ожидаемый вывод (порядок величин):* `xb: (100000, 768), ~293 MB`, `xq: (1000, 768), ~3 MB`.

**Почему float32?** FAISS ожидает float32; float64 даёт ошибки/лишние копирования и расход памяти.  
**Почему C-contiguous?** последовательно-размещённые строки быстрее в низкоуровневых вычислениях FAISS/BLAS.

### 4) Мини-проверка поиска (smoke-test)

Сохраните как `smoke_test.py` и запустите `python smoke_test.py`:

    # smoke_test.py
    import numpy as np, faiss

    xb = np.load("data/xb.npy")
    xq = np.load("data/xq.npy")

    d = xb.shape[1]
    k = 10

    index = faiss.IndexFlatL2(d)   # точный поиск по L2
    index.add(xb)                  # добавляем базу
    D, I = index.search(xq[:5], k) # ищем для 5 запросов

    print("I[0]:", I[0])
    print("D[0][:3]:", D[0][:3])
    print("OK:", I.shape == (5, k) and D.shape == (5, k))

Ожидаем увидеть индексы соседей и `OK: True`. Если всё так — шаг 1 завершён.

### 5) Частые проблемы и быстрые решения

**Раскрыть чек-лист**

- **ModuleNotFoundError: No module named 'faiss'** — ставили пакет не в то окружение. Проверить: `python -c "import sys; print(sys.executable)"`, затем `python -m pip install faiss-cpu`.
- **ImportError для faiss-gpu** — вероятно, несовместимая CUDA/драйвер. Временно используйте `faiss-cpu` или установите через conda.
- **TypeError: array must be float32** — приводите к `np.float32` и делайте `np.ascontiguousarray(...)`.
- **Несоответствие размерностей** — проверьте `xb.shape[1] == xq.shape[1]` и общее `d`.
- **VSCode/WSL видит не то окружение** — выберите интерпретатор WSL (Command Palette → Python: Select Interpreter). Убедитесь, что `pip` и `python` из одного окружения.

Далее, в шаге 2, на этих данных развернём точный поиск (`IndexFlatL2/IP`) и косинус через нормализацию.
