**Ускорение с помощью GPU.** 

Одно из сильных преимуществ FAISS – поддержка GPU. Библиотека может использовать CUDA для ускорения операций поиска и построения индекса. Есть два варианта: GPU-специфичные классы (например, `faiss.GpuIndexFlat`), либо более общий – сконвертировать существующий CPU-индекс на GPU с помощью функции-обёртки. Второй вариант гибче. Покажем на примере:

    res = faiss.StandardGpuResources()  # выделяем ресурсы GPU
    index_cpu = faiss.IndexFlatL2(d)
    index_cpu.add(xb)
    # Переносим на GPU (на устройство 0)
    index_gpu = faiss.index_cpu_to_gpu(res, 0, index_cpu)
    D, I = index_gpu.search(x_query, k)

Функция `index_cpu_to_gpu` берет готовый индекс (тут Flat с данными) и загружает его на указанный девайс (GPU 0). Возвращается объект `GpuIndexFlat` (подкласс Index). Теперь все операции поиска выполняются на видеокарте, что при больших массивах даёт ускорение в разы за счёт параллельности. Аналогично можно создать и GPU-вариант IVF:

    quantizer = faiss.IndexFlatL2(d)
    index_ivf = faiss.IndexIVFFlat(quantizer, d, nlist, faiss.METRIC_L2)
    index_ivf.train(xb)
    index_ivf.add(xb)
    index_ivf.nprobe = 10
    index_gpu2 = faiss.index_cpu_to_gpu(res, 0, index_ivf)
    D, I = index_gpu2.search(x_query, k)

FAISS также предоставляет классы `faiss.GpuIndexIVFPQ` и т.п., с которыми можно работать напрямую, но чаще путь CPU→GPU удобнее: можно отлаживать на CPU, а потом перенести на GPU. Кроме того, `index_cpu_to_gpu` позволяет легко выгрузить индекс обратно: `faiss.index_gpu_to_cpu(index_gpu)`. Это важно: GPU-память ограничена, и иногда индекс может не поместиться туда полностью – можно, скажем, загрузить кусками, искать на GPU (например, шард на GPU, шард на CPU).

 

С GPU можно достичь впечатляющих результатов: векторный поиск, занимавший 100 ms на CPU, может выполняться за 5-10 ms на хорошей видеокарте. Особенно ускоряется **точный поиск (Flat)**, т.к. GPU отлично параллелит вычисление расстояний, и **PQ-декомпрессия**, т.к. можно распараллелить дешифровку кодов. При этом добавление данных и построение индекса (train) тоже могут быть ускорены. Стоит отметить: если данных **очень много**, они могут не влезть в память GPU – тогда GPU-ускорение можно применять лишь частично (например, держать только часть баз векторов на GPU как кеш наиболее частых, или использовать несколько GPU). FAISS поддерживает и **множественные GPU**: можно либо распределить данные по ним (шардинг), либо дублировать индекс на всех и параллельно обрабатывать запросы (для throughput). Настраивается через `gpu_index = faiss.index_cpu_to_all_gpus(index_cpu)` – распределит индекс по всем доступным GPU. Либо можно вручную указывать, на какой GPU что грузить.
