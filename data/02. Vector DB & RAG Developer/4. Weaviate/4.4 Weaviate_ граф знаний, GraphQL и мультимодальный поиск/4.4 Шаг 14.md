### Задание 2. «Сложный GraphQL-маршрут»

**Цель** — освоить навигацию по графу и фильтры.

Используя коллекцию из задания 1:

1. Сформируйте запрос «Найти статьи, **близкие по смыслу** к фразе  
*“vector database scalability”*, написанные авторами из **Canada**, и вернуть `title`, `year`, `author { name }`, `_additional { score }` (k = 5).

2. Запрос должен применять **два** оператора одновременно:

  - `nearText` (семантика)

  - `where` (фильтр по стране через reference-путь `writtenBy.country`)

3. Покажите JSON-ответ с минимум двумя найденными статьями.

**Сдаём**

- Тело GraphQL-запроса

- Мини-скриншот Query-Result (или скопированный JSON).
