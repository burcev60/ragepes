**Гибридный поиск (ключевые слова + векторы).** 

Одна из впечатляющих возможностей Weaviate – **гибридный поиск**, сочетающий классический поиск по словам с семантическим поиском по эмбеддингам. Представьте ситуацию: пользователь вводит запрос "deep learning", и вы хотите найти статьи, где есть эти слова (или близкие по смыслу), но ранжировать с учётом семантики. В обычном полнотекстовом поиске вы получили бы все статьи, где встречается "deep" и "learning". В чисто векторном поиске – статьи по смыслу про глубокое обучение, которые могут даже не содержать этих слов явно. Гибридный подход объединяет два сигнала.

 

В Weaviate для этого есть специальный оператор **`hybrid`** в GraphQL-запросе. Его можно использовать, если включён модуль BM25 (он обычно включается автоматически для текстовых данных – называется `text2vec-contextionary` или с версии 1.14 встроен в текстовые модули). Пример запроса:

    {
      Get {
        Article(hybrid: { query: "deep learning", alpha: 0.5 }) {
          title
          content
          _additional {
            score
          }
        }
      }
    }

Здесь мы задаём `hybrid` с параметрами: `query` – строка запроса, и `alpha` – коэффициент баланса (от 0 до 1). `alpha=0.5` означает, что релевантность будет наполовину зависеть от текстового совпадения, наполовину от сходства эмбеддингов. Weaviate выполнит одновременно поиск по BM25 (ключевым словам) и поиск по вектору (используя встроенный векторизатор для "deep learning"), а затем слеет результаты. Объекты, высоко оценённые обоими методами, окажутся в топе (пример алгоритма – Reciprocal Rank Fusion).

 

При `alpha` ближе к 1 результат больше полагается на традиционный поиск, ближе к 0 – на семантический. Так можно «подмешивать» семантику в классический поиск. Эта функция особенно полезна, когда у вас данные, где важны и точные совпадения (например, юридические термины, даты), и общее сходство темы. Гибридный поиск избавляет от необходимости самим объединять два списка результатов – Weaviate делает это за вас. Помимо `hybrid`, у Weaviate есть также операторы **`nearText`** и **`nearVector`**. Они используются для чисто векторного поиска: `nearText` – если у вас только текстовый запрос (он внутри себя вызывает текстовый векторизатор, преобразуя фразу в эмбеддинг и ищет по нему), а `nearVector` – если вы уже получили где-то эмбеддинг запроса и хотите им искать. Формат: `nearText: { concepts: ["machine learning"] }` или `nearVector: { vector: [0.1, 0.2, ...] }`. Эти операторы можно сочетать с фильтром `where` для ограничения области поиска, но их нельзя напрямую смешивать с BM25 – для этого и существует `hybrid`.
