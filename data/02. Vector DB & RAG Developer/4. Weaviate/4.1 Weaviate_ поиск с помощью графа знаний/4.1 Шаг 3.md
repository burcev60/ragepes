#### Семантический поиск в Weaviate

Для поиска похожих объектов в Weaviate используется специальный GraphQL-оператор, например `NearVector` или `NearText`. Если у вас уже есть вектор запроса, вы можете сделать запрос: `{ Search(class: Article, nearVector: { vector: [0.1,0.2,...], distance: 0.3 }) { title, content } }` – это вернёт статьи, ближайшие к заданному вектору (в пределах distance 0.3), с их полями title и content. Если же вектора нет, но есть текстовый запрос, можно использовать `NearText` при условии, что подключён модуль, умеющий превращать текст запроса в вектор. Например: `{ Search(class: Article, nearText: { concepts: ["machine learning"] }) { title, _additional { score } } }` – Weaviate сам преобразует "machine learning" в эмбеддинг (с помощью выбранного модуля) и найдёт близкие статьи.

Обратите внимание, что в примере запроса мы запрашиваем поле `_additional { score }`. В Weaviate через `_additional` можно получить служебные данные – например, оценку сходства (score), расстояние или даже сам вектор объекта. Это похоже на то, как Qdrant возвращает distance. В GraphQL же мы сами выбираем, что хотим видеть в ответе.

Weaviate поддерживает и фильтры (в GraphQL это параметр `where`). Концептуально фильтрация похожа на Qdrant: можно указать условие на поля объекта, и база будет искать только среди подходящих. Например, `where: { path: ["date"], operator: GreaterThan, valueDate: "2023-01-01" }` – поиск среди статей после 2023 года. Совмещение фильтра с `nearText` позволяет делать очень точечные семантические запросы.
