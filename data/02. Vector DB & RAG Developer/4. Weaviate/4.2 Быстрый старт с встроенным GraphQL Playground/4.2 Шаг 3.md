### Синтаксис GraphQL-запросов в Weaviate
> После того как инстанс запущен и Playground открыт, пора разобраться, **как формулируются запросы**. В этом шаге разберём грамматику GraphQL в контексте Weaviate, основные аргументы `Search`, выбор данных через `_additional` и фильтр `where`.

### 1 Мини-шпаргалка GraphQL

| Элемент | Что это | Пример |
| --- | --- | --- |
| **Query** | Чтение данных | `{ ... }` |
| **Mutation** | Изменение/добавление | `mutation { AddArticle(...) }` |
| **Arguments** | Круглые скобки после поля | `Search(class: Article, limit: 5)` |
| **Selection set** | Фигурные скобки — что вернуть | `{ title, _additional { distance } }` |

 

### 2 Базовый `Search`

Самый частый корневой поле — `Search`. Минимум нужны три аргумента:

    {
      Search(
        class: Article,
        nearText: { concepts: ["machine learning"] }
      ) {
        title
      }
    }

Запрос превращает фразу в эмбеддинг и ищет ближайшие объекты.

### 3 nearText vs nearVector

- **nearText** — дайте текст, Weaviate сам векторизует.

- **nearVector** — дайте готовый массив чисел и (опционно) порог `distance`:

    Search(
      class: Article,
      nearVector: { vector: [0.12, 0.9, …], distance: 0.25 }
    ) { title }

### 4 `_additional` — метаданные ответа

Хотите расстояние, ID или сам вектор? Добавьте подполе `_additional`:

    {
      Search(
        class: Article,
        nearText: { concepts:["machine learning"] }
      ){
        title
        _additional { distance vector }
      }
    }

Поле `_additional` возвращает служебные данные, не влияя на поиск.

### 5 Фильтры `where`

Фильтр в Weaviate выглядит как JSON-дерево:

    where: {
      path: ["date"]
      operator: GreaterThan
      valueDate: "2025-01-15"
    }

Можно комбинировать условия AND/OR, фильтровать по bool, number, text и даже вложенным ссылкам.

### 6 Собираем всё вместе

    {
      Search(
        class: Article
        nearText: { concepts:["deep learning"], certainty: 0.7 }
        where: {
          path:["published"]
          operator:Equal
          valueBoolean:true
        }
        limit: 10
        sort:{ path:["date"], order:desc }
      ){
        title
        date
        _additional { distance }
        hasAuthor {   # cross-reference
          name
        }
      }
    }

*Ищем опубликованные статьи о deep-learning, сортируем по дате, выводим автора и дистанцию.*

### 7 Практика «проверь себя»

1. **Фильтр по диапазону**:  
*Найдите статьи 2024 года с понятием “vector DB” и покажите `title`, `date`, `distance`.*

2. **nearVector + where**:  
*Имея запросный вектор `q`, найдите ближайшие 3 неопубликованные статьи.*

3. **Добавьте `_additional.vector`** и посмотрите, как выглядит эмбеддинг в ответе.
