### Загружаем датасет статей в Weaviate через Python-клиент

*Зачем?* Пустая база не позволяет попрактиковаться. Добавим реальный набор (≈ 100 записей) в класс `Article`.

### 1 Где взять набор статей?

- **Kaggle** — найдите датасет *“Medium Articles Dataset”*, скачайте CSV.
- **arXiv bulk** — JSON-архивы ([arxiv.org](https://arxiv.org/help/bulk_data)) — берём поля `title`, `authors`, `abstract`, `updated`.
- **faker** — сгенерируйте фейковые посты библиотекой [faker](https://faker.readthedocs.io/) (быстро для демо).


### 2 Готовим окружение

    python -m venv .venv
    source .venv/bin/activate     # Windows: .venv\Scripts\activate
    pip install weaviate-client pandas

### 3 Скрипт импорта (`import_articles.py`)

    import pandas as pd
    from weaviate import Client

    WEAVIATE_URL = "http://localhost:8080"
    CSV_PATH     = "articles.csv"          # ваш CSV-файл

    # 1) читаем CSV (title, author, content, date, rating)
    df = pd.read_csv(CSV_PATH).head(100)   # берём 100 строк

    # 2) подключаемся к инстансу
    client = Client(WEAVIATE_URL)

    # 3) создаём класс Article, если его нет
    if not client.schema.contains({ "class": "Article" }):
        client.schema.create_class({
            "class": "Article",
            "vectorizer": "none",          # без авто-векторизации
            "properties": [
                { "name": "title",   "dataType": ["text"] },
                { "name": "author",  "dataType": ["text"] },
                { "name": "content", "dataType": ["text"] },
                { "name": "date",    "dataType": ["date"] },
                { "name": "rating",  "dataType": ["number"] }
            ]
        })

    # 4) батч-импорт (быстрее, чем по одному)
    with client.batch as batch:
        batch.batch_size = 100
        for row in df.itertuples():
            batch.add(
                class_name = "Article",
                data_object = {
                    "title":   row.title,
                    "author":  row.author,
                    "content": row.content,
                    "date":    str(row.date)[:10],   # YYYY-MM-DD
                    "rating":  float(row.rating)
                }
            )
    print("Imported", len(df), "articles")

### 4 Быстрая проверка в Altair

**Сколько статей?**

    {
      Aggregate { Article { meta { count } } }
    }

**Топ-5 по рейтингу:**

    {
      Search(
        class: Article
        sort: { path:["rating"], order: desc }
        limit: 5

        title rating

    }

### Что дальше?

- Нужен семантический поиск — в классе поставьте `"vectorizer":"text2vec-openai"` и передайте ключ `OPENAI_APIKEY` в переменных окружения Weaviate.
- Хотите больше данных — уберите `.head(100)` или загрузите большой CSV.
- Теперь все примеры уроков (`nearText`, `Aggregate`, сортировки) работают на «живой» выборке.
