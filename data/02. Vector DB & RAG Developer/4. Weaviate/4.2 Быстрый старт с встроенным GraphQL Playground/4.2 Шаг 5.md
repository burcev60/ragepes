### Фильтры `where`: уточняем поиск по свойствам

**Цель шага:** научиться ограничивать выдачу по числам, датам, строкам, булевым и гео-координатам, а также комбинировать условия с помощью *AND*/*OR*. После шага вы сможете писать точные запросы вида «найти все опубликованные статьи 2024 года о vector DB с рейтингом > 4.5».

### 1 Общая схема фильтра

    where: {
      path: ["path", "to", "property"]   # массив сегментов
      operator: Equal | GreaterThan | Like | ...   # см. таблицу ниже
      value: ...                  # где  = Text, Number, Date, Boolean, GeoRange
    }

- **path** — к какому полю применяем условие (поддерживает вложенные reference-ссылки).
- **operator** — какой тип сравнения использовать.
- **value** — значение для сравнения. Суффикс `<Type>` обязан соответствовать типу свойства.


### 2 Справочник операторов

| Оператор | Применяется к | Пример |
| --- | --- | --- |
| `Equal` | любые типы | `valueText:"Qdrant"` |
| `NotEqual` | любые | `valueBoolean:false` |
| `GreaterThan / LessThan` | числа, даты | `valueNumber:4.5` |
| `GreaterThanEqual / LessThanEqual` | числа, даты | – |
| `Like` | строки (поддержка ***) | `valueText:"*vector*"` |
| `WithinGeoRange` | гео-точки | см. 4.5 |
| `ContainsAny / ContainsAll` | массивы | `valueText:["Weaviate","Qdrant"]` |

### 3 Базовые примеры

#### 3.1 Фильтр по дате

    {
      Search(
        class: Article
        nearText: { concepts:["vector database"] }
        where: {
          path:["date"]
          operator: GreaterThan
          valueDate:"2024-12-31"
        }
        limit:10
      ){
        title date
      }
    }

#### 3.2 Комбинированный фильтр AND

Weaviate не использует явное «AND». Вместо этого применяется `operator: And`, а все условия помещаются в `operands` — массив подфильтров:

    where:{
      operator: And
      operands:[
        {
          path:["published"]
          operator:Equal
          valueBoolean:true
        },
        {
          path:["rating"]
          operator:GreaterThanEqual
          valueNumber:4.5
        }
      ]
    }

#### 3.3 Список OR-условий

    where:{
      operator: Or
      operands:[
        {
          path:["category"]
          operator:Equal
          valueText:"tutorial"
        },
        {
          path:["category"]
          operator:Equal
          valueText:"guide"
        }
      ]
    }

### 4 Глубокие пути (cross-reference)

Если поле является ссылкой на другой класс, просто добавьте его имя в `path`:

    where:{
      path:["hasAuthor", "experienceYears"]
      operator:GreaterThan
      valueNumber:5
    }

Такой запрос находит статьи, у которых автор имеет опыт > 5 лет.

### 5 Геопространственный фильтр

    where:{
      path:["location"]
      operator:WithinGeoRange
      valueGeoRange:{
        geoCoordinates:{ latitude: -33.87, longitude: 151.21 }   # Sydney
        distance:{ max: 5000 }    # метров
      }
    }

Полезно для приложений «найди ближайший магазин» или «покажи объекты в радиусе 5 км».

### 6 Полезные советы

- **Индексация:** чтобы `where` работал быстро, свойство должно быть включено в inverted-индекс (по умолчанию *true*).
- **Фильтр + векторный поиск:** `nearText/nearVector` выполняется *после* применения `where`, что снижает объём k-NN-поиска.
- **Недостаточно результатов?** Увеличьте `limit` или ослабьте условие (`certainty` ↓ / `distance` ↑).


### 7 Практика

1. **Задача «Vector DB 2024».**  
Найдите первые 7 статей о “vector DB” (nearText), опубликованных в 2024 году и с рейтингом не ниже 4.0. Выведите `title`, `date`, `rating`.

2. **Задача «Опытный автор».**  
С помощью cross-reference фильтра найдите статьи, у которых автор имеет *опыт > 10 лет* ИЛИ *количество публикаций > 30*. Ограничьте вывод 5 объектами.

3. **Задача «Ближайший офис».**  
В коллекции `Office` найдите все офисы в 50 км от координат (48.85, 2.35) — центр Парижа. Отсортируйте по расстоянию (подсказка: используйте `_additional { distance }`).

**Итог:** теперь вы умеете строить сложные фильтры `where` и комбинировать их с семантическим поиском. В следующем шаге мы разберём поле `_additional`: как вытягивать *distance*, *score*, *id*, а при необходимости даже весь вектор или объяснение *scoreExplanation*.
