### Поиск и RAG-запросы: vector → hybrid → generative

### 1. Семантический (vector) поиск

Базовая «near text»-запрос в Weaviate ищет по косинусной близости между векторами объекта и запроса:

    from weaviate.classes.query import NearText

    with weaviate.connect_to_local() as client:
        article = client.collections.get("Article")

        resp = article.query.near_text(
            query="large language models",
            limit=3,
            return_metadata=True        # вернём оценки score
        )

        for o in resp.objects:
            print(f"{o.properties['title']} → score={o.metadata.score:.3f}")

Вы получите три статьи, наиболее близкие по смыслу к запросу, отсортированные по *score* (чем больше, тем лучше).

### 2. Hybrid search ≈ BM25 + vector

Чисто векторный поиск может «промахиваться» по редким словам. Гибридный запрос комбинирует выдачи BM25 и проекцию вектора, смешивая их с весом `alpha` (0 → чистый BM25, 1 → только вектор). Пример из официальной документации: :contentReference[oaicite:0]{index=0}

    from weaviate.classes.query import MetadataQuery

    with weaviate.connect_to_local() as client:
        article = client.collections.get("Article")

        resp = article.query.hybrid(
            query="reinforcement learning",
            alpha=0.4,                 # баланс BM25 / vector
            limit=5,
            return_metadata=MetadataQuery(score=True, explain_score=True)
        )

        for o in resp.objects:
            print(f"{o.properties['title']} → {o.metadata.score:.3f}")
            print("Why:", o.metadata.explain_score[:120], "…\n")

**Что происходит?** Weaviate выполняет два поиска (по индексу HNSW и по инвертированному словарю), нормализует оценки, затем суммирует их с коэффициентом `alpha`.

### 3. Retrieval-Augmented Generation (RAG) в одном запросе

С модулем `generative-openai` Weaviate умеет автоматически допрашивать LLM после retrieval: достаточно добавить `.with_generate()`. Вот «single prompt»-пример из гайда Academy :contentReference[oaicite:1]{index=1}, адаптированный для нашей коллекции `Article`:

    import json

    with weaviate.connect_to_local() as client:
        response = (
            client.query
            .get("Article", ["title", "content"])
            .with_hybrid(query="vector databases in production", limit=3)
            .with_generate(
                single_prompt=(
                    "Сделай краткое резюме (2 предложения) статьи под названием {title} "
                    "и выдели главное практическое применение."
                )
            )
            .do()
        )

    print(json.dumps(response, indent=2, ensure_ascii=False)[:1200], "…")

- *single prompt* — отдельный ответ для каждого объекта;
- *grouped task* (параметр `grouped_task=…`) выдаст один общий вывод по всему набору.


Убедитесь, что в `docker-compose.yml` включён `ENABLE_MODULES=text2vec-openai,generative-openai` и задан `OPENAI_API_KEY`.
