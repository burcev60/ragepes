### Мониторинг и алерты: Prometheus + Grafana для Weaviate

### 1. Почему это важно

- **SLO = p95 latency < 100 мс, error rate < 1 %** — без метрик
 нельзя понимать, когда сервис «проседает».
- Weaviate (v1.20+) экспортирует `/v1/metrics` в формате Prometheus —
 остаётся собрать и визуализировать.
- ⚡ «Бесплатно» получаем p99 latency, Go-GC, usage RAM,
 загрузку HNSW шардов и т.д.


### 2. Обновляем `docker-compose.yml`

    version: "3.4"
    services:
      weaviate:
        image: cr.weaviate.io/semitechnologies/weaviate:1.32.0
        ports:
          - "8080:8080"   # REST + GraphQL
          - "50051:50051" # gRPC
          - "2112:2112"   # 📈 Prometheus metrics
        environment:
          - ENABLE_MODULES=text2vec-openai,generative-openai,backup-s3
          - PROMETHEUS_MONITORING_ENABLED=true
          - PROMETHEUS_MONITORING_PATH=/v1/metrics

      prometheus:
        image: prom/prometheus:v2.53.0
        volumes:
          - ./prometheus.yml:/etc/prometheus/prometheus.yml
        command:
          - --config.file=/etc/prometheus/prometheus.yml
        ports:
          - "9090:9090"

      grafana:
        image: grafana/grafana:11.0.0
        ports:
          - "3000:3000"
        environment:
          - GF_SECURITY_ADMIN_PASSWORD=admin

**Пояснения**

- `2112` — дефолтный порт, изменяемый переменной `PROMETHEUS_MONITORING_PORT`, если нужно.
- Параметр `PROMETHEUS_MONITORING_ENABLED=true` активирует встроенный экспозёр.


### 3. Конфиг `prometheus.yml`

    global:
      scrape_interval: 15s
      evaluation_interval: 30s

    scrape_configs:
    - job_name: "weaviate"
      static_configs:
        - targets: ["weaviate:2112"]

Файл лежит рядом с `docker-compose.yml`.
Перезапустите стэк:

    docker compose down && docker compose up -d

### 4. Проверяем

1. Откройте [localhost:9090](http://localhost:9090/) → *Graph* и запросите метрику `weaviate_api_request_duration_seconds_count`.
2. Сделайте пару запросов к Weaviate (Altair или Python-SDK),
 граф мгновенно «дернется» вверх.


### 5. Готовый дашборд Grafana

1. Зайдите на [localhost:3000](http://localhost:3000/),
 логин/пароль по умолчанию — `admin/admin`.
2. *Settings → Data Sources* → добавьте Prometheus
 (`http://prometheus:9090`).
3. *Dashboards → Import* → вставьте ID `18664` («Weaviate Production Metrics»),
 нажмите *Load*.


На дашборде уже настроены:

- p50/p95/p99 latency (REST & GraphQL);
- CPU, RSS, Go GC pauses;
- HNSW query ops/s, failures;
- GPU util (если включён `text2vec-transformers` с CUDA).


### 6. Алерты (пример)

Добавим правило: «p95 latency > 250 мс 5 минут подряд».

    groups:
    - name: weaviate_alerts
      rules:
      - alert: HighLatencyP95
        expr: histogram_quantile(
                0.95,
                sum by(le) (rate(weaviate_api_request_duration_seconds_bucket[5m]))
              ) > 0.25
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Weaviate p95 latency high"
          description: "p95 > 250 ms for 5 minutes"

Сохраните как `alerts.yml`, добавьте к `prometheus.yml` секцию `alerting`,
перезапустите Prometheus.

### 7. Мини-задания

1. **Сломайте** Weaviate (поставьте `efSearch=512` и отправьте 100 конкурентных запросов) — убедитесь, что алерт сработал.
2. Добавьте правило «error rate > 1 % за 5 мин»
 на основе метрики `weaviate_api_request_total{status!~"2.."}`.
3. Экспортируйте дашборд Grafana в JSON, приложите к репозиторию курса.
