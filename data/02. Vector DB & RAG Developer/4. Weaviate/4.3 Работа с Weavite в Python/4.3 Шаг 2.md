### Создаём схему и заливаем первый батч объектов

### 1. Зачем нужна схема?

В Weaviate каждая коллекция («класс») описывается схемой: поля, типы данных,
используемый векторизатор, параметры HNSW и т. д. Без явного описания Weaviate не
знает, как строить векторы и хранить объекты.

- **Vectorizer** — модуль, который превращает текст/картинку в вектор.
 Здесь мы выберем `text2vec-openai` (GPT-базовый эмбеддер).
- **Properties** — аналог колонок в БД: задаём имя, тип данных,
 токенизацию (для текста) и необязательные описания.
- **Indexes** (HNSW) настраиваются автоматически, но ключевые
 параметры можно переопределять (`efConstruction`, `maxConnections`).


### 2. Определяем коллекцию `Article`

    import weaviate
    from weaviate.classes.init import DataType, Property, Vectorizer

    with weaviate.connect_to_local() as client:
        # если коллекция уже была — удаляем для чистоты примера
        if "Article" in client.collections.list_all():
            client.collections.delete("Article")

        client.collections.create(
            name="Article",
            properties=[
                Property(
                    name="title",
                    data_type=DataType.TEXT,
                    description="Заголовок статьи",
                    tokenization="word"
                ),
                Property(
                    name="content",
                    data_type=DataType.TEXT,
                    description="Полный текст"
                ),
                Property(
                    name="tags",
                    data_type=DataType.TEXT_ARRAY,
                    description="Тематики/теги"
                )
            ],
            vectorizer_config=Vectorizer.text2vec_openai()  # встроенный эмбеддер
        )

        # Проверяем, что коллекция появилась
        print(client.collections.list_all())  # ['Article']

*Что делает код выше?*

1. При первом запуске клиент проверяет, есть ли коллекция с таким именем,
 чтобы избежать конфликта.
2. `Vectorizer.text2vec_openai()` указывает Weaviate автоматически
 вызывать OpenAI Embedding API для полей типа `TEXT`.
3. Если вы используете собственный ключ OpenAI, задайте его в переменной
 окружения `OPENAI_API_KEY` — Weaviate подхватит.

### 4. Батч-импорт: быстро и с автоповторами

    import csv, uuid, time
    from tqdm import tqdm

    with weaviate.connect_to_local() as client:
        article_col = client.collections.get("Article")

        t0 = time.perf_counter()
        with client.batch(
            batch_size=100,     # 100 объектов за раз
            dynamic=True        # SDK сам подбирает размер при ошибках
        ) as batch:
            with open("articles_1k.csv", newline="", encoding="utf-8") as f:
                reader = csv.DictReader(f)
                for row in tqdm(reader, total=1000):
                    properties = {
                        "title": row["title"],
                        "content": row["content"],
                        "tags":   row["tags"].split(";")
                    }
                    # UUID генерируем сами, можно и не указывать
                    batch.add_object(
                        uuid.uuid4(),
                        properties=properties,
                        collection="Article"
                    )
        print(f"Imported 1000 objects in {time.perf_counter() - t0:.1f}s")

SDK параллелит запросы и по умолчанию делает до 3 повторов при сетевых
ошибках — поэтому импорт должен уложиться < 10 с даже на ноутбуке.
