### Установка Python-клиента и подключение к локальной базе

### 1. Что вам понадобится

- **Python ≥ 3.9**  
Проверьте:

    python --version

- **Docker + Docker Compose** — Weaviate запустим в контейнере.
 Установите по официальной инструкции, если ещё не стоит.


### 2. Поднимаем Weaviate локально (1–2 мин)

Создайте файл `docker-compose.yml` в рабочей папке и вставьте конфигурацию
 минимального кластера:

    version: "3.4"
    services:
      weaviate:
        image: cr.weaviate.io/semitechnologies/weaviate:1.32.0
        ports:
          - "8080:8080"   # REST + GraphQL
          - "50051:50051" # gRPC
        environment:
          - QUERY_DEFAULTS_LIMIT=25
          - AUTHENTICATION_ANONYMOUS_ACCESS_ENABLED=true
          - PERSISTENCE_DATA_PATH=/var/lib/weaviate
          - DEFAULT_VECTORIZER_MODULE=text2vec-openai
          - ENABLE_MODULES=text2vec-openai
        volumes:
          - ./weaviate_data:/var/lib/weaviate

Запустите:

    docker compose up -d

Через пару секунд база станет доступна на `http://localhost:8080`.

### 3. Ставим Python-клиент

    pip install -U "weaviate-client[agents]"

*Почему `[agents]`?* С этим «extra» пакет сразу включает встроенный RAG-агент
и дополнительные хелперы. Клиент v4 поддерживает Weaviate ≥ 1.23.7 и
обновляется каждые несколько недель в PyPI.

### 4. Первое подключение: 6 строк кода

    import weaviate

    # подключаемся к локальному инстансу
    with weaviate.connect_to_local() as client:
        ready = client.is_ready()     # health-check
        version = client.get_meta().version
        print(f"Weaviate {version} ready: {ready}")

        # пока коллекций нет — выведет []
        print("Collections:", client.collections.list_all())

Если всё настроено правильно, в терминале появится:

    Weaviate 1.32.0 ready: True
    Collections: []

**Важно.** Начиная с v4.4 клиент следует закрывать вручную или через
контекст-менеджер, иначе соединение «висит» и блокирует контейнер при
остановке.

### 5. Что делать, если не взлетело

| Симптом | Возможная причина | Быстрое решение |
| --- | --- | --- |
| `ConnectionError: Failed to establish a new connection` | Контейнер ещё не прогрелся или порт занят | `docker compose logs -f` — ждём «HTTP server started» |
| `Unsupported version` | Установлен устаревший weaviate-client v3.* | `pip install -U weaviate-client` |
| `Unauthorized` | Отключён анонимный доступ | Добавьте `WEAVIATE_APIKEY` в переменные окружения и  подключайтесь так: `weaviate.connect_to_local(api_key="...")` |

### 6. Мини-задание

1. Измените переменную окружения `QUERY_DEFAULTS_LIMIT` в `docker-compose.yml` с 25 → 10,
 перезапустите контейнер и убедитесь, что параметр применился:

    meta = client.get_meta()
    print(meta.config.query_defaults_limit)  # должно вывести 10

2. Подсказка: после изменения окружения выполните  
`docker compose down && docker compose up -d`.
