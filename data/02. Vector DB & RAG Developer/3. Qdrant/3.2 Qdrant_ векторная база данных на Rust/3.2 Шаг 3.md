#### Создание коллекции и добавление эмбеддингов

Перед тем как сохранять эмбеддинги, нужно определить, как они будут организованы в Qdrant. В этой базе данные хранятся в **коллекциях**. Коллекция – по сути аналог таблицы в реляционных БД, но специализированная под векторы. При создании коллекции мы задаём размерность вектора (число измерений эмбеддинга) и тип меры близости (метрику). Qdrant поддерживает косинусное расстояние, евклидово (L2) и скалярное произведение (dot product). Выбор метрики зависит от того, как получены эмбеддинги. Например, для большинства нормализованных эмбеддингов косинусное сходство – хороший выбор.

Создать коллекцию можно через метод клиента, например: `client.recreate_collection("articles", vectors_config=...`). Можно указать имя коллекции, размерность (например, 768) и метрику. После этого коллекция готова принимать данные. Добавление эмбеддингов выполняется методом `client.upload_records` или `client.upsert`, куда передаётся список векторов и, опционально, связанные payload (метаданные) и идентификаторы. Каждый вектор может иметь свой ID (если не указать, Qdrant сгенерирует ID автоматически).

Пример: пусть у нас есть эмбеддинги статей и для каждой статья мы знаем её категорию. Можно загрузить их так: `client.upsert(collection_name="articles", points=[{"id": 1, "vector": [0.1, 0.2, ...], "payload": {"cat": "tech"}}, ...])`. Этот вызов отправит сразу несколько векторов (batch upload). Qdrant сохранит их, построит необходимые структуры для поиска и будет готов к запросам.
