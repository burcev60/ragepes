#### Развёртывание и подключение Qdrant

Чтобы начать пользоваться Qdrant, нужно запустить сам сервис базы данных. Сделать это можно разными способами: запустить Docker-контейнер, установить через пакетный менеджер (если поддерживается), либо воспользоваться Qdrant Cloud (готовый управляемый сервис в облаке). Для учебных целей часто используют Docker. Предположим, вы запускаете локально: после установки Qdrant будет доступен на определённом порту (например, 6333 по умолчанию для REST API).

Далее, для взаимодействия с базой удобно воспользоваться Python-клиентом. Устанавливаем пакет `qdrant-client` (`pip install qdrant-client`). Затем в коде можно подключиться к базе:

*Пример:* `from qdrant_client import QdrantClient`. Создаём объект клиента: `client = QdrantClient(url="http://localhost:6333")` (если Qdrant запущен локально). Если база в облаке, вместо URL и порта можно указать `QdrantClient(api_key="API-ключ", cloud_url="...")` – подробности зависят от сервиса.

Клиент предоставляет методы для всех основных операций: создания коллекций, добавления векторов, поиска, управления индексами и др. С его помощью мы будем выполнять все упражнения, связанные с Qdrant, чтобы не работать с сырыми HTTP-запросами вручную.
