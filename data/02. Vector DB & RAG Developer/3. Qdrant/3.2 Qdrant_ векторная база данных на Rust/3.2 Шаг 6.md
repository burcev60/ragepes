### Начало работы с Qdrant

*В этом шаге мы перейдём к первому семантическому запросу в Qdrant. Все команды после копирования выполняются как есть.*

#### 1 | Запускаем сервер Qdrant (Docker)

    docker pull qdrant/qdrant
    docker run -d --name qdrant -p 6333:6333 qdrant/qdrant
    # через пару секунд база слушает http://localhost:6333

Контейнер весит < 200 МБ и не требует отдельной настройки — внутри уже включён HNSW-индекс «из коробки».

#### 2 | Готовим окружение Python

    pip install -q qdrant-client sentence-transformers

Библиотека `qdrant-client` работает поверх REST-API, но прячет все детали HTTP-запросов.

#### 3 | Создаём коллекцию под текстовые эмбеддинги

    from qdrant_client import QdrantClient
    from qdrant_client.http import models as rest

    client = QdrantClient(url="http://localhost:6333")

    # Создаём коллекцию, если её нет (384 = длина эмбеддинга all-MiniLM-L6-v2)
    client.recreate_collection(
        collection_name="articles",
        vectors_config=rest.VectorParams(size=384, distance=rest.Distance.COSINE)
    )

Параметр `size` должен совпадать с длиной вектора, иначе вставка точек завершится ошибкой.

#### 4 | Готовим примерные данные

    from sentence_transformers import SentenceTransformer
    import numpy as np

    sentences = [
        "Кот играет на ковре",      # id = 0
        "Собака тихо спит",         # id = 1
        "Автомобиль быстро едет"    # id = 2
    ]
    model = SentenceTransformer("all-MiniLM-L6-v2")

    vectors = model.encode(sentences, normalize_embeddings=True)

#### 5 | Загружаем точки с полезной нагрузкой (payload)

    payloads = [
        {"tag": "animals"},
        {"tag": "animals"},
        {"tag": "vehicles"}
    ]

    client.upsert(
        collection_name="articles",
        points=[
            rest.PointStruct(id=i, vector=v.tolist(), payload=payloads[i])
            for i, v in enumerate(vectors)
        ]
    )

Каждая точка = `id` + `vector` + `payload`. Поля из payload можно использовать в фильтрах.

#### 6 | Делаем первый векторный поиск

    query_vec = model.encode(
        "играющий котёнок", normalize_embeddings=True
    )

    hits = client.search(
        collection_name="articles",
        query_vector=query_vec.tolist(),
        limit=2
    )

    for hit in hits:
        print(f"score={hit.score:.3f}  →  {sentences[hit.id]}")

Вывод покажет, что фраза про кота имеет наибольший счёт.

#### 7 | Поиск + фильтр по метаданным

    hits_animals = client.search(
        collection_name="articles",
        query_vector=query_vec.tolist(),
        limit=2,
        query_filter=rest.Filter(
            must=[rest.FieldCondition(key="tag", match=rest.MatchValue(value="animals"))]
        )
    )

Фильтр `must` отсекает все вектора с тегом `vehicles`, так что результатом будет только «Кот» или «Собака».

#### 8 | Итоги

- База поднята одной строкой `docker run`.
- Коллекция `articles` создана для 384-мерных векторов c косинусной метрикой.
- Мы загрузили точки, добавили метаданные и нашли ближайшие документы, включая запрос с фильтром.
