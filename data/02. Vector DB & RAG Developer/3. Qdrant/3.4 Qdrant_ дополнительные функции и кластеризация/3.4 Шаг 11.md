## Лабораторная 3 — «Многовекторные коллекции и гибридные сценарии» (максимально понятное описание)

**Цель.** Научиться делать мультивекторную коллекцию в Qdrant (картинка + текст по одному товару), выполнять гибридный поиск и простую офлайн-оценку качества (Recall@5) при разных настройках смешивания модальностей.

### Что вы сделаете по шагам

1. Соберёте небольшой набор товаров (таблица CSV: id, название, описание, категория, цена, ссылка на картинку).
2. Посчитаете по *каждому товару* два эмбеддинга: `image_vector` (CLIP) и `text_vector` (Sentence-BERT).
3. Создадите **мультивекторную** коллекцию Qdrant (два именованных вектора) и загрузите точки.
4. Сделаете два сценария поиска: (A) по картинке; (B) гибрид «текст + фильтр».
5. Соберёте **20 валидирующих запросов** (другая фотка и/или парафраз текста на тот же товар), посчитаете Recall@5 для разных схем смешивания модальностей и выберете лучшую.


### Предварительно

- Запущенный Qdrant: `http://localhost:6333` (одиночный узел или router кластера).
- Python 3.10+ и пакеты: `pip install qdrant-client sentence-transformers pillow requests`


### Шаг 1. Данные (что именно нужно)

Сделайте файл `products.csv` (30–50 строк). Каждая строка — *один товар*:

### Шаг 2. Эмбеддинги и загрузка в Qdrant

    from qdrant_client import QdrantClient, models
    from sentence_transformers import SentenceTransformer
    from PIL import Image
    import requests, io, csv

    # модели эмбеддингов
    img_model = SentenceTransformer("clip-ViT-B-32")      # 512-мерный
    txt_model = SentenceTransformer("all-MiniLM-L6-v2")   # 384-мерный

    client = QdrantClient("http://localhost:6333")

    # мультивекторная коллекция (два именованных вектора)
    client.recreate_collection(
        collection_name="products",
        vectors_config={
            "image_vector": models.VectorParams(size=512, distance=models.Distance.COSINE),
            "text_vector":  models.VectorParams(size=384, distance=models.Distance.COSINE),
        },
        on_disk_payload=True,
    )

    points = []
    with open("products.csv", encoding="utf-8") as f:
        for row in csv.DictReader(f):
            # картинка -> эмбеддинг
            if row["image_url"].startswith("http"):
                img = Image.open(io.BytesIO(requests.get(row["image_url"], timeout=20).content)).convert("RGB")
            else:
                img = Image.open(row["image_url"]).convert("RGB")
            img_vec = img_model.encode(img, normalize_embeddings=True)

            # текст -> эмбеддинг (title + description)
            text = f'{row["title"]}. {row["description"]}'
            txt_vec = txt_model.encode(text, normalize_embeddings=True)

            points.append(models.PointStruct(
                id=int(row["id"]),
                vector={"image_vector": img_vec, "text_vector": txt_vec},
                payload={
                    "title": row["title"], "description": row["description"],
                    "category": row["category"], "price": float(row["price"]),
                    "image_url": row["image_url"]
                }
            ))

    client.upload_points("products", points=points, batch_size=1000, parallel=4)
    print("Загружено:", len(points))

    from qdrant_client import models

    query_txt = txt_model.encode("наушники с шумоподавлением и быстрой зарядкой",
                                 normalize_embeddings=True)

    res = client.query_points(
        collection_name="products",
        prefetch=[
            models.Prefetch(query=query_txt, using="text_vector",  limit=50),
            # можно добавить и картинку: models.Prefetch(query=query_img, using="image_vector", limit=50),
        ],
        query=models.FusionQuery(fusion=models.Fusion.DBSF),   # или Fusion.RRF
        query_filter=models.Filter(must=[
            models.FieldCondition(key="category", match=models.MatchValue(value="electronics")),
            models.Range(key="price", lt=500),
        ]),
        limit=5
    )
    print([p.id for p in res.points])

### Шаг 4. «20 ручных эталонных запросов» — что это и как сделать

**Не** используйте «свою же» картинку/текст из базы (иначе Recall будет 100% и это ничего не покажет).

1. Выберите 20 товаров из вашей коллекции (их `id` — это «правильные ответы»).
2. Для каждого товара подготовьте:
  - *image_query*: **другую** фотографию того же товара (другой ракурс/источник),
  - *text_query*: 1–2 фразы **своими словами** (парафраз, а не копипаст из payload).
3. Для каждого запроса запомните `relevant_id` — ID того самого товара в коллекции.


Если временно нет другой картинки — тестируйте текстовую часть (но не копируйте текст из базы).

### Шаг 5. Оценка Recall@5 и «вес модальностей»

Идея простая: при каком смешивании модальностей «правильный ID» чаще попадает в топ-5?

#### Вариант 1 — готовые слияния

- `Fusion.DBSF` — нормализует и суммирует,
- `Fusion.RRF` — устойчив к разным шкалам.


#### Вариант 2 — свои веса (FormulaQuery)

    from qdrant_client import models

    def search_with_weights(img_vec, txt_vec, w_img, w_txt):
        return client.query_points(
            collection_name="products",
            prefetch=[
                models.Prefetch(query=img_vec, using="image_vector", limit=50),
                models.Prefetch(query=txt_vec, using="text_vector",  limit=50),
            ],
            query=models.FormulaQuery(
                formula=models.SumExpression(sum=[
                    models.MultExpression(mult=[w_img, "$score[0]"]),
                    models.MultExpression(mult=[w_txt, "$score[1]"]),
                ])
            ),
            limit=5
        )

#### Как считать Recall@5

    def recall_at_5(queries, mode="dbsf", w_img=0.5, w_txt=0.5):
        hits = 0
        for q in queries:  # q: {"img": PIL.Image or None, "txt": str or None, "id": relevant_id}
            img_vec = img_model.encode(q["img"], normalize_embeddings=True) if q["img"] else None
            txt_vec = txt_model.encode(q["txt"], normalize_embeddings=True) if q["txt"] else None

            if mode == "dbsf":
                res = client.query_points(
                    collection_name="products",
                    prefetch=[
                        *( [models.Prefetch(query=img_vec, using="image_vector", limit=50)] if img_vec is not None else [] ),
                        *( [models.Prefetch(query=txt_vec, using="text_vector",  limit=50)] if txt_vec is not None else [] ),
                    ],
                    query=models.FusionQuery(fusion=models.Fusion.DBSF),
                    limit=5
                )
            elif mode == "rrf":
                res = client.query_points(
                    collection_name="products",
                    prefetch=[
                        *( [models.Prefetch(query=img_vec, using="image_vector", limit=50)] if img_vec is not None else [] ),
                        *( [models.Prefetch(query=txt_vec, using="text_vector",  limit=50)] if txt_vec is not None else [] ),
                    ],
                    query=models.FusionQuery(fusion=models.Fusion.RRF),
                    limit=5
                )
            else:
                res = search_with_weights(img_vec or [0]*512, txt_vec or [0]*384, w_img, w_txt)

            top5 = {p.id for p in res.points}
            hits += 1 if q["id"] in top5 else 0

        return hits / len(queries)
