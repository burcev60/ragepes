### Поиск в Qdrant: базовый k-NN и поиск с фильтрацией
> Покажем, как за несколько строк получить ближайшие векторы к запросу, а затем — как ограничить поиск условиями по payload.

#### 2.1 Базовый поиск (только по вектору)

    from qdrant_client import QdrantClient, models

    client = QdrantClient("http://localhost:6333")

    # ⚠️ Предположим, коллекция 'articles' уже содержит точки размерности 768
    query_vector = [0.12] * 768          # ← эмбеддинг запроса
    top_k        = 5                     # сколько ближайших хотим увидеть

    hits = client.search(
        collection_name="articles",
        query_vector=query_vector,
        limit=top_k,
        with_vectors=False,              # в ответ не тащим сами векторы
        with_payload=True                # но хотим метаданные
    )

    for hit in hits:
        print(f"ID={hit.id:>4}  score={hit.score:.4f}  category={hit.payload.get('category')}")

- **`score`** — косинусная близость (чем больше, тем ближе).

- Если нужен полный вектор результата — поставьте `with_vectors=True`.

#### 2.2 Поиск с фильтром по payload

Допустим, мы ищем похожие статьи **только** из категории `"tech"` и опубликованные **не ранее 2023 г.**

    from datetime import datetime

    flt = models.Filter(
        must=[
            models.FieldCondition(
                key="category",
                match=models.MatchValue(value="tech")
            ),
            models.FieldCondition(
                key="year",
                range=models.Range(gte=2023)
            )
        ]
    )

    hits = client.search(
        collection_name="articles",
        query_vector=query_vector,
        limit=top_k,
        filter=flt,
        with_payload=True
    )

Фильтр-объект комбинирует условия логикой **AND** (`must`).  
Другие варианты:

- `should=[…]` — **OR**-условия;

- `must_not=[…]` — исключить записи;

- `range`, `geo_bounding_box`, `geo_radius` — числовые диапазоны и поиск по координатам.

#### 2.3 Управление точностью/скоростью поиска

По умолчанию Qdrant сам подбирает параметры HNSW. Можно тонко настроить:

    hits = client.search(
        collection_name="articles",
        query_vector=query_vector,
        limit=top_k,
        search_params=models.SearchParams(
            hnsw_ef=128,   # ↑ точность, ↓ скорость (обычный диапазон 32‒256)
            exact=False    # False = Approximate Nearest Neighbour (по умолчанию)
        )
    )

- **`hnsw_ef`** — size of the dynamic candidate list; больше — точнее, но медленнее.

- **`exact=True`** — принудительный полный перебор (только для отладки, медленно).

#### 2.4 Получение точек по ID (если знаете, что искать)

Иногда вместо `search` удобнее «вытащить» несколько конкретных точек:

    points = client.retrieve(
        collection_name="articles",
        ids=[42, 77],
        with_vectors=False,
        with_payload=True
    )
