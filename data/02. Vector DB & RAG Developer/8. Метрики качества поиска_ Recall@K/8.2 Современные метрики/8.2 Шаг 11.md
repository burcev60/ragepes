## Семантические метрики без внешних моделей: SEMSIM (эмбеддинговая косинусная) и BERTScore-lite

**Цель.** Дать рабочие «современные» метрики, которые чувствительнее к перефразировкам, чем EM/ROUGE, и при этом
 запускаются *без внешних библиотек и API*. Реализуем две: (1) *SEMSIM* — косинусная близость предложений на хэш-эмбеддингах
 (char-трёхграммы), (2) *BERTScore-lite* — токен-к-токен «софт-совпадение» через косинусную схожесть токенов. Оба счётчика самодостаточны,
 но имеют *крючок* для подключения настоящих эмбеддингов (любого провайдера) одной функцией.

### 1) Короткая теория

- **Embedding similarity (SEMSIM)**: вместо буквального совпадения строк сравниваем векторы смыслов (здесь — суррогат на char-n-gram hashing).
 Метрика = *max*ref cos(emb(pred), emb(ref)).
- **BERTScore-lite**: для каждого токена предсказания берём максимум схожести по токенам эталона и усредняем (precision);
 зеркально для recall; *F1* объединяет оба. Мы используем косинусную схожесть токеновых векторов (тоже hashing-эмбеддинги).
- **Плюсы:** устойчивы к синонимам/перестановкам; **Минусы:** без «настоящих» эмбеддингов качество приближения ограничено.
 Поэтому код содержит *hook* `embed_external()` для замены hashing-эмбеддинга на ваш провайдер.

### 3) Скрипт метрик (самодостаточно)

Сохраните как `modern_metrics.py`. Он: (a) читает `classic_data.jsonl` или `modern_data.jsonl`, (b) считает
 SEMSIM и BERTScore-lite, (c) строит отчёт и (d) содержит «крючок» для внешних эмбеддингов.

    # modern_metrics.py
    from __future__ import annotations
    import json, re, math, sys, os, random
    from collections import Counter, defaultdict
    from pathlib import Path
    from typing import List, Dict, Tuple

    random.seed(7)

    DATA_CANDIDATES = [Path("classic_data.jsonl"), Path("modern_data.jsonl")]
    REPORT = Path("modern_report.md")

    # ---------- нормализация и токены ----------
    _ws = re.compile(r"\s+")
    _punct = re.compile(r"[^\wа-яё0-9]+", re.IGNORECASE)

    def normalize(s: str) -> str:
        s = (s or "").strip().lower()
        s = _punct.sub(" ", s)
        return _ws.sub(" ", s).strip()

    def word_tokens(s: str) -> List[str]:
        t = normalize(s)
        return t.split() if t else []

    def char_ngrams(s: str, n: int = 3) -> List[str]:
        s = " " + normalize(s) + " "
        return [s[i:i+n] for i in range(max(0, len(s)-n+1))] if s else []

    # ---------- hashing-эмбеддинги (вектор фиксированного размера) ----------
    DIM = 1024

    def _hash_bucket(s: str, dim: int = DIM) -> int:
        # стабильный хэш → индекс [0..dim-1]
        return (hash(s) & 0x7fffffff) % dim

    def embed_hashing(text: str, dim: int = DIM, n: int = 3) -> List[float]:
        vec = [0.0]*dim
        grams = char_ngrams(text, n=n)
        if not grams: return vec
        for g in grams:
            vec[_hash_bucket(g, dim)] += 1.0
        # L2-норма
        norm = math.sqrt(sum(x*x for x in vec)) or 1.0
        return [x/norm for x in vec]

    # --- HOOK для внешних эмбеддингов ---
    USE_EXTERNAL = (os.getenv("USE_EXTERNAL_EMBED") == "1")
    def embed_external(texts: List[str]) -> List[List[float]]:
        """
        Замените реализацией вашего провайдера.
        Должна вернуть список векторов той же длины, что и texts.
        """
        raise NotImplementedError("Подключите внешнего провайдера или не ставьте USE_EXTERNAL_EMBED=1")

    def embed_many(texts: List[str]) -> List[List[float]]:
        if USE_EXTERNAL:
            return embed_external(texts)
        return [embed_hashing(t) for t in texts]

    def cos(a: List[float], b: List[float]) -> float:
        return sum(x*y for x,y in zip(a,b))

    # ---------- SEMSIM: sentence-level ----------
    def semsim(pred: str, refs: List[str]) -> float:
        if not refs: return 0.0
        ev = embed_hashing(pred)
        best = 0.0
        for r in refs:
            best = max(best, cos(ev, embed_hashing(r)))
        return best

    # ---------- BERTScore-lite: token-level soft matching ----------
    def token_embed(tok: str) -> List[float]:
        return embed_hashing(tok)

    def sim_mat(pred_toks: List[str], ref_toks: List[str]) -> List[List[float]]:
        if not pred_toks or not ref_toks: return []
        P = [token_embed(t) for t in pred_toks]
        R = [token_embed(t) for t in ref_toks]
        M = [[cos(p, r) for r in R] for p in P]
        return M

    def bertscore_lite(pred: str, refs: List[str], idf: Dict[str,float] | None = None, beta: float = 1.0) -> Dict[str,float]:
        # берём лучший референс (макс F1) среди refs
        ptoks = word_tokens(pred)
        if not ptoks or not refs:
            return {"P":0.0, "R":0.0, "F1":0.0}
        best = {"P":0.0, "R":0.0, "F1":0.0}
        for ref in refs:
            rtoks = word_tokens(ref)
            if not rtoks: continue
            M = sim_mat(ptoks, rtoks)  # P x R
            if not M:
                cand = {"P":0.0,"R":0.0,"F1":0.0}
            else:
                # веса IDF (по референсам датасета)
                wp = [1.0]*len(ptoks)
                wr = [idf.get(t,1.0) for t in rtoks] if idf else [1.0]*len(rtoks)
                # precision: средний максимум по строкам
                row_max = [max(row) if row else 0.0 for row in M]
                P = sum(m*w for m,w in zip(row_max, wp)) / (sum(wp) or 1.0)
                # recall: средний максимум по столбцам
                # транспонируем матрицу
                col_max = [max(M[i][j] for i in range(len(ptoks))) for j in range(len(rtoks))]
                R = sum(m*w for m,w in zip(col_max, wr)) / (sum(wr) or 1.0)
                F = (1+beta*beta)*P*R/(beta*beta*P+R) if (P+R)>0 else 0.0
                cand = {"P":P,"R":R,"F1":F}
            if cand["F1"] > best["F1"]:
                best = cand
        return best

    # ---------- IDF по всему набору (для ref-токенов) ----------
    def compute_idf(rows: List[dict]) -> Dict[str,float]:
        # считаем df только по "refs"
        docs = 0
        df = Counter()
        for r in rows:
            if r.get("type")!="qa": continue
            toks = set()
            for ref in r.get("refs", []):
                toks.update(word_tokens(ref))
            if toks:
                docs += 1
                for t in toks:
                    df[t]+=1
        idf = {}
        for t,c in df.items():
            idf[t] = math.log((docs+1)/(c+0.5)) if docs>0 else 0.0
        return idf

    # ---------- чтение данных ----------
    def load_rows() -> List[dict]:
        data_path = None
        for p in DATA_CANDIDATES:
            if p.exists():
                data_path = p; break
        if not data_path:
            raise SystemExit("Нет classic_data.jsonl или modern_data.jsonl — создайте один из них.")
        rows=[]
        for line in data_path.read_text(encoding="utf-8").splitlines():
            if not line.strip(): continue
            rows.append(json.loads(line))
        return [r for r in rows if r.get("type")=="qa"]

    # ---------- отчёт ----------
    def build_report():
        rows = load_rows()
        idf = compute_idf(rows)
        lines=[]
        lines += ["# Modern Metrics Report (SEMSIM, BERTScore-lite)", ""]
        lines += ["| id | SEMSIM | BS-lite P | BS-lite R | BS-lite F1 | pred]()
