## Groundedness/Attribution: проверка «опоры на источники» без внешних моделей

**Цель.** Научиться автоматически проверять, что ответ *опирается* на предоставленный контекст (цитаты/ретрив)
 и не «галлюцинирует» факты. Реализуем лёгкие метрики без внешних библиотек: покрытие n-грамм ответом из контекста,
 совпадение чисел/дат, покрытие именованных сущностей (эвристика по капслеттерам), и итоговый композитный *Groundedness Score*.
 Добавим флаги «галлюцинация по числам/сущностям/цитатам» и отчёт.

### 2) Что меряем

- **Attribution (ngram-coverage)**: доля 1–3-грамм ответа, которые встречаются в контекстах (после нормализации).
- **Numeric grounding**: доля чисел/дат/сумм из ответа, найденных в контексте (включая символы %, ₽, год).
- **Entity grounding (эвристика)**: доля «имён/терминов» (слова с заглавной буквы ≥3 символа), встречающихся в контексте.
- **Citation fidelity**: наличие `[doc_id]` и «`SOURCE:`» в ответе.
- **Итог**: *Groundedness Score* = 0.4·ngram + 0.3·numeric + 0.2·entity + 0.1·citation (0/1).


### 3) Скрипт (самодостаточно)

Сохраните как `modern_groundedness.py`. Зависимости: только стандартная библиотека.

    # modern_groundedness.py
    from __future__ import annotations
    import json, re, math, sys
    from pathlib import Path
    from typing import List, Dict, Tuple

    DATA = Path("modern_ctx.jsonl")
    REPORT = Path("groundedness_report.md")

    _ws = re.compile(r"\s+")
    _punct = re.compile(r"[^\wа-яё0-9%₽\.\-:]+", re.IGNORECASE)

    def normalize(s: str) -> str:
        s = (s or "").strip().lower()
        s = _punct.sub(" ", s)
        return _ws.sub(" ", s).strip()

    def tokens(s: str) -> List[str]:
        t = normalize(s);
        return t.split() if t else []

    def ngrams(xs: List[str], n: int) -> List[str]:
        return [" ".join(xs[i:i+n]) for i in range(0, max(0, len(xs)-n+1))]

    # --- метрики ---
    NUM_RE = re.compile(r"(?:\d{1,2}[./-]\d{1,2}[./-]\d{2,4}|\d{4}|\d+[.,]?\d*\s?(?:%|₽)?)")

    def ngram_coverage(answer: str, ctx: str, n_min=1, n_max=3) -> float:
        atoks = tokens(answer)
        ctoks = tokens(ctx)
        if not atoks or not ctoks: return 0.0
        ctx_ngr = set()
        for n in range(n_min, n_max+1):
            ctx_ngr.update(ngrams(ctoks, n))
        ans_ngr = []
        for n in range(n_min, n_max+1):
            ans_ngr += ngrams(atoks, n)
        if not ans_ngr: return 0.0
        hit = sum(1 for g in ans_ngr if g in ctx_ngr)
        return hit/len(ans_ngr)

    def numeric_grounding(answer: str, ctx: str) -> float:
        a_nums = set(NUM_RE.findall(answer))
        if not a_nums: return 1.0  # нет чисел — не штрафуем
        joined = ctx
        hits = sum(1 for n in a_nums if n in joined)
        return hits/len(a_nums)

    # эвристика именованных сущностей для ru/en: Слова с заглавной буквы ≥3 символа (не в начале предложения)
    CAP_RE = re.compile(r"\b[А-ЯA-Z][а-яa-z]{2,}\b")

    def entity_grounding(answer: str, ctx: str) -> float:
        a_ents = set(CAP_RE.findall(answer))
        if not a_ents: return 1.0
        hits = sum(1 for e in a_ents if re.search(r"\b"+re.escape(e)+r"\b", ctx))
        return hits/len(a_ents)

    def citation_fidelity(answer: str) -> int:
        has_br = re.search(r"\[[^\[\]]+\]", answer) is not None
        has_src = "source:" in answer.lower()
        return int(has_br and has_src)

    def groundedness(answer: str, ctxs: List[str]) -> Dict[str, float]:
        ctx = " \n".join(ctxs)
        ngram = ngram_coverage(answer, ctx)
        num   = numeric_grounding(answer, ctx)
        ent   = entity_grounding(answer, ctx)
        cit   = citation_fidelity(answer)
        score = 0.4*ngram + 0.3*num + 0.2*ent + 0.1*cit
        return {"ngram": ngram, "numeric": num, "entity": ent, "citation": float(cit), "score": score}

    def load_rows() -> List[dict]:
        rows=[]
        for line in DATA.read_text(encoding="utf-8").splitlines():
            if not line.strip(): continue
            rows.append(json.loads(line))
        return rows

    def build_report(threshold=0.6):
        rows = load_rows()
        lines=[]
        lines += ["# Groundedness / Attribution Report", ""]
        lines += ["| id | ngram | numeric | entity | cite | score | FLAG | pred |",
                  "|---|---:|---:|---:|---:|---:|---|---|"]
        scores=[]
        flags=[]
        for r in rows:
            ans = r.get("pred","")
            ctxs = r.get("contexts",[])
            met = groundedness(ans, ctxs)
            flag = ""
            if met["score"] < threshold:
                lack = []
                if met["numeric"] < 1.0 and NUM_RE.search(ans): lack.append("num")
                if met["ngram"] < 0.5: lack.append("ngram")
                if met["entity"] < 1.0: lack.append("ent")
                if met["citation"] < 1.0: lack.append("cite")
                flag = "LOW:" + ",".join(lack) if lack else "LOW"
            scores.append(met["score"])
            if flag: flags.append((r["id"], flag))
            lines.append(f"| {r['id']} | {met['ngram']:.2f} | {met['numeric']:.2f} | {met['entity']:.2f} | {met['citation']:.0f} | {met['score']:.2f} | {flag or ''} | {ans} |")
        if scores:
            avg = sum(scores)/len(scores)
            below = sum(1 for s in scores if s < threshold)
            lines += ["", f"- Avg groundedness: {avg:.2f}",
                           f"- Below threshold ({threshold}): {below}/{len(scores)}"]
        if flags:
            lines += ["", "## Investigate", "Проверьте ответы и контекст для следующих id:"]
            for i,(cid, f) in enumerate(flags[:20], start=1):
                lines.append(f"{i}. {cid} — {f}")
        REPORT.write_text("\n".join(lines), encoding="utf-8")
        print(f"OK → {REPORT}")

    # ---- автотесты на примере ----
    def _tests():
        build_report()
        md = REPORT.read_text(encoding="utf-8")
        assert "Groundedness / Attribution Report" in md
        assert "| q1 |" in md and "| q3 |" in md
        # ожидаем, что q1 и q2 сильно grounded; q3 может упасть по numeric (1000 ₽ не в контексте)
        assert "q1" in md and "q2" in md
        print("Автотесты пройдены ✓")

    if __name__ == "__main__":
        if "--report" in sys.argv:
            build_report()
        else:
            _tests()

### 4) Как запускать

1. Положите файл `modern_ctx.jsonl` рядом со скриптом.
2. Выполните:

    python modern_groundedness.py

Создастся `groundedness_report.md` и пройдут автотесты.

3. Для отчёта без автотеста:

    python modern_groundedness.py --report

### 5) Мини-лаба (что проверить)

- **q3** в примере содержит «1000 ₽», которого нет в контексте — увидите падение *numeric* и общий флаг *LOW:num*.
- Удалите «SOURCE:» или `[pX]` из ответа — *citation* станет 0, упадёт общий балл.
- Добавьте в контекст точные фразы из ответа — *ngram* вырастет.


### 6) Подсказки и расширение

- **Числа и даты:** расширьте регэксп под форматы «1 000», «1,000.50», «15 %», «15%-ный». Нормализуйте пробелы-разделители.
- **Сущности:** подключите простой словарь терминов домена или NER (если можно) — повысите точность entity-grounding.
- **Веса:** подберите веса для вашего домена (например, 0.5·numeric, если числовая точность критична).
- **Интеграция с RAG:** логируйте `groundedness_score` на проде и ставьте алерт на падение медианы/доли ниже порога.
