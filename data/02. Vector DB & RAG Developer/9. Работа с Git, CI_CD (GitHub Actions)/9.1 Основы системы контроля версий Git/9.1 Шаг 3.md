#### Базовые команды Git

Представим, вы начали новый проект. Чтобы инициализировать Git-репозиторий, в папке выполните `git init` – появится `.git`, проект отслеживается. Далее вы создаёте файлы, пишете код. Когда готовы зафиксировать изменения, делаете:

1. `git add .` – добавить все новые/изменённые файлы в «индекс» (staging area), подготовить их к коммиту.
2. `git commit -m "Сообщение"` – зафиксировать индексированные изменения как новый коммит с заданным сообщением.


Коммит сохранён локально. Чтобы поделиться с другими через, скажем, GitHub, сперва нужно создать удалённый репозиторий (например, новый репо на GitHub). Затем привязать локальный к удалённому: `git remote add origin https://github.com/user/repo.git`. После этого `git push origin main` отправит ваши коммиты из ветки main на сервер (origin – стандартное имя remote по умолчанию).

Когда кто-то другой внёс изменения на сервере, вы можете получить их командой `git pull` (она, упрощённо, делает fetch + merge – забирает новые коммиты и сливает в вашу текущую ветку). Команда `git clone URL` используется, чтобы склонировать (скачать) целый удалённый репозиторий к себе впервые.

Другие полезные команды: `git status` (показывает текущий статус – какие файлы изменены, какие в индексе), `git log` (показывает журнал коммитов), `git diff` (показывает разницу между текущими изменениями и последним коммитом).
