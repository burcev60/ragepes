#### Работа с GitHub

GitHub – это популярная платформа для хостинга Git-репозиториев с доп. функциями (issues, wiki, CI/CD, и т.д.). Чтобы выложить проект на GitHub, как мы говорили, вы создаёте там репо и делаете `git push`. После этого вся история коммитов доступна в веб-интерфейсе. Можно просматривать код, видеть, кто что изменил (GitHub красиво показывает *diff*ы), обсуждать код (через pull request или напрямую в коммитах).

Для открытых проектов GitHub – практически стандарт: там можно принимать вклад от сообщества через форки (fork – копия репо, из которой делается PR назад), подключать CI/CD (о чём далее). Для нас важно, что GitHub – просто удалённый Git, поэтому все команды те же: `push`, `pull`, `clone`. Разве что аутентификация: сейчас используется токен или через SSH-ключи, чтобы `git push` был авторизованным.

Итак, вы теперь понимаете основы Git. В контексте разработки нашего семантического поискового бота: вы будете версионировать код, каждый этап сохранять коммитами, экспериментировать в ветках. Это позволит уверенно вносить изменения, зная, что всегда можно откатиться или сравнить с предыдущей версией. А когда проект разрастётся или вы станете работать в команде – Git окажется абсолютно незаменимым.
