#### Репозиторий, коммиты и ветки

Основные понятия Git:

- **Репозиторий** – хранилище проекта под управлением Git. Это просто папка с особыми метаданными (внутри есть скрытая папка `.git`), которая отслеживается Git’ом. Репозиторий может быть локальным (на вашем компьютере) и удалённым (например, на GitHub).
- **Коммит** – зафиксированное изменение (снимок состояния проекта). У каждого коммита есть уникальный идентификатор (хеш), автор, дата и сообщение (описание изменений). Когда вы делаете коммит, Git сохраняет все изменения с момента прошлого коммита. Вы можете откатиться к любому коммиту позже или посмотреть, что в нём изменилось.
- **Ветка (branch)** – именованная последовательность коммитов. По умолчанию у репозитория есть основная ветка (часто назвается `main` или `master`). Вы можете создавать другие ветки для разработки новой функции или экспериментального кода. Ветки позволяют изолировать работу: изменения в ветке не влияют на другие ветки, пока вы их не сольёте.
- **Remote (удалённый репозиторий)** – копия репозитория на сервере (например, на GitHub или GitLab). С ним можно синхронизироваться: отправлять свои коммиты (push) и получать чужие (pull).
