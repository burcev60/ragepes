**Пример метрик в коде**  
Чтобы закрепить, приведем пример небольшого кода, интегрирующего Prometheus metrics в FastAPI:

    from prometheus_client import Summary, Gauge

    # Определяем метрики
    REQUEST_TIME = Summary('request_processing_seconds', 'Time spent processing request')
    TOKENS_USED = Gauge('tokens_used_total', 'Total tokens used by last request', ['type'])

    @app.post("/ask")
    def ask_question(req: QuestionRequest):
        start = time.time()
        # ... обработка запроса ...
        answer = chain.run(req.question)
        duration = time.time() - start
        REQUEST_TIME.observe(duration)
        # допустим, chain возвращает объект со свойством tokens
        TOKENS_USED.labels(type="prompt").set(chain.prompt_tokens)
        TOKENS_USED.labels(type="completion").set(chain.completion_tokens)
        return {"answer": answer}

Здесь `Summary` собирает статистику по времени (позже можно получить среднее, перцентили и т.д. из него), а `Gauge` с лейблами 'prompt' и 'completion' устанавливается на кол-во токенов. В реальности, возможно, лучше использовать `Counter` для суммарного количества токенов, увеличивая его на значение, чтобы метрика росла накопительно. Тогда, глядя на разницу, можно вывести использование за период.

 

Чтобы эти метрики были доступны, нужно в FastAPI также подключить роут на `/metrics`:

    from prometheus_client import generate_latest, CONTENT_TYPE_LATEST
    @app.get("/metrics")
    def metrics():
        data = generate_latest()
        return Response(content=data, media_type=CONTENT_TYPE_LATEST)

Тогда Prometheus сможет опрашивать ваш сервис по /metrics и собирать эти цифры.
