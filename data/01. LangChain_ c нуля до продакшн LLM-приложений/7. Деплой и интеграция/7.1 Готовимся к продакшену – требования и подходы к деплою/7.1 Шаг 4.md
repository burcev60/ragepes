**Статика – простая HTML-страница:** Мы хотим, чтобы пользователь мог зайти через браузер и испытать бота. Можно использовать шаблоны или просто написать один HTML-файл с JS fetch. Сделаем файл `index.html` в той же папке:

    <!DOCTYPE html>
    <html>
    <head>
    <meta charset="UTF-8">
    <title>LLM Chat</title>
    <style>
      body { font-family: Arial, sans-serif; max-width:600px; margin:50px auto; }
      #chat { border: 1px solid #ccc; padding:10px; min-height:300px; }
      .user { font-weight: bold; }
      .bot { margin-bottom: 10px; }
    </style>
    </head>
    <body>
      <h1>LLM Chat Assistant</h1>
      <div id="chat"></div>
      <input type="text" id="question" placeholder="Введите сообщение..." style="width:80%;">
      <button onclick="send()">Отправить</button>

    <script>
    async function send() {
        let question = document.getElementById("question").value;
        if(!question) return;
        document.getElementById("question").value = "";
        let chatDiv = document.getElementById("chat");
        // Добавляем в чат блок с вопросом
        chatDiv.innerHTML += "<p class='user'>Вы: " + question + "</p>";
        // Отправляем запрос к API
        let response = await fetch('/ask', {
            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({question: question})
        });
        if(response.ok) {
            let data = await response.json();
            let answer = data.answer;
            chatDiv.innerHTML += "<p class='bot'>Ассистент: " + answer + "</p>";
            chatDiv.scrollTop = chatDiv.scrollHeight;
        } else {
            chatDiv.innerHTML += "<p class='bot'>Ошибка: " + response.statusText + "</p>";
        }
    }
    </script>
    </body>
    </html>

Это простой чат: подгружается стили, скрипт. По нажатию кнопки `send()` берётся текст из input, отображается на странице, отправляется fetch на `/ask`. Когда приходит ответ, добавляется `<p>` с ответом ассистента.

 

Мы предполагаем, что `/ask` на том же домене, поэтому просто `fetch('/ask')` работает. В продакшене, возможно, фронт отдельно, тогда URL полный нужен.
