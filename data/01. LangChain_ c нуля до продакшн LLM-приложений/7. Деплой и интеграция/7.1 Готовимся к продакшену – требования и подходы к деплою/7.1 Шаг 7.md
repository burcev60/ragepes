**Развёртывание на сервере:** Теперь, когда всё работает локально, нужно разместить. Варианты:

- **Docker контейнер:** Написать Dockerfile, собрать образ с нашим приложением. Запускать uvicorn. Это удобно для деплоя на разные платформы.

- **PaaS**: Например, DetaSpace, Railway, Heroku (legacy), Fly.io, Render – могут запустить FastAPI из репо.

- **VM**: Взять сервер, установить, запустить uvicorn или gunicorn.

С Docker: Создайте Dockerfile, например:

    FROM python:3.10-slim
    WORKDIR /app
    COPY requirements.txt .
    RUN pip install -r requirements.txt
    COPY . .
    ENV PYTHONUNBUFFERED=1
    EXPOSE 8000
    CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"]

Соберите `docker build -t my-llm-app .` и запуск `docker run -d -p 8000:8000 my-llm-app`.

 

Не забудьте .env – можно либо COPY .env, либо лучше через env vars.

 

Если PaaS – обычно читают requirements.txt и запускают uvicorn.
