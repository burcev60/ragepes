**Подготовка FastAPI сервиса:** Установите fastapi и uvicorn: `pip install fastapi uvicorn`. Создайте файл `app.py`:

    from fastapi import FastAPI
    from pydantic import BaseModel

    app = FastAPI()

    # Поскольку у нас может быть несколько разных агентов/ботов,
    # определим пока один универсальный эндпоинт

    class Query(BaseModel):
        question: str

    # Допустим, у нас глобально инициализирован какой-то бот/агент, например conversation_chain или agent
    # Здесь пример с простым QA ботом (можно подставить нужный объект)
    # conversation = ConversationChain(...)

    @app.post("/ask")
    async def ask_question(query: Query):
        # Получаем ответ от модели/агента
        user_q = query.question
        # Вызовем синхронно для простоты (если LLM API sync). Если захотим async, можно await ...
        answer = conversation.predict(input=user_q)
        return {"answer": answer}

Это упрощённый сервер: POST запрос на `/ask` с JSON телом `{"question": "..."}`, возвращает JSON `{"answer": "..."}`.

 

Если у вас бот требует streaming ответа (по токенам), FastAPI можно сделать генератор (StreamingResponse), но это сложнее – мы не покрываем в курсе. Вернём сразу весь ответ.
