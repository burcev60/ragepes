**Создание FastAPI-приложения**  
Мы будем использовать **FastAPI** как современный и быстрый фреймворк для Python, отлично подходящий для наших целей. Предположим, что в нашем приложении уже есть настроенная цепочка `qa_chain` (например, ConversationChain или RetrievalQA chain), или мы можем внутри обработчика просто вызывать `llm` напрямую. Давайте напишем простое приложение:

    from fastapi import FastAPI, HTTPException
    from pydantic import BaseModel

    # Инициализируем FastAPI
    app = FastAPI(title="LangChain QA API")

    # Модель запроса (для валидации входных данных)
    class QuestionRequest(BaseModel):
        question: str

    # Заглушка: предположим, у нас есть цепочка chain (LLMChain или похожий), настроенная заранее
    # chain = ...

    @app.post("/ask")
    def ask_question(req: QuestionRequest):
        question_text = req.question
        # Проверяем, что вопрос не пустой
        if not question_text or question_text.strip() == "":
            raise HTTPException(status_code=400, detail="Question cannot be empty")
        # Получаем ответ от модели/цепочки
        answer = chain.run(question_text)
        return {"answer": answer}

Здесь мы определили Pydantic-модель `QuestionRequest` для автоматической валидации JSON с полем `question`. Эндпоинт `/ask` принимает объект `QuestionRequest`, достаёт из него текст вопроса и передаёт его в цепочку `chain`. Мы делаем базовую проверку на пустоту вопроса и, в случае чего, возвращаем HTTP 400 (неправильный запрос). Если всё в порядке, возвращаем JSON с ключом `"answer"`. FastAPI автоматически сериализует словарь в JSON.

 

Предположим, что `chain` – это, например, `ConversationalRetrievalChain` или `LLMChain`, созданный где-то выше (в коде приложения, вне примера). Он уже внутри может использовать multi-provider стратегию из прошлых уроков – для API-метода это не важно, он просто получает финальный ответ.

 

Такое приложение можно запустить через Uvicorn командой `uvicorn main:app --host 0.0.0.0 --port 8000`. После запуска, `POST http://localhost:8000/ask` с телом `{"question": "Какая столица Франции?"}` вернёт `{"answer": "Париж"}` (например).
