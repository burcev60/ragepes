**Клиентская сторона стриминга (кратко)**  
Хотя курс фокусируется на серверной части, кратко упомянем, как потреблять поток на фронтенде. Если у вас веб-приложение, можно использовать JavaScript:

    <script>
      const evtSource = new EventSource("/ask_stream?question=Привет, мир!");
      evtSource.onmessage = function(event) {
          const newText = event.data;
          console.log("New chunk:", newText);
          // Здесь можно обновлять элемент на странице, добавляя newText
      };
    </script>

Каждый вызов `yield` на сервере будет вызывать событие `message` на клиенте с данными `event.data`. Вы можете постепенно выводить текст в интерфейсе, создавая эффект "пишущей машинки". После отправки всего ответа, OpenAI API обычно посылает завершающий chunk (с `finish_reason`), наш код его просто проигнорирует, и поток закроется. EventSource автоматически закроется когда сервер перестанет слать данные.

 

Если клиент – не браузер, а например Python-скрипт, то он тоже может читать ответ построчно из HTTP-ответа. Библиотеки requests для стриминга или специализированные SSE-клиенты помогут. Также можно использовать **веб-сокеты** для стриминга – FastAPI их поддерживает, но SSE проще, если нужен только односторонний поток (от сервера к клиенту).
