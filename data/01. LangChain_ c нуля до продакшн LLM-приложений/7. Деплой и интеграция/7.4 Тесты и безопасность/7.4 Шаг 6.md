**Практический пример: ограничение прав агента**  
Предположим, у нас есть агент с инструментом `PythonREPLTool` для выполнения Python-кода по запросу (в некоторых задачах это удобно). Мы опасаемся, что пользователь может через prompt injection заставить его выполнить вредоносный код. Один из простых механизмов – подсмотреть код инструмента и сделать его подкласс, который переопределяет метод исполнения, добавив проверку. Например:

    from langchain.tools import PythonREPLTool

    class SafePythonREPLTool(PythonREPLTool):
        def run(self, query: str) -> str:
            # запретим удалять файлы и выполнять подозрительные команды
            forbidden_keywords = ["os.remove", "shutil.rmtree", "subprocess", "open(", "import os"]
            for key in forbidden_keywords:
                if key in query:
                    return "Ошибка: Недопустимая операция"
            # Если проверку прошел, вызываем родительский метод
            return super().run(query)

Здесь мы очень наивно блочим по наличию слов, конечно злоумышленник может обойти (например, `import os` можно написать как `i\u006dport os`). Это только иллюстрация. После этого, при инициализации инструментов агента, вместо `PythonREPLTool()` используйте `SafePythonREPLTool()`. Таким образом, агент просто откажется выполнять явные разрушительные команды.

 

Другой пример – ограничение файловой системы. Если у вас есть инструмент чтения файлов, убедитесь, что он работает **только в оговоренной папке**. Можно в методе `run` инструмента прописать проверку пути: если путь содержит `..` (выйти вверх) или не начинается с дозволенной директории, возвращать ошибку.
