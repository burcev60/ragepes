## 🔹 Практическое задание: Реализация гибридного ретривера с реранкером

В этом задании нужно реализовать собственный кастомный ретривер, который объединяет **два разных метода поиска** (BM25 и векторный) и выполняет **повторное ранжирование** документов через **cross-encoder**. Задача — воспроизвести логику гибридного поиска и встроить её в интерфейс `BaseRetriever`.

### 🔸 Цели задания

1. Освоить концепцию гибридного поиска (BM25 + векторный поиск).

2. Реализовать объединение выдач с дедупликацией.

3. Подключить **cross-encoder** для финального rerank.

4. Собрать рабочий кастомный ретривер, полностью совместимый с LangChain.

5. Проверить работу своего ретривера на тестовом наборе документов с замером метрик

### 🔸 Требования к функциональности

- Создайте два базовых ретривера (BM25 и Векторный)

- Реализуйте кастомный класс HybridRerankerRetriever

- Используйте интерфейс `BaseRetriever `

- Используйте объединения результатов с дедупликацией

- Сделайте реранк с помощью **cross-encoder** модели

- параметр `k` — количество документов в итоговой выдаче.

### 🔸 Тестирование

1. Используйте тот же датасет, что использовали на прошлом уроке (или новый, но схожий по структуре)
2. Инициализируйте три разных ретривера (BM25, векторный, гибридный)
3. Прогоните все три ретривера замерив метрики скриптом который вы сделали на прошлом уроке
4. Сравните метрики и опишите результаты


### 🔸 Минимальные требования к проекту

- Лучше оформить все в `.ipynb` ноутбуке, чтобы можно было сделать выводы в разных ячейках и намисать мини отчет с выводами в markdown ячейке.

- Код должен запускаться без изменений после установки зависимостей.

- Должна быть реализация:

  - кастомного класса-ретривера,

  - дедупликации,

  - интеграции cross-encoder,

  - тестового примера работы.
