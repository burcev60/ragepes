## 🔹 Тестовое задание: Индексация документа и поиск по эмбеддингам через FAISS

В этом задании вам предстоит самим на практике реализовать то, что мы прошли в теории. Напишите скрипт, который будет:

1. Загружать документы разных типов (можно взять PDF, Markdown, HTML или что-то другое из того что мы рассматривали в теории)

2. Разбивать их на чанки с помощью `TextSplitter`

3. Строить эмбеддинги с использованием **SentenceTransformer** или `HuggingFaceEmbeddings`.

4. Создавать векторное хранилище на базе **FAISS**.

5. Выполнять семантический поиск, возвращая исходные фрагменты текста.

6. Оформить проект в виде Python-скрипта и загрузить в GitHub.

#### 🔸 Источник данных

Выберите любой реальный текстовый источник (например, PDF-файл, страницу документации или статью). Не используйте фиктивные строки.

#### 🔸 Загрузка

Используйте любой loader из `langchain_community.document_loaders`

- PDF → `PyPDFLoader` / `PyMuPDFLoader`

- HTML → `WebBaseLoader`

- Markdown → `TextLoader`

#### 🔸 Препроцессинг

- Объедините документы в список

- Разбейте их на чанки через `RecursiveCharacterTextSplitter` или `TokenTextSplitter`

#### 🔸 Эмбеддинги

Используйте **один из вариантов**:

- `HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")`

- Любая SentenceTransformer-модель через собственный класс

- Если хотите, можно использовать OpenAI, но это необязательно

#### 🔸 Индексация

Создайте FAISS-индекс:

    from langchain_community.vectorstores import FAISS

    vectorstore = FAISS.from_documents(docs, embeddings)

Сохраните индекс локально, затем загрузите обратно и выполните проверочный запрос.

#### 🔸 Поиск

Реализуйте функцию, которая принимает строку запроса и выводит **текст найденного чанка + метаданные**.

#### 🔸 Формат сдачи

Загрузите в репозиторий **один файл**:

- `rag_faiss_demo.py` (или Jupyter Notebook `.ipynb`)

- В коде должен быть минимум:

  - загрузка данных

  - разбиение на чанки

  - построение эмбеддингов

  - создание FAISS-индекса

  - семантический поиск

Документацию и комментарии писать приветствуется.
