## 🔹 **Практическое задание: оценка качества RAG-систем**

В этом задании закрепим материал по метрикам. Вам предстоит реализовывать скрипт для измерения `precision`, `recall` и базовой `faithfulness`

### 🔸 Задача скрипта

1. **Оценка поиска (Retrieval Metrics)**

  - Precision@k

  - Recall@k

  - Скрипт должен выводить:

    - Метрики по каждому вопросу

    - Средние метрики по всему тестовому набору

2. **Оценка генерации (Faithfulness)**

  - Настройте скрипт на проверку соответствия ответа источнику

  - Реализуйте это без сторонних специализированных фреймворков

  - Используйте LLM для оценки

🔸 **Пример структуры входных данных** 

    from langchain_core.documents import Document

    # Пример документов
    documents = [
        Document(page_content="Фирма ООО 'Одуванчик' основана в 2015 году", metadata={'source': 'doc_1.pdf'}),
        Document(page_content="Директор ООО 'Одуванчик' Смирнов Иван Петрович", metadata={'source': 'doc_2.pdf'}),
    ]

    # Пример ground truth
    ground_truth_docs = {
        "Когда основана компания?": ["doc_1.pdf"],
        "Кто директор компании?": ["doc_2.pdf"]
    }

    # Пример предсказанных ответов
    predicted_answers = {
        "Когда основана компания?": "Компания основана в 2015 году.",
        "Кто директор компании?": "Смирнов Иван Петрович"
    }
> 💡Можете загрузить в репозиторий несколько тестовых документов и подготовить loader для их считывания или загрузить готовое сохранённое векторное хранилище с некоторым количеством документов и индексов или даже оформить синтетические тесты как в примере. Главное в этом задании качественный замер метрик, ваши данные должны быть достаточны для объективной оценки системы.

🔸 **Формат сдачи**

- Подготовленные тестовые данные: 10 вопросов типичных по вашим данным с разметкой документов в которых они лежат
- Готовый python скрипт с реализацией тестогового прогона вашей RAG системы по датасету, который возвращает метрики в консоли в виде отчёта
