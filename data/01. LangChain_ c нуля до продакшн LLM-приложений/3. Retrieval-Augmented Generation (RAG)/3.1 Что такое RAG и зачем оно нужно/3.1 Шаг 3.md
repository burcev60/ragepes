## 🔹 Мини‑пример без индекса (in-memory)

Обычно RAG использует **индекс** — специальную структуру, которая позволяет быстро находить подходящие фрагменты знаний. В деталях разберём это позже. Сейчас же реализуем упрощённый RAG-подобный подход: просто сохраним документы в памяти и будем напрямую искать в них нужные части.

Сначала объявим три небольших текстовых документа:

    doc1 = "OpenAI была основана в декабре 2015 года. Цель компании – разработка ИИ для блага человечества."
    doc2 = "МГУ – старейший университет в России, основанный в 1755 году. Расположен в Москве."
    doc3 = "Париж называют городом любви. Он также знаменит своими историческими памятниками."

Пользователь задаёт вопрос: `В каком году был основан МГУ?`

 

### 🔸 Алгоритм прост:

- Проходим по каждому документу и проверяем наличие ключевых слов.
- Либо ищем подстроку «основан», подогнав под нижний регистр.
- Находим doc2, где содержится «основанный в 1755 году».
- Берём этот фрагмент как контекст.
- Формируем промпт для LLM: *"Вопрос: …; Контекст: …; Ответ:"*.
- Получаем ответ от модели.


 

### 🔸 **Код примера:**

    # Наша маленькая база
    docs = [doc1, doc2, doc3]
    user_question = "В каком году был основан МГУ?"

    # Простой поиск: выберем документы, содержащие слово "основан"
    relevant_docs = [d for d in docs if "основан" in d.lower() and ("мгу" in d.lower() or "университет" in d.lower())]

    context = "\n".join(relevant_docs)  # склеим найденные фрагменты
    prompt = f"Вопрос: {user_question}\nВот данные из источников: {context}\nОтвет:"
    print(prompt)

 

### 🔸 **Промпт получится такой:**

    Вопрос: В каком году был основан МГУ?
    Вот данные из источников: МГУ – старейший университет в России, основанный в 1755 году. Расположен в Москве.
    Ответ:

 

### 🔸 **Отправляем промпт в модель:**

    import os
    from dotenv import load_dotenv
    from langchain_openai import ChatOpenAI

    load_dotenv()
    MODEL = os.getenv("OPENAI_API_MODEL", "gpt-5")

    llm = ChatOpenAI(model_name=MODEL, temperature=0)

    response = llm.invoke(prompt)
    print(response)

 

### 🔸 Ожидаемый ответ модели:

    Московский государственный университет был основан в 1755 году.

То, что и нужно. Модель просто перефразировала найденный контекст.

Мы реализовали RAG вручную: `relevant_docs` — простейший ретривер без эмбеддингов, а `ChatOpenAI.invoke()` — генерация. Такой наивный поиск не масштабируется и может пропустить ответы, если ключевые слова слегка отличаются (например, «когда основан МГУ?» vs «основанный в 1755»). В реальных решениях применяют векторные эмбеддинги для семантического поиска.

Этот простой мини‑скрипт, демонстрирует концепцию, что пригодится для понимания. Дальше будем усложнять и расширять этот подход с индексами и специализированными инструментами, предлагаемыми в langchain
