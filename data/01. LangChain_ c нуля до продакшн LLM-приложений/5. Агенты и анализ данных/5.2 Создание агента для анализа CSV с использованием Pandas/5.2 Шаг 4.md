**Шаг 4: Артефакт – аналитический агент + примеры отчётов**  
**Цель шага:** Собрать всё вместе: создать компонент ассистента, умеющий по запросу пользователя проводить анализ CSV-данных и возвращать осмысленные отчёты (текст + графики). Продемонстрировать на примерах работу этого агента.

Артефактом будет модуль, условно назовём его `csv_agent.py`. Внутри мы реализуем логику:

1. Распознавание запроса, требующего анализа данных. (Например, если в вопросе упоминается *файл, данные, график, таблица* – можно направить в CSV-агент. В интеграции с общим ботом это сделает маршрутизатор, о котором позднее.)

2. Получение от планировщика или напрямую от пользователя задачи, которая связана с CSV.

3. Генерация кода (через GPT) для выполнения.

4. Проверка + выполнение кода в песочнице.

5. Второй вызов GPT для оформления результата.

6. Возврат итогового ответа с возможным изображением.

Мы протестируем агента на нескольких сценариях (примеры отчётов):

*Пример 1:* **Описание данных.**  
**Пользователь:** “Какие столбцы есть в файле sales.csv и сколько там записей?”  
**Действия агента:** модель сгенерирует код:

    import pandas as pd
    df = pd.read_csv("sales.csv")
    print("Колонки:", ", ".join(df.columns))
    print("Количество записей:", len(df))

Выполнение вернёт что-то вроде:

    Колонки: Date, Region, Sales, Cost
    Количество записей: 365

Второй запрос модели получит эти результаты и ответит: *“В CSV-файле `sales.csv` содержатся столбцы: Date, Region, Sales, Cost. Всего записей: 365 (например, по одному на каждый день года).”*

*Пример 2:* **Рассчёт метрики.**  
**Пользователь:** “Посчитай общую прибыль (Sales minus Cost) по всем регионам за год.”  
**Действия агента:** модель может сделать код:

    import pandas as pd
    df = pd.read_csv("sales.csv")
    df['Profit'] = df['Sales'] - df['Cost']
    total_profit = df['Profit'].sum()
    print(total_profit)

Предположим, output: `123456.78`. Модель сформирует ответ: *“Совокупная прибыль за год составляет примерно 123 456.78 (единиц валюты).”*

*Пример 3:* **График и сравнение:**  
**Пользователь:** “Сравни продажи по регионам и покажи это на графике.”  
**Действия агента:** План: вычислить суммарные продажи по `Region`, построить столбчатую диаграмму. Код:

    import pandas as pd
    import matplotlib.pyplot as plt
    df = pd.read_csv("sales.csv")
    region_sales = df.groupby("Region")["Sales"].sum()
    region_sales.plot(kind="bar")
    plt.title("Продажи по регионам")
    plt.ylabel("Сумма продаж")
    plt.savefig("output.png")
    print(region_sales.to_string())

Вывод, скажем:

    Region
    East     45600
    North    37800
    South    41200
    West     39000

Модель-ассистент ответит: *“Продажи по регионам распределились следующим образом: East – 45 600, North – 37 800, South – 41 200, West – 39 000 (единиц). Больше всего продаж в регионе East, меньше всего – в North. Ниже приведён график для наглядности:”* (и приложенное изображение столбчатой диаграммы).

Как видим, агент-аналитик способен выполнять вычисления и предоставлять отчёты, которые были бы трудоёмки при ручном подсчёте. При этом все примеры работают в России благодаря использованию EssayAI proxy (мы в коде указываем `openai.api_base = "https://api.essayai.ru/v1"` для всех вызовов модели, так что запросы пойдут через российский сервер).

**Подход "живой, прикладной":** Мы не просто рассказали теорию, а фактически создали рабочий прототип аналитического модуля. Такие агенты уже сейчас (в 2025 году) внедряются в инструментах для аналитиков. Например, OpenAI выпустил Advanced Data Analysis (бывший Code Interpreter), позволяющий людям без навыков программирования делать анализ данных с помощью GPT-4. Наш агент повторяет ту же идею в продуктовой форме, интегрируемой в чат-бота.

На этом этапе важно также отметить ограничения: модель может ошибаться в коде (например, неправильно назвать колонку или сделать опечатку). Поэтому, в идеале, наш агент должен уметь обрабатывать ошибки выполнения: если скрипт дал ошибку, передать её модели и попробовать исправить. (Мы это можем реализовать через цикл retry: поймали исключение -> послали модели сообщение об ошибке -> она поправила код). В рамках учебного модуля 5 мы не углублялись в это, но имейте в виду как возможность. **Guardrails** для кода мы детально обсудим далее – в следующем уроке.

Итак, мы получили второго важного помощника – **агент для анализа CSV с Pandas**. Пора позаботиться о безопасности: ограничить его возможности, чтобы он не натворил бед.
