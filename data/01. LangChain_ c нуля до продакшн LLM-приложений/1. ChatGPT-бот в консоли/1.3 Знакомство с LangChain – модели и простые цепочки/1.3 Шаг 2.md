## 🔹 Простейшая цепочка Prompt → LLM → Output

На этом шаге мы разберём создание простейшей цепочки (**Chain**), основного концепта фреймворка langchain, суть которого кратко мы описывали на предыдущем шаге

Самая простая цепочка – это подача промпта в LLM и получающая ответ. В актуальной версии фреймворка для этого используется класс **RunnableSequence**

 

### 🔸**Шаги для создания и использования цепочки**

1. **Определить шаблон промпта.** Например, мы хотим, чтобы модель объяснила какое-то понятие простыми словами. Создадим шаблон: *"Объясни простыми словами, что такое {question}"*  
Здесь `{question}` – это переменная. В **ChatPromptTemplate** мы зададём эту переменную, а вдальнейшем при вызове эта переменная будет заменятся строкой из запроса.

    from langchain_core.prompts import ChatPromptTemplate

    prompt = ChatPromptTemplate.from_template("Объясни простыми словами, что такое {question}")

  Теперь `prompt` – объект, который умеет принять конкретный `question` и выдать готовую строку. Например *"Объясни простыми словами, что такое машинное обучение."*, если в запросе будет указано *машинное обучение*

2. **Создать объект модели.** Возьмем, например, `ChatOpenAI` (для GPT-4o).

    from langchain_openai import ChatOpenAI

    model = ChatOpenAI(model="gpt-4o", temperature=0)

  Здесь мы ставим temperature=0 для максимальной детерминированности ответа (чтобы не расплывался). Объект model готов к использованию.

3. **Создать цепочку (Chain).**

    fromlangchain_core.runnables import RunnableSequence

        chain= RunnableSequence(first=prompt, last=model)

  Теперь `chain` – связывает наш шаблон и модель.

4. **Вызвать цепочку с конкретным входом**

  Для нашего шаблона требуется переменная `"question"`. Значит:

    result = chain.invoke({"question": "машинное обучение"})
    print(result.content)

  LangChain сам возьмет шаблон, подставит `question="машинное обучение"`, получит строчку `"Объясни простыми словами, что такое машинное обучение."`, затем вызовет модель `model` с этим промптом. Модель вернет ответ вроде `"Машинное обучение – это ... "`). **RunnableSequence** вернёт именно содержимое ответа. В `result.content` будет строка с объяснением. Мы ее печатаем.

 

### 🔸**Изменение параметров**

Мы указали `temperature=0`, чтобы ответ был более определенным. Попробуйте поменять на `1` и запустить код несколько раз – могут различаться формулировки ответа (он станет более творческим, но и менее стабильным). Это демонстрирует, что **RunnableSequence** не мешает нам контролировать параметры модели – мы задаем их при создании model.

Если бы шаблон имел несколько переменных, `ChatPromptTemplate.from_template("переменная 1: {var1}, переменная 2: {var2}")` , то и `chain.invoke()` нужно было бы вызывать со всеми аргументами. `chain.invoke({"var1": "один", "var2": "два"})`

 

### 🔸**Вызов модели напрямую vs через RunnableSequence**

Можно отметить, что мы могли не использовать **RunnableSequence**, а делать:

    prompt = template.invoke({"question": "машинное обучение"})
    response = model.invoke(prompt)

и получить тот же результат.

Да, LangChain допускает и так. Но при усложнении цепочек (несколько шагов, memory, обработка результата) выгоднее сразу держать всё в цепочке.

**RunnableSequence** обеспечитвает единообразие: вы всегда вызываете `.invoke()` вне зависимости от того, что внутри – один LLM или сложная последовательность. Позже, если нужно будет поменять логику (например, добавить memory), вы модифицируете `chain`, а код вызова останется `chain.invoke(...)`.

 

### 🔸**Дополнительный пример (для практики)**

Создайте другой шаблон – например, простой переводчик:

    from langchain_core.prompts import ChatPromptTemplate
    from langchain_openai import ChatOpenAI
    from langchain_core.runnables import RunnableSequence

    prompt = ChatPromptTemplate.from_template("Переведи на английский: {текст}")

    model = ChatOpenAI(model="gpt-4o", temperature=0)

    chain = RunnableSequence(first=prompt, last=model)

    result = chain.invoke({"текст": "Доброе утро"})
    print(result.content)

Ожидаемый ответ – `"Good morning"` (GPT-4o с temperature 0 даст прямой перевод). Так мы убедимся, что можно переиспользовать **RunnableSequence** с разными шаблонами.
> 💡 Обратите внимание, мы можем писать шаблон в том числе и название переменных в шаблоне на русском и модель понимает их, потому что GPT-4o владеет русским языком. **LangChain** не привязан к языку – шаблоны могут быть на любом языке, главное, чтобы модель понимала
