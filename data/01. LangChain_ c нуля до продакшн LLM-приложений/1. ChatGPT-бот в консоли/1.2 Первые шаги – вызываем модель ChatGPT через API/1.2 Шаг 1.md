## 🔹 Подготовка окружения

Перед началом работы с LangChain важно убедиться, что всё необходимое установлено и настроено корректно. Этот урок поможет вам подготовить систему, окружение и инструменты, чтобы без проблем проходить курс и запускать примеры кода.

### 🔸 Требования к знаниям

Для комфортного прохождения курса студент должен:

- Владеть **Python** на уровне **уверенного пользователя** (работа с функциями, классами, импортами, базовыми библиотеками);

- Понимать основы **работы с API** и **JSON**;

- Уметь пользоваться **терминалом** и **виртуальными окружениями** (`venv` или `poetry`);

- Иметь базовое представление о **pip** и **установке зависимостей.**

### 🔸 Подготовка виртуального окружения

Чтобы ваш проект не конфликтовал с другими и было проще управлять зависимостями, **рекомендуется создать виртуальное окружение**. В Python есть несколько подходов, два популярных – стандартный `venv` и менеджер пакетов **Poetry**. Рассмотрим оба:

- **Виртуальное окружение (venv)**  
Это встроенный инструмент Python. Откройте терминал в папке вашего проекта (где лежит README и планируется код). Выполните команду для создания окружения:

    python -m venv .venv

  Здесь `venv` после -m модуль для создания окружения, а `.venv` – имя папки, куда оно будет установлено (можете назвать по-другому, но принято `.venv` или `venv`). После выполнения у вас появится папка `.venv` с локальной копией интерпретатора и pip. Теперь активируйте окружение:

  После активации в начале строки терминала вы увидите название окружения. Теперь все `pip install` будут ставиться локально, в эту папку, не затрагивая глобальные пакеты.

  - `source .venv/bin/activate` Linux/Mac

  - `.venv\Scripts\activate.bat` Windows (CMD)

  - `.venv\Scripts\Activate.ps1` Windows (PowerShell)

  - `source .venv/Scripts/activate` Windows (bash)

- **Poetry**

  Это более продвинутый инструмент, который управляет зависимостями и виртуальным окружением, используя файл `pyproject.toml`

  Если вы хотите использовать Poetry, сначала установите его:

    pip install poetry
> или по инструкции с официального сайта

  В папке проекта выполните:

    poetry init

  Эта команда проведет интерактивную настройку проекта спросит имя, версию Python, зависимости (пока можно пропустить или указать openai) и создаст `pyproject.toml`.

  После этого можно создать окружение и установить зависимости (если указали):

    poetry install

  и активировать окружение

    poetry shell

Оба подхода хороши. Если вы новичок, стандартный `venv` может быть понятнее, а Poetry дает больше автоматизации. Выберите один способ и доведите его до конца.
> ⚠️ **Важно:** после активации окружения у вас должна работать команда `pip` (или `poetry add`), устанавливающая пакеты локально в виртуальном окружении, и команда `python` должна ссылаться на версию внутри окружения.

### 🔸 Установка пакетов

Официальная библиотека называется просто **openai.** На момент 2025 года она поддерживает работу с актуальными моделями (GPT-4o, GPT-5) и различными функциями API. Мы будем использовать ее для отправки запросов ChatCompletion (диалоговый формат) и, возможно, других запросов позже. Установим её через менеджер пакетов:
> 💡 так же если вы планируете хранить ключи и другие переменные в `.env` файле рекомендуем сразу установить и **python-dotenv** через менеджер пакетов. Эта маленькая библиотека облегчит загрузку переменных окружения из файла, как обсуждали ранее. Без нее можно обойтись, но вручную парсить .env неудобно

**С pip:**

Создайте файл `requirements.txt` со следующим содержимым:

    langchain==1.0.3
    langchain-community==0.4.1
    langchain-huggingface==1.0.1
    langchain-openai==1.0.2
    langgraph==1.0.2
    openai==2.7.1
    pydantic==2.12.3
    python-dotenv==1.2.1
    PyYAML==6.0.3
    requests==2.32.5

Установите зависимости одной командой: `pip install -r requirements.txt `

**С poetry:**

    poetry add \
        langchain==1.0.3 \
        langchain-community==0.4.1 \
        langchain-huggingface==1.0.1 \
        langchain-openai==1.0.2 \
        langgraph==1.0.2 \
        openai==2.7.1 \
        pydantic==2.12.3 \
        python-dotenv==1.2.1 \
        PyYAML==6.0.3 \
        requests==2.32.5
> 💡 Так же по аналогии устанавливаются и другие пакеты в виртуальное окружение

**Для проверки установок запустите Python код:**

    import openai

    print(openai.__version__)

или в командной строке можно ввести

    pip show openai

Аналогично можно проверить версии (и не только в случае с `show`) других библиотек. Также убедитесь, что установка прошла в вашем виртуальном окружении: если деактивировать окружение и в глобальном Python попробовать `openai`, он не должен находиться (если раньше не ставили глобально). Это подтверждает изоляцию окружения.

 

### 🔸 **Структура проекта**

На данный момент у вас в папке проекта должны быть: `.env` (с вашими ключами) и окружение (папка `.venv` или файлы Poetry: `pyproject.toml` и т.д.). Код мы еще не писали. Рекомендуется создать подпапку (например, `src` или `app`) для исходников, либо писать скрипты прямо в корне – на ваше усмотрение. В учебном проекте можно и в корне, но следите, чтобы имена файлов не конфликтовали с названиями пакетов (например, не называйте файл `openai.py`).
> ⚠️ При использовании Git для контроля версий, не забудьте добавить `.env` и `.venv/` в `.gitignore`
