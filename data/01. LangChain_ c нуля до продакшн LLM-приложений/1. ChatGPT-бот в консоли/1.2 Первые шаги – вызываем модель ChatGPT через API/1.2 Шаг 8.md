### 📝 Задание: Создайте простой скрипт для работы с LLM

Вам нужно дополнить код программы, которая делает запрос к языковой модели и выводит ответ.

**Что нужно сделать:**

1. Создайте OpenAI клиента, используя функцию `create_client()` (она уже реализована для вас)
2. Выполните запрос к модели через `responses.create()` со следующими параметрами:
  - `model` — используйте переменную `MODEL_NAME`
  - `instructions` — передайте системную инструкцию из переменной `SYSTEM_PROMPT`
  - `input` — передайте пользовательский запрос из переменной `user_query`
3. Получите текст ответа из объекта ответа (используйте атрибут `output_text`)
4. Выведите **только текст ответа** (без дополнительной информации)


**Подсказки:**

- Клиент создаётся так: `client = create_client()`
- У клиента есть атрибут `responses` с методом `create()`
- Результат имеет атрибут `output_text`, который содержит текст ответа модели
- Используйте `.strip()` для удаления лишних пробелов
> ⚠️ Библиотеки в коде являются имитацией раельных библиотек в ввиду того что на платформе stepik нет возможности импортирования реальных библиотек. В имитированных библиотеках реализован лишь базовый функционал необходимый для этого задания.
