## 🔹 PromptTemplate / ChatPromptTemplate

На этом этапе мы познакомимся с инструментами LangChain для создания шаблонов промптов — классами `PromptTemplate` и `ChatPromptTemplate`. Разберём их отличия, научимся создавать многоразовые шаблоны запросов и узнаем, в каких случаях целесообразнее использовать каждый из них.

В предыдущем уроке мы писали промпты вручную, вставляя переменные прямо в строку. LangChain упрощает эту задачу, предоставляя специальные классы:

- **PromptTemplate** – шаблон для *однострочного* текстового промпта. Используется в ситуациях, когда модель принимает единичное текстовое сообщение (например, старые GPT‑3 модели). Вы задаёте строку-шаблон с плейсхолдерами (например, `{topic}`, `{user_input}`), а затем подставляете конкретные значения через метод `format` или `invoke`.
- **ChatPromptTemplate** – шаблон для моделей чат-формата, которые работают с последовательностью сообщений (с ролями вроде system, human, ai). С его помощью можно определить шаблоны сразу для нескольких сообщений (например: системное сообщение → пользовательское сообщение → модель → пользовательское). Затем метод `format_messages` или `format_prompt` возвращает список сообщений с подставленными значениями переменных, пригодный для вызова чат-модели. Работает именно с `Message objects` и может использовать разные форматы входа.


Использование шаблонов даёт ряд преимуществ: код становится чище (шаблон можно определить один раз и переиспользовать), уменьшается вероятность допустить синтаксическую ошибку в строке, проще управлять версионностью промптов. Вместо конкатенации строк или вставки через f‑строки вы оперируете объектом шаблона.

 

### 🔸 Пример (PromptTemplate)

    from langchain_core.prompts import PromptTemplate

    template_str = "Ты опытный переводчик. Переведи текст с английского на русский:\n\"{input_text}\""
    template = PromptTemplate.from_template(template_str)

    # Вариант 1 — format (возвращает просто строку)
    prompt_text = template.format(input_text="Hello, world!")
    print('format result:', prompt_text)

    # Вариант 2 — invoke (возвращает объект типа StringPromptValue)
    prompt_strobj = template.invoke({"input_text": "Hello, world!"})
    print('invoke result:', prompt_strobj)
    print(type(prompt_strobj))

**Вывод:**

    format result: Ты опытный переводчик. Переведи текст с английского на русский:
    "Hello, world!"
    invoke result: text='Ты опытный переводчик. Переведи текст с английского на русский:\n"Hello, world!"'
    <class 'langchain_core.prompt_values.StringPromptValue'>

**Заметьте:** внутри шаблона используется переменная `{input_text}`.  
Для подстановки этой переменной:

- в метод **`format()`** передаются **именованные аргументы** по имени этих переменных

- в метод **`invoke()`** передаётся **словарь**, где ключи совпадают с именами переменных
> 💡 Если пропустить переменную или указать неверное имя — LangChain выдаст понятное сообщение об ошибке, что упрощает отладку.

в отличии от метода **`format()`**, который просто подставляет в шаблон нужные куски текста и возвращает нам строку, метод **`invoke()`** возвращает специальный объект типа `StringPromptValue`
> 💡 Метод`.from_template()` позволяет более кратко создать шаблон с переменными, этот метод автоматически считывает их из фигурных скобок:
>
> prompt = PromptTemplate.from_template("Вопрос: {question}")
>
> Это аналогично вот такой записи:
>
> prompt = PromptTemplate(
> template="Вопрос: {question}",
> input_variables=["question"]
> )
>
> Если это простой шаблон с переменными, то короче записать через `PromptTemplate.from_template()`, а если нужно указывать дополнительные аргументы, то нужно использовать `PromptTemplate()`

 

### 🔸 Пример (ChatPromptTemplate)

    from langchain_core.prompts import (
        ChatPromptTemplate,
        SystemMessagePromptTemplate,
        HumanMessagePromptTemplate
    )

    # Создаём шаблон чата с системным и пользовательским сообщением
    chat_template = ChatPromptTemplate.from_messages([
        SystemMessagePromptTemplate.from_template("Ты — опытный переводчик."),
        HumanMessagePromptTemplate.from_template("Переведи текст с английского на русский:\n\"{input_text}\"")
    ])

    # Вариант 1 — format_messages (возвращает список сообщений/объектов для модели)
    messages_list = chat_template.format_messages(input_text="Hello, world!")
    print("format_messages result:", messages_list)

    # Вариант 2 — invoke (возвращает объект ChatPromptValue со списком внутри него)
    prompt_chatobj = chat_template.invoke({"input_text": "Hello, world!"})
    print("invoke result:", prompt_chatobj)
    print(type(prompt_chatobj))


**Вывод:**

    format_messages result: [SystemMessage(content='Ты — опытный переводчик.', additional_kwargs={}, response_metadata={}), HumanMessage(content='Переведи текст с английского на русский:\n"Hello, world!"', additional_kwargs={}, response_metadata={})]
    invoke result: messages=[SystemMessage(content='Ты — опытный переводчик.', additional_kwargs={}, response_metadata={}), HumanMessage(content='Переведи текст с английского на русский:\n"Hello, world!"', additional_kwargs={}, response_metadata={})]
    <class 'langchain_core.prompt_values.ChatPromptValue'>

Здесь мы создали шаблон из двух сообщений:

- системного (с фиксированной ролью «Ты – опытный переводчик.»)
- пользовательского (с плейсхолдером для текста)


Разница между **`format_messages()`** и **`invoke()`** аналогично предыдущему примеру, с той лишь разницей что первый обрабатывает строки и объекты по очереди и выводит их в списке, а второй создаёт специальные объект типа `ChatPromptValue`

Модель получит структурированный промпт с разделением роли, что предпочтительно при использовании GPT‑5/ GPT‑4o.

Для передачи в модель `ChatOpenAI` можно использовать любой из описанных выше вариантов промпта

    from langchain_openai import ChatOpenAI

    llm = ChatOpenAI(model_name="gpt-5")

    for prompt in [prompt_text, prompt_strobj, messages_list, prompt_chatobj]:
        response = llm.invoke(prompt)
        print(response.content)

Ответ `response.content` будет переводом строки "Hello, world!" на русский.

 

### 🔸 Технические детали

`PromptTemplate` и `ChatPromptTemplate` под капотом похожи – второй по сути содержит набор PromptTemplate для разных ролей. LangChain также предоставляет методы сериализации шаблонов (сохранения в файл JSON/YAML) и загрузки обратно. Это пригодится, если вы захотите вынести промпты в конфиги.

`StringPromptValue` и `ChatPromptValue` — это **универсальные контейнеры** для готового промпта.  
Они позволяют передавать промпты в модель или цепочку без забот о формате, обеспечивая совместимость, читаемость и надёжность кода. Если вам понадобится достать из этих объектов строку или список сообщений, то у них есть методы `.to_string()` и `.to_messages()`

 

### 🔸 Рекомендации

Начинайте любую автоматизацию с создания шаблонов. Даже если задача кажется разовой, оберните промпт в `PromptTemplate` – это не только удобство, но и дисциплина: вы явно перечисляете, какие переменные ожидаются, что предотвращает многие ошибки. Давайте шаблонам понятные имена – промпты будут расти и важно не запутаться. В дальнейшем вы сможете собирать из шаблонов более сложные цепочки, подключать версии промптов и т.д.

Шаблоны сообщений (ChatPromptTemplate) особенно полезны, когда нужно динамически менять части системных инструкций или добавлять сообщения – они помогут не «захардкодить» лишнего.
