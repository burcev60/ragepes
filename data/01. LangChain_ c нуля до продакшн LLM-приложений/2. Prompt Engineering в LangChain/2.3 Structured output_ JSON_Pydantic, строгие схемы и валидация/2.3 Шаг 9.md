## 🔹 Задание — скрипт API, отдающий валидный JSON

Вам предстоит создадть мини‑API (или консольный скрипт), который будет вызывать модель и гарантировать возврат результата в виде валидного JSON по заданной схеме.

 

### 🔸 Что предстоит сделать

1. Скрипт принимает входные данные (параметр командной строки, `input()`, чтение из файла или фиксированный в коде). Для примера спросим название города.
2. Формируем запрос к модели через LangChain: `PromptTemplate` и `PydanticOutputParser`
3. Модель должна вернуть JSON, соответствующий схеме. Например, погода:

    class WeatherInfo(BaseModel):
        city: str
        temperature: float
        condition: str

1. Парсим и валидируем через Pydantic. Если валидация прошла – получаем объект.
2. Выводим результат в виде JSON. Для этого в Pydantic V2 нужно использовать метод `.model_dump_json()`.
3. Добавляем обработку ошибок `try`/`except`. В случае ошибки выводим JSON с полем `error`, например: `{"error": "Invalid response format"}`. ​​​​​Опционально можно повторить вызов или вывести пояснение для отладки.
