### 🔹 Практическое задание:

Вам предстоит реализовать чтение промптов из внешнего YAML-файла с промптами.

Структура файла следующая:

    support_answer:
      current: v2
      versions:
        v1: |
          Ты – помощник...
          (старый вариант)
        v2: |
          Ты – помощник...
          (новый вариант)

Чтение из YAML-файла уже произведено в переменную `data`:

    import yaml

    with open("prompts.yaml", "r", encoding="utf-8") as f:
        data = yaml.safe_load(f)

### 🔸Задание

Реализуйте функцию `get_prompt(data, prompt_name, version=None)`, которая:

- Принимает `data` — словарь, полученный из YAML-файла
- Принимает `prompt_name` — название промпта (например, `"support_answer"`)
- Принимает `version` — опциональный параметр версии (например, `"v1"` или `"v2"`)
- Если `version` не указан или равен `None`, возвращает текущую версию промпта (указанную в поле `current`)
- Возвращает текст промпта в виде строки


### 🔸Примеры

    # Если version не указан, вернёт v2 (текущая версия)
    get_prompt(data, "support_answer")  # вернёт текст v2

    # Если version указан явно
    get_prompt(data, "support_answer", "v1")  # вернёт текст v1
    get_prompt(data, "support_answer", "v2")  # вернёт текст v2
