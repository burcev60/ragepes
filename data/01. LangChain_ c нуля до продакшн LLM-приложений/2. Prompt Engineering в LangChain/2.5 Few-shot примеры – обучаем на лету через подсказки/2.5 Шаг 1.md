## 🔹 Что такое Few-shot метод?

Подход *few-shot* — это обучение на лету через примеры в подсказке, он позволяет показать модели несколько пар «вопрос‑ответ» перед новым запросом, тем самым задавая ей формат и стиль ответа без изменения весов модели и повышая качество ответов.

### 🔸Суть подхода

Few-shot prompting основан на том, что в запрос (prompt) к модели включаются несколько примеров входных данных и ожидаемых ответов. Таким образом, модель не обучается заранее на отдельном датасете, а получает «обучение на лету» прямо внутри запроса. Эти примеры показывают ей формат, стиль и логику решения задачи.

Например, если нужно, чтобы модель выдавала ответ в виде таблицы, списка или текста в определённом стиле, достаточно привести 2–3 готовых примера — и новый ответ, с высокой вероятностью, будет следовать этому шаблону.

**Few-shot** подсказки особенно полезны, когда обычного **zero-shot** режима (только инструкция без примеров) недостаточно — например, при сложных рассуждениях, специфических форматах или нестандартном стиле ответа.

Современные модели (GPT-4o, GPT-5 и др.) обладают развитым **in-context learning** — они способны извлекать закономерности и шаги решения прямо из предоставленных примеров, повышая качество результата без дообучения.

Такие промпты занимают промежуточное место между zero-shot запросами и полноценным обучением модели. Мы не меняем веса модели, но демонстрируем, каким образом нужно отвечать. Это позволяет повысить точность и снизить количество ошибок на специализированных задачах.

### 🔸Технические особенности

Few-shot примеры занимают часть **контекстного окна** модели: ту область, где хранятся данные запроса и ответа. Поэтому чем больше примеров, тем меньше остаётся места для самого ввода.  
На практике используют **от 1 до 5 примеров** — этого достаточно, чтобы задать направление, не выходя за пределы контекста.

Так как few-shot не изменяет параметры модели, метод подходит для:

- задач с малым количеством данных;

- быстрого тестирования нового формата ответов;

- прототипирования без обучения.

Контекстные окна современных моделей (например, у GPT-5) стали значительно шире, что позволяет использовать больше примеров. Однако важно учитывать **стоимость токенов**: каждый добавленный пример увеличивает цену и время отклика.

### 🔸Практические примеры

1. **Структурированные ответы.**  
Если нужно получать ответы в формате JSON, достаточно привести 1–2 пары «запрос → JSON-ответ». После этого модель начнёт стабильно воспроизводить нужный формат.

2. **Математика и логика.**  
Несколько решённых примеров с пошаговым объяснением помогают модели освоить логику рассуждений и применять её к новым задачам.

3. **Юридические, медицинские и научные ответы.**  
Даже 2–3 тщательно подобранных примера задают нужную терминологию и стиль, что повышает точность и профессиональность ответов.

4. **Работа с кодом.**  
В системах вроде кодовых интерпретаторов few-shot особенно полезен: добавив пары «код с ошибкой → исправленный код», мы задаём модели формат патча, а не текстового объяснения.

### 🔸Реализация в **LangChain**

В фреймворке LangChain, **few-shot** подход реализуется через класс **`FewShotPromptTemplate()`**. Такой подход упрощает создание промптов с примерами и обеспечивает совместимость с актуальными моделями OpenAI.

    import os
    from dotenv import load_dotenv
    from langchain_core.prompts import PromptTemplate, FewShotPromptTemplate
    from langchain_openai import ChatOpenAI

    load_dotenv()
    MODEL = os.getenv("OPENAI_API_MODEL", "gpt-5")

    llm = ChatOpenAI(model=MODEL, temperature=0)

    example_prompt = PromptTemplate.from_template(
        "Ввод: {input}\nВывод: {output}"
    )

    examples = [
        {"input": "happy", "output": "sad"},
        {"input": "tall", "output": "short"}
    ]

    prompt = FewShotPromptTemplate(
        examples=examples,
        example_prompt=example_prompt,
        prefix="Дайте антоним каждого слова:",
        suffix="Ввод: {input}\nВывод:",
        input_variables=["input"]
    )

    formatted_prompt = prompt.format(input="young")
    response = llm.invoke(formatted_prompt)

    print(response.content) # Вывод: old

Тут мы:

1. Определяем шаблон одного примера `example_prompt`, через **`PromptTemplate()`** (**`Ввод → Вывод`**).

2. Задаём список **few-shot** примеров `examples`: пары слов и их антонимов.

3. Формируем **few-shot** промпт `prompt` через **`FewShotPromptTemplate()`**, объединяя примеры с префиксом и суффиксом, где `{input}` — переменная запроса.

4. Генерируем новый запрос для слова `"young"` с использованием LLM и получаем ответ `"old"`.

 

### 🔸Рекомендации

- **Выбирайте релевантные примеры.** Они должны точно соответствовать задаче.

- **Избегайте ошибок.** Модель перенимает неточности из примеров.

- **Минимизируйте объём.** Примеры должны быть короткими и по существу.

Когда few-shot **не стоит применять**:

- При наличии большого набора однотипных данных (лучше fine-tuning или retrieval);

- Если запросы короткие, а примеры слишком объёмные (высокие издержки по токенам).
