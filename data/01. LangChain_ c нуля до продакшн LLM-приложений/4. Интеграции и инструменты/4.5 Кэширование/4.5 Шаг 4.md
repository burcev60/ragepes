**Шаг 4: Артефакт: кэш-слой с конфигом**  
*Цель шага:* Реализовать модуль кэширования с возможностью настройки (какие типы данных кэшировать, размер TTL, размер кэша). Получить артефакт – например, `cache.py`, и продемонстрировать его использование в нашем проекте.

**Объяснение:**  
Мы создаём модуль `cache.py` с классами или функциями для различных кэшей:

- `EmbeddingCache`: словарь для эмбеддингов с методами `get(text)` и `set(text, embedding)`. Внутри хранит хэш текста -> вектор. Можно использовать `functools.lru_cache` декоратор для простоты (например, пометив функцию, генерирующую эмбеддинг, декоратором – Python сам будет кэшировать по аргументу). Но нам нужно и persistence (сохранение на диск) возможно, тогда придётся вручную. В учебном проекте можно не сохранять на диск, просто в памяти, либо в pickle по завершении.

- `ResponseCache`: для ответов. Может быть выключен по умолчанию, или ограничен. Например, используем только если `len(question) < 100 символов` (короткие FAQ). В методе `get_answer(q)` возвращаем сохранённый ответ если есть. TTL можно хранить вместе с записью: сохранить время кэширования и при чтении проверять, не прошло ли больше TTL.

- `SearchCache`: мы уже делали – хранит результаты веб-поиска.

Сделаем возможность конфигурации через константы или файл: e.g. `CACHE_EMBEDDINGS=True`, `EMBEDDING_CACHE_SIZE=10000`, `RESPONSE_CACHE_TTL=86400` (сутки) и т.п.

В основном коде, при инициализации системы, выводим: "Embedding cache enabled, max 10000 entries, will use MD5 keys." Пользователь (разработчик) сможет менять эти настройки, например отключить кэш, если отладка нужна (кэш иногда мешает видеть изменения).

**Тесты артефакта:**  
Мы проверили, что при повторном запросе эмбеддинга одного и того же текста, функция генерации вызывается один раз, второй – берётся мгновенно из кэша. Проверили, что удаление документа из базы вызывает `cache.invalidate(hash(doc))`.

**Пример использования:**  
В коде ретривера:

    vector = embedding_cache.get(text_chunk)
    if vector is None:
        vector = embedder.embed(text_chunk)
        embedding_cache.set(text_chunk, vector)
    vector_list.append(vector)

Или, ещё проще, использовать caching-обёртку: `embed_query = lru_cache(maxsize=10000)(embedder.embed_query)` – это автоматически кеширует по значению аргумента.

К финалу урока у нас есть полноценный **кэш-слой**, который ускорит повторные действия. Мы добавили соответствующие сообщения в observability: можно логировать hit/miss (промахи/попадания) для кэша. Например, "Embeddings cache: 10 hits, 2 misses". Это показывает эффективность.

В реальной работе, кэш значительно экономит средства на API и улучшает отзывчивость. Но требуются хорошие стратегии – что мы и потренировались продумывать: как долго хранить, что делать при обновлении. Теперь наша система стала умнее: не будет тратить ресурс на одни и те же вычисления.

    # cache.py
    from __future__ import annotations

    import hashlib
    import pickle
    import threading
    import time
    from dataclasses import dataclass, field
    from typing import Any, Callable, Dict, Iterable, List, Optional, Tuple
    from collections import OrderedDict
    import os
    import json

    # =========================
    # Конфиг
    # =========================

    @dataclass
    class CacheConfig:
        # Embeddings
        embeddings_enabled: bool = True
        embeddings_capacity: int = 10_000
        embeddings_ttl_sec: Optional[float] = None  # обычно None (эмбеддинги детерминированы)
        embeddings_persist_path: Optional[str] = None  # "emb_cache.pkl"

        # Responses (FAQ/короткие ответы)
        responses_enabled: bool = True
        responses_capacity: int = 5_000
        responses_ttl_sec: float = 24 * 60 * 60  # сутки
        responses_max_q_len: int = 120  # кэшируем только короткие запросы

        # Web search
        search_enabled: bool = True
        search_capacity: int = 1_000
        search_ttl_sec: float = 60 * 60  # час


    # =========================
    # Общая реализация LRU+TTL
    # =========================

    @dataclass
    class CacheStats:
        hits: int = 0
        misses: int = 0
        puts: int = 0
        evictions: int = 0

        def as_dict(self) -> Dict[str, int]:
            return dict(hits=self.hits, misses=self.misses, puts=self.puts, evictions=self.evictions)


    class LruTtlCache:
        """Потокобезопасный LRU-кэш с TTL."""
        def __init__(self, capacity: int, ttl_sec: Optional[float] = None) -> None:
            self.capacity = int(capacity)
            self.ttl_sec = ttl_sec
            self._store: "OrderedDict[str, Tuple[Optional[float], Any]]" = OrderedDict()
            self._lock = threading.RLock()
            self.stats = CacheStats()

        def _now(self) -> float:
            return time.time()

        def _is_expired(self, expiry: Optional[float]) -> bool:
            return expiry is not None and self._now() > expiry

        def _expire_and_prune(self) -> None:
            """Удаляет протухшие записи и лишние (LRU)."""
            with self._lock:
                # убрать протухшие
                to_del = [k for k, (exp, _) in self._store.items() if self._is_expired(exp)]
                for k in to_del:
                    self._store.pop(k, None)
                # LRU эвикции
                while len(self._store) > self.capacity:
                    self._store.popitem(last=False)  # самый старый
                    self.stats.evictions += 1

        def clear(self) -> None:
            with self._lock:
                self._store.clear()

        def get(self, key: str) -> Optional[Any]:
            with self._lock:
                item = self._store.get(key)
                if item is None:
                    self.stats.misses += 1
                    return None
                exp, val = item
                if self._is_expired(exp):
                    self._store.pop(key, None)
                    self.stats.misses += 1
                    return None
                # bump по LRU
                self._store.move_to_end(key, last=True)
                self.stats.hits += 1
                return val

        def set(self, key: str, value: Any) -> None:
            with self._lock:
                exp = (self._now() + self.ttl_sec) if self.ttl_sec is not None else None
                self._store[key] = (exp, value)
                self._store.move_to_end(key, last=True)
                self.stats.puts += 1
                self._expire_and_prune()

        def invalidate(self, key: str) -> None:
            with self._lock:
                self._store.pop(key, None)

        def size(self) -> int:
            with self._lock:
                return len(self._store)

        def snapshot(self) -> Dict[str, Any]:
            with self._lock:
                return {
                    "size": len(self._store),
                    "capacity": self.capacity,
                    "ttl_sec": self.ttl_sec,
                    "stats": self.stats.as_dict(),
                }


    # =========================
    # Вспомогательные ключи
    # =========================

    def md5_key(*parts: str) -> str:
        h = hashlib.md5()
        for p in parts:
            h.update((p or "").encode("utf-8"))
            h.update(b"\x1f")  # разделитель
        return h.hexdigest()


    # =========================
    # EmbeddingCache
    # =========================

    class EmbeddingCache:
        def __init__(self, cfg: CacheConfig) -> None:
            self.enabled = cfg.embeddings_enabled
            self._cache = LruTtlCache(cfg.embeddings_capacity, cfg.embeddings_ttl_sec)
            self.persist_path = cfg.embeddings_persist_path
            # ленивый автозагруз
            if self.persist_path and os.path.exists(self.persist_path):
                try:
                    self.load(self.persist_path)
                except Exception:
                    pass  # не валим приложение из-за испорченного файла

        def _k(self, text: str, *, model: Optional[str] = None, namespace: Optional[str] = None) -> str:
            return md5_key("emb", model or "", namespace or "", text)

        def get(self, text: str, *, model: Optional[str] = None, namespace: Optional[str] = None) -> Optional[Any]:
            if not self.enabled:
                return None
            return self._cache.get(self._k(text, model=model, namespace=namespace))

        def set(self, text: str, vector: Any, *, model: Optional[str] = None, namespace: Optional[str] = None) -> None:
            if not self.enabled:
                return
            self._cache.set(self._k(text, model=model, namespace=namespace), vector)

        def invalidate_text(self, text: str, *, model: Optional[str] = None, namespace: Optional[str] = None) -> None:
            self._cache.invalidate(self._k(text, model=model, namespace=namespace))

        def stats(self) -> Dict[str, Any]:
            return self._cache.snapshot()

        # персист
        def save(self, path: Optional[str] = None) -> None:
            if not path:
                path = self.persist_path
            if not path:
                return
            blob = {
                "meta": {"version": 1},
                "cache": list(self._cache._store.items()),
                "stats": self._cache.stats.as_dict(),
            }
            with open(path, "wb") as f:
                pickle.dump(blob, f)

        def load(self, path: Optional[str] = None) -> None:
            if not path:
                path = self.persist_path
            if not path or not os.path.exists(path):
                return
            with open(path, "rb") as f:
                blob = pickle.load(f)
            # мягко загружаем
            items: List[Tuple[str, Tuple[Optional[float], Any]]] = blob.get("cache", [])
            self._cache._store = OrderedDict(items)


    # =========================
    # ResponseCache
    # =========================

    class ResponseCache:
        def __init__(self, cfg: CacheConfig) -> None:
            self.enabled = cfg.responses_enabled
            self.max_q_len = cfg.responses_max_q_len
            self._cache = LruTtlCache(cfg.responses_capacity, cfg.responses_ttl_sec)

        def _k(self, question: str, *, model: Optional[str] = None, namespace: Optional[str] = None) -> str:
            qn = (question or "").strip()
            return md5_key("resp", model or "", namespace or "", qn)

        def get(self, question: str, *, model: Optional[str] = None, namespace: Optional[str] = None) -> Optional[str]:
            if not self.enabled:
                return None
            if len((question or "")) > self.max_q_len:
                return None
            return self._cache.get(self._k(question, model=model, namespace=namespace))

        def set(self, question: str, answer: str, *, model: Optional[str] = None, namespace: Optional[str] = None) -> None:
            if not self.enabled:
                return
            if len((question or "")) > self.max_q_len:
                return
            self._cache.set(self._k(question, model=model, namespace=namespace), answer)

        def stats(self) -> Dict[str, Any]:
            return self._cache.snapshot()


    # =========================
    # SearchCache (веб-поиск)
    # =========================

    class SearchCache:
        def __init__(self, cfg: CacheConfig) -> None:
            self.enabled = cfg.search_enabled
            self._cache = LruTtlCache(cfg.search_capacity, cfg.search_ttl_sec)

        def _k(self, query: str, *, k: int = 5, provider: str = "ddg") -> str:
            return md5_key("search", provider, str(k), (query or "").strip())

        def get(self, query: str, *, k: int = 5, provider: str = "ddg") -> Optional[List[Dict[str, str]]]:
            if not self.enabled:
                return None
            return self._cache.get(self._k(query, k=k, provider=provider))

        def set(self, query: str, results: List[Dict[str, str]], *, k: int = 5, provider: str = "ddg") -> None:
            if not self.enabled:
                return
            self._cache.set(self._k(query, k=k, provider=provider), results)

        def stats(self) -> Dict[str, Any]:
            return self._cache.snapshot()


    # =========================
    # Удобные обёртки
    # =========================

    def wrap_embedder(embed_func: Callable[[str], Any],
                      emb_cache: EmbeddingCache,
                      *,
                      model: Optional[str] = None,
                      namespace: Optional[str] = None) -> Callable[[str], Any]:
        """
        Оборачивает embed_func так, чтобы кэшировать по тексту.
        """
        def _wrapped(text: str) -> Any:
            hit = emb_cache.get(text, model=model, namespace=namespace)
            if hit is not None:
                return hit
            vec = embed_func(text)
            emb_cache.set(text, vec, model=model, namespace=namespace)
            return vec
        return _wrapped

    def example_retriever_usage():
        """
        Пример нарезки текста на чанки и эмбеддинга с использованием EmbeddingCache.
        """
        cfg = CacheConfig()
        emb_cache = EmbeddingCache(cfg)

        # фейковый эмбеддер (дорогая функция)
        calls = {"n": 0}

        def fake_embed(txt: str) -> List[float]:
            time.sleep(0.05)  # имитация сетевого вызова
            calls["n"] += 1
            # простая "проекция"
            return [float((sum(map(ord, txt)) % 100) / 100.0)]

        embed = wrap_embedder(fake_embed, emb_cache, model="demo-emb")

        chunks = ["alpha", "beta", "gamma", "alpha", "beta", "delta"]
        vectors: List[List[float]] = []
        t0 = time.time()
        for c in chunks:
            vectors.append(embed(c))
        dt = time.time() - t0

        print("Vectors:", vectors)
        print("Embedder calls:", calls["n"], "(ожидаем 4, т.к. два хита по кэшу)")
        print("Embeddings cache stats:", json.dumps(emb_cache.stats(), ensure_ascii=False, indent=2))
        print(f"Elapsed: {dt:.3f}s")


    def example_search_usage():
        """
        Пример кэширования веб-поиска: второй вызов — мгновенный hit.
        """
        cfg = CacheConfig()
        s_cache = SearchCache(cfg)

        def fake_search(query: str, k: int = 3) -> List[Dict[str, str]]:
            time.sleep(0.1)  # сетевой вызов
            return [{"rank": i + 1, "title": f"Result {i+1}", "url": f"https://ex/{i+1}", "snippet": "..."} for i in range(k)]

        q = "president of Brazil 2025"
        t0 = time.time()
        res = s_cache.get(q, k=3) or fake_search(q, k=3)
        if s_cache.get(q, k=3) is None:
            s_cache.set(q, res, k=3)
        t1 = time.time()

        res2 = s_cache.get(q, k=3) or fake_search(q, k=3)
        t2 = time.time()

        print("First call took:", f"{(t1 - t0)*1000:.1f} ms")
        print("Second (cached) took:", f"{(t2 - t1)*1000:.1f} ms")
        print("Search cache stats:", json.dumps(s_cache.stats(), ensure_ascii=False, indent=2))


    def example_response_usage():
        """
        Пример кэширования коротких ответов (FAQ).
        """
        cfg = CacheConfig(responses_ttl_sec=2.0)  # короткий TTL для демо
        r_cache = ResponseCache(cfg)

        q = "Когда основана компания XYZ?"
        ans = "Компания основана в 1999 году."

        print("Put →", q)
        r_cache.set(q, ans, model="gpt-4o-mini")

        print("Hit 1:", r_cache.get(q, model="gpt-4o-mini"))
        time.sleep(2.2)
        print("Hit 2 (expired → None):", r_cache.get(q, model="gpt-4o-mini"))
        print("Response cache stats:", json.dumps(r_cache.stats(), ensure_ascii=False, indent=2))
