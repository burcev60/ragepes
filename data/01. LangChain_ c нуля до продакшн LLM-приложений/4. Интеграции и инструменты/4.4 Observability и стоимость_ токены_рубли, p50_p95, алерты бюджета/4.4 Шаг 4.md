**Шаг 4: Артефакт: сбор метрик + дашборд (локально)**  
*Цель шага:* Собрать финальный артефакт – систему сбора метрик и простой дашборд (пусть даже текстовый или в консоли) для наблюдения. Продемонстрировать, как можно отслеживать состояние ассистента во время работы.

**Объяснение:**  
В артефакте мы объединяем всё, что сделали по наблюдаемости:

- Код, который при каждом запросе собирает данные (время, токены, т.д.) и обновляет глобальные метрики.

- Периодический вывод этих метрик: например, каждые 10 запросов печатать строку статистики.

- Возможность приостановить/остановить систему, если бюджет исчерпан (например, `if cost_month > BUDGET: raise SystemExit("Budget limit")` или circuit breaker на все запросы).

- (Опционально) небольшой статический HTML или Markdown отчет. Можно, например, по завершении работы программы сгенерировать Markdown-файл с итоговыми цифрами: сколько запросов, средняя латентность, топ-5 самых частых вопросов (если логировали тексты), и т.д.

Конечно, полноценный дашборд требовал бы инструмента (Grafana), но мы можем сымитировать: например, формируя ASCII-графики или таблицы в консоли. Для простоты, сделаем текстовый вывод.

**Пример итогового вывода:**

    --- Statistics (Session) ---
    Queries handled: 42
    Total tokens processed: 12345 (≈2.47 USD ≈ 222.3 руб)
    Average latency: 3.2 s
    Latency distribution: p50=2.1 s, p95=7.8 s, max=10.5 s
    Tools used: Search (10 calls), Calculator (5 calls)
    Errors: 2 (4.7%)
    -----------------------------

И рядом в логах могли бы быть предупреждения, если были.

Таким образом, у нас получился небольшой мониторинг. Даже в учебном режиме это ценно: мы увидим, сколько запросы стоят, как быстро отвечают, где узкие места. В реальной системе эти данные отправляются в системы наблюдения, на основе которых настраиваются авто-алерты (смс дежурному) и принимаются решения по оптимизации (например, если p95 слишком высокий – возможно, надо ускорять ретривер или кэшировать больше). Мы создали базис для такого анализа внутри нашего проекта.

    # metrics_dashboard.py
    from __future__ import annotations

    import time
    import json
    import math
    import atexit
    import statistics as stats
    from dataclasses import dataclass, field
    from typing import Dict, Any, List, Optional, Tuple, Callable
    from contextlib import contextmanager
    from collections import Counter, defaultdict

    # ===== (опционально) грубая оценка токенов =====
    # если tiktoken установлен — считаем точно, иначе приближенно chars/4
    def estimate_tokens(text: str, model_hint: str | None = None) -> int:
        try:
            import tiktoken  # type: ignore
            enc = tiktoken.get_encoding("cl100k_base")
            return len(enc.encode(text))
        except Exception:
            # приближенно: 1 токен ≈ 4 символа
            return max(1, math.ceil(len(text) / 4))


    # ===== Конфигурация и типы =====
    @dataclass
    class Price:
        # стоимость в USD за 1k токенов
        input_per_1k: float
        output_per_1k: float

    @dataclass
    class MetricsConfig:
        session_name: str = "local-dev"
        snapshot_every_n_queries: int = 10
        budget_usd_month: Optional[float] = None  # например, 50.0; если None — бюджета нет
        usd_to_rub: float = 90.0                  # грубо; для печати
        model_prices: Dict[str, Price] = field(default_factory=dict)  # {"gpt-4o-mini": Price(0.15,0.60)}

    class BudgetLimitReached(Exception):
        pass


    # ===== Реестр метрик =====
    @dataclass
    class MetricsRegistry:
        cfg: MetricsConfig = field(default_factory=MetricsConfig)

        # counters
        queries_total: int = 0
        errors_total: int = 0

        tokens_in: int = 0
        tokens_out: int = 0
        cost_usd: float = 0.0

        # latency storage (секунды)
        latencies: List[float] = field(default_factory=list)

        # инструменты и типы событий
        tools_calls: Counter = field(default_factory=Counter)            # {"web_search": 12, ...}
        tools_errors: Counter = field(default_factory=Counter)           # {"web_search": 2, ...}
        models_calls: Counter = field(default_factory=Counter)           # {"gpt-4o-mini": 8, ...}

        # топ частых вопросов (или нормализованных intent'ов)
        top_queries: Counter = field(default_factory=Counter)

        # расширенный лог по событиям (опционально)
        events: List[Dict[str, Any]] = field(default_factory=list)

        def _maybe_snapshot(self) -> None:
            if self.queries_total % self.cfg.snapshot_every_n_queries == 0:
                print(self.render_snapshot())

            if self.cfg.budget_usd_month is not None and self.cost_usd > self.cfg.budget_usd_month:
                msg = f"[BUDGET] Monthly budget exceeded: ${self.cost_usd:.2f} > ${self.cfg.budget_usd_month:.2f}"
                print(msg)
                raise BudgetLimitReached(msg)

        def record_query(
            self,
            *,
            query: str,
            model: Optional[str],
            latency_s: float,
            prompt_tokens: int,
            completion_tokens: int,
            ok: bool,
            error_type: Optional[str] = None,
        ) -> None:
            self.queries_total += 1
            self.tokens_in += prompt_tokens
            self.tokens_out += completion_tokens
            self.latencies.append(float(latency_s))
            if not ok:
                self.errors_total += 1
            if model:
                self.models_calls[model] += 1
                self._acc_cost(model, prompt_tokens, completion_tokens)

            # для «топ вопросов» — храните укороченную форму
            normalized = (query or "").strip().lower()[:120]
            if normalized:
                self.top_queries[normalized] += 1

            self.events.append({
                "type": "query",
                "ts": time.time(),
                "query": query,
                "model": model,
                "latency_s": latency_s,
                "ok": ok,
                "error_type": error_type,
                "prompt_tokens": prompt_tokens,
                "completion_tokens": completion_tokens,
            })
            self._maybe_snapshot()

        def record_tool(
            self,
            *,
            name: str,
            latency_s: float,
            ok: bool,
            error_type: Optional[str] = None,
        ) -> None:
            self.tools_calls[name] += 1
            if not ok:
                self.tools_errors[name] += 1
            self.events.append({
                "type": "tool",
                "ts": time.time(),
                "tool": name,
                "latency_s": latency_s,
                "ok": ok,
                "error_type": error_type,
            })

        def _acc_cost(self, model: str, prompt_toks: int, completion_toks: int) -> None:
            price = self.cfg.model_prices.get(model)
            if not price:
                return  # цены не заданы — пропускаем оценку
            self.cost_usd += (prompt_toks / 1000.0) * price.input_per_1k
            self.cost_usd += (completion_toks / 1000.0) * price.output_per_1k

        # --- отрисовка «дашборда» ---
        def render_snapshot(self) -> str:
            if self.latencies:
                p50 = percentile(self.latencies, 50)
                p95 = percentile(self.latencies, 95)
                p99 = percentile(self.latencies, 99)
                mx = max(self.latencies)
                avg = sum(self.latencies) / len(self.latencies)
            else:
                p50 = p95 = p99 = mx = avg = 0.0

            rub = self.cost_usd * self.cfg.usd_to_rub
            tools_used = ", ".join(f"{k}({v})" for k, v in self.tools_calls.most_common()) or "—"
            tools_errs = ", ".join(f"{k}({v})" for k, v in self.tools_errors.most_common()) or "—"
            models = ", ".join(f"{k}({v})" for k, v in self.models_calls.most_common()) or "—"

            lines = [
                "\n--- Statistics (Session) ---",
                f"Session: {self.cfg.session_name}",
                f"Queries handled: {self.queries_total}",
                f"Total tokens: in={self.tokens_in} out={self.tokens_out}",
                f"Estimated cost: ${self.cost_usd:.2f} (≈{rub:.1f} RUB)",
                f"Latency: avg={avg:.2f}s p50={p50:.2f}s p95={p95:.2f}s p99={p99:.2f}s max={mx:.2f}s",
                f"Models: {models}",
                f"Tools used: {tools_used}",
                f"Tools errors: {tools_errs}",
                f"Errors: {self.errors_total} ({pct(self.errors_total, max(1,self.queries_total)):.1f}%)",
                "-----------------------------",
            ]
            return "\n".join(lines)

        # --- финальный Markdown отчёт ---
        def write_markdown_report(self, path: str = "metrics_report.md") -> str:
            if self.latencies:
                p50 = percentile(self.latencies, 50); p95 = percentile(self.latencies, 95)
                p99 = percentile(self.latencies, 99); mx = max(self.latencies)
                avg = sum(self.latencies)/len(self.latencies)
            else:
                p50 = p95 = p99 = mx = avg = 0.0

            rub = self.cost_usd * self.cfg.usd_to_rub

            def table_from_counter(c: Counter, header: Tuple[str,str]) -> str:
                if not c: return "_нет_"
                rows = "\n".join(f"| {k} | {v} |" for k,v in c.most_common())
                return f"| {header[0]} | {header[1]} |\n|---|---|\n{rows}"

            md = []
            md.append(f"# Metrics Report — **{self.cfg.session_name}**\n")
            md.append("## Summary\n")
            md.append(f"- Queries: **{self.queries_total}**")
            md.append(f"- Tokens: in=**{self.tokens_in}**, out=**{self.tokens_out}**")
            md.append(f"- Cost: **${self.cost_usd:.2f}** (≈{rub:.1f} RUB)\n")
            md.append("## Latency\n")
            md.append(f"- avg={avg:.2f}s, p50={p50:.2f}s, p95={p95:.2f}s, p99={p99:.2f}s, max={mx:.2f}s\n")
            md.append("## Models\n")
            md.append(table_from_counter(self.models_calls, ("model","calls")) + "\n")
            md.append("## Tools\n")
            md.append(table_from_counter(self.tools_calls, ("tool","calls")) + "\n")
            md.append("## Errors\n")
            md.append(f"- Total: **{self.errors_total}**")
            md.append(table_from_counter(self.tools_errors, ("tool","errors")) + "\n")
            md.append("## Top queries\n")
            md.append(table_from_counter(self.top_queries, ("query","count")) + "\n")
            md.append("## Raw events (truncated)\n")
            sample = self.events[-50:] if len(self.events)>50 else self.events
            md.append("```json\n" + json.dumps(sample, ensure_ascii=False, indent=2) + "\n```\n")

            content = "\n".join(md)
            with open(path, "w", encoding="utf-8") as f:
                f.write(content)
            return path


    # ===== Удобные контекст-менеджеры =====
    @contextmanager
    def measure_latency(callback: Callable[[float], None]):
        t0 = time.time()
        try:
            yield
        finally:
            callback(time.time() - t0)


    # ===== Процентили/утилиты =====
    def percentile(arr: List[float], p: float) -> float:
        if not arr: return 0.0
        a = sorted(arr)
        k = (len(a) - 1) * (p/100.0)
        f, c = math.floor(k), math.ceil(k)
        if f == c: return a[int(k)]
        return a[f] + (a[c] - a[f]) * (k - f)

    def pct(part: int, whole: int) -> float:
        return (part / whole) * 100.0 if whole else 0.0


    # ===== Интеграция: обёртка LLM-вызова =====
    def call_llm_with_metrics(
        *,
        send_func: Callable[[str], str],      # например, LLMClient.send_request
        meter: MetricsRegistry,
        model_name: str,
        prompt: str,
        completion_text: Optional[str] = None # если известен ответ до вычисления токенов
    ) -> str:
        prompt_toks = estimate_tokens(prompt, model_hint=model_name)
        ok, err = True, None
        out = ""
        with measure_latency(lambda dt: meter.record_query(
            query=prompt, model=model_name, latency_s=dt,
            prompt_tokens=prompt_toks, completion_tokens=estimate_tokens(out or completion_text or "", model_hint=model_name),
            ok=ok, error_type=err
        )):
            try:
                out = send_func(prompt)
                return out
            except Exception as e:
                ok, err = False, type(e).__name__
                raise
            finally:
                # обновим completion_tokens по фактическому out (если был успешный ответ)
                if out:
                    meter.tokens_out += max(0, estimate_tokens(out, model_hint=model_name) - estimate_tokens(completion_text or "", model_hint=model_name))
