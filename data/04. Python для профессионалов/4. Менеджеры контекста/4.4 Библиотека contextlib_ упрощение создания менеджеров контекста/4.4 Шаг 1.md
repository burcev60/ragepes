Python предоставляет модуль `contextlib`, облегчающий работу с менеджерами контекста.

Одним из наиболее полезных инструментов является декоратор `@contextmanager`, который позволяет написать функцию-генератор вместо полного определения класса с `__enter__`/`__exit__`. Функция-генератор должна выполнить действия до `yield` (это будет код при входе в контекст) и после `yield` (код при выходе).

Пример эквивалента класса `Timer` с использованием `contextlib.contextmanager`:

    from contextlib import contextmanager
    import time

    @contextmanager
    def timer():
        start = time.time()
        try:
            yield  # точка передачи управления в блок with
        finally:
            end = time.time()
            interval = end - start
            print(f"Блок кода выполнялся {interval:.4f} секунд")

    # Использование:
    with timer():
        # код, время выполнения которого измеряется
        total = sum(i*i for i in range(1000000))

Здесь функция `timer` обрамлена декоратором `@contextmanager`. До `yield` мы зафиксировали время начала. Когда выполнение переходит в блок `with`, наша функция приостанавливается на строке `yield`. После выхода из блока управление возвращается и выполняется код после `yield` (в блоке `finally` для гарантированного выполнения). Таким образом, автоматически выводится время выполнения блока.

Обратите внимание:

- Используем конструкцию `try/finally` вокруг `yield`, чтобы гарантировать, что завершающий код выполнится независимо от исключений.

- Если нужно вернуть значение, которое будет привязано к переменной после `as`, можно указать его в `yield`. Например: `val = yield some_value`.

Модуль `contextlib` также предоставляет:

- `contextlib.ExitStack` – менеджер контекста, позволяющий динамически создавать и управлять **множеством** менеджеров контекста. Полезно, когда количество ресурсов, которые нужно открыть, зависит от условий (например, неизвестно заранее, сколько файлов надо открыть – можно добавлять их в ExitStack).

- Контекстные менеджеры для перенаправления вывода: `contextlib.redirect_stdout` и `redirect_stderr` для временного перенаправления потока вывода (например, записать все, что печатается, в файл).

- `contextlib.suppress` – контекстный менеджер, подавляющий указанные исключения. Например, `with suppress(FileNotFoundError): ...` выполнит блок, игнорируя `FileNotFoundError` если он возникнет.

Менеджеры контекста – мощный инструмент управления ресурсами и поведением "входа/выхода" из блока кода. Они позволяют обезопасить код от утечек ресурсов и сократить шаблонные конструкции (открытие/закрытие, acquire/release). В следующем модуле мы рассмотрим асинхронное программирование с использованием `async/await` и библиотеки `asyncio`, которое в некотором смысле является развитием идей генераторов и требует понимания работы событийного цикла.
