Рассмотрим пример использования менеджера контекста с файлом:

    with open("data.txt", "r") as f:
        data = f.read()
        # здесь файл открыт и доступен как f
    # здесь (после блока) файл автоматически закрыт

В этом коде вызов `open("data.txt", "r")` возвращает объект файла, который реализует методы `__enter__` и `__exit__`. При входе в `with` файл открывается (фактически `open` уже вернул открытый файл, а `__enter__` обычно просто возвращает сам файл). После выполнения блока `with` (чтения файла), `__exit__` автоматически вызовет `f.close()`.

Преимущество такого подхода – гарантированное освобождение ресурса (закрытие файла) даже если внутри блока произойдет ошибка. Например, если во время чтения возникнет исключение, `__exit__` все равно выполнится (закрыв файл), затем исключение будет "проброшено" дальше вверх по коду.

Другие примеры встроенных менеджеров контекста:

- Объект `threading.Lock` предоставляет менеджер контекста: при входе выполняется `lock.acquire()`, при выходе `lock.release()`. Таким образом, можно писать `with lock: ...` для автоматического захвата и освобождения блокировки.

- Функция `open` мы уже рассмотрели.

- Функция `decimal.localcontext()` из модуля `decimal` создает контекст с локальными настройками (точностью и т.п.) для вычислений с десятичными числами, при выходе восстанавливает предыдущий контекст.
