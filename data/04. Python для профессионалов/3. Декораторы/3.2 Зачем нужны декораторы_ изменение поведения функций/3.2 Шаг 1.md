**Декоратор** – это функция, которая принимает другую функцию и возвращает новую функцию, обычно расширяющую поведение исходной. Декораторы позволяют добавить к функциям дополнительную функциональность (например, логирование, контроль доступа, измерение времени выполнения, кэширование результатов и т.д.), не изменяя исходный код декорируемой функции.

Ключевая идея: мы определяем функцию-декоратор, которая обёртывает исходную функцию в новую функцию-«обёртку». Эта обёртка вызывает исходную функцию, а вокруг этого вызова выполняет какие-то дополнительные действия.

Начнём с простого примера: пусть у нас есть функция, которая печатает приветствие, и мы хотим автоматически печатать до и после неё какие-то отладочные сообщения.

    def greet(name):
        print(f"Привет, {name}!")

    # Определим декоратор
    def debug_decorator(func):
        def wrapper(*args, **kwargs):
            print(f"[DEBUG] Вызываем функцию {func.__name__} с аргументами {args} {kwargs}")
            result = func(*args, **kwargs)
            print(f"[DEBUG] Функция {func.__name__} выполнена, результат: {result}")
            return result
        return wrapper

    # Используем декоратор
    greet = debug_decorator(greet)
    greet("Мир")

При выполнении этого кода мы получим вывод:

    [DEBUG] Вызываем функцию greet с аргументами ('Мир',) {}
    Привет, Мир!
    [DEBUG] Функция greet выполнена, результат: None

Разберёмся, что произошло. Функция `debug_decorator` принимает функцию `func` и внутри определяет функцию `wrapper`, которая обёртывает вызов `func`: печатает отладочное сообщение перед и после вызова, и возвращает результат вызова `func`. Затем `debug_decorator` возвращает функцию-обёртку `wrapper`. Мы присваиваем `greet = debug_decorator(greet)`, то есть заменяем оригинальную функцию `greet` на её обёрнутую версию. Теперь `greet("Мир")` фактически вызывает `wrapper("Мир")` внутри декоратора.

Этот шаблон – определение декоратора, внутри которого определяется функция-обёртка – является основой для всех декораторов.
