Реализуйте декоратор `debug`, который при каждом вызове декорируемой функции печатает отладочную информацию: имя функции, переданные ей аргументы и результат вызова. Декоратор должен работать с функциями любой арности. Формат вывода отладки точно такой:

    [DEBUG] Вызываем: <имя функции>(<арг1>, <арг2>, ..., <аргN>)
    [DEBUG] Результат: <результат>

После определения декоратора примените его к функции `add(a, b)`, которая возвращает сумму a+b. Затем считайте два числа из ввода, вызовите `add` и выведите результат (при этом декоратор выведет отладочные сообщения).

**Формат ввода:** Два целых числа через пробел.  
**Формат вывода:** Сначала две строки отладки, затем сумма двух чисел.
