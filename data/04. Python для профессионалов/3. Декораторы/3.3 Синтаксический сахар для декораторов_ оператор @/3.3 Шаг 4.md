Реализуйте декоратор `counter`, который считает количество вызовов декорируемой функции. При каждом вызове функция должна печатать сообщение:

`[DEBUG] Функция <имя> вызвана <N> раз(а) `

После этого функция возвращает свой обычный результат.  
В основной программе:

1. Считайте одну строку с двумя целыми числами через пробел.

2. Определите функцию `multiply(a, b)`, которая возвращает произведение, и оберните её декоратором `@counter`.

3. Вызовите `multiply(a, b)` дважды и выведите оба результата.
