В Python для удобства применения декораторов существует специальный синтаксис – аннотация с помощью символа `@`. Вместо явного присваивания `func = decorator(func)` мы можем использовать `@decorator` перед определением функции.

Перепишем пример с декоратором `debug_decorator` с использованием синтаксического сахара:

    def debug_decorator(func):
        def wrapper(*args, **kwargs):
            print(f"[DEBUG] Вызываем функцию {func.__name__} с аргументами {args} {kwargs}")
            result = func(*args, **kwargs)
            print(f"[DEBUG] Функция {func.__name__} выполнена, результат: {result}")
            return result
        return wrapper

    @debug_decorator
    def greet(name):
        print(f"Привет, {name}!")

    greet("Python")

Когда интерпретатор встречает `@debug_decorator` над определением функции `greet`, он автоматически применяет функцию-декоратор к определяемой функция. То есть это эквивалентно `greet = debug_decorator(greet)`. После этого вызов `greet("Python")` будет проходить через декоратор.

Декораторы можно **наслаивать** друг на друга. Если над функцией указано несколько декораторов, то они применяются сверху вниз (ближайший к функции – применяется последним). Например:

    @decorator1
    @decorator2
    def func():
        pass

Эквивалентно `func = decorator1(decorator2(func))`. Нужно быть внимательным с порядком, особенно если декораторы делают что-то существенное с входными или выходными данными.

Ещё один важный аспект – сохранение метаданных функции. После декорирования оригинальная функция обычно теряет своё имя и документацию, так как её место занимает функция-обёртка. Чтобы этого избежать, используют декоратор `functools.wraps` из стандартной библиотеки. Он копирует имя, строку документации и другие атрибуты функции в обёртку.

Пример использования `functools.wraps`:

    import functools

    def debug_decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            print(f"[DEBUG] Вызов {func.__name__}")
            result = func(*args, **kwargs)
            print(f"[DEBUG] Завершение {func.__name__}")
            return result
        return wrapper

    @debug_decorator
    def add(a, b):
        """Возвращает сумму двух чисел."""
        return a + b

    print(add.__name__)  # Выведет "add", а не "wrapper"
    print(add.__doc__)   # Выведет "Возвращает сумму двух чисел."

Здесь декоратор `debug_decorator` помечает свою обёртку `wrapper` с помощью `@functools.wraps(func)`. Это гарантирует, что атрибуты `__name__`, `__doc__` и другие важные метаданные копируются из `func` в `wrapper`. Без этого `add.__name__` был бы "wrapper", и документация потерялась бы.
