Напишите функцию `make_adder(a)`, которая создает и возвращает функцию `adder(b)`, прибавляющую к числу `b` заранее заданное число `a`. То есть вызов `make_adder(5)` должен вернуть функцию, которая прибавляет 5 к любому числу. После определения `make_adder`, программа должна прочитать из ввода два числа: первое — значение `a` для создания функции, второе — число `b`, которое нужно преобразовать. Программа должна вывести результат вызова созданной функции с аргументом `b`.

**Примечание:** Не вычисляйте сумму сразу — необходимо сначала получить функцию через `make_adder`, а затем вызвать ее.

**Формат ввода:** Два целых числа `a` и `b` через пробел.  
**Формат вывода:** Одно целое число — результат `a + b`.
