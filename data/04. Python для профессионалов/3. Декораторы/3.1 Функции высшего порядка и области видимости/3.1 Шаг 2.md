### FAQ:
> Справочник будет пополняться новыми вопросами из комментариев к уроку.

**1. Что делает функцию «высшего порядка»?**  
Функция считается высшего порядка, если она **принимает** другую функцию как аргумент **или** **возвращает** функцию.

    def apply(func, value):
        return func(value)          # ← принимает функцию

    def make_adder(a):
        def adder(b):               # ← возвращает функцию
            return a + b
        return adder

**2. В Python функции действительно такие же объекты, как строки и списки?**  
Да. Они:

- присваиваются переменным (`f = print`),

- передаются как аргументы,

- хранятся в структурах данных,

- возвращаются из других функций.  
Это свойство называют *функции первого класса* (first-class functions).

**3. Чем вложенная функция отличается от замыкания (closure)?**

- **Вложенная функция** — определена внутри другой функции.

- **Замыкание** — вложенная функция, которая **удерживает** ссылки на переменные из внешней области видимости после завершения внешней функции.

    def outer():
        x = 10
        def inner():          # ← вложенная
            return x          # ← захватывает x → замыкание
        return inner

**4. Где физически хранятся захваченные переменные?**  
Python создаёт для них *cell-объекты*; посмотреть можно так:

    adder = make_adder(5)
    adder.__closure__[0].cell_contents   # => 5

Каждый вызов внешней функции создаёт **новый** набор ячеек, поэтому два замыкания независимы.

**5. Как внутри замыкания изменить захваченную переменную?**  
Используйте ключевое слово `nonlocal`:

    def counter():
        n = 0
        def inc():
            nonlocal n
            n += 1
            return n
        return inc

Без `nonlocal` присваивание создало бы новую локальную переменную, а не изменило захваченную.

**6. Почему в цикле замыкания часто «запоминают» последнее значение?**

    funcs = []
    for i in range(3):
        funcs.append(lambda: i)   # все вернут 2

Все лямбды ссылаются на **одну** ячейку `i`, которая после цикла стала равна 2. Решение — «зафиксировать» текущее значение в параметре по умолчанию:

    funcs.append(lambda i=i: i)

**7. Замыкания — это дорого?**  
Нет: захватываются **ссылки**, а не копии данных. Однако если вы удерживаете в замыкании объёмные структуры (списки, DataFrame), они будут жить, пока живёт функция-замыкание.
