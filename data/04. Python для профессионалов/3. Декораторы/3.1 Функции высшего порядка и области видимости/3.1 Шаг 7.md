Реализуйте функцию `compose(f, g)`, которая возвращает новую функцию-композицию двух функций `f` и `g`: результатом вызова композиции должна быть подача результата функции `g` в функцию `f`. Например, если `f(x) = x*2`, а `g(x) = x+3`, то `compose(f,g)(5)` сначала вычислит `g(5) = 8`, а потом `f(8) = 16`.

Далее, в основной программе, прочитайте входные данные: сначала строку с кодом функции `f` (например, `lambda x: x*2`), затем строку с кодом функции `g`. Эти строки можно преобразовать с помощью функции `eval` в реальные функции. После этого прочитайте число `x` и выведите результат `compose(f,g)(x)`.

**Формат ввода:**

- Первая строка: выражение для анонимной функции `f` (например, `lambda x: x**2`).

- Вторая строка: выражение для анонимной функции `g`.

- Третья строка: число (целое или вещественное), которое нужно подставить.

**Формат вывода:** Результат применения композиции `f(g(x))`. Если результат – вещественное число, вывести как есть (может быть `float`).
