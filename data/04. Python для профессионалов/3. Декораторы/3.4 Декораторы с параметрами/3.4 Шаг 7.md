Реализуйте декоратор с параметрами `repeat(n)`, который принимает целое число `n` и заставляет декорируемую функцию вызываться `n` раз подряд, возвращая результат последнего вызова.  
В основной программе:

1. Считайте одну строку с двумя числами через пробел: первое – аргумент для функции, второе – значение `n` для повторения.

2. Определите функцию `square(x)`, которая возвращает квадрат числа x, и оберните её декоратором `@repeat(n)`.

3. Вызовите функцию и верните результат.
