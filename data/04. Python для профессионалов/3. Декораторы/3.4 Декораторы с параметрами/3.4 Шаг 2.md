### FAQ

*Справочник пополняется вопросами из комментариев.*

1. **Зачем превращать декоратор в «фабрику» (декоратор с параметрами)?**  
Чтобы одной логикой управлять множеством функций, не создавая десятки похожих декораторов.  
`@cache(seconds=60)`, `@retry(times=3, delay=1)`, `@timing(dp=4)` —
 все они делаются одним шаблоном «функция → возвращает декоратор».
2. **Как понять порядок вызовов при `@timing(5)`?**  
Синтаксис разворачивается в два шага:  

    compute = timing(5)(compute)
               └───┬────┘ └─┬───┘
               фабрика      декоратор

1) вызывается `timing(5)` → возвращает `decorator`  
2) `decorator` оборачивает `compute`.

3. **Почему внутри `decorator` всё ещё нужен `wrapper`?**  
Фабрика передаёт параметры (например, `decimal_places`),  
а `wrapper` уже обрабатывает *каждый* вызов исходной функции, сохраняя доступ к
 захваченным значениям через замыкание.
4. **Можно ли забыть круглые скобки и написать `@timing`?**  
Можно — тогда вызов фабрики не произойдёт, и в качестве
 декоратора в функцию передастся сама `timing`, что почти всегда приведёт
 к ошибке `'function' object is not callable`.
 Поэтому для параметризованных декораторов скобки обязательны, даже если параметров нет: `@mydecorator()`.
5. **Нужно ли применять `functools.wraps` и где?**  
Да, внутри самого *настоящего* декоратора:

    def timing(dp=3):
        def decorator(func):
            @wraps(func)          # ← здесь!
            def wrapper(*a, **kw):
                ...
            return wrapper
        return decorator
  

Это сохранит `__name__`, `__doc__`, аннотации и делает стек-трейсы понятнее.

6. **Как передать несколько параметров с разными именами?**  
Просто укажите их в фабрике с дефолтами:

    def log(level="INFO", *, to_file=False):
        ...
  

Ключевое слово `*` защищает аргументы от позиционного использования, делая
 вызовы читаемыми: `@log(level="DEBUG", to_file=True)`.

7. **Можно ли создать параметризованный декоратор как класс?**  
Да: реализуйте `__init__(self, ...)` для параметров и `__call__(self, func)` — тогда экземпляр класса будет вести себя
 как декоратор. Внутри `__call__` верните функцию-обёртку.
8. **Как комбинируются два параметризованных декоратора?**  
Точно так же, как обычные:

    @retry(times=3)
    @timing(dp=4)
    def f(): ...
    # порядок: f = retry(3)( timing(4)( f ) )
  

Сначала вызываются фабрики (`retry(3)`, `timing(4)`), затем
 оборачивают функцию согласно стеку `@`.
