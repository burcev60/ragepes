Иногда возникает необходимость параметризовать декоратор – например, делать логирование с разным уровнем детализации, или кэшировать определённое количество последних вызовов. Для этого декоратор нужно определить как функцию, которая возвращает функцию-декоратор.

То есть нам понадобится **фабрика декораторов**: функция, принимающая параметры декорации и возвращающая собственно декоратор (функцию, которая будет применяться к функции).

Рассмотрим пример: декоратор, выводящий время выполнения функции. Мы хотим иметь возможность настраивать, сколько знаков после запятой показывать в секундах.

    import time

    def timing(decimal_places=3):
        def decorator(func):
            def wrapper(*args, **kwargs):
                start = time.time()
                result = func(*args, **kwargs)
                end = time.time()
                duration = end - start
                print(f"Функция {func.__name__} заняла {duration:.{decimal_places}f} секунд")
                return result
            return wrapper
        return decorator

    @timing(decimal_places=5)
    def compute(n):
        # Некоторая вычислительно трудоёмкая задача
        total = 0
        for i in range(n):
            total += i*i
        return total

    compute(1000000)

Здесь `timing` – функция, которая при вызове возвращает конкретный декоратор `decorator` с захваченной переменной `decimal_places`. Внутри `decorator` мы определяем `wrapper` как обычно. Использование `@timing(decimal_places=5)` декорирует функцию `compute` так, что при каждом её вызове будет выводиться время работы, форматированное с 5 знаками после точки.

Обратите внимание: `@timing(decimal_places=5)` – это синтаксический сахар для `compute = timing(decimal_places=5)(compute)`. То есть сначала вызывается `timing(5)`, возвращается функция-декоратор `decorator`, которая потом применяется к `compute`.

Такая конструкция "функция, возвращающая декоратор" позволяет создавать очень гибкие декораторы. Например, можно сделать декоратор, который логирует вызовы только определённых типов или пропускает вызов в зависимости от условий.
