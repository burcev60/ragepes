Декораторы можно применять не только к функциям, но и к методам в классах, и даже к самим классам.

**Декораторы методов.** По сути, метод — это функция, привязанная к экземпляру. Когда мы пишем декоратор над методом класса, он получает на вход функцию (несвязанный метод) и должен вернуть функцию. Все механизмы те же самые. Стоит помнить, что декорированный метод всё ещё будет получать `self` как первый аргумент при вызове из экземпляра.

Например, можно сделать декоратор, который регистрирует вызов метода в каком-то логе:

    def log_method(func):
        def wrapper(self, *args, **kwargs):
            print(f"Лог: вызов метода {func.__name__} у экземпляра {self}")
            return func(self, *args, **kwargs)
        return wrapper

    class MyClass:
        def __init__(self, x):
            self.x = x

        @log_method
        def do_something(self, value):
            print(f"Выполнение do_something: {value}, x = {self.x}")

    obj = MyClass(10)
    obj.do_something(5)

При вызове `obj.do_something(5)` мы увидим:

    Лог: вызов метода do_something у экземпляра <__main__.MyClass object at 0x...>
    Выполнение do_something: 5, x = 10

Наш декоратор `log_method` добавил печать до выполнения метода, получив доступ к `self` и аргументам.

**Декораторы классов.** Python позволяет определять декораторы, которые принимают класс и возвращают изменённый класс. Синтаксис аналогичен декорированию функций, только объектом декорирования выступает класс.

Для чего это может использоваться:

- Регистрация класса в каком-то реестре (например, автоматически записывать класс в глобальный словарь по имени).

- Добавление или изменение атрибутов класса.

- Динамическое изменение базового класса или внедрение миксинов.

Пример: декоратор класса, который добавляет ему новый метод или атрибут.

    def add_repr(cls):
        # Добавим классу стандартный __repr__, если не определен
        if "__repr__" not in cls.__dict__:
            def __repr__(self):
                return f"<{cls.__name__} object at {id(self):#x}>"
            cls.__repr__ = __repr__
        return cls

    @add_repr
    class Point:
        def __init__(self, x, y):
            self.x = x
            self.y = y

    p = Point(2, 3)
    print(p)  # Выведет что-то вроде <Point object at 0x7f...>

Здесь `add_repr` получает на вход класс `Point`, проверяет, есть ли у него метод `__repr__`. Если нет – добавляет стандартную реализацию. Возвращённый модифицированный класс заменяет оригинальный `Point`. После этого экземпляры `Point` имеют метод `__repr__`, хотя в исходном определении класса его не было.

Стоит отметить, что для декораторов классов нет специального встроенного синтаксического сахара, кроме самого `@decorator` перед объявлением класса.

Кроме того, многие встроенные декораторы (например, `@staticmethod`, `@classmethod`, `@property`) – это специальные объекты, которые используют либо технику декорирования, либо дескрипторы, чтобы изменить поведение методов внутри класса:

- `@staticmethod` и `@classmethod` – это по сути вызываемые объекты (не совсем функции) которые при применении к функции возвращают объект-дескриптор. `staticmethod` просто помечает функцию как статическую (без `self`), а `classmethod` преобразует функцию так, что первым аргументом будет класс (`cls`) вместо экземпляра.

- `@property` – использует протокол дескриптора, чтобы сделать метод класса атрибутом, вычисляемым при доступе.

Эти встроенные механизмы мы рассмотрим подробнее (дескрипторы – в разделе про метапрограммирование), но важно понимать, что они также вписываются в общую концепцию декораторов: изменить или расширить поведение функций/методов (или классов).
