Python 3.9 представил ряд удобных фич:

- **Объединение словарей (PEP 584)**: появились операторы `|` и `|=` для словарей.

    a = {"x": 1, "y": 2}
    b = {"y": 3, "z": 4}
    c = a | b
    # c -> {"x": 1, "y": 3, "z": 4}
    a |= {"w": 0}
    # a -> {"x": 1, "y": 2, "w": 0}

При конфликте ключей в `a | b` приоритет у правого операнда (как при `dict.update`). До этого объединение словарей делалось через `{**a, **b}` или вызовом методов, новый синтаксис короче и читабельнее.

- **str.removeprefix и str.removesuffix (PEP 616)**: упрощение удаления префикса/суффикса из строки:

    "HelloWorld".removeprefix("Hello")  # "World"
    "filename.txt".removesuffix(".txt")  # "filename"

Это удобнее, чем использовать startswith/endswith и срезы.

- **Типы в контейнерах** (PEP 585) – уже упоминалось, теперь можно `list[int]`, `tuple[str, ...]` и пр.

- **zoneinfo** (PEP 615) – поддержка часовых поясов в стандартной библиотеке через `zoneinfo.ZoneInfo`.

- **functools.cached_property** – как @property, но вычисляет значение один раз и кэширует его в экземпляре (аналог часто используемого паттерна с @property и сохранением в self):

    from functools import cached_property
    class Data:
        @cached_property
        def big_computation(self):
            print("Вычисляем...")
            return sum(range(100000))

Первый доступ `obj.big_computation` вычислит значение и сохранит как обычный атрибут, последующие просто вернут сохраненное значение.

- Оптимизации внутренних структур: список, dict в 3.9 стали немного более экономичны по памяти.

Хотя эти изменения не революционные, они делают язык более удобным и выразительным.
