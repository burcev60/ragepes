PEP 570 добавил в Python синтаксис для указания **позиционных-only** параметров в определении функции. Это позволяет создавать функции, некоторые параметры которых **нельзя** передавать по имени (ключевому слову), только позиционно.

Синтаксис: в списке параметров функции можно использовать слэш (`/`), чтобы отделить позиционные-only параметры от остальных:

    def pow(x, y, /, mod=None):
        result = x ** y
        if mod:
            result %= mod
        return result

    # Вызовы:
    pow(2, 10)          # корректно
    pow(2, 10, mod=3)   # корректно
    pow(x=2, y=10)      # Ошибка: x и y должны передаваться только позиционно

Встроенные функции исторически имеют позиционные-only параметры (например, `round(x, ndigits=None)` – x нельзя передать по имени в Python 3). Теперь и пользовательские функции могут явно выражать эту идею.

Другие изменения, связанные с функциями и параметрами:

- **Keyword-only параметры** (появились еще в Python 3.0) – обозначаются `*` в списке параметров, чтобы параметры после него можно было передавать только по имени. Позиционные-only и keyword-only можно комбинировать:

    def func(x, /, y, *, z): ...

Здесь x – только позиционно, y – можно и так, и так, z – только именованно.

- **Аннотации типов**: Продолжает развиваться система типов:

  - PEP 484 (Python 3.5) и далее: возможность аннотировать параметры функций и возвращаемое значение. Эти аннотации не влияют на выполнение, но используются инструментами (mypy, IDE).

  - Python 3.9/3.10 позволили использовать встроенные коллекции в аннотациях: `list[int]` вместо `typing.List[int]`, `dict[str, int]` и т.п. (PEP 585).

  - PEP 604 (Python 3.10) – объединил `typing.Union` синтаксически: теперь можно писать `int | str` вместо `Union[int, str]`.

  - PEP 563 (Python 3.7) – предложил отложенное вычисление аннотаций (хранить их как строки). По умолчанию в 3.10 всё ещё обычное поведение (аннотации вычисляются), но можно включить отложенное через `from __future__ import annotations`. В Python 3.11 решили не делать отложенные по умолчанию, вместо этого PEP 649 предложил другой подход.

  - `typing.Annotated` (PEP 593, Python 3.9) – позволяет добавлять метаданные к аннотациям (например, диапазоны значений, подсказки для библиотек).

Аннотации типов становятся частью "современного стиля" написания Python-кода, повышая его понятность и облегчив обнаружение ошибок, хотя сам интерпретатор их не применяет для проверки.
