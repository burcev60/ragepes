Ключевое новшество в Python 3.10 – введение **структурного паттерн-сопоставления** (structural pattern matching), которое реализовано через новый оператор `match/case`. Оно позволяет сравнивать сложные структуры объектов с образцом (паттерном) и, при совпадении, выполнять соответствующий блок кода, при этом извлекая данные.

Синтаксис:

    match subject:
        case <pattern1>:
            ...  # действия, если pattern1 совпал
        case <pattern2>:
            ...  # действия, если pattern2
        case _:
            ...  # действия по умолчанию, если ничто не совпало

Pattern может быть литералом, кортежем, списком, dict, классом и др., с возможностью раздевания на переменные.

Простейший пример – замена цепочки if/elif:

    status_code = 404
    match status_code:
        case 200:
            result = "OK"
        case 400 | 404:
            result = "Bad Request / Not Found"
        case _:
            result = "Unknown"

Здесь вертикальная черта `|` используется как "или" внутри pattern.

Но возможности pattern matching гораздо шире:

- **Сопоставление последовательностей**:

    match cmd:
        case ["move", x, y]:
            print(f"Move to {x},{y}")
        case ["turn", ("left" | "right") as direction]:
            print(f"Turn {direction}")

Здесь если `cmd` список из трех элементов, первый "move", второй и третий распакуются в x и y. Во втором case cmd ожидается список из двух элементов: "turn" и кортеж, который должен быть либо "left", либо "right". `as direction` присваивает совпавшее значение в переменную direction.

- **Сопоставление dict (структур)**:

    user = {"name": "Alice", "age": 30}
    match user:
        case {"name": name, "age": age}:
            print(f"{name} is {age} years old")

Паттерн `{"name": name, "age": age}` проверит, что `user` словарь с ключами "name" и "age" (может быть и другими тоже, если нужно строго – можно добавить `*rest`).

- **WILDCARD и** `as`: `_` в паттерне значит "любое значение" (не сохраняет его). Можно писать, например, `case ("error", _)` для кортежа из 2 элементов, где первый "error", второй неважно. Можно писать переменные для захвата значений.

- **Гвардии (if условие)**:

    case {"x": x, "y": y} if x == y:
        ...

Сначала паттерн должен совпасть, потом проверяется условие `if`.

- **Шаблоны классов**: класс может участвовать, используя `__match_args__` или dataclasses.

    from dataclasses import dataclass
    @dataclass
    class Point:
        x: int
        y: int

    p = Point(1, 2)
    match p:
        case Point(x, y):
            print(f"{x=}, {y=}")

Здесь dataclass Point генерирует **match_args** = ("x", "y"), так что паттерн Point(x,y) извлекает атрибуты x и y.

Структурное сопоставление позволяет очень лаконично разбирать JSON-подобные структуры, деревья синтаксиса, AST и др. PEP 636 содержит детальное руководство с примерами.

Важно: pattern matching – это **не** просто switch-case по значению. Это более общий механизм, родственный ML-языкам (как в Rust, Scala, Haskell). Нужно потратить время, чтобы привыкнуть, но в некоторых случаях он сильно упрощает код.
