Одним из заметных новых операторов, появившихся в Python 3.8, является **оператор присваивания в выражениях**, также известный как "моржовый оператор" (`:=`). Он позволяет присвоить значение переменной прямо внутри выражения, возвращая это же значение.

До введения этого оператора нередко приходилось писать код вроде:

    data = input()
    if data:
        print(data)

Если мы хотели переиспользовать результат вычисления выражения несколько раз, приходилось делать присваивание отдельно. С `:=` можно объединить:

    if (data := input("Введите что-нибудь: ")):
        print(f"Вы ввели: {data}")

Здесь ввод сохраняется в переменную `data` и одновременно используется в условии `if`.

Другой пример – чтение из файла построчно:

    while (line := file.readline()) != "":
        process(line)

Без `:=` приходилось бы писать `line = file.readline()` перед условием и дублировать переменную внутри условия.

PEP 572 ввел этот оператор с синтаксисом `NAME := expression`. Важные детали:

- Присваивание в выражении возвращает присвоенное значение.

- Его можно использовать в контексте, где обычное присваивание синтаксически нельзя (внутри выражения, генератора, в условии).

- Следует применять оператор умеренно, когда он действительно упрощает код; в противном случае злоупотребление им может снизить читаемость.

Еще пример использования – извлечение по регулярному выражению:

    import re
    if match := re.match(r"(\w+):(\d+)", text):
        user = match.group(1)
        port = int(match.group(2))
        ...

Здесь `match` будет присвоен и проверен на истинность в одном выражении.
