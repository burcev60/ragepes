**Считайте** из ввода несколько целых чисел, по одному на строке; вход заканчивается пустой строкой.  
**Реализуйте** генератор `running_average()`, который при каждом `yield` выдаёт текущее скользящее среднее обрабатываемых чисел.  
Используйте метод `send()`: сначала вызовите `avg = running_average(); next(avg)` для инициализации, затем для каждого считанного числа `x` выполняйте `avg_val = avg.send(x)` и **собирайте** все `avg_val`.  
**Выведите** через пробел все усреднённые значения (с точностью до трёх знаков после точки).
