Напишите программу, которая читает одну строку из стандартного ввода. Эта строка содержит Python‑литерал, представляющий объект. Программа должна попытаться вызвать функцию iter() на этом объекте. Если объект итерируемый, программа должна вручную (с использованием next()) перебрать все его элементы и вывести их по одному в отдельных строках. Если объект не итерируемый, программа должна вывести сообщение:

`Объект <значение> не является итерируемым. `

где `<значение>` – исходная строка входных данных.
