Кроме функций-генераторов, Python предоставляет краткий синтаксис, похожий на списковое включение (list comprehension), для создания генераторов: **генераторные выражения**. Генераторное выражение выглядит как списковое включение, заключенное в круглые скобки вместо квадратных.

Пример спискового включения и эквивалентного ему генераторного выражения:

    # Списковое включение (list comprehension):
    squares_list = [x*x for x in range(1, 6)]
    # Генераторное выражение:
    squares_gen = (x*x for x in range(1, 6))

В первом случае `squares_list` будет сразу вычисленным списком `[1, 4, 9, 16, 25]`. Во втором случае `squares_gen` станет генератором, который сможет выдавать значения по одному. Например:

     

    print(squares_list)         # [1, 4, 9, 16, 25]
    print(squares_gen)          # <generator object <genexpr> at 0x...>
    print(list(squares_gen))    # [1, 4, 9, 16, 25]
    print(list(squares_gen))    # [] (генератор уже исчерпан)

Мы видим, что генераторное выражение не вычисляет сразу все значения, а выдает их по одному при итерации. После исчерпания (мы преобразовали генератор в список, тем самым извлекли все значения) он стал пустым.

Генераторные выражения особенно полезны, когда нужно итерировать по какому-то преобразованию последовательности, не храня все результаты в памяти. Например, если у нас очень большая последовательность, и мы хотим подсчитать сумму квадратов:

    # сумма квадратов 1..1000000 без хранения списка из миллиона элементов
    total = sum(x*x for x in range(1, 1000001))

Функция `sum` будет последовательно запрашивать элементы у генератора (через протокол итерации), и генератор будет выдавать квадраты чисел от 1 до 1000000. При этом в памяти одновременно хранится только текущее число и текущий квадрат, а не весь список квадратов.

Важно понимать разницу между списковым включением и генераторным выражением:

- Списковое включение создает полный список сразу (может занимать значительную память для больших последовательностей).

- Генераторное выражение создаёт ленивую последовательность, которую можно обходить поэлементно. Но один и тот же генератор нельзя пройти заново – после завершения итерации он пустой.
