Дан список целых чисел. Найдите с помощью генераторного выражения значение максимального разрыва между соседними элементами после сортировки списка. Другими словами, для отсортированного списка вычислите все разности `a[i+1] - a[i]` и возьмите максимальную из них. Если список содержит менее 2 элементов, выведите 0.

На вход программе поступают целые числа в одну строку. Необходимо вывести одно число — максимальный "разрыв" между соседними элементами отсортированного списка. Для решения желательно использовать генераторное выражение.

**Формат ввода:** Целые числа, разделенные пробелом (может быть одна или ни одной).  
**Формат вывода:** Одно целое число – максимальная разница между соседними элементами после сортировки.
