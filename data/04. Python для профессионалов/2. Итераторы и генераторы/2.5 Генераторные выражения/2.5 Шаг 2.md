### FAQ:
> Справочник будет расширяться по мере появления новых комментариев — добавляйте вопросы!

#### 1. **Почему `(x*x for x in range(5))` без `list()` ничего не выводит в консоль?**

Потому что генераторное выражение само по себе лишь **создаёт объект‑генератор**; элементы вычисляются только при итерации: в цикле `for`, при вызове `next()`, в функциях вроде `sum()`, `any()`, `min()`.

    gen = (x*x for x in range(5))
    print(gen)          # <generator object ...>
    print(list(gen))    # [0, 1, 4, 9, 16]

#### 2. **Как проверить, “исчерпан” ли генератор?**

Надёжного встроенного способа нет — протокол итерации не хранит «длину оставшихся элементов». Привычно либо:

- попытаться вызвать `next()` и обработать `StopIteration`,

- превращать в список и проверять результат (потеря ленивости).

#### 3. **Что быстрее: `sum([x*x for x in data])` или `sum(x*x for x in data)`?**

- **Маленькие объёмы (до ≈50 000 элементов)** — списковое включение чуть быстрее: все данные уже в RAM, C‑цикл `sum()` идёт без оверхеда Python‑объектов.

- **Большие объёмы / потоковые данные** — генератор выигрывает по памяти (O(1)), а скорость сопоставима из‑за отсутствия аллокаций.

Выбирайте по‑ситуации; профилируйте, если критично.

#### 4. **Можно ли использовать условие “`if`” и множественные `for` в генераторе, как в списковом включении?**

Да, синтаксис тот же:

    # квадраты только нечётных чисел
    odd_squares = (x*x for x in range(10) if x % 2)
    # декартово произведение
    pairs = ((x, y) for x in range(3) for y in range(2))

#### 5. **Генератор в аргументе функции: нужны ли скобки?**

Если генераторное выражение — **единственный** позиционный аргумент, круглые скобки можно опустить:

    total = sum(x*x for x in range(100))   # OK, без (...)
    maxval = max((x for x in data), key=abs)  # нужно (...), потому что есть ещё key=

#### 6. **Почему второй вызов `list(gen)` возвращает пустой список?**

Генератор *одноразовый*. После полного обхода его внутреннее состояние «на конце», и `next()` сразу выбрасывает `StopIteration`. Чтобы пройти заново, создайте новый генератор:

    gen = (x for x in range(3))
    list(gen)   # [0, 1, 2]
    list(gen)   # []
    gen = (x for x in range(3))  # новый объект

#### 7. **Можно ли вложить генераторные выражения друг в друга?**

Да, это обычная практика:

    avg = sum(len(word) for line in lines for word in line.split()) / len(lines)

Однако при сложной логике лучше развернуть код в несколько строк или использовать именованные генераторы для читабельности.

#### 8. **Как “раскрыть” генераторное выражение в несколько потоков без исчерпания?**

С помощью `itertools.tee()`:

    from itertools import tee
    gen1, gen2 = tee((x*x for x in range(5)), 2)
    print(list(gen1))  # [0, 1, 4, 9, 16]
    print(list(gen2))  # [0, 1, 4, 9, 16]

Учтите, что `tee()` хранит буфер для уже прочитанных элементов, поэтому экономия памяти частично теряется.
