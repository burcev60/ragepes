Напишите функцию-генератор `squares(n)`, которая генерирует квадраты чисел от 1 до n включительно. Затем напишите программу, которая считывает натуральное число n и с помощью генератора `squares(n)` выводит квадраты чисел от 1 до n через пробел. Использовать внутри генератора цикл для yield.

**Формат ввода:** Одно натуральное число n (n >= 1).  
**Формат вывода:** Квадраты чисел 1, 2, ..., n через пробел.
