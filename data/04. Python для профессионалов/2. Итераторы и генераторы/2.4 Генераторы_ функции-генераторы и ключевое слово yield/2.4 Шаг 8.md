Напишите генератор-итератор `merge_sorted(gen1, gen2)`, объединяющий два отсортированных по возрастанию ряда чисел, представленных генераторами `gen1` и `gen2`. Генератор `merge_sorted` на каждом шаге должен выдавать меньшее из текущих значений двух генерируемых рядов, удаляя его из рассмотрения. Если один из рядов закончился, генератор должен затем выдавать все оставшиеся элементы второго ряда.

Далее напишите программу, которая считывает два отсортированных списка целых чис (каждый в отдельной строке, числа через пробел), создает по ним генераторы (функция-генератор, использующая `yield` для обхода списка), и с помощью `merge_sorted` выдает объединенную отсортированную последовательность.

**Формат ввода:**  
Два ряда целых чис в двух строках (каждая строка – уже отсортированный по возрастанию список чисел, разделенных пробелами). Возможно, один из рядов окажется пустым.  
**Формат вывода:** Отсортированная последовательность, содержащая все числа из обоих входных рядов, через пробел.
