**Генераторы** — это особый вид итераторов, которые создаются с помощью функций с ключевым словом `yield` или с помощью **генераторных выражений**. Генераторы позволяют писать итеративный код более кратко и читаемо, не заботясь явно о сохранении состояния и возбуждении `StopIteration`.

**Функция-генератор** — это функция, которая вместо `return` может использовать оператор `yield` для выдачи значения. Когда такая функция вызывается, она не выполняется полностью, а возвращает объект генератора (который является итератором). При последующем итерировании (вызовах `next()` или прохождении в цикле) код внутри функции-генератора исполняется до следующего оператора `yield`, который возвращает очередное значение, после чего выполнение функции приостанавливается до следующего запроса элемента.

Пример простой функции-генератора, выдающей квадраты чисел от 1 до N:

     

    def squares(n):
        i = 1
        while i <= n:
            yield i * i
            i += 1

    # Использование генератора:
    for square in squares(5):
        print(square)

Вывод:

    1
    4
    9
    16
    25

В этом примере функция `squares` при каждом вызове `yield i * i` возвращает очередной квадрат числа, приостанавливая свое выполнение, и продолжает со следующей итерации цикла `while` при следующем обращении (`next`). Когда `i` становится больше `n`, выполнение функции достигает конца (нет больше `yield`), и генератор возбуждает `StopIteration` автоматически.

Важные свойства генераторов:

- Генератор **запоминает свое состояние** между вызовами. В примере выше, переменная `i` сохраняет значение между итерациями.

- Когда генератор исчерпан (функция-генератор завершила выполнение или встретила `return` без значения), дальнейшие обращения к нему вызовут `StopIteration`.

- Генераторы, как и другие итераторы, можно использовать лишь один раз. После окончания (исчерпания) они больше не выдают значений. Если нужно начать заново, нужно получить новый генератор, вызвав функцию-генератор снова.

Генераторы позволяют выразить многие последовательности проще. Например, тот же диапазон нечетных чисел можно реализовать генератором:

    def odd_range(start, end):
        current = start if start % 2 == 1 else start + 1
        while current < end:
            yield current
            current += 2

    for num in odd_range(1, 10):
        print(num)

Этот код даст такой же результат, как класс `OddRange`, но при этом он короче и проще для понимания.

Генераторы часто используются для работы с потоками данных или большими последовательностями, где важно "ленивое" вычисление (вычисление по требованию). Они вычисляют каждый следующий элемент только в момент запроса, что экономит память по сравнению с созданием списка всех результатов сразу.
