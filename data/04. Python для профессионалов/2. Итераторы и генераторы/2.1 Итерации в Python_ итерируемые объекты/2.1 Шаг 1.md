Итерация – один из фундаментальных процессов в программировании. **Итерировать** означает последовательно проходить по элементам некоторого набора данных. В Python имеется мощный механизм итерации, позволяющий обходить элементы разнообразных структур данных (списков, кортежей, множеств, словарей и т.д.) единообразно – при помощи цикла `for` или других конструкций.

**Итерируемым объектом (iterable)** называется любой объект, по которому можно проитерироваться (то есть последовательно получить каждый элемент). Примеры итерируемых объектов: списки, строки, кортежи, множества, словари, диапазоны (`range`), файлы (объекты файлового ввода-вывода), а также многие другие, в том числе пользовательские типы, поддерживающие протокол итерации. Простейший способ узнать, является ли объект итерируемым – попробовать использовать его в цикле `for` или передать встроенной функции `iter()`.

В Python реализация итерации основана на специальных методах. Итерируемый объект должен предоставлять метод `__iter__`, который возвращает итератор – объект, способный выдавать элементы по одному. В самом простом случае итерируемый объект может сам быть итератором (и `__iter__` может возвращать `self`), или `__iter__` может возвращать отдельный объект-итератор. Например, вызов `iter(spisok)` на списке возвращает специальный объект-итератор, который знает, как обходить список.

Рассмотрим простой пример использования итерации:

    fruits = ["apple", "banana", "cherry"]
    for fruit in fruits:
        print(f"Фрукт: {fruit}")

Здесь список `fruits` является итерируемым объектом. Цикл `for` неявно вызывает `iter(fruits)`, получая итератор, а затем повторно вызывает `next()` на этом итераторе, чтобы последовательно получить каждый элемент списка до исчерпания элементов. В результате на экран будут выведены названия фруктов.

Стоит отметить, что **итерация** в контексте цикла `for` или подобных конструкций абстрагирует от программиста логику получения следующего элемента. Однако под капотом цикл `for` работает через вызовы функций `iter()` и `next()`.
