Python позволяет определять собственные классы, поддерживающие протокол итератора. Для этого нужно реализовать методы `__iter__` и `__next__`.

Рассмотрим сценарий: у нас есть класс, представляющий диапазон нечетных чисел в заданном диапазоне. Например, итерирование по объекту этого класса `OddRange(1, 10)` должно давать последовательность 1, 3, 5, 7, 9.

Создадим такой класс:

    class OddRange:
        def __init__(self, start, end):
            self.start = start
            self.end = end
            self.current = start if start % 2 == 1 else start + 1  # первое нечетное число

        def __iter__(self):
            # Метод __iter__ должен возвращать итератор.
            # В простейшем случае сам объект является итератором, поэтому возвращаем self.
            return self

        def __next__(self):
            # Если текущий элемент вышел за границы end, итерация заканчивается.
            if self.current >= self.end:
                raise StopIteration
            # Сохраняем значение для возврата
            result = self.current
            # Переходим к следующему нечетному числу
            self.current += 2
            return result
    #Теперь можно использовать OddRange в цикле:


    odds = OddRange(1, 10)
    for num in odds:
        print(num)

Вывод будет:

    1
    3
    5
    7
    9

Обратим внимание: наш класс `OddRange` сам является итератором (метод `__iter__` возвращает `self`). Это удобно, когда одна и та же сущность хранит состояние перебора. Альтернативно, можно сделать `__iter__` создающим и возвращающим новый объект-итератор, отделенный от самого итерируемого объекта.

Например, стандартный тип `list` в Python: сам список не является итератором (у списка нет метода `__next__`), но он итерируемый, потому что имеет `__iter__`, который возвращает специальный объект-итератор, хранящий текущий индекс. Это позволяет иметь несколько независимых итераторов по одному списку.

При реализации собственных итераторов важно учитывать:

- Метод `__next__` должен либо возвращать очередной элемент, либо возбуждать `StopIteration`, иначе итерация будет бесконечной или нарушенной.

- Состояние итератора (в нашем примере, переменная `current`) должно изменяться при каждом вызове `__next__`, чтобы итерация продвигалась.

- Можно реализовать итератор так, чтобы один итерируемый объект создавал множество независимых итераторов (пример: `__iter__` возвращает новый экземпляр итератора). Это бывает полезно, если итерируемый объект хранит данные, а итератор — отдельный объект, проходящий по этим данным.

Теперь мы научились создавать собственные итераторы. Но Python предоставляет более простой и лаконичный способ создания итераторов для некоторых задач — генераторы.
