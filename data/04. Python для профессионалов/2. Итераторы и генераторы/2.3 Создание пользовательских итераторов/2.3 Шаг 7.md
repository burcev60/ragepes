Реализуйте класс-итератор `RepeatIterator`, который циклически итерируется по элементам заданной коллекции фиксированное число раз. Конструктор класса принимает два аргумента: `data` (итерируемый объект) и `times` (количество полных проходов). Итератор должен проходить по `data` столько раз, сколько указано в `times`.

Напишите программу, которая считывает список (на одной строке через пробел) и целое число k. Затем создает `RepeatIterator` для этого списка и k, и выводит все элементы, которые генерирует этот итератор, через пробел.

**Формат ввода:**  
Первая строка – элементы списка через пробел.  
Вторая строка – целое число k.  
**Формат вывода:** Элементы исходного списка, повторенные k раз, через пробел.
