Считайте одну строку, содержащую несколько пар «ключ значение», разделённых пробелами (например:

`a 1 b 2 a 3 `

). Используя `collections.defaultdict(list)`, сгруппируйте значения по ключу, а затем для каждого ключа вычислите сумму значений. Верните строку, где каждая строка имеет формат:

`<ключ>: <сумма> `

Строки должны быть отсортированы по ключу (лексикографически).
