Модуль `collections` предоставляет несколько полезных структур данных и классов, расширяющих встроенные коллекции.

- **collections.namedtuple** – фабрика, создающая подкласс tuple с именованными полями. Позволяет обращаться к элементам по имени.

    from collections import namedtuple
    Point = namedtuple('Point', ['x', 'y'])
    p = Point(2, 3)
    print(p.x, p.y)  # 2 3
    print(p)         # Point(x=2, y=3)

Namedtuple создаёт неизменяемый (immutable) класс, который ведёт себя как кортеж, но с атрибутами для полей.

- **collections.deque** – двусторонняя очередь (deque = double-ended queue). Позволяет эффективно добавлять и удалять элементы с обоих концов (амортизированная O(1)). Можно использовать как очередь FIFO или LIFO (стек).

    from collections import deque
    d = deque([1, 2, 3])
    d.append(4)        # добавляет в конец
    d.appendleft(0)    # добавляет в начало
    print(d)           # deque([0, 1, 2, 3, 4])
    print(d.pop())     # 4 (удаляет с конца)
    print(d.popleft()) # 0 (удаляет с начала)

Deque также имеет полезный параметр maxlen, который ограничивает размер и при переполнении автоматически удаляет старые элементы (например, хранение последних N событий).

- **collections.Counter** – счетчик, подкласс dict для подсчета частоты элементов.

    from collections import Counter
    cnt = Counter("hello world")
    print(cnt)        # Counter({'l': 3, 'o': 2, 'h': 1, 'e': 1, ' ': 1, 'w': 1, 'r': 1, 'd': 1})
    print(cnt['l'])   # 3
    cnt.update("lollipop")  # добавляем счетчики из нового слова
    print(cnt['l'])   # теперь 6 (3 + 3 из "lollipop")

Counter удобен для задачи вроде подсчета слов в тексте или элементов списка.

- **collections.defaultdict** – словарь, который при обращении к несуществующему ключу может создавать и вставлять значение по умолчанию через функцию-фабрику.

    from collections import defaultdict
    dd = defaultdict(list)
    dd['a'].append(1)
    dd['b'].append(2)
    print(dd)  # {'a': [1], 'b': [2]} (при первом обращении dd['a'] создает новый список автоматически)

Здесь мы указали, что значение по умолчанию будет `list()`. При попытке доступа к несуществующему ключу defaultdict создаст новый список.

- **collections.OrderedDict** – упорядоченный словарь, помнящий порядок вставки ключей. (Начиная с Python 3.7 обычный `dict` уже сохраняет порядок вставки как стандартное поведение, но OrderedDict все еще может иметь полезные методы, например, `move_to_end`).

- **collections.ChainMap** – удобно для логического объединения нескольких словарей или контекстов в один (например, для поиска ключа сразу в нескольких словарях последовательно).

- **collections.UserDict, UserList, UserString** – классы-обертки, которые можно наследовать для создания своих версий dict, list, string, переопределяя определенные методы.

В Python 3.10 добавлены новые функциональности:

- **Объединение Counter**: оператор `|` теперь поддерживается для Counter (объединяет счетчики, складывая значения), а также метод `Counter.subtract` для вычитания.

- **Паттерн-сопоставление** (рассмотрено в отдельном модуле) может применять `collections.abc.Sequence` для распаковки.

**Модуль collections.abc** – содержит абстрактные базовые классы для контейнеров (Iterable, Sequence, Mapping, etc.). Их можно использовать для проверки типа (`isinstance(x, Iterable)`) или для создания своих классов, которые будут признаваться, например, последовательностями (наследование от Sequence с реализацией необходимых методов).
