Стандартная библиотека Python обширна. Кратко упомянем еще несколько модулей, полезных в продвинутом применении:

- **math и statistics**: помимо базовых функций в math (sin, cos, sqrt, etc.), есть `math.comb`, `math.perm` для комбинаций и перестановок, `math.prod` для перемножения элементов списка. Модуль statistics предоставляет функции для вычисления средних, дисперсий, медиан и т.д.

- **decimal и fractions**: для точных расчетов с плавающей точкой. `decimal.Decimal` – десятичные числа с контролируемой точностью (важно для финансовых расчетов, чтобы избежать бинарных погрешностей). `fractions.Fraction` – рациональные числа, хранящиеся как числитель/знаменатель.

- **datetime**: для работы с датами и временем. `datetime.datetime`, `datetime.date`, `datetime.timedelta` – основные классы; поддерживают арифметику дат, сравнения, форматирование. В Python 3.9+ появился модуль `zoneinfo` для поддержки часовых поясов из базы IANA.

- **pathlib**: современный модуль для работы с файловыми путями, предоставляет объектно-ориентированный интерфейс вместо использования функций `os.path`.

    from pathlib import Path
    p = Path("/tmp") / "subdir" / "file.txt"
    if not p.exists():
        p.parent.mkdir(parents=True, exist_ok=True)
        p.write_text("Hello")
    print(p.read_text())  # "Hello"

- **logging**: мощный модуль для логирования. Позволяет выводить сообщения разного уровня (DEBUG, INFO, WARNING, ERROR, CRITICAL) с гибкой настройкой выводов (в файлы, в консоль, в сеть). Хорошей практикой считается использовать logging вместо принтов для информационных сообщений в приложениях.

- **argparse**: для разбора аргументов командной строки. Позволяет легко задать параметры, их типы, значения по умолчанию, и автоматически генерирует помощь (-h).

- **re**: модуль регулярных выражений для поиска и замены по шаблону в строках.

- **json, csv, xml.etree.ElementTree**: парсеры и генераторы для распространенных форматов данных (JSON, CSV, XML).

- **sqlite3**: встроенная база данных SQLite, позволяет выполнять SQL-запросы к файлам баз данных прямо из Python, без установки внешних серверов.

- **multiprocessing**: упомянутый ранее, позволяет явно создавать процессы, обмениваться данными между ними (через очереди, каналы, общую память).

- **threading**: модуль для работы с потоками напрямую (класс Thread, а также примитивы Lock, Event, Condition и т.д.).

- **queue**: очереди, безопасные для межпоточного использования (очереди FIFO, LIFO, приоритетные).

- **subprocess**: запуск внешних программ и взаимодействие с ними (ввод/вывод, ожидание завершения, коды возврата).

- **shutil, os**: для операций с файловой системой на высоком уровне (копирование файлов, обход каталогов и др.).

- **sys**: доступ к объектам Python, взаимодействующим с интерпретатором (argv, stdout, exit и др.).

- **tempfile**: создание временных файлов и директорий.

- **inspect**: для интроспекции (уже упоминалось).

- **dataclasses**: (появился в 3.7) для быстрого создания классов данных без явного написания **init** и других методов (подробнее в последнем модуле).

При необходимости почти для любой типичной задачи Python предлагает готовый модуль. Полезно изучать документацию стандартной библиотеки – можно обнаружить, что многие "велосипеды" уже изобретены и оптимально реализованы.
