### FAQ

*Стандартная библиотека богата «сокровищами». Здесь собраны самые частые вопросы; добавляйте новые в комментариях!*

1. **Когда вместо float стоит использовать `decimal.Decimal` или `fractions.Fraction`?**  
  - **decimal** — финансы, валюты, отчётность: нужен фиксированный масштаб и точный результат 0.1+0.2=0.3.
  - **fraction** — учебные/математические задачи, где важна без-ошибочная рациональная арифметика (1/3+1/6 = 1/2).
  - **float** — наука, ML, графика: скорость важнее абсолютной точности, допускаются микроскопические погрешности.
2. **Зачем нужен `pathlib`, если есть `os.path`?**  
`Path`-объекты:
  - Интуитивный «/»-оператор для конкатенации путей (`Path("dir") / "file.txt"`).
  - Методы высокого уровня: `read_text()`, `iterdir()`, `with_suffix()`.
  - Одинаково работают под Windows/Linux — не нужно думать о разделителях.
3. **Чем `logging` лучше `print()`?**  
  - Разные уровни (DEBUG/INFO/…); можно скрыть лишнее на продакшене.
  - Гибкие хэндлеры: файл, syslog, e-mail, JSON, собственный поток.
  - Встроенная маршрутизация, форматирование, ротация файлов.
  - `print` — только stdout/stderr и всегда «уровень INFO».
4. **Для чего пригодится `argparse`, если скрипт принимает пару аргументов?**  
Удобство для пользователя («-h» выводит автогенерируемую справку), валидация типов,
 значения по умолчанию, подкоманды (`git commit` / `git push`).
 Даже при 2-3 флагах код на `argparse` чище, чем ручной `sys.argv`-парсинг.
5. **Как быстро посчитать медиану/стандартное отклонение без NumPy?**  
`statistics.median(iterable)`, `statistics.stdev(iterable)`.
 Для небольших наборов (<10⁶) работает достаточно быстро; для больших массивов
 всё-таки выгоднее NumPy.
6. **Как работать с часовыми поясами только средствами stdlib?**  
В Python 3.9+ есть `zoneinfo.ZoneInfo("Europe/Moscow")`.
 До 3.9 — используйте `pytz` или ручное смещение.
7. **`sqlite3` — это «игрушка» или можно в продакшн?**  
Для локальных приложений, встраиваемых БД, офлайн-анализов — да.
 Не для высоконагруженных веб-серверов (нет параллельной записи).
 Плюс: поставляется вместе с Python, zero-config.
8. **Когда выбрать `subprocess.run()` против `os.system()`?**  
`subprocess` даёт полный контроль: захват stdout/stderr, таймаут,
 передача списка аргументов (без шелл-инъекций), работа асинхронно через `Popen`. `os.system()` — «быстро, но грязно».
9. **Что такое `dataclasses` и заменяют ли они `namedtuple`/`attrs`?**  
`@dataclass` генерирует `__init__`, `__repr__`,
 сравнения, опционально — неизменяемость (`frozen=True`), order, slots.
 Гибче чем `namedtuple`, легче чем `attrs` (без внешних зависимостей).
10. **Какой модуль использовать для временных файлов?**  
`tempfile.TemporaryFile()`, `NamedTemporaryFile`, `TemporaryDirectory`. Они автоматически удаляют ресурс при
 закрытии/выходе из контекста.
