`itertools` предоставляет целый набор "инструментов для итерации". Все функции в этом модуле возвращают итераторы (или генераторы), которые можно использовать в циклах или комбинировать между собой.

Некоторые важные функции:

- **itertools.count(start=0, step=1)** – бесконечный итератор, генерирует числа от `start` с заданным шагом. Например, `count(5)` даст 5, 6, 7, ... бесконечно.

- **itertools.cycle(iterable)** – бесконечно циклично повторяет элементы переданного iterable. Например, `cycle("AB")` даст последовательность A, B, A, B, ...

- **itertools.repeat(elem, n=None)** – повторяет элемент `elem` n раз (если n не указан – бесконечно).

- **itertools.product(iter1, iter2, ..., repeat=1)** – декартово произведение (комбинации каждого элемента из iter1 с каждым из iter2 и т.д.). Параметр `repeat` позволяет повторить один итерируемый объект несколько раз.

     

    import itertools
    cards = list(itertools.product(['♥', '♣', '♦', '♠'], range(1, 14)))
    print(cards[0], cards[-1])  # ('♥', 1) ('♠', 13)
    print(len(cards))           # 52 (колода карт)

- **itertools.permutations(iterable, r)** – все перестановки из элементов iterable длиной `r` (по умолчанию `r = len(iterable)`, т.е. все перестановки полной длины).

- **itertools.combinations(iterable, r)** – все комбинации (без повторений) из элементов по `r`.

- **itertools.combinations_with_replacement(iterable, r)** – все комбинации с повторениями.

    import itertools
    letters = "ABC"
    print(list(itertools.permutations(letters, 2)))
    # [('A','B'), ('A','C'), ('B','A'), ('B','C'), ('C','A'), ('C','B')]
    print(list(itertools.combinations(letters, 2)))
    # [('A','B'), ('A','C'), ('B','C')]

- **itertools.chain(iter1, iter2, ...)** – объединяет несколько последовательностей подряд как одну.

- **itertools.islice(iterable, start, stop, step)** – как срез для итератора. Можно, например, взять первые N элементов бесконечной последовательности или любой части последовательности.

- **itertools.groupby(iterable, key=None)** – группирует подряд идущие элементы, имеющие один и тот же ключ. (Важно: группировка происходит по соседним элементам, а не по всем данным как `sort+group`).

    import itertools
    data = "AAABBAACCC"
    for key, group in itertools.groupby(data):
        print(key, list(group))
    # Вывод:
    # A ['A', 'A', 'A']
    # B ['B', 'B']
    # A ['A', 'A']
    # C ['C', 'C', 'C']

- **itertools.accumulate(iterable, func=operator.add)** – возвращает накопленные результаты применения функции (по умолчанию суммирование). Например:

    import itertools, operator
    data = [1, 2, 3, 4]
    print(list(itertools.accumulate(data)))  
    # [1, 3, 6, 10] (накопленные суммы)
    print(list(itertools.accumulate(data, operator.mul)))  
    # [1, 2, 6, 24] (накопленные произведения)

Многие из этих функций помогают писать код более декларативно и избегать лишнего хранения промежуточных списков.

Например, задача: есть список чисел, нужно получить все уникальные пары (комбинации по 2) и посчитать их сумму:

    import itertools
    numbers = [1, 2, 3, 4]
    pairs = list(itertools.combinations(numbers, 2))
    sums = [sum(pair) for pair in pairs]
    print(pairs)  # [(1,2), (1,3), (1,4), (2,3), (2,4), (3,4)]
    print(sums)   # [3, 4, 5, 5, 6, 7]

Или, используя ленивый подход:

    sums_iter = (a+b for a, b in itertools.combinations(numbers, 2))
    print(list(sums_iter))

Генераторное выражение обходит комбинации и сразу суммирует, не храня все комбинации сразу.
