### FAQ

*Добавляйте вопросы в комментариях — мы будем расширять раздел.*

1. **Почему функции `count`, `cycle`, `repeat` «бесконечные»?
 Как безопасно их использовать?**  
Эти итераторы генерируют элементы без остановки.
 Ограничивайте их:
  - через `itertools.islice()` (`islice(count(), 10)`);
  - через `zip()` с конечным итератором;
  - или с `break` внутри цикла.
2. **Чем отличаются `permutations`, `combinations` и `product`?**  
  - `permutations(a, r)` — размещения: порядок важен, без повторений.
  - `combinations(a, r)` — сочетания: порядок не важен, без повторений.
  - `product(a, repeat=r)` — декартово произведение: порядок важен, с повторениями.
3. **Почему `groupby` «схлопывает» только соседние элементы?**  
Алгоритм идёт по входу *один раз* и группирует подряд идущие
 элементы с одинаковым ключом.
 Если требуется глобальная группировка, предварительно `sorted()` по тому же ключу.
4. **Как получить N-ое значение бесконечной последовательности
 (например, 1 000-й элемент `count()`)?**  
Используйте `islice` с пустым «stop» и возьмите `next()`:

    from itertools import islice, count
    print(next(islice(count(), 999, None)))   # 999-й индекс → значение 999
  

5. **Есть ли альтернатива `sum`/`map` для «ленивых» вычислений?**  
Да: `itertools.accumulate()` возвращает промежуточные суммы/произведения,
 а `map()` уже ленив в Py3. Если нужно «ленивое sum» без
 промежуточных значений — используйте генератор и `sum()` поверх него.
6. **Как развернуть итератор «в несколько строк», как `zip(*iterables)`,
 но лениво?**  
Воспользуйтесь `itertools.tee()` —
 он создаёт N независимых копий входного итератора.
 Имейте в виду: память копится по мере продвижения разных копий.
7. **Что быстрее для “flatten” списка списков: `sum(lists, [])` или `itertools.chain.from_iterable(lists)`?**  
`chain.from_iterable` значительно быстрее и O(1) по дополнительной памяти,
 потому что не создаёт промежуточных копий. `sum()` с начальным пустым списком реализует конкатенацию, копируя данные каждый шаг.
8. **Можно ли использовать функции `itertools` с произвольными классами?**  
Да, если объекты реализуют протокол итератора (`__iter__` & `__next__`)
 и, где нужно, сравнение/хеш.
 Пример: `itertools.combinations(my_deque, 3)` работает,
 даже если `deque` не поддерживает индексацию.
9. **Как остановить `accumulate`, когда накопленная сумма превысила порог?**  
`accumulate` не умеет сам прерываться; оберните его в `itertools.takewhile(lambda x: x < limit, accumulate(seq))`.
10. **Где найти ещё рецепты комбинирования `itertools`?**  
Официальная документация [«Itertools — Recipes»](https://docs.python.org/3/library/itertools.html#itertools-recipes) содержит готовые конструкции: «windowed», «roundrobin», «powerset» и др.
