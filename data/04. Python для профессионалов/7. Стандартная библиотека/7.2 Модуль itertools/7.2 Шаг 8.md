Считайте две строки. Первая строка содержит элементы, разделённые пробелами (например, `1 2 3`); вторая строка содержит целое число r (размер комбинации).  
С помощью функции `itertools.combinations` вычислите все возможные комбинации по r элементов из заданной последовательности. Верните результат в виде строки, где каждая комбинация представлена в формате кортежа (элементы разделены запятыми), а комбинации разделены переводами строк.
