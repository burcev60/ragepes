`functools` – модуль, содержащий функции высшего порядка и инструменты для функционального программирования.

Некоторые основные возможности:

- **functools.wraps** – мы уже упоминали его в теме декораторов. Это декоратор для декораторов, переносит метаданные функции (имя, документацию и др.).

- **functools.partial** – позволяет зафиксировать часть аргументов функции и получить новую функцию с меньшей арностью. Например:

    from functools import partial
    int_base2 = partial(int, base=2)
    print(int_base2("1010"))  # 10, эквивалент int("1010", base=2)

Здесь `partial(int, base=2)` создает функцию `int_base2`, которая вызывается как `int` с предустановленным `base=2`.

- **functools.reduce** – функция для свёртки (accumulate) последовательности в одно значение, итерируя с функцией. Например:

    from functools import reduce
    import operator
    result = reduce(operator.add, [1, 2, 3, 4], 0)
    print(result)  # 10 (0 + 1 + 2 + 3 + 4)

Здесь функция `operator.add` последовательно складывает элементы списка, начиная с начального значения 0.

- **functools.lru_cache** – декоратор для мемоизации функций (кэширование результатов). LRU (Least Recently Used) означает, что при переполнении кэша удалятся самые давно использованные записи.

    from functools import lru_cache

    @lru_cache(maxsize=1000)
    def fib(n):
        if n < 2:
            return n
        return fib(n-1) + fib(n-2)

    print(fib(50))

Без кэша рекурсивное вычисление 50-го числа Фибоначчи было бы очень медленным, с кэшем оно выполняется мгновенно, переиспользуя результаты.

- **functools.singledispatch** – декоратор, позволяющий создать функцию с одиночной динамической диспетчеризацией по типу первого аргумента. То есть можно написать "генерик" функцию, а затем регистрировать для нее реализации для разных типов.

    from functools import singledispatch

    @singledispatch
    def process(value):
        print(f"Обработка объекта: {value}")

    @process.register
    def _(value: int):
        print(f"Обработка числа: {value}")

    @process.register
    def _(value: list):
        print(f"Обработка списка из {len(value)} элементов")

    process(5)       # Обработка числа: 5
    process([1, 2])  # Обработка списка из 2 элементов
    process("hello") # Обработка объекта: hello  (для str не зарегистрировано, взята общая функция)

Здесь `process` – обобщенная функция, у которой есть специальные версии для `int` и `list`. Аннотация в `process.register` помогает выбрать правильную версию по типу аргумента.

- **functools.total_ordering** – класс-декоратор, который, если в классе определены `__eq__` и один из `<, <=, >, >=`, добавит остальные методы сравнения автоматически, чтобы облегчить реализацию сортируемых объектов.

- **functools.cmp_to_key** – функция для использования старого стиля функций сравнения (как в Python 2) с функциями сортировки Python 3. Преобразует функцию сравнения `cmp(x, y)` в ключ сортировки.
