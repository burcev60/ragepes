Напишите функцию `threaded_sum(n)`, которая вычисляет сумму квадратов чисел от 1 до n с помощью двух потоков. Для этого:

1. Определите функцию `cpu_work(n)`, которая возвращает сумму квадратов чисел от 1 до n.

2. Создайте два потока с использованием модуля `threading`. Каждый поток должен независимо вычислить `cpu_work(n)`.

3. Дождитесь завершения обоих потоков и сложите их результаты.

4. Верните итоговую сумму в виде строки.  
*Пояснение:*  
При последовательном выполнении `cpu_work(n)` возвращает S, а при параллельном через два потока итоговый результат должен равняться 2*S, так как каждый поток выполняет всю работу из‑за GIL (то есть вычисления не ускоряются, а выполняются последовательно внутри потоков).
