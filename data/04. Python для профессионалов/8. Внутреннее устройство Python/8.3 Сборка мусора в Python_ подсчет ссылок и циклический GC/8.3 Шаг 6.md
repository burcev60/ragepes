Реализуйте функцию `cyclic_gc()`, которая создаёт цикл ссылок следующим образом:

1. Создайте объект списка `l` и добавьте в него самого себя (т.е. выполните `l.append(l)`), чтобы создать циклическую ссылку.

2. Удалите внешнюю ссылку на этот объект (например, с помощью `del l`).

3. Вызовите `gc.collect()` для явной сборки мусора и верните результат (число собранных объектов) в виде строки.
