Для микрооптимизаций или сравнения разных способов выполнить некую операцию удобен модуль `timeit`. Он предназначен для точного измерения времени выполнения небольшого фрагмента кода за счет многократного повторения и снижения влияния случайностей.

Пример использования:

    import timeit

    # Сравним скорость создания списка разными способами
    list_comp = "[x for x in range(1000)]"
    loop_append = """
    result = []
    for x in range(1000):
        result.append(x)
    """
    print(timeit.timeit(list_comp, number=10000))
    print(timeit.timeit(loop_append, number=10000))

Вывод покажет что-то вроде (условно):

    0.12  # list comprehension
    0.20  # цикл с append

То есть списковое включение быстрее.

Функция `timeit.timeit(stmt, setup, number)` выполняет `setup` (строка кода для подготовки, по умолчанию `pass`), затем выполняет выражение `stmt` заданное количество `number` раз и возвращает общее время выполнения. Чем больше number, тем точнее результат. По умолчанию, если number не указан, timeit подбирает его, чтобы получить ощутимое время.

Также в командной строке:

    python -m timeit "x = [i for i in range(1000)]"

Timeit сам повторит и выдаст среднее время.

Timeit учитывает тонкости:

- По умолчанию отключает сборку мусора (чтобы случайный запуск сборщика не исказил результаты короткого бенчмарка).

- Отдельный процесс для каждого прогона (в CLI) для изоляции эффекта кэша процессора и т.п.

Используя timeit, можно сравнивать, например:

- Разные методы конкатенации строк (через `+` или через `join`).

- Поиск элемента в списке vs множестве.

- Различные реализации алгоритма (цикл на Python vs использование numpy, и пр.).

Пример:

    import timeit
    print(timeit.timeit("'-'.join(str(n) for n in range(100))", number=10000))
    print(timeit.timeit("s='' \nfor n in range(100): s += str(n) + '-'", number=10000))

Ожидаемо, join будет быстрее.

Важно: интерпретировать результаты с пониманием. Разница в несколько процентов может быть нерелевантна в контексте общей программы, а разница в порядок – уже значима.
