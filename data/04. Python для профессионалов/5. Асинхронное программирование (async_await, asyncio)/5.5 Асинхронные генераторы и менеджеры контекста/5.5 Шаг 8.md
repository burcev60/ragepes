Реализуйте класс-контекстный менеджер `AsyncReader`, который предназначен для имитации асинхронного чтения чисел. В конструкторе класс не принимает аргументов.

- В методе `__aenter__` он должен возвращать сам объект (self).

- Реализуйте асинхронный метод `read_numbers(self, numbers)`, который принимает список чисел и асинхронно (с задержкой 0.01 сек на число с помощью `await asyncio.sleep(0.01)`) генерирует квадрат каждого числа с помощью оператора `yield`.

- В методе `__aexit__` ничего делать не нужно (просто вернуть False).  
В основной программе:

1. Считайте одну строку, содержащую числа, разделённые пробелами.

2. Преобразуйте их в список целых чисел.

3. Вызовите асинхронную функцию, которая с помощью конструкции `async with AsyncReader() as reader` и `async for` обходит результаты метода `read_numbers`, собирает их в список, а затем возвращает строку с квадратами чисел, разделёнными переводами строк.
