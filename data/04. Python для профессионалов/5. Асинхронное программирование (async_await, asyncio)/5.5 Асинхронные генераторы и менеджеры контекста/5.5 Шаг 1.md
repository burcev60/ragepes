В дополнение к `async def` и `await`, Python поддерживает асинхронные итерации и асинхронные контекстные менеджеры:

- **Асинхронные генераторы** – функции с `async def`, которые используют `yield` для генерации последовательности, могут использовать `await` внутри. Они позволяют итерироваться по результатам с помощью `async for`.

- **Асинхронные менеджеры контекста** – объекты, у которых определены методы `__aenter__` и `__aexit__`, используемые в конструкции `async with`.

Пример асинхронного генератора:

    async def countdown(n):
        while n > 0:
            yield n
            n -= 1
            await asyncio.sleep(1)

    async def main():
        async for number in countdown(3):
            print(number)

    asyncio.run(main())

Вывод:

    3
    2
    1

Генератор `countdown` каждую секунду выдает следующее число. Мы можем проходить по нему в `async for`, используя асинхронную итерацию. Асинхронный цикл `async for` сам по себе выполняет `await` при запросе нового элемента у генератора.

Асинхронный менеджер контекста используется аналогично обычному `with`, но при входе/выходе вызываются `await __aenter__` и `await __aexit__`. Многие объекты в asyncio, например `aiohttp.ClientSession` в примере выше, реализуют асинхронный контекстный менеджер (чтобы, например, установить сетевое соединение при входе и корректно закрыть при выходе).

Пример собственной реализации (в качестве иллюстрации):

    class AsyncPrinter:
        async def __aenter__(self):
            print("Начало async контекста")
            return self

        async def __aexit__(self, exc_type, exc, tb):
            print("Завершение async контекста")

        async def print_data(self, data):
            await asyncio.sleep(1)
            print(f"Данные: {data}")

    async def main():
        async with AsyncPrinter() as printer:
            await printer.print_data("Hello")
            await printer.print_data("World")

    asyncio.run(main())

Вывод:

    Начало async контекста
    Данные: Hello
    Данные: World
    Завершение async контекста

Асинхронные генераторы и менеджеры контекста становятся полезными при работе с потоками данных и ресурсами в асинхронном коде, чтобы писать код в знакомом стиле (генераторы, with), но с использованием `await` внутри.
