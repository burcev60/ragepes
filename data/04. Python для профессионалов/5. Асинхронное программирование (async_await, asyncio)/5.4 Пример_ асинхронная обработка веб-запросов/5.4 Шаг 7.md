Считайте одну строку, содержащую несколько URL, разделённых пробелами.  
Реализуйте асинхронную функцию `fetch_all(urls)`, которая параллельно отправляет HTTP‑GET запросы для каждого URL с использованием `aiohttp` и возвращает строку, содержащую первые 15 символов ответа для каждого URL, объединенные через пробел.  
В основной программе:

1. Считайте одну строку с URL, разделёнными пробелами.

2. Вызовите функцию `fetch_all(urls)` через `asyncio.run` и верните результат.
