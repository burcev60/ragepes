Рассмотрим практический пример, иллюстрирующий преимущества асинхронности. Допустим, нам нужно отправить несколько HTTP-запросов к веб-ресурсам и обработать результаты. Если делать это последовательно, общее время будет суммой времен каждого запроса. Асинхронно мы можем отправить их почти одновременно и дождаться всех.

Для примера воспользуемся модулем `aiohttp`, который позволяет выполнять HTTP-запросы асинхронно (учтем, что `aiohttp` не входит в стандартную библиотеку, но часто используется с asyncio).

    import asyncio
    import aiohttp
    import time

    async def fetch(session, url):
        async with session.get(url) as response:
            data = await response.text()
            return data[:15]  # возвращаем первые 15 символов тела как пример

    async def main():
        urls = [
            "https://www.python.org",
            "https://www.google.com",
            "https://www.github.com"
        ]
        async with aiohttp.ClientSession() as session:
            tasks = [asyncio.create_task(fetch(session, url)) for url in urls]
            start = time.time()
            for task in asyncio.as_completed(tasks):
                result = await task
                print("Получены данные:", result)
            end = time.time()
            print(f"Общее время: {end - start:.2f} сек")

    asyncio.run(main())

В этой программе мы отправляем три HTTP GET-запроса практически одновременно. Мы используем `asyncio.as_completed`, чтобы обрабатывать результаты по мере готовности (как только любой из запросов завершится, мы печатаем полученные данные). Это позволяет начать обработку самых быстрых ответов, не дожидаясь самых медленных.

Вывод может быть примерно таким (реальные данные опустим):

    Получены данные: <!doctype html>
    Получены данные: <HTML><HEAD><
    Получены данные: <!DOCTYPE html>
    Общее время: 0.45 сек

Общее время (~0.45 сек) приблизительно равно времени самого медленного запроса, а не сумме (которая могла бы быть значительно больше, если бы запрашивали последовательно).
