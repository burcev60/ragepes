Какой из следующих фрагментов кода корректно реализует асинхронную функцию для выполнения HTTP‑запроса и получения первых 15 символов текста ответа?

- A.

    async def fetch(url):
        async with aiohttp.ClientSession() as session:
            async with session.get(url) as response:
                text = await response.text()
                return text[:15]

- B.

    async def fetch(url):
        session = aiohttp.ClientSession()
        response = await session.get(url)
        text = await response.text()
        await session.close()
        return text[:15]
