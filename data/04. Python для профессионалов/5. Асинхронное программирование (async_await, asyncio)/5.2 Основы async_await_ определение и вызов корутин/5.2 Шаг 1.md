В Python начиная с версии 3.5 появился синтаксис `async def` и `await` для написания *корутин* (coroutines). Короутина — это функция, которая может приостанавливать свое выполнение, давая возможность другим корутинам выполняться, и потом продолжать с того же места. Это похоже на генераторы (которые мы рассматривали ранее) с тем отличием, что синтаксис специально предназначен для конкурентного выполнения и чтения асинхронного кода.

**Определение корутины:**

    async def fetch_data():
        print("Запрос данных...")
        # Имитация задержки, например, сетевой запрос
        await asyncio.sleep(1)
        print("Данные получены")
        return {"data": 123}

Здесь `fetch_data` объявлена с помощью `async def`. Такая функция при вызове не выполняется сразу, а возвращает объект *корутина* (coroutine object). Чтобы получить результат выполнения, эту корутину нужно запустить в цикл событий и дождаться (вызвать `await` на ней из другой корутины или запустить через специальные функции).

Ключевое слово `await` используется внутри `async` функции для приостановки выполнения текущей корутины до тех пор, пока **ожидаемый** (`await`-able) объект не завершится. `await`-ить можно либо корутину (вызов другой async-функции), либо объект типа `Task` или `Future` (о них ниже), либо что-то, что определяет метод `__await__`. В примере выше `await asyncio.sleep(1)` приостанавливает `fetch_data` на 1 секунду, при этом управление возвращается в цикл событий, который может заняться другими задачами. После 1 секунды выполнение `fetch_data` продолжится.

**Запуск корутин:** Вне асинхронной функции нельзя напрямую использовать `await`. Вместо этого корутины нужно запускать через цикл событий. В модуле `asyncio` есть функция высокого уровня `asyncio.run()`, которая запускает переданную корутину и, пока она не завершится, управляет циклом событий.

Пример:

    async def main():
        result = await fetch_data()
        print("Результат:", result)

    asyncio.run(main())

Здесь мы определяем корутину `main`, которая вызывает `fetch_data` и ждет результат. `asyncio.run(main())` запускает `main` в новом цикле событий, и когда всё внутри завершится, возвращает результат (в данном случае `None`, так как `main` ничего не возвращает, но она печатает результат).

Важно: `asyncio.run` можно вызывать только из обычного синхронного контекста (например, из модуля, запускаемого как скрипт). Внутри уже выполняющегося цикла событий (например, внутри корутины) `asyncio.run` вызывать нельзя; для запуска дополнительных задач внутри корутины используются другие механизмы (например, `asyncio.create_task`).
