Модуль `asyncio` – это библиотека стандартной библиотеки Python для организации асинхронного ввода-вывода и управления корутинами. Ключевое понятие – **цикл событий** (event loop).

**Цикл событий** – это объект, который управляет выполнением асинхронных задач. Он берет готовые к исполнению задачи (корутины), выполняет их до первого `await` (либо до завершения), затем переключается на другие задачи, которые стали готовыми. Он также обрабатывает завершение задач, вызовы обратных функций (callbacks) и прочие события, связанные с вводом-выводом.

В высокоуровневом API asyncio почти не нужно вручную управлять циклом событий – достаточно вызывать `asyncio.run` для запуска, а внутри корутин использовать функции `asyncio` для создания задач и ожидания результатов.

Некоторые важные функции и классы `asyncio`:

- `asyncio.create_task(coro)` – принимает корутину, планирует её выполнение в фоновом режиме (как отдельную задачу) и возвращает объект `Task`. Task – это обертка вокруг корутины, которая является одновременно и объектом Future (то есть его можно `await`).

- `await asyncio.gather(coro1, coro2, ...)` – запускает несколько корутин параллельно (каждая становится задачей) и ждет их завершения, возвращая результаты в виде списка. Если любая из них бросит исключение, то исключение пробросится (и остальные также будут отменены).

- `asyncio.sleep(seconds)` – асинхронный сон, приостанавливает текущую корутину на указанное время, не блокируя поток.

- `asyncio.Queue` – асинхронная очередь для обмена данными между корутинами (подобно очередям из threading, но для async).

- Объекты синхронизации: `asyncio.Lock`, `asyncio.Event`, `asyncio.Semaphore` – для синхронизации асинхронных задач (работают аналогично своим потоковым версиям, но контролируются циклом событий).

Пример: запустим несколько задач параллельно и дождемся их результатов:

    async def task(name, delay):
        print(f"Начало {name}")
        await asyncio.sleep(delay)
        print(f"Завершение {name}")
        return f"{name} выполнена"

    async def main():
        # Планируем три задачи одновременно
        results = await asyncio.gather(
            task("A", 2),
            task("B", 1),
            task("C", 3)
        )
        print("Результаты всех задач:", results)

    asyncio.run(main())

Вывод:

    Начало A
    Начало B
    Начало C
    Завершение B
    Завершение A
    Завершение C
    Результаты всех задач: ['A выполнена', 'B выполнена', 'C выполнена']

Обратите внимание на порядок: задача B завершилась первой (через 1 секунду), затем A (через 2 секунды), затем C (через 3 секунды). Но мы запустили их практически одновременно, и основной поток не был заблокирован на ожидании каждой по очереди – ожидание происходило внутри `await`, позволяя другим задачам выполняться.
