В Python **метакласс** – это класс, экземплярами которого являются другие классы. Обычно класс создается автоматически интерпретатором при исполнении определения класса. Метаклассы позволяют вмешаться в этот процесс: определить, как будет создаваться класс, какие атрибуты в него попадут, и т.д.

По умолчанию метаклассом для всех классов является `type` (сам `type` – это метакласс по умолчанию). Когда мы пишем:

    class Example:
        pass

происходит примерно следующее: `Example = type("Example", (), {})`. То есть вызывается метакласс `type`, которому передается имя класса, кортеж базовых классов и словарь атрибутов.

Мы можем определить свой метакласс, унаследовав его от `type`, и затем использовать параметр `metaclass` в определении класса.

Например, определим метакласс, который автоматически регистрирует все классы в глобальный словарь:

    class RegistryMeta(type):
        def __new__(metacls, name, bases, class_dict):
            cls = super().__new__(metacls, name, bases, class_dict)
            # регистрируем класс:
            print(f"Регистрация класса: {name}")
            registry[name] = cls
            return cls

    registry = {}

    class MyClass(metaclass=RegistryMeta):
        pass

    class OtherClass(metaclass=RegistryMeta):
        pass

    print("Зарегистрированные классы:", registry.keys())

Когда интерпретатор встречает определение класса `MyClass(metaclass=RegistryMeta)`, он вызывает `RegistryMeta.__new__` (метод класса) для создания нового класса. Наш метакласс в `__new__` выводит сообщение и сохраняет класс в словаре `registry`. Аналогично для `OtherClass`.

Вывод:

    Регистрация класса: MyClass
    Регистрация класса: OtherClass
    Зарегистрированные классы: dict_keys(['MyClass', 'OtherClass'])

В этом примере мы переопределили метод `__new__` метакласса, который получает параметры:

- `name` – имя создаваемого класса,

- `bases` – кортеж базовых классов,

- `class_dict` – словарь атрибутов (методов, переменных класса) нового класса.

Метод `__new__` должен создать класс, обычно вызвав `super().__new__` (то есть `type.__new__`) с теми же аргументами, получить класс, а затем можно его модифицировать или использовать.

Альтернативно или дополнительно можно переопределять `__init__` метакласса (который вызывается после создания класса). Но часто достаточно `__new__`.

Примечание: Метакласс влияет на класс и *все его подклассы* (если не переопределить метакласс в подклассе). То есть, если класс `A` определен с метаклассом `M`, то все классы, унаследованные от `A`, по умолчанию тоже будут с метаклассом `M` (если метаклассы базовых классов совместимы).
