Реализуйте дескриптор `LoggedAttribute`, который управляет атрибутом класса следующим образом:

- При получении атрибута (метод `__get__`) он возвращает значение, хранящееся в экземпляре, и записывает (сохраняет) сообщение в атрибуте `self.log` в виде `"Attribute accessed"`.

- При установке атрибута (метод `__set__`) он сохраняет новое значение в экземпляре (например, в `instance.__dict__`) и добавляет сообщение `"Attribute set to <value>"` в атрибут `self.log` (обновляя его, либо дописывая через пробел).

- При удалении атрибута (метод `__delete__`) он удаляет значение из экземпляра и добавляет сообщение `"Attribute deleted"` в атрибут `self.log`.

В основной программе:

1. Считайте одну строку – Python‑литерал начального значения (например, число или строку).

2. Создайте класс `TestClass`, содержащий атрибут `attr`, управляемый дескриптором `LoggedAttribute`.

3. Создайте экземпляр класса, установите атрибут `attr` в новое значение (прочитайте из входных данных вторую строку), затем удалите атрибут `attr` через оператор `del`.

4. Верните итоговую строку, состоящую из сообщений, записанных в дескрипторе (атрибут `log`).  
Если в процессе ни одно сообщение не сформировалось, верните пустую строку.
