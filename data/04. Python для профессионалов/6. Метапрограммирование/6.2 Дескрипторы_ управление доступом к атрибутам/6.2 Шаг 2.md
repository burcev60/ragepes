### FAQ

*Если вашего вопроса нет — напишите его в комментариях, и мы дополним раздел.*

1. **Что такое *data-descriptor* и *non-data-descriptor*?**  
  - **Data-descriptor** реализует `__set__` и/или `__delete__` (часто ещё и `__get__`). Он имеет приоритет над записями в `instance.__dict__`.
  - **Non-data-descriptor** определяет только `__get__`. Если в экземпляре есть одноимённый атрибут, он «перекроет» дескриптор.
Поэтому свойство `property` — data-descriptor, а функция-метод — non-data.
2. **В каком порядке Python ищет атрибут?**  
`obj.attr` →
 1) data-descriptor в атрибутах класса;  
2) `obj.__dict__`;  
3) non-data-descriptor или обычный атрибут класса;  
4) поиск вверх по MRO.  
Изучить можно через `inspect.getattr_static()`.
3. **Зачем дескриптору метод `__set_name__(self, owner, name)`?**  
Он вызывается один раз, когда класс создаётся, и передаёт дескриптору имя
 атрибута и класс-владельца. Удобно хранить имя приватного поля автоматически:

    class Logged:
        def __set_name__(self, owner, name):
            self.storage = "_" + name
  

4. **Как работает `property()` под капотом?**  
`property` — класс-дескриптор с `__get__`, `__set__`, `__delete__`. Он вызывает переданные функции-геттер/сеттер/делитер
 при обращении к атрибуту экземпляра.
5. **Можно ли создать «кеширующий» дескриптор с ленивой инициализацией?**  
Да: в `__get__` вычислите значение, положите его в `instance.__dict__[self.name]` и верните.
 Следующие обращения будут брать готовое значение без повторных вычислений.
6. **Как передать аргументы дескриптору (например, min/max при валидации)?**  
Через `__init__(self, ...)` экземпляра дескриптора:

    class Range:
        def __init__(self, lo, hi): self.lo, self.hi = lo, hi
        def __set__(self, inst, value):
            if not (self.lo <= value <= self.hi):
                raise ValueError("out of range")
            inst.__dict__[self.lo_name] = value
  

Экземпляр создаётся на уровне класса: `age = Range(0, 120)`.

7. **Почему функции в классах становятся «связанными методами»?**  
Объекты-функции имеют `__get__`, который при доступе через
 экземпляр возвращает объект типа `types.MethodType` —
 функцию плюс ссылку на `self`.
8. **Можно ли применить дескриптор к атрибутам класса-наследника?**  
Да. Один экземпляр дескриптора, объявленный в базовом классе, работает
 для всех наследников. При необходимости можно «переопределить» его,
 присвоив новый экземпляр в дочернем классе.
9. **Как сделать дескриптор *read-only*?**  
Определите только `__get__`; отсутствие `__set__` приведёт к `AttributeError` при попытке присвоения.
10. **Дескрипторы и `slots` совместимы?**  
Да. Если у класса есть `__slots__`, дескриптор может хранить
 данные в них либо использовать отдельное хранилище (WeakKeyDictionary).
 Главное — помнить, что `instance.__dict__` может отсутствовать.
