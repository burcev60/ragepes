## **Первичная настройка Git**

После установки Git необходимо выполнить базовую настройку, чтобы ваши коммиты были подписаны вашим именем и электронной почтой.

### **Настройка имени и почты**

Выполните следующие команды, заменив `Ваше Имя` и `your_email@example.com` своими данными:

    git config --global user.name "Ваше Имя"
    git config --global user.email "your_email@example.com"

### **Проверка настроек**

Для просмотра текущих настроек выполните команду:

`git config --list `

Пример вывода:

`user.name=Ваше Имя user.email=your_email@example.com`
