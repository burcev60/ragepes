### **Для macOS**

Установить Git можно с помощью Homebrew. Если Homebrew ещё не установлен, выполните команду в терминале:

`/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" `

Затем установите Git:

`brew install git `

Проверьте версию:

`git --version`
