## **Настройка текстового редактора по умолчанию**

Git использует текстовый редактор для ввода сообщений коммитов. По умолчанию это `vim`, но вы можете изменить его на другой, например, `nano` или `VSCode`:

`git config --global core.editor "nano" # Для nano git config --global core.editor "code --wait" # Для Visual Studio Code`
