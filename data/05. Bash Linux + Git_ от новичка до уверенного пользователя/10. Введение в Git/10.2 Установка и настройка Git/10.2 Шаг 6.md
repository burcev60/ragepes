## **Проверка и тестирование настроек**

Теперь мы проверим, что Git работает корректно, создав тестовый репозиторий:

1. Создайте папку для проекта и перейдите в неё:

  `mkdir test-repo cd test-repo `

2. Инициализируйте новый репозиторий:

  `git init `

  Вы увидите сообщение:

  `Initialized empty Git repository in /path/to/test-repo/.git/ `

3. Создайте файл `README.md`:

  `echo "# Тестовый репозиторий" > README.md `

4. Добавьте файл в индекс:

  `git add README.md `

5. Сделайте первый коммит:

  `git commit -m "Первый коммит"`
