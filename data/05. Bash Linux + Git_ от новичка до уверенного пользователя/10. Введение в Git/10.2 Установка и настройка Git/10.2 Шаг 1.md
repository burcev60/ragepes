## **Установка Git**

### **Для Windows**

1. Перейдите на официальный сайт Git: [https://git-scm.com](https://git-scm.com/)
2. Скачайте последнюю версию установочного файла.
3. Запустите установщик и следуйте инструкциям. Обратите внимание на ключевые шаги:
  - **Выберите текстовый редактор по умолчанию** (рекомендуется оставить `Vim` или выбрать `Notepad++`).
  - **Настройка PATH** — выберите параметр «Git from the command line and also from 3rd-party software».
  - **Конфигурация Line endings** — рекомендуется выбрать «Checkout Windows-style, commit Unix-style line endings».


После завершения установки проверьте версию Git:

    git --version
