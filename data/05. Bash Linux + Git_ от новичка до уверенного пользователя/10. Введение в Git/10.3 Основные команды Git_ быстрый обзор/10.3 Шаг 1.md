### Основные команды Git: Управление файлами и первый коммит

В этом уроке мы изучим базовые команды Git, которые необходимы для работы с файлами в репозитории. Вы научитесь добавлять изменения, делать коммиты и отслеживать состояние вашего проекта. Этот урок — ключевой шаг к пониманию Git на практике.
