## **Просмотр и отмена изменений**

Иногда вы хотите просмотреть изменения или отменить их.

1. **Просмотр изменений:**  
Если вы изменили файл после добавления его в индекс, используйте `git diff`:

  `git diff `

  Эта команда покажет разницу между текущей версией файла и последним индексированным состоянием.

2. **Отмена изменений:**  
Чтобы удалить изменения из индекса, используйте:

  `git reset README.md `

  Файл будет удалён из индекса, но его содержимое останется неизменным.
