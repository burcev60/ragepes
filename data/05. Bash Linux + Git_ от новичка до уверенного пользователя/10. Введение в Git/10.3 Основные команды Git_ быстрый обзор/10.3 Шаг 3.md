## **Добавление файлов и индексирование**

Когда вы создаёте или изменяете файл, Git не сразу включает его в историю. Сначала нужно добавить его в индекс.

1. Создайте файл `README.md` с кратким описанием вашего проекта:

  `echo "# My Git Project" > README.md `

2. Проверьте статус репозитория:

  `git status `

  Вы увидите, что файл `README.md` находится в списке **untracked files** — он ещё не добавлен в индекс.

3. Добавьте файл в индекс:

  `git add README.md `

  Команда `git add` подготавливает файл для следующего коммита. Теперь файл находится в состоянии **staged**.

4. Проверьте статус снова:

  `git status `

  Вы увидите, что файл `README.md` готов для коммита.
