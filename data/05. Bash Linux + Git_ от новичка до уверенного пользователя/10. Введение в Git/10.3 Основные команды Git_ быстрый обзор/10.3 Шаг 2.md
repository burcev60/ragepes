## **Создание и инициализация репозитория**

Репозиторий — это хранилище вашего кода и истории изменений. Давайте создадим новый репозиторий для работы.

1. Создайте папку для нового проекта и перейдите в неё:

  `mkdir my-git-project cd my-git-project `

2. Инициализируйте новый репозиторий:

  `git init `

  Команда `git init` создаёт скрытую папку `.git`, где будет храниться вся история изменений.
