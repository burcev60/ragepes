## **Создание первого коммита**

Коммит фиксирует текущее состояние репозитория и сохраняет его в истории.

1. Сделайте первый коммит:

  `git commit -m "Первый коммит: добавлен файл README.md" `

  - Флаг `-m` позволяет добавить сообщение к коммиту.
  - Сообщение должно быть коротким и описывать внесённые изменения.

2. Проверьте историю коммитов:

  `git log `

  Вы увидите подробную информацию о каждом коммите: хэш, автора, дату и сообщение.
