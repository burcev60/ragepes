# Разбор команды mv

## Что такое mv?

**mv** (от английского *move*) — это команда, которая используется для перемещения файлов и каталогов из одного места в другое, а также для их переименования. По сути, mv изменяет расположение или имя объекта в файловой системе.

## Основной синтаксис

    mv [опции] источник назначение

- **источник** — файл или каталог, который требуется переместить или переименовать.
- **назначение** — новое имя файла или путь, куда объект будет перемещён.


## Основные варианты использования

### 1. Перемещение файлов или каталогов

    mv file.txt /home/user/documents/

Команда перемещает файл *file.txt* в каталог */home/user/documents/*. Если в указанном каталоге уже существует файл с таким же именем, он будет перезаписан (если не используется интерактивный режим).

### 2. Переименование файлов или каталогов

    mv oldname.txt newname.txt

Команда переименовывает файл *oldname.txt* в *newname.txt*. Переименование — это фактически перемещение файла в том же каталоге, но с новым именем.

### 3. Перемещение нескольких файлов в каталог

`mv file1.txt file2.txt file3.txt /home/user/backup/ `

При таком использовании все указанные файлы будут перемещены в каталог */home/user/backup/*.

## Основные опции mv

- **-i (interactive)**  
Интерактивный режим. Перед перезаписью существующего файла mv запрашивает подтверждение.

  `mv -i file.txt /home/user/documents/ `

- **-f (force)**  
Принудительное перемещение без запроса подтверждения, даже если файл назначения существует. Это значение по умолчанию, если не указана опция -i.

  `mv -f oldfile.txt newfile.txt `

- **-n (no-clobber)**  
Не перезаписывать существующие файлы в каталоге назначения.

  `mv -n file.txt /home/user/documents/ `

- **-v (verbose)**  
Подробный режим, при котором выводятся сообщения о каждом перемещённом файле или каталоге.

  `mv -v file.txt /home/user/documents/ `

## Примеры использования

### Пример 1: Переименование файла

    mv report_old.txt report_final.txt

В данном случае файл *report_old.txt* переименовывается в *report_final.txt* в том же каталоге.

### Пример 2: Перемещение файла в другой каталог

    mv image.jpg /home/user/Pictures/

Файл *image.jpg* перемещается в каталог */home/user/Pictures/*. Если в этом каталоге уже есть файл с именем *image.jpg*, он будет перезаписан (если не указан интерактивный режим).

### Пример 3: Перемещение нескольких файлов

    mv file1.log file2.log file3.log /var/log/old_logs/

Все перечисленные файлы перемещаются в каталог */var/log/old_logs/*.

### Пример 4: Использование интерактивного режима

    mv -i data.csv /backup/data.csv

Если в каталоге /backup уже существует файл data.csv, mv запросит подтверждение перед его перезаписью.

## Полезные советы

- **Переименование через перемещение:**  
Команда mv позволяет легко переименовывать файлы и каталоги, не требуя отдельной утилиты для переименования.

- **Интерактивный режим для безопасности:**  
Рекомендуется использовать опцию `-i`, чтобы избежать случайной потери данных при перемещении файлов в каталог, где уже есть файлы с такими же именами.

- **Скрипты и автоматизация:**  
В Bash-скриптах команда mv часто используется для организации логов, резервного копирования или подготовки данных к дальнейшей обработке.
