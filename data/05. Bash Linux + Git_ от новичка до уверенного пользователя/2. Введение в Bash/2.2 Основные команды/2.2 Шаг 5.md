# Разбор команды mkdir

## Что такое mkdir?

**mkdir** (сокращение от *make directory*) — это команда, предназначенная для создания новых каталогов (директорий) в файловой системе. Это одна из базовых команд, которая позволяет организовывать файлы в структуру каталогов для удобства работы.

## Основной синтаксис

`mkdir [опции] имя_каталога `

- **имя_каталога** — имя (или имена) новых директорий, которые вы хотите создать. Это может быть как относительный путь (относительно текущего каталога), так и абсолютный путь.


## Основные опции mkdir

- **-p**  
Создаёт родительские каталоги при необходимости. Если вы указываете вложенный путь, и промежуточные каталоги не существуют, опция `-p` создаст их автоматически.  
*Пример:*

    mkdir -p /home/user/projects/new_project/src

  Здесь, если каталоги `/home/user/projects/new_project` не существуют, они будут созданы вместе с `src`.

- **-v**  
(verbose) — режим подробного вывода. При использовании опции `-v` команда выводит сообщение о каждом созданном каталоге.

  `mkdir -v my_folder `

  Вы увидите сообщение: `mkdir: создан каталог 'my_folder'`.

## Примеры использования

### 1. Создание одного каталога

    mkdir my_folder

Эта команда создаст каталог с именем `my_folder` в текущей директории.

### 2. Создание нескольких каталогов одновременно

    mkdir folder1 folder2 folder3

Команда создаст три каталога (`folder1`, `folder2` и `folder3`) в текущем каталоге.

### 3. Создание вложенной структуры каталогов

Если нужно создать сразу несколько уровней каталогов, используйте опцию `-p`:

    mkdir -p projects/project1/src

Эта команда создаст каталог `projects` (если его нет), затем `project1` внутри `projects` и, наконец, `src` внутри `project1`.

### 4. Подробное создание каталога с выводом информации

    mkdir -v new_directory

При использовании `-v` вы увидите сообщение о созданном каталоге.

## Практическое применение

- **Организация файлов:**  
Используйте mkdir для структурирования данных: создавайте отдельные каталоги для проектов, документов, резервных копий и т.д.

- **Автоматизация скриптов:**  
В Bash-скриптах mkdir часто используется для создания временных или постоянных директорий перед записью файлов или логов. Например, можно проверять наличие каталога и создавать его, если его нет:

    [ -d "backup" ] || mkdir -p backup

## Советы и особенности

- **Ошибки при создании:**  
Если каталог с таким именем уже существует, команда `mkdir` выдаст сообщение об ошибке. Опция `-p` подавляет эту ошибку, если каталог уже существует.
- **Права доступа:**  
Создаваемые каталоги наследуют права доступа, заданные по умолчанию для пользователя. Если требуется изменить права, можно использовать команду `chmod` после создания каталога.
