# Разбор команды cd

## Что такое cd?

Команда **cd** (от английского *change directory*) предназначена для смены текущего рабочего каталога. Это одна из самых используемых команд в командной строке, поскольку позволяет перемещаться по файловой системе, переходить в нужные директории и организовывать работу со скриптами и файлами.

## Основной синтаксис

`cd [путь] `

- **Путь** может быть абсолютным (начинается с `/`) или относительным (относительно текущей директории).
- Если путь не указан, команда переходит в домашнюю директорию пользователя (то есть эквивалентна выполнению `cd ~`).


## Основные варианты использования

### 1. Переход в домашнюю директорию

    cd
    # или
    cd ~

Если путь не задан, Bash автоматически перемещается в домашний каталог текущего пользователя.

### 2. Абсолютный путь

    cd /usr/local/bin

Команда перемещает вас в каталог `/usr/local/bin` независимо от того, где вы находитесь.

### 3. Относительный путь

    cd Documents

Если вы находитесь в домашней директории и вводите `cd Documents`, то Bash переходит в подкаталог `Documents`.

### 4. Переход на уровень вверх

    cd ..

Команда `cd ..` поднимает вас на один уровень выше в иерархии каталогов (в родительский каталог).

### 5. Переход в предыдущий каталог

    cd -

Команда `cd -` позволяет переключиться на предыдущую рабочую директорию. Это удобно, если вы хотите быстро вернуться к месту, где были до текущего перехода.

### 6. Использование точки и двойной точки

- `.` обозначает текущий каталог, а `..` – родительский каталог.
- Например, команда:

    cd ./subdir

перейдёт в подкаталог `subdir` текущей директории, а

    cd ../otherdir

переместится в каталог `otherdir`, находящийся в родительской директории.

## Примеры использования

### Пример 1: Переход в домашнюю директорию

    cd pwd

Вы увидите полный путь к вашему домашнему каталогу.

### Пример 2: Переход в конкретный каталог

    cd /var/log pwd

Команда `pwd` покажет, что вы теперь находитесь в каталоге `/var/log`.

### Пример 3: Переход на уровень выше

    cd /usr/local/bin cd .. pwd

После выполнения `cd ..` вы окажетесь в каталоге `/usr/local`.

### Пример 4: Использование cd -

    cd /etc cd /var cd -

Команда `cd -` вернёт вас в предыдущий каталог, т.е. в `/etc`.

## Полезные советы

- **Проверка текущего каталога:**  
Если вы не уверены, где находитесь, используйте команду `pwd` для вывода абсолютного пути текущей директории.
- **Автодополнение:**  
При вводе команды `cd` можно воспользоваться автодополнением (нажимая клавишу Tab), чтобы быстрее перейти в нужный каталог.
- **Символ `~`:**  
Знак тильды (`~`) всегда означает домашний каталог. Например, `cd ~/Downloads` переместит вас в каталог загрузок вашего домашнего каталога.
