# Разбор команды help

## Что такое help?

**help** — это встроенная команда Bash, которая предназначена для вывода справочной информации именно о встроенных командах (builtins) оболочки. В отличие от команды **man**, которая предоставляет подробные руководства для большинства системных утилит, **help** сосредоточена на быстром и удобном получении справки по командам, встроенным непосредственно в Bash (например, `cd`, `alias`, `read`, `echo` и др.). Это особенно полезно, когда вам нужно быстро узнать синтаксис или краткое описание команды, не покидая сессии терминала.

## Основной синтаксис

`help [-dms] [имя_встроенной_команды...] `

- **Без аргументов:**  
Если вызвать `help` без дополнительных параметров, команда выведет список всех встроенных команд Bash вместе с кратким описанием.

- **Аргументы:**  
Если указать одно или несколько имён встроенных команд, `help` выведет справочную информацию для них.

- **Опции:**

  - **-d**  
Выводит только краткое описание (description) каждой команды.
  - **-m**  
Форматирует вывод в виде, напоминающем страницы руководства (man-like).
  - **-s**  
Выводит краткий синопсис (synopsis) использования команды.

## Примеры использования

### 1. Просмотр списка всех встроенных команд

`help `

Команда выведет список всех встроенных команд Bash с кратким описанием. Это хороший способ узнать, какие команды доступны внутри Bash.

### 2. Получение справки для конкретной команды

`help cd `

Выведет подробную информацию о команде **cd**, включая синтаксис, описание опций (если они есть) и примеры использования.

### 3. Использование опций для настройки вывода

- **Краткое описание синтаксиса для команды alias:**

  `help -s alias `

- **Вывод справки для команды read в формате, похожем на man-страницу:**

  `help -m read `

## Пример вывода

При выполнении команды:

`help cd `

Вы можете увидеть примерно такой вывод:

    cd: cd [-L|-P] [dir]
        Change the shell working directory.
        Change the current directory to DIR.  The default DIR is the value of the
        HOME shell variable.

Здесь видно:

- **Синтаксис:** `cd [-L|-P] [dir]`
- **Описание:** краткое объяснение того, что делает команда и как она работает.


## Полезные советы

- **Быстрый доступ к справке:**  
Используйте **help** для получения справочной информации по встроенным командам, не выходя из текущей Bash-сессии. Это особенно полезно для новичков, чтобы быстро разобраться в синтаксисе и назначении команд.

- **Сравнение с man:**  
Помните, что **help** работает только с встроенными командами Bash. Для остальных программ и утилит используйте `man`.

- **Использование опций:**  
Опции `-d`, `-m` и `-s` позволяют адаптировать вывод справки под ваши нужды: от краткого описания до более детализированного формата.
