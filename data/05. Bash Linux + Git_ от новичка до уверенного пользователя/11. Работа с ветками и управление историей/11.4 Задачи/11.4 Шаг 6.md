#### **Практическое задание**

**Задание:**

1. Сделайте три коммита, изменяя файл `notes.txt`.
2. Посмотрите историю коммитов с помощью `git log`.
3. Удалите второй коммит с помощью `git reset --soft`.
4. Измените сообщение последнего коммита (`git commit --amend`).
