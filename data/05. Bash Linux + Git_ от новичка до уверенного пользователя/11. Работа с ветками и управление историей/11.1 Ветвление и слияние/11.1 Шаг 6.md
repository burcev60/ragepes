## **Практическая часть**

**Шаги для выполнения задания:**

1. Создайте новую ветку `feature-branch` и переключитесь на неё. `git switch -c feature-branch `

2. Внесите изменения в файл `README.md` и сделайте коммит.

3. Переключитесь обратно на основную ветку (`main`) и выполните слияние:

  `git switch main git merge feature-branch `

4. Если возникнет конфликт, решите его и завершите слияние.
