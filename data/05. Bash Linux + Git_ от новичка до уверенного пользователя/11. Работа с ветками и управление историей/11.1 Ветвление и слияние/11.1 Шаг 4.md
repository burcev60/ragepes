## **Разрешение конфликтов**

Конфликт возникает, если изменения в разных ветках затрагивают одну и ту же часть файла. В этом случае Git не может автоматически объединить изменения.

### Пример конфликта:

`<<<<<<< HEAD Текст из основной ветки ======= Текст из feature-branch >>>>>>> feature-branch `

**Как разрешить конфликт:**

1. Отредактируйте файл, выбрав правильное содержимое.

2. Добавьте файл в индекс:

  `git add conflicted-file.txt `

3. Завершите слияние:

  `git commit -m "Решён конфликт при слиянии"`
