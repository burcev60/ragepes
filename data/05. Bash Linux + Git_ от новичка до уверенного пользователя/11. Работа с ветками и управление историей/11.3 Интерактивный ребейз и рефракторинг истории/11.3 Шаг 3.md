## **Типичные ошибки и их исправление**

При использовании интерактивного ребейза возможны конфликты.

### **Решение конфликта во время ребейза:**

1. Отредактируйте конфликтующие файлы.

2. Добавьте их в индекс:

  `git add conflicted-file.txt `

3. Продолжите ребейз:

  `git rebase --continue `

4. Если вам нужно прервать процесс и вернуться к исходному состоянию:

  `git rebase --abort`
