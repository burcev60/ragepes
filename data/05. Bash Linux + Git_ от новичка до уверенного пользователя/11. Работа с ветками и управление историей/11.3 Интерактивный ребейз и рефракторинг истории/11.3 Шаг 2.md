## **Основные сценарии использования интерактивного ребейза**

### **1. Объединение коммитов (`squash`)**

Если у вас есть несколько мелких коммитов, которые логически относятся к одной задаче, их можно объединить в один.  
**Пример:**

`pick a1b2c3 Добавлен файл README.md `

`pick d4e5f6`Обновлено описание в README.md

Измените `pick` на `squash` во втором коммите:

`pick a1b2c3 Добавлен файл README.md `

`squash d4e5f6 Обновлено описание в README.md `

Git предложит объединить сообщения коммитов, и вы можете оставить только одно.

### **2. Изменение сообщений коммитов**

Чтобы изменить сообщение коммита, используйте `reword`.  
**Пример:**

`pick a1b2c3 Добавлен файл README.md `

`reword d4e5f6 Обновлено описание в README.md `

После этого Git откроет редактор, где вы сможете отредактировать сообщение.

### **3. Удаление коммитов**

Чтобы удалить ненужный коммит, просто замените `pick` на `drop`.  
**Пример:**

`pick a1b2c3 Добавлен файл README.md `

`drop d4e5f6 Исправление неактуальной ошибки `
