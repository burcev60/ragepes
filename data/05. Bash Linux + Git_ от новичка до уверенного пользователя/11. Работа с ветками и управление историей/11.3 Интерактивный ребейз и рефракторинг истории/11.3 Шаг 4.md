## **Практическая часть**

**Шаги для выполнения задания:**

1. Создайте несколько коммитов с мелкими изменениями в файле `README.md`.
2. Используйте `git rebase -i HEAD~3` для интерактивного ребейза.
3. Объедините два из трёх коммитов (`squash`).
4. Измените сообщение одного из коммитов (`reword`).
5. Создайте ситуацию с конфликтом и решите его во время ребейза.
