## **Просмотр изменений**

Для эффективной работы с Git важно уметь отслеживать изменения, которые вы вносите в проект. Git предоставляет несколько полезных команд для этого.

### **`git diff`: просмотр различий**

Команда `git diff` позволяет увидеть изменения, которые ещё не добавлены в индекс.

`git diff `

**`git diff HEAD`: сравнение с последним коммитом**  
Если вы хотите сравнить текущую версию файлов с последним коммитом, используйте:

`git diff HEAD `

### **`git status`: текущее состояние репозитория**

Команда `git status` показывает, какие файлы были изменены, добавлены или удалены, а также их статус (индексированы или нет).
