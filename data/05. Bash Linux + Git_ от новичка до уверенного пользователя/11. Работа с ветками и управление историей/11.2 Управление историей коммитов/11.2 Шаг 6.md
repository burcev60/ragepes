## **Практическая часть**

**Шаги для выполнения задания:**

1. Сделайте несколько коммитов, изменяя файл `README.md`.
2. Посмотрите историю коммитов с помощью `git log`.
3. Измените последний коммит, добавив новый файл (`git commit --amend`).
4. Попробуйте отменить изменения в одном из файлов с помощью `git restore`.
5. Используйте `git revert`, чтобы создать новый коммит, отменяющий один из предыдущих.
