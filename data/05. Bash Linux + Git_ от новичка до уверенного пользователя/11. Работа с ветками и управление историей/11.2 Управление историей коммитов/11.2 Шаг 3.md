## **Отмена коммитов**

Иногда приходится отменять уже сделанные коммиты. Git предлагает несколько способов это сделать.

### **`git reset`: отмена коммитов**

`git reset` удаляет коммиты и возвращает изменения обратно в рабочий каталог. Используйте с осторожностью!

`git reset HEAD~1 `

Эта команда отменяет последний коммит и возвращает его изменения в рабочую область.

### **`git revert`: безопасная отмена**

В отличие от `reset`, команда `revert` создаёт новый коммит, отменяющий предыдущий, что сохраняет историю изменений.

`git revert HEAD `
