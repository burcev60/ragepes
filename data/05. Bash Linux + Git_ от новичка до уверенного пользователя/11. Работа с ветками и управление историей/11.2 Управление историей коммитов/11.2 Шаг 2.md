## **Отмена изменений**

Иногда вам нужно отменить изменения или восстановить файлы. Git предоставляет несколько способов для этого.

### **`git restore`: восстановление изменений**

Если вы изменили файл и хотите вернуть его к последней версии из коммита, используйте:

`git restore <filename> `

### **`git reset`: удаление изменений из индекса**

Если вы случайно добавили файл в индекс (`git add`), но ещё не сделали коммит, вы можете удалить его из индекса:

`git reset <filename>`
