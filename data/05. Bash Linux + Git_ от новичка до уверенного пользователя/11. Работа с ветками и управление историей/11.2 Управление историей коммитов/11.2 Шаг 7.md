## **Итоги урока**

В этом уроке вы научились:

- Использовать команды `git diff`, `git status` и `git log` для просмотра изменений и истории.
- Отменять изменения с помощью `git restore` и `git reset`.
- Использовать `git revert` для безопасного отката изменений.
- Изменять последний коммит с помощью `git commit --amend`.
