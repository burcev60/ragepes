**case:** Эта конструкция для множественного выбора по шаблонам (похожа на switch/case в других языках). Синтаксис:

    case $VARIABLE in
      "значение1")
        # команды, если VARIABLE равна "значение1"
        ;;
      "значение2")
        # команды для значения2
        ;;
      *)
        # команды по умолчанию, если ни один случай не совпал
        ;;
    esac

Звёздочка `*` обозначает "любой другой случай". Каждую ветку нужно заканчивать `;;`.

Пример использования case:

    case $1 in
      "start")
        echo "Запуск процесса..."
        ;;
      "stop")
        echo "Остановка процесса..."
        ;;
      "restart")
        echo "Перезапуск процесса..."
        ;;
      *)
        echo "Использование: $0 {start|stop|restart}"
        ;;
    esac

Если сохранить это как скрипт `service.sh` и передать ему аргумент (`start`/`stop`/`restart`), он выведет соответствующее сообщение. Если передать что-то другое или не передать ничего, выполнится блок `*` с подсказкой, как правильно пользоваться скриптом.
