# Разбор команды test

## Что такое test?

**test** — это встроенная в Bash утилита, предназначенная для проверки условий. Команда test позволяет сравнивать строки, числа, проверять существование файлов и каталоги, а также определять другие свойства. Результатом работы test является код возврата: 0 (истина) или 1 (ложь). Это позволяет использовать её в условных конструкциях, например, в операторах `if`, `while` и т.д.

`[ expr ]` — это форма команды `test expr` с обязательной закрывающей `]`. В Bash обе обычно реализованы как встроенные. Дополнительно в Bash есть `[[ expr ]]` — ключевое слово с расширенным, более безопасным синтаксисом. Для переносимости используйте `[`/`test`, для чистого Bash — предпочтительно `[[`.

## Основной синтаксис

    test условие

или эквивалентно:

    [ условие ]

При этом обязательно нужно ставить пробелы между квадратными скобками и условием.

## Основные типы проверок

### 1. Проверка строк

- **Сравнение строк:**

  `test "$str1" = "$str2" [ "$str1" = "$str2" ] `

  Проверяет, равны ли строки.  
Аналогично можно использовать `!=` для проверки неравенства.

- **Проверка на пустоту строки:**

  `[ -z "$str" ] `

  Возвращает истину, если строка пустая.

  `[ -n "$str" ] `

  Возвращает истину, если строка не пуста.

### 2. Проверка чисел

- **Сравнение числовых значений:**

    [ "$num1" -eq "$num2" ]
    [ "$num1" -ne "$num2" ]
    [ "$num1" -lt "$num2" ]
    [ "$num1" -le "$num2" ]
    [ "$num1" -gt "$num2" ]
    [ "$num1" -ge "$num2" ]

Здесь используются операторы:
  - `-eq` (equal),
  - `-ne` (not equal),
  - `-lt` (less than),
  - `-le` (less or equal),
  - `-gt` (greater than),
  - `-ge` (greater or equal).

### 3. Проверка существования файлов и каталогов

- **Проверка существования файла:**

  `[ -e "file" ] `

  Возвращает истину, если файл или каталог существует.

- **Проверка, является ли объект файлом:**

  `[ -f "file" ] `

- **Проверка, является ли объект каталогом:**

  `[ -d "directory" ] `

- **Проверка на доступность для чтения/записи/исполнения:**

    [ -r "file" ] # файл доступен для чтения
    [ -w "file" ] # файл доступен для записи
    [ -x "file" ] # файл доступен для исполнения (или это каталог)

### 4. Логические операторы

- **Логическое И (AND):**  
Можно комбинировать условия с помощью `-a` или использовать синтаксис `&&` в оболочке.

    [ "$num" -gt 0 -a "$num" -lt 10 ]

- **Логическое ИЛИ (OR):**  
Используется `-o` или `||` в оболочке.

    [ "$str" = "yes" -o "$str" = "y" ]

- **Отрицание:**  
Для отрицания условия можно использовать `!`.

    [ ! -e "file" ]

## Примеры использования

### Пример 1: Проверка равенства строк

    #!/bin/bash
    str1="hello"
    str2="world"
    if [ "$str1" = "$str2" ]; then
        echo "Строки равны."
    else
        echo "Строки не равны."
    fi

### Пример 2: Проверка числовых значений

    #!/bin/bash
    num=5
    if [ "$num" -gt 0 ] && [ "$num" -lt 10 ]; then echo
        "Число $num находится в диапазоне от 1 до 9."
    else
        echo "Число $num вне диапазона."
    fi

### Пример 3: Проверка существования файла

    #!/bin/bash
    if [ -f "/etc/passwd" ]; then
        echo "Файл /etc/passwd существует."
    else
        echo "Файл /etc/passwd не найден."
    fi

### Пример 4: Использование отрицания

    #!/bin/bash
    if [ ! -d "backup" ]; then
        echo "Каталог backup не существует, создаём его..."
        mkdir backup
    fi
