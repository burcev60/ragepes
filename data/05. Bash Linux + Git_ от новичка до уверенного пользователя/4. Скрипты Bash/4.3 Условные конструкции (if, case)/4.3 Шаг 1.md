### Условные конструкции (if, case)

Жизнь полна условий: "если идёт дождь – взять зонт, иначе – надеть очки от солнца". Bash-скрипты тоже должны уметь принимать решения на основе каких-то проверок. Для этого служит конструкция `if` (если) и `case` (разветвление по случаям).

**if-then-else:** В Bash синтаксис условной конструкции выглядит так:

    if [ условие ]; then
        # команды, если условие истинно
    elif [ другое условие ]; then
        # команды, если истинно другое условие (необязательная часть)
    else
        # команды, если ни одно условие не истинно (необязательная часть)
    fi

Обрати внимание: после `if` условие пишется **внутри квадратных скобок**, окружённых пробелами. `then` можно писать на той же строчке через точку с запятой, либо на новой строке. В конце конструкции ставится `fi` (if наоборот), чтобы Bash знал, где условие закончилось.

Что можно писать в условии? Очень многое! Часто используют команду `test` (она же вызывается через `[ ]`) для проверки файлов и сравнения значений:

- `[ -f somefile ]` – истинно, если файл *somefile* существует (и это файл, а не каталог).

- `[ -d somedir ]` – истинно, если *somedir* существует и это директория.

- `[ 5 -gt 3 ]` – сравнение чисел (*greater than*: 5 > 3, будет истинно).

- `[ "$NAME" = "Вася" ]` – сравнение строк (равна ли переменная NAME строке "Вася"). Здесь кавычки вокруг `$NAME` на случай, если переменная пуста, чтобы не получить ошибку синтаксиса.

Например:

    if [ -d "$1" ]; then
        echo "Каталог $1 существует."
    else
        echo "Каталог $1 не найден."
    fi

Этот скрипт (предположим, $1 – путь к каталогу) проверяет наличие директории. Если она есть – выводит одно сообщение, если нет – другое.

Важно: вместо `[` и `]` можно писать команду прямо:

    if ping -c 1 8.8.8.8 > /dev/null 2>&1; then
        echo "Интернет соединение в порядке!"
    fi

Здесь `ping` отправляет 1 пакет на 8.8.8.8 (Google DNS) и **не выводит** ничего (`> /dev/null 2>&1` отправляет весь вывод в "чёрную дыру"). Если `ping` прошёл успешно (вернул код 0), то условие считается истинным и выполняется `echo`. Если нет – условие ложно и блок if просто пропускается (можно было бы добавить `else` с сообщением "Интернет недоступен").
