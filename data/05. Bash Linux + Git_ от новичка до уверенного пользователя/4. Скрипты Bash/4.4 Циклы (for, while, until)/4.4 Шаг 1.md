### Циклы (for, while, until)

Повторение – мать учения, а для компьютера повторение – часть работы. В Bash есть несколько способов организовать повторяющиеся действия.

**Цикл for:** Используется, когда нужно перебрать набор значений. Например, перебрать список файлов или чисел:

    for i in 1 2 3 4 5; do
        echo "Счёт: $i"
    done

Этот скрипт выведет счёт от 1 до 5. А вот более практичный пример – перебор файлов:

    for file in *.txt; do
        echo "Найден текстовый файл: $file"
    done

Здесь `*.txt` – шаблон, и Bash подставит вместо него все файлы, оканчивающиеся на .txt в текущей директории. Переменная `file` по очереди принимает значение каждого имени, а внутри цикла мы просто печатаем его.

**Цикл while:** Выполняет блок команд, пока условие истинно. Формат:

    while [ условие ]; do
        # команды
    done

Например

    count=1
    while [ $count -le 5 ]; do
        echo "Повтор $count"
        count=$((count+1))
    done

Этот скрипт будет печатать "Повтор 1", "Повтор 2", ... пока переменная count не станет 6 (условие `$count -le 5` станет ложным). Обрати внимание на строчку `count=$((count+1))`: так в Bash работает арифметика (добавляем 1 к переменной count). Также существуют сокращения типа `((count++))` для инкремента.

While полезен, когда заранее не известен точный список итераций, а нужно "крутиться" пока выполняется какое-то условие. Например, можно читать файл построчно: `while read LINE; do ...; done < file.txt` – этот цикл будет бежать по всем строкам файла, пока они не закончатся.

**Цикл until:** Это почти то же самое, что while, но условие проверяется на ложность: цикл выполняется **пока условие ложно**. То есть

    until [ условие ]; do ...; done

эквивалентно

    while [ ! условие ]; do ...; done`.

Некоторые предпочитают `until`, потому что иногда условие "пока не X" проще выразить, чем "пока не не X". Но на практике можно обходиться и одним `while`.

В циклах также работают ключевые слова **break** (прервать цикл досрочно) и **continue** (перейти сразу к следующей итерации, пропустив остаток тела цикла).

Например, добавим проверку в наш первый пример:

    for i in 1 2 3 4 5; do
        if [ $i -gt 3 ]; then
            break  # прервать цикл, если i больше 3
        fi
        echo "i = $i"
    done

Этот цикл выведет `i = 1`, `i = 2`, `i = 3` и остановится, потому что при i=4 сработает break.

С помощью циклов можно автоматизировать массу однообразной работы: от проверки списка серверов пингом до конвертации сотни картинок разом. Главное – чётко задать условие, чтобы не получить "бесконечный цикл" (ужас каждого программиста, когда скрипт не заканчивается, потому что условие всегда истинно).
