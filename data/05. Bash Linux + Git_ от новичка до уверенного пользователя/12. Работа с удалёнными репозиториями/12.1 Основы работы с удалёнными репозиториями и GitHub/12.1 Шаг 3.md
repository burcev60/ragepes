## **Подключение к удалённому репозиторию**

Для подключения локального репозитория к удалённому используется команда `git remote`. Обычно главный удалённый репозиторий называется `origin`.

### **Добавление удалённого репозитория**

`git remote add origin <URL> `

Замените `<URL>` на ссылку вашего удалённого репозитория (например, `https://github.com/username/repo.git`).

### **Проверка подключённых удалённых репозиториев**

`git remote -v `

Вы увидите список подключённых репозиториев и их URL.
