Чтобы облегчить себе жизнь, давайте добавим себе на GitLab или на GitHub ssh-ключ. Он позволит не вводить каждый раз пароль/Access Token при операциях с удаленным репозиторием.

### Генерация ключа

1. Откройте терминал (Git Bash, macOS Terminal или Linux shell).

2. Выполните команду генерации ключа ED25519 (рекомендуется) или RSA, если ED25519 не поддерживается:

  `ssh-keygen -t ed25519 -C "you@example.com" `

  - Git предложит путь `~/.ssh/id_ed25519` — нажмите **Enter**, чтобы принять по умолчанию.

  - При желании введите **passphrase** (парольную фразу) для защиты ключа или нажмите **Enter**, чтобы оставить пустой (автоматический доступ).
> **Ожидаемый вывод:**
>
> Generating public/private ed25519 key pair.
> Enter file in which to save the key (/home/user/.ssh/id_ed25519):
> Enter passphrase (empty for no passphrase):
> Enter same passphrase again:
> Your identification has been saved in /home/user/.ssh/id_ed25519
> Your public key has been saved in /home/user/.ssh/id_ed25519.pub
> The key fingerprint is:
> SHA256:… you@example.com
> The key's randomart image is:
> +--[ED25519 256]--+
> |   .+*oo         |
> |  . o=+.o        |
> …
> +----[SHA256]-----+

### 2. Запуск SSH-агента и добавление ключа

Чтобы система могла автоматически подставлять ваш приватный ключ при соединении:

    # Запустить фонового ssh-агента eval "$(ssh-agent -s)"

    # Добавить ключ в агент ssh-add ~/.ssh/id_ed25519
> Если вы задали passphrase, вас попросят его ввести здесь.

### 3. Копирование публичного ключа

Скопируйте содержимое `~/.ssh/id_ed25519.pub` в буфер обмена:

- **Linux**:

  `xclip -sel clip < ~/.ssh/id_ed25519.pub `

- **macOS**:

  `pbcopy < ~/.ssh/id_ed25519.pub `

- **Windows (Git Bash)**:

  `cat ~/.ssh/id_ed25519.pub | clip `

### 4. Добавление ключа на Git-хостинг

1. **GitHub**

  - Откройте *Settings → SSH and GPG keys → New SSH key*.

  - В поле **Title** дайте понятное имя (например, “Work Laptop”).

  - Вставьте скопированный ключ и нажмите **Add SSH key**.

2. **GitLab**

  - Перейдите в *Profile Settings → SSH Keys*.

  - Вставьте ключ в поле **Key**, по желанию добавьте **Title**, нажмите **Add key**.

3. **Bitbucket**

  - Откройте *Personal settings → SSH keys → Add key*.

  - Вставьте ключ и сохраните.

### 5. Настройка файла `~/.ssh/config` (опционально)

Чтобы не прописывать каждый раз полный адрес, добавьте в `~/.ssh/config`:

    Host github.com
        HostName github.com
        User git
        IdentityFile ~/.ssh/id_ed25519
        IdentitiesOnly yes

    Host gitlab.com
        HostName gitlab.com
        User git
        IdentityFile ~/.ssh/id_ed25519

    # Добавьте аналогичные блоки для других хостов

### 6. Проверка соединения

Убедитесь, что всё работает:

`ssh -T git@github.com `

Ожидаемый ответ (пример для GitHub):
> Hi username! You’ve successfully authenticated, but GitHub does not provide shell access.

### 7. Клонирование и работа с репозиторием

Теперь ваши команды `git clone`, `git push` и `git pull` будут выполняться по SSH без запроса пароля:

    git clone git@github.com:youruser/your-repo.git
    cd your-repo
    # вносите правки
    git add .
    git commit -m "Some changes"
    git push origin main
