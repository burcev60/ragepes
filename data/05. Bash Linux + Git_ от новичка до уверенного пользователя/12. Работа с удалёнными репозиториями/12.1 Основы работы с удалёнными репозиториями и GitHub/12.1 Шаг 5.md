## **Обновление и публикация изменений**

### **`git fetch`: получение изменений**

`git fetch` загружает изменения из удалённого репозитория, но не сливает их с вашей локальной веткой.

`git fetch origin `

### **`git pull`: получение и слияние изменений**

`git pull` объединяет `git fetch` и автоматическое слияние.

`git pull origin main `

### **`git push`: отправка изменений**

После внесения изменений в локальный репозиторий, вы можете отправить их в удалённый репозиторий.

`git push origin main `

Если вы работаете с новой веткой, используйте флаг `-u` для установки отслеживания этой ветки:

`git push -u origin feature-branch`
