## **Частые ошибки и их решение**

1. **`fatal: remote origin already exists`**  
**Решение:** Удалите старый удалённый репозиторий и добавьте новый:

  `git remote remove origin git remote add origin <URL> `

2. **`! [rejected]`** при попытке `git push`.  
**Причина:** Ваш локальный репозиторий отстаёт от удалённого.  
**Решение:** Выполните `git pull` перед `git push`.
