## **Практическая часть**

**Задание:**

1. Создайте новый репозиторий на GitHub.

2. Свяжите его с локальным проектом:

  `git remote add origin https://github.com/username/my-repo.git `

3. Сделайте изменения в файле `README.md` и добавьте их в коммит:

  `echo "My first remote repo" > README.md git add README.md git commit -m "Добавлен файл README.md" `

4. Отправьте изменения в удалённый репозиторий:

  `git push origin main `

5. Проверьте результат в веб-интерфейсе GitHub.
