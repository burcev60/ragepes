## **Практическая часть**

1. Создайте ветку `feature-branch` и внесите изменения в файл `README.md`.

2. Запушьте изменения в удалённый репозиторий:

  `git push origin feature-branch `

3. Создайте Pull Request на GitHub, добавив описание изменений.

4. Попросите коллегу или друга проверить Pull Request и оставить комментарии.

5. Решите конфликт (если он возникнет) и завершите слияние.
