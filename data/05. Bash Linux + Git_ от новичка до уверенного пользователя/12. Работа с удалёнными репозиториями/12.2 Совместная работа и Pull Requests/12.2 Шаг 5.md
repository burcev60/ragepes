## **Решение конфликтов в Pull Request**

Конфликты возникают, если изменения в вашей ветке пересекаются с изменениями в основной ветке. GitHub позволяет решать конфликты через веб-интерфейс.

### **Шаги для решения конфликта:**

1. Перейдите в Pull Request и нажмите **Resolve conflicts**.
2. Отредактируйте конфликтующий файл, выбрав правильное содержимое.
3. Нажмите **Mark as resolved** и затем **Commit merge**.


Если конфликт слишком сложный, решите его локально:

`git pull origin main `

`git merge feature-branch # Решите конфликт, затем: `

`git add . git commit -m "Решён конфликт" `

`git push origin feature-branch`
