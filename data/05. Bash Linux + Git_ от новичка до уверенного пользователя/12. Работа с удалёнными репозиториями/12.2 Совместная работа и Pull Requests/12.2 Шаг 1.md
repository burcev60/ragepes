## **Что такое Pull Request (PR)?**

Pull Request (PR) — это запрос на внесение изменений из одной ветки в другую. Он позволяет:

- **Проводить код-ревью** перед слиянием изменений.
- **Обсуждать и улучшать код** с коллегами.
- **Документировать процесс разработки.**


**Пример использования:**  
Вы создаёте новую функцию в ветке `feature-branch` и хотите внести её в основную ветку `main`. Вместо мгновенного слияния вы создаёте Pull Request. Ваши коллеги проверяют изменения, комментируют код и одобряют его перед слиянием.
