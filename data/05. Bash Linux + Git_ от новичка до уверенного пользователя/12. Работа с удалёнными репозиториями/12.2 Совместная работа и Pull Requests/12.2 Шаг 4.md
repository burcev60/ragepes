## **Code Review и комментарии к Pull Request**

Code Review — важная часть командной работы. GitHub позволяет добавлять комментарии к отдельным строкам кода, задавать вопросы и давать советы по улучшению.

### **Основные шаги:**

1. Перейдите к разделу **Files Changed** в Pull Request.
2. Наведите курсор на строку кода и нажмите **+ Add a comment**.
3. Напишите комментарий и нажмите **Start a review**.
