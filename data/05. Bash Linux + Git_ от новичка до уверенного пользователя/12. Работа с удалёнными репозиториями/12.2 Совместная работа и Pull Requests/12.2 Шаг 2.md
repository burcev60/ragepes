## **Создание Pull Request на GitHub**

### **Через веб-интерфейс GitHub:**

1. **Перейдите в ваш репозиторий на GitHub.**
2. Нажмите на вкладку **Pull Requests** и затем **New Pull Request**.
3. Выберите ветки для слияния (`base` — ветка, в которую будут внесены изменения, и `compare` — ветка с вашими изменениями).
4. Напишите **заголовок** и **описание** Pull Request, объясняя цель изменений.
5. Нажмите **Create Pull Request**.
