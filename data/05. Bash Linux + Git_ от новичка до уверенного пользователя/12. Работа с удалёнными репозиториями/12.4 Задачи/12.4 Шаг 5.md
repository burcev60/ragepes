#### **Практическое задание**

**Задание:**

1. Создайте ветку `feature-branch` и внесите изменения в файл `README.md`.
2. Запушьте изменения в удалённый репозиторий.
3. Создайте Pull Request на GitHub для слияния `feature-branch` в `main`.
4. Попросите коллегу оставить комментарии к вашему Pull Request.

    git checkout -b feature-branch  
    echo "New feature" >> README.md  
    git add README.md  
    git commit -m "Добавлена новая функция"  
    git push origin feature-branch

Затем создайте Pull Request через веб-интерфейс GitHub.
