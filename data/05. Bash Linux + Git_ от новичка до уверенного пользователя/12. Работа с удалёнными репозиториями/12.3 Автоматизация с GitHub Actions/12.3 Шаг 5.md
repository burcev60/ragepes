## **Практическая часть**

1. Создайте приватный репозиторий на GitHub.
2. Нашите простенькую программу на вашем любимом языке, например функцию, которая складывает 2 числа
3. Напишите под нее тесты
4. Создайте новый файл `.github/workflows/ci.yml` в вашем репозитории.
5. Напишите конфигурацию для автоматического тестирования проекта при каждом пуше в ветку `main`.
6. Убедитесь, что workflow успешно выполняется, проверив вкладку **Actions** на GitHub.
