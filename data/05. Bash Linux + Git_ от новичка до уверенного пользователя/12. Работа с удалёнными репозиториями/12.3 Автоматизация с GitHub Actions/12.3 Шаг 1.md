## **Что такое GitHub Actions?**

GitHub Actions — это инструмент для автоматизации рабочих процессов (workflow) в вашем репозитории. Он позволяет:

- **Автоматически тестировать код** при каждом изменении.
- **Собирать и развертывать приложения.**
- **Проверять качество кода и стиль.**


**Пример использования:**  
Вы хотите, чтобы каждый новый коммит в ветку `main` запускал тесты. Если тесты проходят успешно, код считается готовым для продакшена. GitHub Actions автоматически выполняет эту задачу.
