## **Создание простого workflow**

### **Шаги для создания файла конфигурации:**

1. В корне вашего репозитория создайте папку `.github/workflows/`.
2. В этой папке создайте файл `ci.yml`.


**Пример файла `ci.yml`:**

    name: CI

    on:
      push:
        branches:
          - main

    jobs:
      build:
        runs-on: ubuntu-latest
        steps:
          - name: Checkout code
            uses: actions/checkout@v2

          - name: Install Node.js
            uses: actions/setup-node@v2
            with:
              node-version: 14

          - name: Run tests
            run: npm test

**Что делает этот workflow:**

- Запускается при каждом пуше в ветку `main`.
- Проверяет код из репозитория.
- Устанавливает Node.js версии 14.
- Запускает тесты командой `npm test`.
