## **Популярные действия (actions)**

GitHub предоставляет множество готовых действий (actions), которые упрощают настройку рабочих процессов.

### **Примеры:**

- **`actions/checkout`** — проверка кода из репозитория.
- **`actions/setup-node`** — установка Node.js.
- **`docker/build-push-action`** — сборка и публикация Docker-образов.
