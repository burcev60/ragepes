### Функции: определение и вызов

По мере роста скрипта некоторые действия могут повторяться. Вместо того чтобы копировать-вставлять одни и те же команды, разумно вынести их в функцию. **Функция** в Bash – как мини-скрипт внутри скрипта, которому можно присвоить имя и потом вызывать сколько угодно раз. Аналогия: если ты часто готовишь одно и то же блюдо, проще сохранить рецепт отдельно, чем вспоминать его с нуля каждый раз.

**Как объявить функцию:**

    myfunc() {
        # здесь набор команд
    }

Так мы создаём функцию с именем `myfunc`. Можно также писать `function myfunc() { ... }` – разницы почти нет, это вопрос стиля. Внутри фигурных скобок размещаем любые команды. Объявление функции само по себе ничего не выполняет, оно просто "запоминается" Bash'ем.

**Вызов функции:** Чтобы исполнить код функции, в скрипте достаточно написать её имя как отдельную команду. Например:

    #!/bin/bash
    hello() {
        echo "Hello, $1!"
    }
    hello "world"
    hello "Bash"

Эта программа определяет функцию `hello` (которая печатает приветствие, используя первый аргумент $1 как имя) и потом дважды вызывает её: сначала с аргументом "world", потом с "Bash". В результате в терминале появится:

    Hello, world!
    Hello, Bash!

Обрати внимание: мы можем передавать параметры в функцию так же, как в скрипт – через `$1`, `$2` и т.д., внутри тела функции. После вызова функции выполнение основного скрипта продолжается со следующей строки после вызова.

Функции помогают сделать код понятнее и избежать дублирования. Например, если несколько раз в разных местах надо проверить доступность сайта, можно написать функцию `check_site` с `curl` или `ping` внутри, и вызывать её по необходимости.

**Локальные переменные в функциях:** По умолчанию переменные, созданные внутри функции, являются **глобальными** для всего скрипта (если их имя не совпадает с именем другой переменной снаружи). То есть если в функции ты сделал `x=5`, то после выхода из функции переменная `$x` сохранит значение 5. Это может привести к нежелательным эффектам, если случайно использовал одно имя дважды. Чтобы ограничить переменную рамками функции, объяви её с ключевым словом `local`:

    function demo() {
        local temp="временно"
        echo "Внутри функции: $temp"
    }
    demo
    echo "Снаружи функции: $temp"

В этом примере вне функции переменная `$temp` не будет существовать (или останется прежней, если где-то была объявлена снаружи), потому что внутри функции она была локальной.

**Возврат из функции:** Функция может возвращать **код выхода** (как и скрипт, завершиться с кодом 0 или другим). Для этого используется команда `return <код>`. По умолчанию, если явно не указать `return`, результатом будет код выхода последней выполненной команды внутри функции. Код возврата функции можно получить через `$?` после её вызова. Однако чаще в Bash поступают иначе: если нужно получить какое-то вычисленное значение из функции, просто выведи его (через `echo`) и "поймай" этот вывод в переменную через подстановку команд. Например:

    add() {
        echo $(($1 + $2))
    }
    result=$(add 5 7)
    echo "Результат сложения: $result"

Здесь функция `add` выводит сумму, а конструкция `result=$(add 5 7)` запускает функцию и кладёт то, что она вывела, в переменную result.
