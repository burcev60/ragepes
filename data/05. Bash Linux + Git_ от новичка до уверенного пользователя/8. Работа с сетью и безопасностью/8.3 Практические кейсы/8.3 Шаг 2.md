### Скрипт мониторинга системы

Теперь задача: следить за состоянием системы и предупреждать, если что-то выходит за рамки нормы. Например, место на диске заканчивается или какой-то сервис упал. Настроим простой мониторинг: проверим использование диска и, если оно слишком высокое, выведем предупреждение.

Пример скрипта `disk_monitor.sh`:

    #!/bin/bash
    THRESHOLD=90  # порог в процентах

    # Получаем процент использования корневого раздела /
    usage=$(df / | tail -1 | awk '{print $5}' | sed 's/%//')

    if [ "$usage" -ge "$THRESHOLD" ]; then
        echo "ВНИМАНИЕ: заполнение диска составляет ${usage}% (превышает порог ${THRESHOLD}%)!"
    else
        echo "Место на диске в порядке: занято ${usage}%.";
    fi

Разберём ключевые моменты:

- `df /` выводит таблицу использования дисков, нас интересует строка для корневого раздела (последняя строка, поэтому `tail -1`).

- В этой строке 5-й столбец (поле) — процент использования с символом `%`. Мы используем `awk` чтобы вытащить 5-е поле, оно будет, например, "85%".

- Через `sed 's/%//'` убираем знак процента, чтобы осталось только число.

- Дальше условие `if` сравнивает это число с порогом (`90`). Если больше или равно – бьём тревогу, выводим предупреждение. Иначе – сообщаем, что всё нормально.

На практике такой скрипт можно также настроить на запуск раз в час и, например, отсылать email администратору вместо простого echo (но это уже следующий уровень).

Другой пример мониторинга: проверка, работает ли веб-сервер. Можно использовать команду curl для запроса страницы и проверять код ответа:

    if curl -s --head http://localhost | grep "200 OK" > /dev/null; then
        echo "Сервер отвечает нормально."
    else
        echo "Сервер не отвечает!"
    fi

Здесь с помощью curl делаем тихий (`-s`) HTTP-запрос к localhost (предположим, там должен быть веб-сервер) и смотрим только заголовки ответа (`--head`). Если находим строку "200 OK", значит сервер в порядке, иначе – проблема. Такой скрипт можно запускать через cron каждую минуту и в случае проблемы предпринимать действия (например, перезагрузить сервис или отправить уведомление).
