# Разбор команды wget

## Что такое wget?

**wget** — это командная утилита, предназначенная для скачивания файлов по протоколам HTTP, HTTPS и FTP. Она работает в фоновом режиме, поддерживает возобновление загрузок, рекурсивное скачивание и многое другое. Благодаря своей надежности и возможности работать в автономном режиме wget часто используется для автоматизации загрузок и создания резервных копий веб-сайтов.

## Основной синтаксис

`wget [опции] URL `

- **URL** — это адрес ресурса, который необходимо скачать.
- **Опции** позволяют задавать дополнительные параметры для управления загрузкой.


## Основные опции

- **-O [файл]**  
Сохраняет загруженный контент в указанный файл, вместо использования имени, заданного на сервере.  
*Пример:*

  `wget -O page.html https://example.com `

- **-c**  
Продолжает загрузку файла, если она была прервана (resume).  
*Пример:*

  `wget -c largefile.zip `

- **-q**  
Работает в тихом (quiet) режиме, не выводя подробностей загрузки.  
*Пример:*

  `wget -q https://example.com/file.txt `

- **-r**  
Рекурсивное скачивание, которое позволяет загружать веб-сайт целиком, следуя по ссылкам.  
*Пример:*

  `wget -r https://example.com `

- **-np**  
(no-parent) Используется с рекурсивным скачиванием для предотвращения перехода wget к родительским каталогам.  
*Пример:*

  `wget -r -np https://example.com/subdir/ `

- **-nd**  
(no-directories) Скачивает все файлы в текущий каталог, не создавая структуру директорий, соответствующую сайту.  
*Пример:*

  `wget -r -nd https://example.com/files/ `

- **--limit-rate**  
Ограничивает скорость загрузки, что полезно для контроля пропускной способности.  
*Пример:*

  `wget --limit-rate=100k https://example.com/largefile.iso `

- **-U [User-Agent]**  
Позволяет задать строку User-Agent для имитации определённого браузера или клиента.  
*Пример:*

  `wget -U "Mozilla/5.0" https://example.com `

## Примеры использования

### Пример 1: Скачивание одного файла

`wget https://example.com/file.zip `

Скачивает файл `file.zip` в текущий каталог, используя имя, заданное сервером.

### Пример 2: Скачивание с указанием имени файла

`wget -O myfile.zip https://example.com/file.zip `

Скачивает файл и сохраняет его под именем `myfile.zip`.

### Пример 3: Продолжение прерванной загрузки

`wget -c https://example.com/largefile.iso `

Если загрузка файла `largefile.iso` была прервана, команда продолжит её с того места, где она остановилась.

### Пример 4: Рекурсивное скачивание сайта

`wget -r -np -nd https://example.com/gallery/ `

Скачивает все файлы из каталога `gallery` на сайте example.com, не переходя в родительские каталоги и сохраняя файлы в текущем каталоге без создания вложенной структуры.

### Пример 5: Ограничение скорости загрузки

`wget --limit-rate=50k https://example.com/largefile.iso `

Скачивает файл, ограничивая скорость загрузки до 50 килобайт в секунду.

## Полезные советы

- **Рекурсивное скачивание:**  
Используйте комбинацию опций `-r -np -nd`, если хотите загрузить файлы из определённого каталога без создания вложенной структуры и без перехода на уровни выше.

- **Возобновление загрузки:**  
Если у вас часто прерывается соединение, добавляйте опцию `-c`, чтобы wget мог продолжить загрузку файла без повторного скачивания уже полученной части.

- **Тихий режим:**  
Для использования в скриптах, когда вам не нужно видеть подробный вывод, используйте опцию `-q`.

- **Ограничение скорости:**  
Если сеть используется другими критичными задачами, установите ограничение скорости с помощью `--limit-rate`.
