### Основы сетевых команд (ping, netstat, curl, wget)

Bash хорош не только для работы с файлами, но и для взаимодействия с сетью. Вот несколько команд, которые пригодятся для проверки соединения и скачивания данных:

- **ping** – проверяет доступность удалённого узла по сети. Это как послать короткое "привет, ты там?" и ждать "да, я здесь!" в ответ. Команда `ping 8.8.8.8` начнёт отправлять сетевые пакеты на адрес 8.8.8.8 (Google DNS) и выводить статистику их возврата. Обычно ping посылает пакеты бесконечно, пока его не прервёшь (Ctrl+C). С опцией `-c` можно указать число пакетов, например `ping -c 4 example.com` отправит 4 пакета на example.com и остановится.

- **netstat** – отображает сетевую статистику и список соединений. Запустив `netstat -tulnp` (требует прав sudo на многих системах), ты увидишь все открытые порты (слушающие сокеты) и какие процессы их используют, а также активные соединения. Более простая форма `netstat -a` покажет все соединения и порты, а `netstat -r` – таблицу маршрутизации. Если нужно узнать, слушает ли машина порт 80 (HTTP), или какие соединения установлены, netstat поможет. (Примечание: в новых дистрибутивах вместо netstat часто используют команду `ss` с похожими параметрами).

- **curl** – универсальная утилита для запросов по разным протоколам (HTTP, FTP и др.). Особенно часто используется для скачивания веб-страниц или данных через API. Например, `curl http://example.com` выведет HTML код страницы example.com прямо в консоль. Можно сохранить вывод в файл: `curl -o page.html http://example.com`. Curl умеет отправлять данные методом POST, загружать файлы по FTP, показывать только заголовки ответа (`-I`), и многое другое – он настоящая "швейцарская армия" сетевых команд.

- **wget** – ещё одна утилита для скачивания из интернета, более простая в использовании для базовых задач. Команда `wget http://example.com/file.zip` скачает файл *file.zip* в текущую директорию. В отличие от curl, wget сразу сохраняет результат на диск (по умолчанию в файл с оригинальным именем), а не выводит в консоль. Wget хорош для простого скачивания файлов, поддерживает докачку прерванной загрузки (`-c`), рекурсивное скачивание сайтов (`-r`), и работает без лишних настроек.

Попробуй: с помощью curl получить заголовки ответа от сайта (например, `curl -I http://example.com`), или с помощью wget скачать какой-нибудь файл. Так ты убедишься, что интернет-команды работают.
