# Разбор команды curl

## Что такое curl?

**curl** (Client URL) — это командная утилита для передачи данных с использованием различных протоколов, таких как HTTP, HTTPS, FTP, SMTP и многих других. С её помощью можно получать и отправлять данные, выполнять HTTP-запросы, работать с API, а также скачивать файлы и страницы. Благодаря гибкости и множеству опций, curl является незаменимым инструментом для разработчиков, системных администраторов и тестировщиков.

## Основной синтаксис

`curl [опции] [URL] `

- **URL** — адрес ресурса, с которым необходимо взаимодействовать.
- **Опции** — позволяют настраивать запросы, выбирать методы (GET, POST, PUT и т.д.), устанавливать заголовки, передавать данные, управлять куками и многое другое.


## Основные опции

- **-o [файл]**  
Сохраняет полученный контент в указанный файл.

  `curl -o index.html https://example.com `

- **-O**  
Сохраняет файл с тем же именем, которое указано в URL.

  `curl -O https://example.com/file.zip `

- **-L**  
Следует за перенаправлениями (HTTP 3xx), что позволяет автоматически переходить по новому URL.

  `curl -L https://example.com `

- **-I**  
Выполняет HTTP HEAD-запрос, выводя только заголовки ответа, без тела.

  `curl -I https://example.com `

- **-X [метод]**  
Указывает HTTP-метод для запроса (например, GET, POST, PUT, DELETE).  
*Пример:*

  `curl -X POST https://example.com/api `

- **-d [данные]**  
Передаёт данные в теле запроса (используется с методами POST или PUT).

  `curl -d "param1=value1&param2=value2" -X POST https://example.com/api `

- **-H [заголовок]**  
Позволяет добавить пользовательский HTTP-заголовок к запросу.  
*Пример:*

  `curl -H "Content-Type: application/json" -d '{"key": "value"}' -X POST https://example.com/api `

- **-u [пользователь:пароль]**  
Задает данные для аутентификации (Basic Authentication).  
*Пример:*

  `curl -u username:password https://example.com/secure `

- **-v**  
Включает подробный режим (verbose), выводящий отладочную информацию о процессе выполнения запроса.  
*Пример:*

  `curl -v https://example.com `

## Примеры использования

### Пример 1: Загрузка веб-страницы

`curl -o page.html https://www.example.com `

Скачивает содержимое страницы и сохраняет его в файл `page.html`.

### Пример 2: Скачивание файла с сохранением исходного имени

`curl -O https://www.example.com/archive.zip `

Загружает файл и сохраняет его под именем `archive.zip`.

### Пример 3: Отправка POST-запроса с данными

    curl -X POST -H "Content-Type: application/json"
    -d '{"username": "john", "password": "secret"}'
    https://api.example.com/login

Отправляет POST-запрос для аутентификации с данными в формате JSON.

### Пример 4: Получение HTTP-заголовков

`curl -I https://www.example.com `

Отправляет HEAD-запрос и выводит только заголовки ответа.

### Пример 5: Следование перенаправлениям

`curl -L https://bit.ly/some-short-url `

Следует за перенаправлениями, чтобы получить окончательный ответ.
