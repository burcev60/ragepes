## **Распространённые ошибки при работе с Git и как их избежать**

### **Ошибка 1: Случайное удаление ветки или коммита**

**Что произошло:** Вы удалили ветку или коммит, который содержит важные изменения.

**Как исправить:**

- Используйте `git reflog` для восстановления коммита:

    git reflog  
    git checkout <commit-hash>  

- Создайте новую ветку из восстановленного коммита:

    git checkout -b restored-branch
