## **Подготовка к командной работе**

### **Проведение код-ревью**

Код-ревью помогает улучшить качество кода и избежать ошибок.

**Рекомендации:**

- Давайте конструктивную обратную связь.
- Проверяйте читаемость и тестируемость кода.
- Следите за стилем и стандартами команды.


### **Написание удобных и понятных сообщений коммитов**

**Плохое сообщение:**

`fix bug `

**Хорошее сообщение:**

`Исправлена ошибка отображения кнопки в мобильной версии (#123) `

**Советы:**

- Используйте краткие и точные описания.
- Указывайте номер задачи или баг-репорта.
- Добавляйте подробности, если необходимо.
