### **Ошибка 2: Конфликты слияния (`merge conflicts`)**

**Что произошло:** При слиянии двух веток Git не смог автоматически объединить изменения.

**Как исправить:**

1. Найдите конфликтующие файлы — Git пометит их в вашем проекте.
2. Откройте файлы и вручную разрешите конфликты.  
Пример конфликта:

    <<<<<<< HEAD  
    версия из ветки `main`  
    =======  
    версия из ветки `feature`  
    >>>>>>> feature  

3. После разрешения конфликта выполните коммит

    git add .  
    git commit -m "Resolved merge conflict"
