## **Оптимизация репозитория**

1. **Создайте файл `.gitignore`:**  
Убедитесь, что ненужные файлы и директории исключены из репозитория.  
**Пример `.gitignore`:**

    __pycache__/  
    *.log  
    .env  
    node_modules/  

**Очистите историю:**  
Удалите большие файлы из истории, если они попали в репозиторий случайно.

`git filter-branch --tree-filter 'rm -f large-file.bin' HEAD `
