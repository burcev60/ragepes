## **Создание структуры репозитория**

1. **Создайте новый репозиторий на GitHub:**  
Перейдите на GitHub и создайте репозиторий с именем `final-project`. Убедитесь, что он публичный и инициализирован с файлом `README.md`.

2. **Добавьте подмодули:**  
Создадим два подмодуля — библиотеку для интерфейса и набор утилит.

    git submodule add https://github.com/username/ui-library.git external/ui-library  
    git submodule add https://github.com/username/utils.git external/utils  

  После этого инициализируйте и обновите подмодули:

    git submodule init  
    git submodule update  

   

3. **Проверьте структуру:**  
Убедитесь, что подмодули добавлены и обновлены:

  `git submodule `
