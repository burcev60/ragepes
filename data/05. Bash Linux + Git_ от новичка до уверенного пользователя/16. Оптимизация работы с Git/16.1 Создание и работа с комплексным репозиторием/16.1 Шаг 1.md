## **Описание репозитория.**

В этом уроке мы соберём воедино всё, что вы изучили за курс, и создадим полноценный репозиторий с продвинутыми функциями. Основной задачей будет создание репозитория с несколькими подмодулями, внедрением CI/CD, использованием Git Flow и настройкой автоматических проверок.

**Основные цели проекта:**

1. Создать многоуровневый репозиторий с подмодулями.
2. Использовать Git Flow для управления ветками.
3. Настроить автоматическое тестирование и деплой через GitHub Actions.
4. Подключить таск-трекеры для управления задачами.
5. Оптимизировать репозиторий и настроить `.gitignore`.
