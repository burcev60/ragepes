## **Настройка Git Flow**

1. **Установите Git Flow (если ещё не сделали этого):**

    brew install git-flow  # Для macOS  
    sudo apt-get install git-flow  # Для Ubuntu  

2. **Инициализируйте Git Flow:**

    git init            # если репозиторий ещё не инициализирован
    git add .
    git commit -m "Initial commit"
    git flow init

  Следуйте инструкциям и настройте ветки `develop`, `feature/*`, `release/*`, `hotfix/*`.

3. **Создайте ветку для новой функции:**

  `git flow feature start new-feature `

  Внесите изменения в файл `README.md` и завершите работу над веткой:

  `git flow feature finish new-feature `
