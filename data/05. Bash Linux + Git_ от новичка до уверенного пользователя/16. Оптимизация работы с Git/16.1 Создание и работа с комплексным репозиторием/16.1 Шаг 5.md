## **Подключение таск-трекера и управление задачами**

1. **GitHub Issues:**  
Создайте задачу в разделе **Issues** и свяжите её с коммитами, используя ключевые слова `Closes #<номер задачи>`.

  `git commit -m "Добавлена новая функция. Closes #5" `

2. **Jira:**  
Свяжите репозиторий с Jira и используйте идентификаторы задач (`TASK-123`) в сообщениях коммитов.
