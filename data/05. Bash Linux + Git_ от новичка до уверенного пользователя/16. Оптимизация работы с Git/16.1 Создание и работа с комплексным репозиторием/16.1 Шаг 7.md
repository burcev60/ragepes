## **Практическая часть**

### **Задание:**

1. Создайте новый репозиторий и добавьте два подмодуля.
2. Настройте Git Flow и создайте ветку `feature/new-feature`.
3. Настройте GitHub Actions для автоматического тестирования.
4. Создайте файл `.gitignore` и исключите временные файлы.

    git submodule add https://github.com/username/ui-library.git external/ui-library  
    git submodule init  
    git submodule update  
    git flow init  
    git flow feature start new-feature  
    echo "print('New feature')" >> feature.py  
    git add feature.py  
    git commit -m "Добавлена новая функция"
