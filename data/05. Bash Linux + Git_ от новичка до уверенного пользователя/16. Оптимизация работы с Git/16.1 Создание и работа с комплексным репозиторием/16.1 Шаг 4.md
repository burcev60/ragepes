## **Настройка автоматического тестирования с GitHub Actions**

1. Создайте файл `.github/workflows/ci.yml`.
2. Добавьте следующий YAML-код для автоматического тестирования Python-проекта:

    name: CI

    on:
      push:
        branches:
          - main
          - develop

    jobs:
      test:
        runs-on: ubuntu-latest
        steps:
        - name: Checkout code
          uses: actions/checkout@v2

        - name: Set up Python
          uses: actions/setup-python@v2
          with:
            python-version: 3.8

        - name: Install dependencies
          run: pip install -r requirements.txt

        - name: Run tests
          run: pytest

Каждый раз при пуше в ветку `main` или `develop` будут запускаться тесты.
