### **Слияние или перемотка (`merge` vs `rebase`)**

- **`git merge`** — сохраняет историю веток, добавляя новый коммит слияния.
- **`git rebase`** — переписывает историю, делая её линейной.


**Когда использовать `merge`:**

- При работе в команде, чтобы сохранить историю работы.


**Когда использовать `rebase`:**

- Для линейной и чистой истории, особенно в личных ветках.
