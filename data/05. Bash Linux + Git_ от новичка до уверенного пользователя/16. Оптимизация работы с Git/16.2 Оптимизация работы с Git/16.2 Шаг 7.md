## **Практическая часть**

### **Задание 1: Уменьшение размера репозитория**

1. Найдите большой файл (`large-file.bin`) в истории.
2. Удалите его с помощью `git filter-branch`.

    git filter-branch --tree-filter 'rm -f large-file.bin' HEAD  
    git push origin --force  

 

### **Задание 2: Восстановление удалённого коммита**

1. Выполните команду `git reflog`.
2. Найдите хэш удалённого коммита и восстановите его.


**Шаги:**

    git reflog  
    git checkout <commit-hash>  

### **Задание 3: Использование шаблона сообщений коммитов**

1. Создайте файл `commit-template.txt`.
2. Используйте его при создании нового коммита.


**Шаги:**

    echo "Краткое описание изменений" > commit-template.txt  
    git commit -t commit-template.txt
