## **Уменьшение размера репозитория**

### **Проблема:**

Большие файлы или бинарные данные могут значительно увеличить размер репозитория.

### **Решение:** Использование Git LFS

Git LFS (Large File Storage) позволяет заменить большие файлы на ссылки, сохраняя их отдельно.

**Добавление файлов в Git LFS:**

    git lfs track "*.psd"  
    git add .gitattributes large-file.psd  
    git commit -m "Добавлен большой файл через Git LFS"
