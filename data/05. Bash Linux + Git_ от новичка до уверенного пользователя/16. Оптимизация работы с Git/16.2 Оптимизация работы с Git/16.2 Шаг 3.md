### **Удаление больших файлов из истории**

Если большой файл случайно попал в репозиторий, его можно удалить из истории.

**Пример команды для удаления файла `large-file.bin`:**

`git filter-branch --tree-filter 'rm -f large-file.bin' HEAD `

**После удаления:**

`git push origin --force `

**Важно:** Эта команда изменяет историю, будьте осторожны и предупредите коллег.
