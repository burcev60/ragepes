## **Шаблоны и хуки для команды**

### **Шаблоны сообщений коммитов**

Создание шаблона поможет стандартизировать сообщения коммитов.

**Пример шаблона `commit-template.txt`:**

    # Краткое описание изменений (50 символов максимум)

    # Подробное описание изменений (необязательно)
    # Укажите, какие задачи или баги решаются этим коммитом.

Использование шаблона:

    git commit -t commit-template.txt  

### **Настройка хуков для проверки кода**

**`pre-commit` хук для проверки кода:**

    #!/bin/sh
    npm run lint
    if [ $? -ne 0 ]; then
      echo "Ошибки линтера. Коммит отклонён."
      exit 1
    fi
