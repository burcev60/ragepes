## **Итоги урока**

В этом уроке вы научились:

- Уменьшать размер репозитория с помощью Git LFS и удаления файлов из истории.
- Восстанавливать потерянные коммиты с помощью `git reflog`.
- Работать с `merge` и `rebase` для управления ветками.
- Использовать шаблоны и хуки для стандартизации работы команды.
