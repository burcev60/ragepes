## **Зачем оптимизировать работу с Git?**

Со временем репозиторий может увеличиваться в размерах и усложняться. Это замедляет работу команды и приводит к трудностям при работе с историей изменений и ветками. Оптимизация Git помогает:

- **Уменьшить размер репозитория.**
- **Избежать конфликтов и ошибок.**
- **Повысить скорость работы с ветками и коммитами.**
