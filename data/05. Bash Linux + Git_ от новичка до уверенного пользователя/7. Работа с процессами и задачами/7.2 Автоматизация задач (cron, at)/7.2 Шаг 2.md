# Гайд по cron

## Что такое cron?

**cron** — это демон, который запускается в фоне и периодически проверяет файлы расписания (crontab), чтобы запустить заданные задачи (скрипты или команды) в указанное время. Благодаря cron можно настроить автоматическое выполнение регулярных задач, таких как резервное копирование, обновление системных данных, отправка отчетов и многое другое.

## Основы работы с crontab

### 1. Crontab

Каждый пользователь может иметь свой файл crontab, в котором записаны задачи для планировщика. Для редактирования своего crontab используется команда:

    crontab -e

После запуска откроется текстовый редактор (обычно nano или vi), где можно добавить или изменить задачи.

### 2. Структура записи crontab

Запись в crontab состоит из шести полей:

    *  *  *  *  *  команда
    |  |  |  |  |  
    |  |  |  |  +---- День недели (0-7) (0 или 7 – воскресенье)
    |  |  |  +------- Месяц (1-12)
    |  |  +---------- День месяца (1-31)
    |  +------------- Час (0-23)
    +---------------- Минуты (0-59)

Примеры:

- `0 2 * * * /home/user/backup.sh`  
– запуск скрипта `backup.sh` каждый день в 2:00 ночи.
- `*/5 * * * * /usr/bin/python3 /home/user/script.py`  
– запуск Python-скрипта каждые 5 минут.
- `0 9 * * 1-5 /home/user/report.sh`  
– запуск скрипта для формирования отчета каждый будний день (с понедельника по пятницу) в 9:00 утра.


### 3. Специальные символы

- ***** – звёздочка означает "каждое возможное значение". Например, `*` в поле минут означает "каждую минуту".
- **,** – запятая используется для перечисления нескольких значений. Например, `1,15,30` в поле дня месяца означает, что задача запустится 1-го, 15-го и 30-го числа.
- **-** – дефис задаёт диапазон значений. Например, `1-5` в поле дня недели означает с понедельника по пятницу.
- **/n** – косая черта с числом означает шаг. Например, `*/10` в поле минут означает "каждые 10 минут".


## Примеры использования cron

### Пример 1: Ежедневное резервное копирование

Запись в crontab:

`0 2 * * * /home/user/backup.sh `

Каждый день в 2:00 ночи выполняется скрипт резервного копирования.

### Пример 2: Периодическая проверка логов

Запись в crontab:

`*/15 * * * * /home/user/check_logs.sh >> /home/user/logs/check_logs.log 2>&1 `

Скрипт `check_logs.sh` запускается каждые 15 минут. Вывод команды (включая ошибки) добавляется в лог-файл.

### Пример 3: Еженедельная очистка временных файлов

Запись в crontab:

`0 3 * * 0 /home/user/clean_temp.sh `

Каждое воскресенье в 3:00 ночи запускается скрипт очистки временных файлов.
