# Разбор команды cat

## Что такое cat?

**cat** (от английского *concatenate*, что можно перевести как «сцеплять» или «объединять») — это команда, которая используется для вывода содержимого одного или нескольких файлов в стандартный вывод (обычно в терминал). Команда cat часто применяется для быстрого просмотра текстовых файлов, объединения нескольких файлов в один, а также для создания новых файлов, если данные подаются через стандартный ввод.

## Основной синтаксис

    cat [опции] [файлы]

- **файлы** — один или несколько файлов, содержимое которых нужно вывести или объединить. Если файлы не указаны, cat ждёт ввода с клавиатуры (stdin).


## Основные опции

- **-n**  
Нумерует все строки в выводе.

    cat -n file.txt

- **-b**  
Нумерует только непустые строки (аналогично -n, но пустые строки не нумеруются).

    cat -b file.txt

- **-s**  
Сокращает подряд идущие пустые строки до одной. Это полезно для «сжатия» вывода при просмотре файлов с большим количеством пустых строк.

    cat -s file.txt

- **-E**  
Отображает символ доллара (`$`) в конце каждой строки, что помогает визуально определить, где заканчиваются строки.

    cat -E file.txt

- **-T**  
Показывает символ табуляции как `^I`, что позволяет увидеть невидимые символы табуляции в файле.

    cat -T file.txt

## Примеры использования

### 1. Вывод содержимого файла

    cat file.txt

Эта команда выводит всё содержимое файла *file.txt* в терминал.

### 2. Объединение нескольких файлов

    cat file1.txt file2.txt > merged.txt

Команда объединяет содержимое файлов *file1.txt* и *file2.txt* и записывает результат в новый файл *merged.txt*. Если файла *merged.txt* не существует, он будет создан; если существует — его содержимое будет перезаписано.

### 3. Нумерация строк в файле

    cat -n file.txt

Выводит содержимое файла *file.txt*, нумеруя каждую строку.

### 4. Создание нового файла через cat

    cat > newfile.txt

После ввода команды терминал ждёт ввода текста. Введите нужное содержимое и завершите ввод, нажав `Ctrl+D`. В результате файл *newfile.txt* будет создан с введённым содержимым.

### 5. Сокращение пустых строк

    cat -s file.txt

Если в файле много подряд идущих пустых строк, опция `-s` заменяет их одной пустой строкой.

## Полезное применение

- **Быстрый просмотр файлов:**  
Команда cat позволяет быстро просмотреть содержимое текстового файла, особенно если файл небольшой.

- **Объединение файлов:**  
Cat часто используется для объединения нескольких файлов в один. Это полезно при работе с логами или при подготовке данных.

- **Создание файлов:**  
Через перенаправление можно создать новый файл и ввести в него данные вручную.

- **Отладка:**  
Дополнительные опции, такие как -E и -T, помогают обнаружить невидимые символы (концы строк, табуляцию), что бывает полезно при отладке текстовых файлов и скриптов.
