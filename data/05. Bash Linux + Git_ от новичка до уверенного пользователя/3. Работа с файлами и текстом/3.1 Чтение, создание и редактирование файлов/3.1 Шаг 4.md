# Разбор команды more

## Что такое more?

**more** — это простой пейджер, предназначенный для постраничного просмотра текстовых файлов. В отличие от команды `cat`, которая выводит весь текст сразу, `more` разбивает вывод на страницы, что позволяет пользователю удобно читать длинные файлы. Команда была широко распространена в ранних Unix-системах и до сих пор используется, хотя многие современные системы предпочитают `less`, предоставляющий больше возможностей.

## Основной синтаксис

`more [опции] [файл] `

- **файл** — имя текстового файла, который требуется просмотреть.
- Если файл не указан, `more` ожидает ввода с стандартного ввода (stdin).


## Основные возможности и особенности

- **Постраничный вывод:**  
После открытия файла `more` выводит первую страницу текста. Для перехода к следующей странице нажмите **пробел**.

- **Прокрутка по строкам:**  
Нажмите **Enter** для вывода следующей строки.

- **Выход:**  
Для выхода из просмотра нажмите клавишу **q**.

- **Поиск:**  
Некоторые реализации `more` поддерживают поиск по тексту. Для поиска нажмите `/`, затем введите искомый текст и нажмите Enter.

- **Ограниченная навигация:**  
В отличие от `less`, команда `more` обычно не позволяет прокручивать текст назад. Это делает её менее гибкой, особенно при необходимости вернуться к ранее просмотренной части файла.

## Примеры использования

### 1. Просмотр файла

`more example.txt `

Открывает файл *example.txt* для постраничного просмотра. Нажмите **пробел** для перехода к следующей странице, **Enter** — для перехода на одну строку, а **q** — чтобы выйти.

### 2. Просмотр вывода другой команды

`dmesg | more `

Вывод команды `dmesg` (сообщения ядра) передаётся через конвейер в `more`, что позволяет просматривать длинный вывод постранично.

### 3. Поиск по тексту (если поддерживается)

В некоторых версиях `more` можно выполнить поиск:

- После открытия файла нажмите `/`
- Введите искомый текст (например, `error`) и нажмите Enter.  
(Обратите внимание: функциональность поиска может варьироваться в зависимости от версии `more`.)


## Полезные советы

- **Пользовательский интерфейс:**  
При просмотре файла с помощью `more` на экране может отображаться информация о текущем проценте просмотренного файла или о текущей позиции (в зависимости от реализации).

- **Ограничения:**  
Если требуется более гибкий просмотр, возможность перематывать назад или совершать расширенный поиск, лучше использовать команду `less`, которая обладает более широким функционалом.

- **Использование с конвейерами:**  
`more` удобно применять для постраничного просмотра вывода любой команды, например:

    ls -l | more

  Это позволяет просматривать длинный список файлов порциями, не заполняя весь экран.
