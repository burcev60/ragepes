## Группировка и альтернативы

### Группировка с помощью круглых скобок `()`

Группировка используется для объединения символов или шаблонов, чтобы применять к ним квантификаторы или для выделения подвыражений.

*Пример:*  
`(ab)+` соответствует «ab», «abab», «ababab» и т.д.

### Альтернация с символом `|`

Символ `|` используется для обозначения альтернатив (логическое ИЛИ).

*Пример:*  
`cat|dog` соответствует либо «cat», либо «dog».  
При использовании внутри группы:  
`^(cat|dog)$` соответствует строке, которая целиком равна либо «cat», либо «dog».
