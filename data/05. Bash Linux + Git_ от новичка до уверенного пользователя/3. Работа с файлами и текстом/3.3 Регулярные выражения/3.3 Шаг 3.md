## Символьные классы и диапазоны

Символьные классы позволяют задать множество символов, из которых должен быть выбран один.

- **`[abc]`** – соответствует любому из символов «a», «b» или «c».
- **`[a-z]`** – соответствует любой строчной букве от a до z.
- **`[0-9]`** – соответствует любой цифре.
- **`[^abc]`** – соответствует любому символу, кроме «a», «b» или «c». Символ `^` внутри квадратных скобок означает отрицание.


Пример:  
Шаблон `[A-Za-z0-9]` соответствует любой букве или цифре.
