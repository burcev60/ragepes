## Практические примеры использования регулярных выражений в Bash

### Поиск с помощью grep

1. **Найти строки, начинающиеся с цифры:**

  `grep '^[0-9]' file.txt `

  Здесь `^` указывает на начало строки, а `[0-9]` — на любую цифру.

2. **Найти строки, оканчивающиеся на .txt:**

  `grep '\.txt$' file.txt `

  Обратите внимание, что точку нужно экранировать (`\.`), чтобы она воспринималась как литерал.

3. **Найти строки, содержащие слово error (без учёта регистра):**

  `grep -i 'error' file.txt `

### Замена с помощью sed

1. **Заменить все вхождения слова «foo» на «bar»:**

  `sed 's/foo/bar/g' file.txt `

2. **Удалить все строки, начинающиеся с комментария (#):**

  `sed '/^#/d' file.txt `

### Обработка данных с помощью awk

1. **Вывести все строки, где первое поле (разделённое пробелом) соответствует шаблону, начинающемуся с заглавной буквы:**

  `awk '$1 ~ /^[A-Z]/ {print}' file.txt`
