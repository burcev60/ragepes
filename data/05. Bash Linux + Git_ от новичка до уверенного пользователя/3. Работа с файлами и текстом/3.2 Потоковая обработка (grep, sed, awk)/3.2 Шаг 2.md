# Разбор команды grep

## Что такое grep?

**grep** (от англ. *global regular expression print*) — мощная команда для поиска и фильтрации текста в файлах или потоках данных. Команда ищет строки, соответствующие заданному шаблону (регулярному выражению), и выводит их на экран. Благодаря гибкости шаблонов, grep широко используется для быстрого анализа логов, проверки исходного кода и отладки скриптов.

## Основной синтаксис

    grep [опции] шаблон [файл ...]

- **шаблон** — регулярное выражение или строка, которую необходимо найти.
- **файл** — один или несколько файлов, в которых производится поиск. Если файлы не указаны, grep читает данные из стандартного ввода (stdin).


## Основные опции

- **-i**  
Игнорирует регистр символов при поиске.

    grep -i "error" logfile.txt

  Найдёт строки с "error", "Error", "ERROR" и т.д.

- **-v**  
Инвертирует поиск: выводит строки, которые НЕ соответствуют заданному шаблону.

    grep -v "DEBUG" logfile.txt

- **-r или -R**  
Рекурсивный поиск по каталогу. Позволяет искать шаблон во всех файлах внутри указанного каталога (и его подкаталогов).

    grep -r "function" src/

- **-n**  
Выводит номера строк вместе с найденными строками.

    grep -n "main" program.c

- **-E**  
Использует расширенные регулярные выражения (эквивалентно вызову egrep).

    grep -E "cat|dog" animals.txt

- **-F**  
Использует поиск по фиксированной строке (без интерпретации символов как метасимволов регулярных выражений), что может ускорить поиск.

    grep -F "http://" links.txt

- **-c**  
Выводит только количество строк, соответствующих шаблону.

    grep -c "ERROR" logfile.txt

- **-l**  
Выводит только имена файлов, содержащих хотя бы одну строку, соответствующую шаблону.

    grep -l "TODO" *.c

## Примеры использования

### 1. Базовый поиск

    grep "main" program.c

Выведет все строки файла *program.c*, содержащие слово "main".

### 2. Поиск с игнорированием регистра

    grep -i "warning" log.txt

Найдёт все строки, где встречается "warning" в любом регистре (например, Warning, WARNING и т.д.).

### 3. Вывод с номерами строк

    grep -n "function" source.c

Каждая найденная строка будет предваряться номером строки, что помогает быстро ориентироваться в файле.

### 4. Рекурсивный поиск

    grep -r "TODO" .

Поиск всех упоминаний "TODO" во всех файлах текущего каталога и его подкаталогов.

### 5. Инвертированный поиск

    grep -v "^#" config.conf

Выведет все строки из файла *config.conf*, которые не начинаются с символа `#` (например, для исключения комментариев).

### 6. Поиск по фиксированной строке

    grep -F "http://" links.txt

Поиск строк, содержащих точную последовательность "http://", без обработки как регулярное выражение.

## Полезные советы

- **Комбинирование опций:**  
Опции можно комбинировать для более точного поиска. Например, `grep -rin "error" /var/log` выполнит рекурсивный поиск, проигнорирует регистр и выведет номера строк.

- **Использование в конвейерах:**  
grep часто используется вместе с другими командами через пайп, что позволяет фильтровать вывод. Пример:

    dmesg | grep -i "usb"

  Выведет только строки, связанные с USB, из системных сообщений.

- **Регулярные выражения:**  
Освоив регулярные выражения, вы сможете создавать гибкие и мощные шаблоны для поиска. Например, шаблон `^Error:` найдёт строки, начинающиеся с "Error:".
