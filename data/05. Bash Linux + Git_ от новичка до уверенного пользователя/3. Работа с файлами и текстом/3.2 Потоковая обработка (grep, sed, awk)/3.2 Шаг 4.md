# Разбор команды awk

## Что такое awk?

**awk** — это язык программирования и утилита для обработки текстовых данных, предназначенная для сканирования входных строк, разбивки их на поля и выполнения над ними действий. Название происходит от фамилий его создателей (Aho, Weinberger, Kernighan). awk широко применяется для извлечения, анализа и преобразования данных, особенно из текстовых файлов, таблиц и логов.

## Основной синтаксис

    awk 'условие {действие}' [файл ...]

- **условие:** Может быть регулярным выражением или логическим выражением для выбора строк. Если условие опущено, действие выполняется для каждой строки.
- **действие:** Блок команд, который выполняется для строк, удовлетворяющих условию. Если действие не указано, awk по умолчанию выводит всю строку.
- **файл:** Один или несколько файлов для обработки. Если файлы не указаны, awk читает данные из стандартного ввода.


## Основные возможности awk

- **Разбиение на поля:**  
По умолчанию awk разделяет строки на поля по пробелам и табуляции. Каждое поле можно получить через переменные: `$1`, `$2`, ..., а вся строка — `$0`.

- **Встроенные переменные:**

  - **NR:** номер текущей строки (record number).
  - **NF:** количество полей в текущей строке.
  - **FS:** разделитель полей (по умолчанию пробел).
  - **OFS:** разделитель, используемый при выводе (по умолчанию пробел).

- **Условия и действия:**  
awk позволяет выполнять арифметические и логические операции, сравнения, а также использовать циклы и условные конструкции, что делает его полноценным языком программирования для обработки текстов.

- **Форматированный вывод:**  
С помощью функции `printf` можно выводить данные в нужном формате.

## Примеры использования

### 1. Вывод всех строк файла

    awk '{print}' file.txt

Выводит каждую строку файла *file.txt*. Условие отсутствует, поэтому действие выполняется для каждой строки.

### 2. Вывод первого поля каждой строки

    awk '{print $1}' file.txt

Выведет только первое поле каждой строки, что полезно для извлечения данных из таблиц или логов.

### 3. Вывод строк, где второе поле больше 100

    awk '$2 > 100 {print}' data.txt

Для каждой строки файла *data.txt*, если значение второго поля больше 100, строка выводится на экран.

### 4. Подсчёт количества строк в файле

    awk 'END {print NR}' file.txt

После обработки всех строк блок `END` выполняется, выводя общее количество строк (NR).

### 5. Форматированный вывод с помощью printf

    awk '{printf "Поле 1: %s, Поле 2: %s\n", $1, $2}' file.txt

Выводит данные в заданном формате: значения первого и второго полей каждой строки.

### 6. Изменение разделителя полей

Если данные разделены не пробелами, а запятыми, можно установить новый разделитель:

    awk 'BEGIN {FS=","} {print $1}' file.csv

Команда задаёт запятую в качестве разделителя полей и выводит первое поле для каждой строки файла *file.csv*.

## Полезные советы

- **Использование BEGIN и END:**  
Блок **BEGIN** выполняется до обработки входных данных, а **END** — после, что удобно для инициализации переменных или вывода итогов.

- **Регулярные выражения:**  
awk позволяет использовать регулярные выражения для отбора строк. Пример:

    awk '/^Error/ {print}' logfile.txt

  Выведет строки, начинающиеся со слова "Error".

- **Комбинирование условий:**  
Можно использовать логические операторы (&&, ||) для сложных условий.

    awk '$2 > 100 && $3 == "ACTIVE" {print $1}' data.txt

  Выведет первое поле тех строк, где второе поле больше 100, а третье равно "ACTIVE".
