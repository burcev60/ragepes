# Разбор команды sed

## Что такое sed?

**sed** (от англ. *stream editor*) — это мощный редактор потокового текста, позволяющий читать входной поток, выполнять заданные преобразования и выводить результат. sed особенно полезен для автоматизированной обработки текстовых файлов: замены, удаления, вставки и форматирования данных с использованием регулярных выражений.

## Основной синтаксис

    sed [опции] 'команда' [файл]

- **команда** — инструкция (или набор инструкций) для обработки текста. Чаще всего используется команда замены `s/шаблон/замена/` и другие команды, такие как `d` (удаление), `p` (печать) и т.д.
- **файл** — имя файла, который обрабатывается. Если файл не указан, sed читает данные из стандартного ввода (stdin).


## Основные возможности и команды sed

### Команда замены (s)

Наиболее часто используемая команда в sed — это `s`, которая заменяет найденный шаблон на заданный текст.

**Синтаксис:**

`s/шаблон/замена/флаги `

- **шаблон:** Регулярное выражение, определяющее, что искать.
- **замена:** Текст, на который будет заменён найденный шаблон.
- **флаги:** Дополнительные модификаторы (например, `g` для глобальной замены всех вхождений в строке, `i` для игнорирования регистра).


**Пример:**

    sed 's/old/new/g' file.txt

Эта команда заменит все вхождения слова "old" на "new" в каждой строке файла *file.txt*.

### Удаление строк (d)

Команда `d` удаляет строки, соответствующие шаблону.

**Пример:**

    sed '/^#/d' config.conf

Эта команда удалит все строки, начинающиеся с символа `#` (часто комментарии).

### Печать строк (p)

Команда `p` выводит строки, соответствующие шаблону. Часто используется вместе с опцией `-n`, которая подавляет автоматический вывод.

**Пример:**

    sed -n '/error/p' logfile.txt

Эта команда выведет только те строки из *logfile.txt*, в которых встречается слово "error".

### Другие возможности

- **Вставка строк (i, a):**
  - `i\текст` — вставляет строку до текущей.
  - `a\текст` — вставляет строку после текущей.

- **Изменение строк (c):**  
Команда `c` позволяет заменить целиком строку на заданный текст.

- **Работа с файлами:**  
Можно применять sed как фильтр, обрабатывая вывод других команд через конвейеры:

  `ls -l | sed 's/ */ /g' `

Это удалит лишние пробелы в выводе команды ls.

## Примеры использования

### Пример 1: Замена текста в файле

    sed 's/foo/bar/g' input.txt > output.txt

В файле *input.txt* все вхождения "foo" заменяются на "bar". Результат записывается в *output.txt*.

### Пример 2: Удаление комментариев

    sed '/^#/d' config.txt > clean_config.txt

Удаляет все строки, начинающиеся с `#` (комментарии), и сохраняет результат в *clean_config.txt*.

### Пример 3: Изменение только 2-й строки файла

    sed '2s/.*/Замена второй строки/' file.txt

Заменяет содержимое второй строки файла на «Замена второй строки».

### Пример 4: Выборочная печать строк

    sed -n '10,20p' file.txt

Выводит строки с 10-й по 20-ю из файла *file.txt*.

## Полезные советы

- **Регулярные выражения:**  
Освоив основы регулярных выражений, вы сможете создавать более сложные и точные шаблоны для поиска и замены.
- **Флаги:**  
Флаг `g` позволяет заменить все вхождения шаблона в строке, а не только первое. Флаг `i` делает поиск нечувствительным к регистру.
- **Резервное копирование:**  
Перед массовыми изменениями полезно сделать резервную копию файла, используя опцию `-i.bak`, которая сохраняет исходный файл с расширением .bak:

    sed -i.bak 's/foo/bar/g' file.txt

- **Работа в конвейере:**  
sed часто используется вместе с другими утилитами в цепочке команд (например, ls, cat, grep) для динамической обработки данных.
