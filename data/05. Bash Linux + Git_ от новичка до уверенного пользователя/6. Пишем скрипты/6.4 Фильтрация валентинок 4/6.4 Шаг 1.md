Теперь девушек произвольное количество, и у каждой девушки есть своя папка валентинок. Вы хотите для девочки с номером i вывести её кандидатов. По прежнему считаем, что требования у всех девочек совпадают и никто не рассматривает кандидатов, признавшихся кому то еще.

Напишите скрипт find_boyfriend4.sh [OPTION] ... i DIR1, DIR2, ...

DIRj - директория для поиска валентинок для j-ой девушки

i - номер девушки, для которой нужно найти кандидатов

OPTIONS:

--max_age NUMBER - максимальный возраст кандидата

--min_age NUMBER - минимальный возраст кандидата

--min_income NUMBER - минимальный доход кандидата

--min_height NUMBER - минимальный рост
