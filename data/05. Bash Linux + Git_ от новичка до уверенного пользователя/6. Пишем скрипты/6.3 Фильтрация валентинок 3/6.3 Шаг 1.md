У Маши есть подруга Аня, которая тоже получила на 14 февраля коробку валентинок. Маша и Аня не хотят рассматривать кандидатов, которые отправили валентинки им обеим. Мы считаем, что если 2 человека с одинаковыми именами, одинаковым доходом, возрастом и ростом отправили валентинки двум подругам, то это один и тот же человек:)

Напишите скрипт find_boyfriend3.sh [OPTION] ... DIR_MASHA DIR_ANYA

DIR_MASHA - директория для поиска валентинок Маши

DIR_ANYA - директория для поиска валентинок Ани

OPTIONS:

--max_age NUMBER - максимальный возраст кандидата

--min_age NUMBER - минимальный возраст кандидата

--min_income NUMBER - минимальный доход кандидата

--min_height NUMBER - минимальный рост

Считаем, что критерии выбора у девочек совпадают. Выведите отфильтрованных кандидатов для Маши.
