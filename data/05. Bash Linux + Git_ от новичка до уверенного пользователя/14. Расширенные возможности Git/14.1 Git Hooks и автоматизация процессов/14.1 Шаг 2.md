## **Основные типы Git Hooks**

Git Hooks делятся на две группы:

1. **Клиентские хуки** — выполняются на локальном компьютере (перед коммитом, слиянием и т. д.).
2. **Серверные хуки** — выполняются на сервере (при приёме коммита или обновлении ветки).


### **Клиентские хуки:**

- **`pre-commit`** — выполняется перед созданием коммита. Используется для проверки кода.
- **`commit-msg`** — проверяет сообщение коммита и может отклонить его, если оно не соответствует шаблону.
- **`post-merge`** — выполняется после слияния веток. Можно использовать для обновления зависимостей.


### **Серверные хуки:**

- **`pre-receive`** — проверяет коммиты перед добавлением в репозиторий.
- **`post-receive`** — используется для развертывания кода.
