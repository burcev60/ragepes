## **Интеграция с Husky (Node.js)**

Для Node.js-проектов проще всего использовать **Husky** для работы с хуками. Это удобный инструмент, позволяющий управлять хуками через `package.json`.

### **Установка Husky:**

`npm install husky --save-dev npx husky install `

### **Добавление хука:**

`npx husky add .husky/pre-commit "npm test" `

Теперь каждый раз перед коммитом будет запускаться команда `npm test`.
