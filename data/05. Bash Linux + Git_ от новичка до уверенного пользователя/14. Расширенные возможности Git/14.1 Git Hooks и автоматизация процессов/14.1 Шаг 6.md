## **Практическая часть**

### **Что мы будем делать?**

Мы создадим простой `pre-commit` хук, который перед каждым коммитом будет проверять, есть ли в файле `README.md` слово `TODO`. Если оно есть, коммит будет заблокирован, чтобы вы случайно не забыли удалить это замечание.

### **Пошаговая инструкция:**

1. **Перейдите в папку `.git/hooks`:**  
Это специальная папка, где хранятся все Git Hooks. Вам не нужно знать команды Linux — просто откройте эту папку через проводник (или Finder на Mac).

2. **Создайте файл `pre-commit`:**  
Если вы работаете на Windows:

  - Создайте новый текстовый файл и назовите его `pre-commit` **(без расширения `.txt`)**.

  На Mac/Linux — используйте команду:

  `touch .git/hooks/pre-commit `

3. **Добавьте в файл следующий код:**  
Этот код проверяет, содержит ли `README.md` слово `TODO`. Если содержит, коммит будет заблокирован.

    #!/bin/sh
    if grep -q "TODO" README.md; then
      echo "Ошибка: файл README.md содержит TODO. Удалите его перед коммитом."
      exit 1
    fi

   

4. **Сделайте файл исполняемым:**  
На Mac/Linux:

  `chmod +x .git/hooks/pre-commit `

  На Windows: просто сохраните файл — дополнительная команда не нужна.

### **Проверка работы хука:**

1. **Добавьте слово `TODO` в `README.md`:**

  `This is my project. TODO: Add more details later. `

2. **Попробуйте создать коммит:**

  `git add README.md git commit -m "Обновлён README" `

  Вы увидите сообщение:

  `Ошибка: файл README.md содержит TODO. Удалите его перед коммитом. `

3. **Удалите слово `TODO` и повторите попытку:**  
Теперь коммит пройдёт успешно.

### **Почему это полезно?**

- **Автоматическая проверка** перед каждым коммитом помогает избежать ошибок.
- `pre-commit` хуки можно использовать для других проверок: запуск тестов, проверка синтаксиса или правильности формата кода.
