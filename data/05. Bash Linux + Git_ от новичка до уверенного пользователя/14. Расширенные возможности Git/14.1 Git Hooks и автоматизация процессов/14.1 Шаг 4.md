## **Настройка `commit-msg` хука**

**Пример: Проверка сообщения коммита**

1. Создайте файл `commit-msg` в папке `.git/hooks`.
2. Добавьте следующий скрипт, проверяющий, что сообщение коммита начинается с определённого префикса (например, `TASK-123`):

     

`#!/bin/sh commit_msg=$(cat "$1") if ! echo "$commit_msg" | grep -q '^TASK-[0-9]\+'; then echo "Сообщение коммита должно начинаться с TASK-<номер задачи>." exit 1 fi `

1. Сделайте файл исполняемым:


`chmod +x .git/hooks/commit-msg`
