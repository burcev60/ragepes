## **Что такое Git Hooks?**

Git Hooks — это скрипты, которые выполняются автоматически на определённых этапах работы с Git. Они позволяют автоматизировать рутинные задачи и обеспечить дополнительный контроль над действиями в репозитории.

### **Основные примеры использования Git Hooks:**

- Проверка стиля кода перед созданием коммита (`pre-commit`).
- Проверка правильности сообщения коммита (`commit-msg`).
- Автоматическое выполнение тестов перед пушем (`pre-push`).
