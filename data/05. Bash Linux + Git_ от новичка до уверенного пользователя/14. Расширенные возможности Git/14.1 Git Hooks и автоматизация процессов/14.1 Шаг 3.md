## **Настройка `pre-commit` хука**

**Пример: Автоматическая проверка стиля кода перед коммитом**

1. Перейдите в папку `.git/hooks` вашего репозитория.
2. Создайте файл `pre-commit` (или отредактируйте существующий).
3. Добавьте в него следующий скрипт:


`#!/bin/sh echo "Проверка стиля кода перед коммитом..." npm run lint if [ $? -ne 0 ]; then echo "Ошибки линтера. Коммит отклонён." exit 1 fi `

1. Сделайте файл исполняемым:


`chmod +x .git/hooks/pre-commit `

Теперь перед каждым коммитом Git будет запускать линтер (`npm run lint`). Если будут найдены ошибки, коммит будет отклонён.
