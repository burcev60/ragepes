## **Временное сохранение изменений с помощью `git stash`**

`git stash` позволяет временно сохранить изменения, не делая коммит. Это полезно, если вам нужно переключиться на другую ветку, не теряя текущие изменения.

### **Пример использования:**

1. Внесите изменения в файл `main.py`:

  `print("Working on a new feature...") `

2. Выполните `git stash`:

  Это сохранит изменения и вернёт файлы к последнему коммиту.

3. **Проверка сохранённых изменений:**

  `git stash list `

  Пример вывода:

  `stash@{0}: WIP on main: 7b2c4f Добавлен новый раздел `

4. **Восстановление изменений:**

  `git stash apply `

5. **Удаление сохранённого состояния:**  
После восстановления можно удалить его из списка:

  `git stash drop `

### **`git stash` с сообщением:**

Если вы хотите дать имя сохранённым изменениям:

`git stash push -m "Работа над новой функцией" `

### **Удалить все сохранённые состояния:**

`git stash clear `
