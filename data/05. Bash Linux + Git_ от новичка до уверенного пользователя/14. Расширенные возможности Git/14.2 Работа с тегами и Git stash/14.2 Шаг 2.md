## **Создание тегов**

### **1. Создание лёгкого тега:**

`git tag v1.0 `

Этот тег привязывается к текущему коммиту и называется `v1.0`.

**Просмотр всех тегов:**

`git tag `

### **2. Создание аннотированного тега:**

`git tag -a v1.0 -m "Первый стабильный релиз" `

Флаг `-a` создаёт аннотированный тег с описанием.

### **3. Привязка тега к определённому коммиту:**

Если вы хотите создать тег для прошлого коммита, используйте его хэш:

`git tag -a v1.0 <commit-hash> -m "Описание тега" `

**Пример:**

`git tag -a v1.1 7b2c4f -m "Исправлены ошибки"`
