## **Практическая часть**

**Задание 1: Работа с тегами**

1. Создайте аннотированный тег `v1.0` с описанием «Первый релиз».
2. Проверьте, что тег создан, с помощью `git tag`.
3. Отправьте тег в удалённый репозиторий.
4. Перейдите к коммиту по тегу и проверьте код в этом состоянии.


**Шаги для выполнения:**

    git tag -a v1.0 -m "Первый релиз"  
    git tag                 # Просмотр тегов  
    git push origin v1.0    # Отправка тега  
    git checkout v1.0       # Переход к коммиту по тегу  

**Задание 2: Работа с `git stash`**

1. Внесите изменения в файл `main.py`.
2. Сохраните изменения с помощью `git stash`.
3. Переключитесь на другую ветку.
4. Восстановите изменения.


**Шаги для выполнения:**

    echo "print('Temporary changes')" >> main.py  
    git stash                      # Сохранение изменений  
    git checkout another-branch    # Переключение на другую ветку  
    git stash apply                # Восстановление изменений  
    git stash drop                 # Удаление сохранённого состояния
