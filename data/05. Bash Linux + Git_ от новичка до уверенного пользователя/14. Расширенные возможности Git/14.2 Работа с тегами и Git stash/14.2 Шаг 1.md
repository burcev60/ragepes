## **Что такое теги в Git?**

Теги (tags) в Git — это метки, которые привязываются к определённому коммиту. Они используются для **обозначения ключевых версий проекта**, таких как релизы (`v1.0`, `v2.0`), и позволяют легко вернуться к этим точкам в истории.

### **Виды тегов:**

1. **Аннотированные теги (annotated tags)**
  - Содержат информацию о версии, автора, дату и комментарий.
  - Рекомендуются для релизов.
2. **Лёгкие теги (lightweight tags)**
  - Это просто метка на коммит без дополнительной информации.
