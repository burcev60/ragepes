## **Практическая часть**

### **Задание 1: Работа с подмодулями**

1. Создайте новый репозиторий на GitHub (`submodule-test`).
2. Добавьте его в основной проект в папку `external/submodule-test`.
3. Инициализируйте и обновите подмодуль.
4. Попробуйте обновить подмодуль до последней версии.


**Шаги:**

    git submodule add https://github.com/username/submodule-test.git external/submodule-test  
    git submodule init  
    git submodule update  
    cd external/submodule-test  
    git pull origin main

### **Задание 2: Работа с Git LFS**

1. Установите Git LFS и инициализируйте его в проекте.
2. Добавьте файл `large-file.bin` и настройте его отслеживание через LFS.
3. Сделайте коммит и отправьте изменения в удалённый репозиторий.


**Шаги:**

    git lfs install  
    git lfs track "*.bin"  
    echo "big file content" > large-file.bin  
    git add .gitattributes large-file.bin  
    git commit -m "Добавлен файл large-file.bin через LFS"  
    git push origin main
