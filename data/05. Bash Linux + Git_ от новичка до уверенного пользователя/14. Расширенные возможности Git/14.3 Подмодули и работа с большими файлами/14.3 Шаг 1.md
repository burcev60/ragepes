## **Что такое подмодули в Git?**

Подмодули (submodules) позволяют включать один Git-репозиторий в другой. Это полезно, когда вы хотите использовать отдельный проект как зависимость для вашего основного проекта, сохраняя возможность обновлять его независимо.

### **Пример использования:**

- Основной проект — веб-приложение, подмодуль — библиотека с общими компонентами интерфейса.
- Основной проект — игра, подмодуль — библиотека для физического движка.
