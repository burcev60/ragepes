## **Добавление файлов в Git LFS**

### **Отслеживание определённых типов файлов:**

`git lfs track "*.psd" `

Эта команда добавляет все файлы с расширением `.psd` в список отслеживаемых Git LFS.

**Проверка отслеживаемых файлов:**

`git lfs ls-files `

### **Пример работы с LFS:**

1. **Добавьте новый файл:**

  `echo "test content" > large-file.bin git add large-file.bin git commit -m "Добавлен большой файл" `

2. **Проверьте, что файл отслеживается через LFS:**

  `git lfs ls-files `

3. **Отправьте файл в удалённый репозиторий:**

  `git push origin main `
