## **Работа с большими файлами с помощью Git LFS**

Git LFS (Large File Storage) предназначен для управления большими файлами, такими как изображения, видео, бинарные файлы, которые плохо подходят для обычного Git.

### **Проблема:**

Git плохо работает с большими файлами — увеличивается размер репозитория и замедляется работа.

### **Что делает Git LFS?**

- Git LFS сохраняет вместо самого файла ссылку на него.
- Файл хранится в отдельном хранилище, а не в основном репозитории.
