## **Установка и настройка Git LFS**

### **Установка Git LFS:**

**На macOS:**

`brew install git-lfs `

**На Ubuntu/Debian:**

`sudo apt-get install git-lfs `

**На Windows:**  
Загрузите и установите [Git LFS](https://git-lfs.github.com/).

### **Инициализация Git LFS в проекте:**

`git lfs install`
