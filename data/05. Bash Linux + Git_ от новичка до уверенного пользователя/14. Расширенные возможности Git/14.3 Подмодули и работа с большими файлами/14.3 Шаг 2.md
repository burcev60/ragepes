## **Работа с подмодулями**

### **Добавление подмодуля:**

`git submodule add <URL> <path> `

**Пример:**

`git submodule add https://github.com/example/library.git external/library `

### **Инициализация и обновление подмодулей:**

После клонирования репозитория с подмодулями нужно инициализировать и обновить их:

`git submodule init git submodule update `

### **Просмотр списка подмодулей:**

`git submodule `

### **Обновление подмодуля до последней версии:**

`cd external/library `

`git pull origin main `

### **Удаление подмодуля:**

1. Удалите запись из `.gitmodules`.
2. Удалите запись из `.git/config`.
3. Удалите папку подмодуля.
