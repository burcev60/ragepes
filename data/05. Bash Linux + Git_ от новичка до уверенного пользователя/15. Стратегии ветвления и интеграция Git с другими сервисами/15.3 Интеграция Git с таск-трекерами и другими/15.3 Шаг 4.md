## **Интеграция с инструментами для анализа кода**

### **1. SonarQube — статический анализ кода**

SonarQube проверяет ваш код на наличие багов, уязвимостей и проблем со стилем.

**Пример интеграции через GitHub Actions:**

    name: SonarQube Analysis

    on:
      push:
        branches:
          - main

    jobs:
      sonar:
        runs-on: ubuntu-latest
        steps:
        - name: Checkout code
          uses: actions/checkout@v2
        - name: Run SonarQube
          run: |
            sonar-scanner \
              -Dsonar.projectKey=my-project \
              -Dsonar.host.url=https://sonarqube.example.com \
              -Dsonar.login=$SONAR_TOKEN

### **2. Dependabot — автоматическое обновление зависимостей**

Dependabot проверяет ваши зависимости и создаёт Pull Requests с обновлениями, если найдены устаревшие или уязвимые версии.
