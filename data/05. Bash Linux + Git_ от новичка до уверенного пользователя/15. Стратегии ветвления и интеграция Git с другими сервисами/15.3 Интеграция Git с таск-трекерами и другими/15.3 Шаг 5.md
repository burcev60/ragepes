## **Практическая часть**

### **Задание 1: Интеграция Git с Jira**

1. Создайте задачу в Jira с идентификатором `TASK-100`.

2. Сделайте коммит, указав идентификатор задачи:

  `git commit -m "TASK-100: Добавлена новая функция" `

3. Убедитесь, что коммит отобразился в задаче в Jira.

### **Задание 2: Интеграция с GitHub Issues**

1. Создайте новый **Issue** на GitHub (`#55`).

2. Сделайте коммит с сообщением:

  `git commit -m "Исправление ошибки. Closes #55" `

3. Создайте Pull Request и убедитесь, что Issue закрывается автоматически после слияния.

### **Задание 3: Настройка SonarQube для анализа кода**

1. Установите SonarQube в вашем проекте.
2. Настройте GitHub Actions для автоматического запуска анализа кода при каждом пуше.
