## **Интеграция с системами мониторинга и логирования**

### **1. Sentry — отслеживание ошибок**

Sentry — это инструмент для мониторинга и отслеживания ошибок в приложениях.

**Пример интеграции:**

1. Установите SDK Sentry для вашего проекта.
2. Добавьте обработчик ошибок, чтобы Sentry собирал отчёты о сбоях и исключениях.


**Python-пример:**

    import sentry_sdk
    sentry_sdk.init("https://your-dsn@sentry.io/project-id")

    try:
        1 / 0
    except ZeroDivisionError:
        sentry_sdk.capture_exception()

### **2. Prometheus и Grafana — мониторинг системы**

- **Prometheus** собирает метрики с приложения и систем.
- **Grafana** визуализирует эти данные в виде дашбордов.


**Пример метрики в Prometheus:**

    from prometheus_client import start_http_server, Gauge

    g = Gauge('app_requests_total', 'Total requests processed')
    g.inc()  # Увеличить значение на 1
