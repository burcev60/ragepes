## **Интеграция Git с таск-трекерами**

### **Связь с Jira**

Jira — один из самых популярных таск-трекеров, который часто используется в командах для управления проектами и задачами.

**Пример интеграции:**

1. **Добавление номера задачи в коммит:**  
При коммите указывайте идентификатор задачи в сообщении:

  `git commit -m "TASK-123: Исправлен баг с отображением" `

  Это автоматически привяжет коммит к задаче в Jira.

2. **Автоматическое обновление статуса задачи:**  
Можно настроить правила, чтобы задачи переходили в статус «In Progress» при первом коммите или в «Done» после слияния Pull Request.

### **Использование GitHub Issues для управления задачами**

GitHub Issues позволяет создавать и управлять задачами прямо в репозитории.

**Пример:**

- Создайте задачу в разделе **Issues**.

- Свяжите её с коммитом, используя `#<номер задачи>` в сообщении коммита:

  `git commit -m "Исправлена ошибка. Closes #42" `

После слияния Pull Request задача закроется автоматически.
