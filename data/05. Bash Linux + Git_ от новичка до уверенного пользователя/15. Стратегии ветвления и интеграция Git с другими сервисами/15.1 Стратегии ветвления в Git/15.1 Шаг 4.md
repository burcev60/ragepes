## **Практическая часть**

### **Задание 1: Работа с Git Flow**

1. Создайте ветку `develop` и переключитесь на неё. `git checkout -b develop `

2. Создайте ветку `feature/new-feature` и добавьте изменения.

3. Слейте изменения из `feature/new-feature` в `develop`.

4. Создайте ветку `release/v1.0` и выполните финальные изменения.

5. Слейте `release/v1.0` в `main`.

### **Задание 2: Работа с GitHub Flow**

1. Создайте ветку `feature/task-456`. `git checkout -b feature/task-456 `

2. Внесите изменения и создайте коммит. `echo "New feature" > feature.txt git add feature.txt git commit -m "Добавлена новая функция" `

3. Создайте Pull Request и выполните слияние через GitHub.
