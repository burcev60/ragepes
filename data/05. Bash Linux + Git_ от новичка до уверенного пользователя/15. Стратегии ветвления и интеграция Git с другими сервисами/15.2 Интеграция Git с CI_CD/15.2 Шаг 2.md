## **Основные инструменты CI/CD**

1. **GitHub Actions** — встроенный инструмент для автоматизации задач в репозиториях GitHub.
2. **GitLab CI/CD** — мощный CI/CD-инструмент для GitLab.
3. **Jenkins** — гибкая система для построения конвейеров CI/CD.
4. **CircleCI** — сервис CI/CD с поддержкой Docker и Kubernetes.
