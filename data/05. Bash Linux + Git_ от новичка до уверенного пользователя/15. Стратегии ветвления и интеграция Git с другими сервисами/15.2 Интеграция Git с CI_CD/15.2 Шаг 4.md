## **Настройка CI/CD с GitLab CI/CD**

### **Основные элементы:**

1. **.gitlab-ci.yml** — файл конфигурации для GitLab CI/CD.
2. **Jobs** — задачи, выполняемые в пайплайне (pipeline).
3. **Stages** — этапы выполнения задач (например: `build`, `test`, `deploy`).


### **Пример конфигурации для Python-проекта:**

    stages:
      - test

    test:
      stage: test
      image: python:3.8
      script:
        - pip install -r requirements.txt
        - pytest

При каждом коммите GitLab будет запускать тесты на базе образа Python 3.8.
