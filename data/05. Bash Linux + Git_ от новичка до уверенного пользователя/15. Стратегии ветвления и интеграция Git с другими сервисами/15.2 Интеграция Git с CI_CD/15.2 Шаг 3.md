## **Настройка CI/CD с GitHub Actions**

**GitHub Actions** — это инструмент для автоматизации рабочих процессов (workflow). Вы можете настроить тестирование, сборку и развёртывание проекта.

### **Пример workflow для Node.js:**

1. Создайте файл `.github/workflows/ci.yml` в корне вашего проекта.
2. Добавьте следующий YAML-код:

    name: CI

    on:
      push:
        branches:
          - main

    jobs:
      build:
        runs-on: ubuntu-latest

        steps:
        - name: Checkout code
          uses: actions/checkout@v2

        - name: Install Node.js
          uses: actions/setup-node@v2
          with:
            node-version: 14

        - name: Install dependencies
          run: npm install

        - name: Run tests
          run: npm test
