## **Что такое CI/CD?**

CI/CD (Continuous Integration и Continuous Delivery/Deployment) — это практика автоматизации процессов интеграции, тестирования и развертывания приложений.

- **Continuous Integration (CI)** — каждый коммит проходит автоматическое тестирование и сборку.
- **Continuous Delivery (CD)** — код постоянно готов к развертыванию.
- **Continuous Deployment** — изменения автоматически развёртываются в рабочее окружение после успешного тестирования.


### **Зачем использовать CI/CD?**

- **Быстрое обнаружение ошибок.**
- **Меньше ручных операций.**
- **Непрерывная поставка кода.**
- **Повышение стабильности и качества продукта.**
