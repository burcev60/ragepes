### Что такое WSL?

**Windows Subsystem for Linux (WSL)** – это подсистема, позволяющая запускать полноценное Linux-окружение (например, Ubuntu) внутри Windows без использования виртуальных машин или двойной загрузки. Это удобное решение для разработчиков и тех, кто хочет пользоваться привычными инструментами Bash на Windows.

### Требования

- Windows 10 версии 2004 и выше (рекомендуется обновить до последней версии) или Windows 11.
- Подключение к Интернету для скачивания необходимых компонентов.


### Пошаговая инструкция по установке WSL

1. **Открытие PowerShell с правами администратора:**

  Нажмите **Пуск**, введите «PowerShell», затем щёлкните правой кнопкой мыши по «Windows PowerShell» и выберите «Запуск от имени администратора».

2. **Запуск команды установки WSL:**

  В окне PowerShell введите следующую команду:

 

    wsl --install

Эта команда установит WSL и по умолчанию скачает дистрибутив Ubuntu. Если ваша система не поддерживает эту команду, можно включить необходимые компоненты вручную:

- Выполните:

    dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

- Затем перезагрузите компьютер.


- **Перезагрузка системы:**

  После выполнения команды `wsl --install` или ручной активации функций, перезагрузите компьютер для завершения установки.

- **Первоначальная настройка Ubuntu:**

  После перезагрузки в меню «Пуск» найдите установленное приложение **Ubuntu** и запустите его. При первом запуске вас попросят создать нового пользователя и задать пароль. Следуйте инструкциям на экране.

- **Обновление WSL (опционально):**

  Чтобы обновить WSL до последней версии, можно выполнить команду:

 

    wsl --update
