### **Создание и переключение веток**

1. В нижнем левом углу нажмите на текущую ветку.
2. Выберите **Create new branch** и введите имя новой ветки (`feature-branch`).
3. Переключитесь на новую ветку, выбрав её из списка.


**Команда в терминале (альтернативный способ):**

`git switch -c feature-branch`
