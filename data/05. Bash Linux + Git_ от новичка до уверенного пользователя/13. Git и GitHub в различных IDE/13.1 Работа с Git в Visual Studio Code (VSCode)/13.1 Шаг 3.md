## **Основные действия с Git в VSCode**

### **Создание и управление коммитами**

1. Внесите изменения в файл (например, `README.md`).
2. На панели **Source Control** вы увидите список изменённых файлов.
3. Нажмите **+ (Stage Changes)**, чтобы добавить изменения в индекс.
4. Введите сообщение для коммита и нажмите **✓ (Commit)**.


**Пример:**  
Добавьте строку в `README.md`:

`# My First Git Project `

Затем выполните коммит через VSCode с сообщением «Добавлен файл README.md».
