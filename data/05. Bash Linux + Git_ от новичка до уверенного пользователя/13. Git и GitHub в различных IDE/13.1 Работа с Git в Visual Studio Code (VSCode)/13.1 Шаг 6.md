## **Интеграция с GitHub**

VSCode позволяет подключаться к GitHub и управлять Pull Requests прямо из редактора. Для этого используйте расширение **GitHub Pull Requests and Issues**.

### **Шаги для интеграции с GitHub:**

1. Установите расширение **GitHub Pull Requests and Issues** через **Extensions**.
2. Войдите в свою учётную запись GitHub: **View → Command Palette → Sign in to GitHub**.
3. После авторизации вы сможете:
  - Создавать и просматривать Pull Requests.
  - Оставлять комментарии к коду.
  - Обсуждать изменения в режиме реального времени.
