## **Настройка Git в VSCode**

Перед началом работы убедитесь, что Git установлен на вашем компьютере. Проверьте это с помощью команды:

`git --version `

### **Шаги для настройки:**

1. Установите VSCode, если он ещё не установлен: [https://code.visualstudio.com](https://code.visualstudio.com/).
2. Включите панель управления Git: **View → SCM (Source Control Management)**.
3. Откройте папку с вашим проектом: **File → Open Folder**.
4. Если папка ещё не является репозиторием Git, нажмите кнопку **Initialize Repository**.
