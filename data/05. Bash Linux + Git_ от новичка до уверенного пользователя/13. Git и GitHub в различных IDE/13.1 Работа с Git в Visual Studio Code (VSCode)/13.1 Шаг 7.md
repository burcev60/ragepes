## **Практическая часть**

**Задание:**

1. Создайте новый репозиторий в VSCode.   - Нажмите **Initialize Repository** в панели **Source Control**.

2. Добавьте файл `README.md` и внесите в него текст:

  `# My VSCode Git Project `

3. Создайте коммит с сообщением «Добавлен файл README.md».

4. Создайте новую ветку `feature-branch` и добавьте в `README.md` новую строку:

  `Добавлен новый раздел. `

5. Выполните слияние веток через интерфейс VSCode.

6. Подключите репозиторий к GitHub и создайте Pull Request.
