## **Работа с Git в Android Studio**

Android Studio, основанная на IntelliJ IDEA, имеет встроенную поддержку Git и GitHub. Работа с Git в Android Studio похожа на работу в PyCharm.

### **Настройка Git в Android Studio**

1. Перейдите в **File → Settings → Version Control → Git**.
2. Убедитесь, что путь к Git указан правильно (`git --version`).
3. Нажмите **Test**, чтобы проверить подключение.


### **Создание и управление репозиториями**

1. Откройте проект и перейдите в **VCS → Enable Version Control Integration**.
2. Выберите **Git** в списке систем контроля версий.


### **Создание и управление коммитами**

1. Внесите изменения в файл `MainActivity.java`.
2. Перейдите в панель **Commit** (справа).
3. Добавьте изменения в индекс, нажав **+ (Stage Changes)**.
4. Напишите сообщение для коммита и нажмите **Commit**.


### **Работа с ветками**

1. В правом нижнем углу выберите текущую ветку и нажмите **New Branch**.
2. Переключайтесь между ветками через это меню.


### **Интеграция с GitHub**

1. Перейдите в **File → Settings → Version Control → GitHub**.
2. Добавьте свой аккаунт GitHub с помощью токена доступа.
3. После подключения вы сможете публиковать проекты и создавать Pull Requests.
