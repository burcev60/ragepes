## **Практическая часть**

**Задание:**

1. Создайте новый проект в Eclipse или Android Studio.
2. Инициализируйте репозиторий Git.
3. Добавьте файл `Main.java` или `MainActivity.java` и внесите изменения.
4. Создайте коммит и новую ветку `feature-branch`.
5. Выполните слияние веток через интерфейс IDE.
6. Подключите проект к GitHub и создайте Pull Request.
