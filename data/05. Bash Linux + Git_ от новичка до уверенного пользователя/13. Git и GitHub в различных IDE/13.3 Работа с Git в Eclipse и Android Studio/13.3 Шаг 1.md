## **Работа с Git в Eclipse**

Eclipse — одна из самых популярных IDE для разработки на Java и других языках. С помощью плагина **EGit**, который обычно устанавливается по умолчанию, вы можете управлять репозиториями Git напрямую из Eclipse.

### **Настройка Git в Eclipse**

1. Перейдите в **Window → Preferences → Team → Git**.
2. Убедитесь, что путь к Git указан правильно. Если нет, укажите путь вручную.
3. Нажмите **Test Connection**, чтобы убедиться, что Git работает.


### **Создание репозитория**

1. Перейдите в **File → New → Git Repository**.
2. Выберите папку, в которой хотите создать репозиторий, и нажмите **Finish**.  
Теперь ваш проект является Git-репозиторием.


### **Создание и управление коммитами**

1. Внесите изменения в файл (например, `Main.java`).
2. Перейдите в **Git Staging** (вкладка внизу окна).
3. Добавьте изменения в индекс, перетащив файлы в раздел **Staged Changes**.
4. Напишите сообщение для коммита и нажмите **Commit**.


### **Работа с ветками и слияние**

1. Перейдите в **Git Repositories** и нажмите **Create Branch**.
2. Переключайтесь между ветками через это же меню.
3. Для слияния веток используйте **Merge** в контекстном меню выбранной ветки.


### **Интеграция с GitHub**

1. Перейдите в **File → Import → Projects from Git → Clone URI**.
2. Укажите URL вашего репозитория на GitHub.
3. После клонирования вы можете работать с удалённым репозиторием через **Git Staging**.
