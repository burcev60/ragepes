## **Настройка Git в PyCharm**

### **Шаги для настройки:**

1. Убедитесь, что Git установлен и доступен в командной строке (`git --version`).
2. В PyCharm перейдите в **File → Settings → Version Control → Git**.
3. Укажите путь к Git (обычно он определяется автоматически).
4. Нажмите **Test**, чтобы убедиться, что Git настроен правильно.
