## **Практическая часть**

**Задание:**

1. Создайте новый проект в PyCharm.

2. Добавьте файл `main.py` и напишите код:

  `print("My first PyCharm Git project") `

3. Инициализируйте репозиторий и сделайте первый коммит.

4. Создайте ветку `feature-branch` и добавьте новую функцию в `main.py`.

5. Выполните слияние веток через интерфейс PyCharm.

6. Подключите проект к GitHub и создайте Pull Request.
