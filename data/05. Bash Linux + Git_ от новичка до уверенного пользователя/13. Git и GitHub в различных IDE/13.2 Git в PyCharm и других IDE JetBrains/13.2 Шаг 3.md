## **Создание репозитория и работа с коммитами**

### **Создание репозитория:**

1. Откройте проект в PyCharm.
2. Перейдите в **VCS → Enable Version Control Integration**.
3. Выберите **Git** в списке систем контроля версий.  
Теперь ваш проект является Git-репозиторием.


### **Создание коммитов:**

1. Внесите изменения в файл (например, `main.py`).
2. Откройте панель **Commit** (справа внизу).
3. Добавьте изменения в индекс, нажав **+ (Stage Changes)**.
4. Напишите сообщение для коммита и нажмите **Commit**.
