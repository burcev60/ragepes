## **Работа с ветками**

### **Создание и переключение веток:**

1. Перейдите в правый нижний угол окна PyCharm и нажмите на текущую ветку.
2. Выберите **New Branch** и введите имя (`feature-branch`).
3. Переключитесь на новую ветку.


### **Слияние веток:**

1. Переключитесь на основную ветку (`main`).
2. Нажмите на текущую ветку и выберите **Merge**.
3. Выберите ветку, которую хотите слить, и подтвердите действие.
