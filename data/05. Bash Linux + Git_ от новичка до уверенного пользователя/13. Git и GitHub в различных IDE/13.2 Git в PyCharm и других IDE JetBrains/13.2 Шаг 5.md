## **Интеграция с GitHub**

PyCharm позволяет подключаться к GitHub и выполнять все действия, включая создание Pull Requests, через графический интерфейс.

### **Шаги для подключения к GitHub:**

1. Перейдите в **File → Settings → Version Control → GitHub**.
2. Нажмите **+ Add Account** и войдите в свою учётную запись GitHub.
3. После авторизации вы сможете:
  - Публиковать проекты на GitHub.
  - Создавать Pull Requests.
  - Просматривать Issues и комментировать код.
