## **Просмотр истории и сравнение изменений**

PyCharm позволяет визуально отслеживать историю изменений и сравнивать версии файлов.

### **Шаги для просмотра истории:**

1. Перейдите в **VCS → Git → Show History**.
2. Вы увидите список всех коммитов с сообщением, автором и датой.


### **Сравнение изменений:**

1. В истории изменений выберите коммит.
2. Нажмите **Show Diff** для сравнения изменений.
