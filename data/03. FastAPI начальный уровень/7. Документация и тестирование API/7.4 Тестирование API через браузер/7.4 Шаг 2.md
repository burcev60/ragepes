## Использование Swagger UI

FastAPI **автоматически** предоставляет Swagger UI по умолчанию на `/docs`. В этом интерфейсе:

1. Находите нужный эндпоинт.

2. Нажимаете **Try it out**.

3. Заполняете параметры.

4. Нажимаете **Execute**.

5. Смотрите результат в виде текста JSON, кода ответа, заголовков.

Это самый быстрый способ отправить запросы **GET**, **POST**, **PUT**, **DELETE** без установки дополнительных инструментов.

## 4. Передача query-параметров

Если маршрут принимает query-параметры, то их можно указать в адресной строке:

    @app.get("/search")
    def search(q: str, limit: int = 10):
        return {"q": q, "limit": limit}

В браузере:

    http://127.0.0.1:8000/search?q=apple&limit=5

Ответ:

    {
      "q": "apple",
      "limit": 5
    }

## 5. Тестирование POST/PUT/DELETE без Swagger

По умолчанию, браузер умеет легко отправлять **GET**-запросы. Для **POST**, **PUT** или **DELETE** требуется либо использовать HTML-форму (только POST), либо `fetch`/`Axios` из консоли разработчика, либо обратиться к Swagger UI.

### 5.1 HTML-форма (только POST)

Можно создать простую HTML-страницу:

    <!DOCTYPE html>
    <html>
    <body>
        <form method="post" action="http://127.0.0.1:8000/items" enctype="application/x-www-form-urlencoded">
            <label>Name:</label>
            <input type="text" name="name" />
            <button type="submit">Send POST</button>
        </form>
    </body>
    </html>

Она отправит POST-запрос с полем `name`. Но это неудобно для JSON, т.к. форма кодирует данные в `application/x-www-form-urlencoded`.

### 5.2 `fetch` из консоли браузера

Если хочется отправить JSON, можно открыть **Developer Tools** (F12 в Chrome, Firefox), перейти на вкладку **Console** и написать:

    fetch('http://127.0.0.1:8000/items', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ "name": "New Item", "price": 12.5 })
    })
      .then(response => response.json())
      .then(data => console.log(data));

Таким образом, вы сделаете POST-запрос с телом JSON, а результат будет в `console.log(data)`.

Это простой способ проверить эндпоинт, если нет желания запускать Postman
