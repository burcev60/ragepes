### Тестирование API через браузер

Хотя существует множество инструментов и библиотек для тестирования API (например, **Postman**, **Insomnia**, **HTTPie**, Python TestClient), иногда хочется быстро проверить работоспособность маршрута прямо из браузера, не прибегая к дополнительным программам. В этом уроке мы рассмотрим несколько подходов к тому, как можно протестировать ваше FastAPI-приложение, используя только браузер.

## 1. Когда уместно тестирование через браузер?

1. **Быстрая проверка**: Нужно оперативно удостовериться, что эндпоинт даёт ожидаемый ответ.

2. **Эндпоинты GET**: При методе GET вы можете просто ввести URL в адресную строку браузера и увидеть JSON или другой ответ.

3. **Swagger UI / ReDoc**: Встроенные инструменты документации также дают возможность отправлять запросы, но это не всегда покрывает все сценарии.

## 2. Простое тестирование маршрутов GET

Если ваш маршрут использует метод **GET** и не требует авторизации, можно перейти по нему напрямую:

    http://127.0.0.1:8000/items
    http://127.0.0.1:8000/items/3

### Пример

    @app.get("/items")
    def list_items():
        return ["item1", "item2"]

Открыв `http://127.0.0.1:8000/items` в браузере, вы увидите JSON-массив:

    ["item1", "item2"]

Однако, если приложение возвращает **медиа** (например, изображения) или **HTML**, браузер отобразит их напрямую в визуальном виде.
