## Добавление пользовательских заголовков в схему

Если в ваших маршрутах используются дополнительные заголовки, можно явно задокументировать их:

    @app.get("/headers", responses={
        200: {
            "description": "Успешный ответ",
            "headers": {
                "X-Custom-Header": {
                    "description": "Специальный заголовок",
                    "schema": {
                        "type": "string"
                    }
                }
            }
        }
    })
    def custom_headers():
        response = Response("Hello!")
        response.headers["X-Custom-Header"] = "MyValue"
        return response

Swagger UI покажет, что при 200-м ответе ожидается заголовок `X-Custom-Header`.

## 8. Примеры для схем (examples)

Помимо `example` внутри Pydantic-моделей, вы можете указывать примеры на уровне маршрута:

    @app.post("/items", responses={
        200: {
            "content": {
                "application/json": {
                    "example": {
                        "name": "Example item",
                        "price": 19.99
                    }
                }
            }
        }
    })
    def create_item(item: Item):
        return item

При раскрытии в Swagger UI пользователь увидит этот пример.

## 9. Практический пример

    from fastapi import FastAPI, HTTPException
    from pydantic import BaseModel
    from fastapi.openapi.utils import get_openapi

    app = FastAPI(
        title="Advanced API",
        description="API с кастомной OpenAPI-схемой",
        version="1.0.0",
    )

    class User(BaseModel):
        id: int
        name: str

    class Error(BaseModel):
        error: str
        detail: str

    DB = [User(id=1, name="Alice"), User(id=2, name="Bob")]

    @app.get("/users/{user_id}", responses={
        200: {"model": User},
        404: {"model": Error, "description": "User not found"}
    })
    def get_user(user_id: int):
        user = next((u for u in DB if u.id == user_id), None)
        if not user:
            raise HTTPException(status_code=404, detail="No user with this ID")
        return user

    def custom_openapi():
        if app.openapi_schema:
            return app.openapi_schema
        openapi_schema = get_openapi(
            title=app.title,
            version=app.version,
            description=app.description,
            routes=app.routes,
        )
        openapi_schema["info"]["x-logo"] = {
            "url": "https://fastapi.tiangolo.com/img/logo-margin/logo-teal.png"
        }
        app.openapi_schema = openapi_schema
        return app.openapi_schema

    app.openapi = custom_openapi

- Определяем две модели: `User` и `Error`.

- В эндпоинте `/users/{user_id}` используем `responses`, чтобы явно описать 200 и 404.

- Переопределяем `openapi()`, добавляя поле `x-logo`.

- Теперь, перейдя на `/docs` или `/redoc`, увидим кастомное логотип-поле в метаданных и подробные описания ответов.
