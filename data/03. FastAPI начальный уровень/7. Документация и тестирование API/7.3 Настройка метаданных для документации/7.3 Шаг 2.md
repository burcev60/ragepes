## Изменение метаданных через параметры FastAPI

При создании приложения вы можете передать дополнительные поля:

    app = FastAPI(
        title="My Custom API",
        description="Подробное описание",
        version="2.0.0",
        contact={
            "name": "John Doe",
            "url": "https://example.com",
            "email": "john@example.com"
        },
        license_info={
            "name": "Apache 2.0",
            "url": "https://www.apache.org/licenses/LICENSE-2.0.html"
        }
    )

Эти поля появятся в `openapi.json` и будут видны в Swagger UI/ReDoc. Ключи `contact` и `license_info` — часть OpenAPI-спецификации.

## 4. Описание тегов (openapi_tags)

Теги помогают группировать эндпоинты, а через `openapi_tags` можно дать каждому тегу заголовок и описание:

    tags_metadata = [
        {
            "name": "users",
            "description": "Операции, связанные с пользователями",
        },
        {
            "name": "items",
            "description": "Управление товарами",
        },
    ]

    app = FastAPI(openapi_tags=tags_metadata)

Затем в маршрутах:

    @app.get("/users", tags=["users"])
    def list_users():
        return ["user1", "user2"]

    @app.get("/items", tags=["items"])
    def list_items():
        return ["item1", "item2"]

В Swagger UI и ReDoc теги будут сопровождаться вашими комментариями.
