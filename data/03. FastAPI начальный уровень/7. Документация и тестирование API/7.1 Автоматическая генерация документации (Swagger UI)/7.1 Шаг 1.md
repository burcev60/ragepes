### Автоматическая генерация документации (Swagger UI) в FastAPI

FastAPI предоставляет встроенный механизм автоматической генерации OpenAPI-спецификации и визуализации этой спецификации с помощью **Swagger UI**. Это даёт огромное преимущество при разработке и тестировании, а также делает ваш API более понятным для остальных разработчиков.

## 1. Что такое Swagger UI?

**Swagger UI** (ранее известный как OpenAPI UI) — это веб-интерфейс, который:

1. Отображает спецификацию API в формате OpenAPI.

2. Позволяет **интерактивно** отправлять запросы и смотреть ответы без написания клиентского кода.

3. Генерируется в FastAPI **автоматически**, без необходимости ручной настройки, если вы используете модели Pydantic и декораторы роутов.

## 2. Где доступна документация?

По умолчанию, когда вы запускаете приложение FastAPI, документация Swagger UI становится доступной по адресу:

    http://127.0.0.1:8000/docs

Альтернативный интерфейс — **ReDoc** — доступен по адресу:

    http://127.0.0.1:8000/redoc

При желании вы можете изменить эти пути или вовсе их отключить.
