## Формирование OpenAPI-схемы

OpenAPI-схема формируется на основе:

1. **Декораторов методов** (`@app.get(...)`, `@app.post(...)`, т.д.).

2. **Моделей Pydantic** в параметрах и в `response_model`.

3. **Описаний параметров** через `Query`, `Path`, `Body`.

Пример:

    from fastapi import FastAPI
    from pydantic import BaseModel

    app = FastAPI()

    class Item(BaseModel):
        name: str
        price: float

    @app.post("/items", response_model=Item)
    def create_item(item: Item):
        return item

- FastAPI автоматически создаст описание `POST /items`.

- Укажет модель запроса (body) и модель ответа.

- Сгенерирует описание полей: `name: str`, `price: float`.
