## Настройка Swagger UI в FastAPI

### 4.1 Переименование URL документации

Если хотите изменить путь документации (`/docs`) или путь OpenAPI (`/openapi.json`), это можно сделать при создании приложения:

    app = FastAPI(
        title="My API",
        description="Пример моего супер API",
        version="1.0.0",
        docs_url="/mydocs",
        redoc_url="/myredoc",
        openapi_url="/myopenapi.json"
    )

Теперь:

- Swagger UI: `http://127.0.0.1:8000/mydocs`

- ReDoc: `http://127.0.0.1:8000/myredoc`

- Схема OpenAPI: `http://127.0.0.1:8000/myopenapi.json`

### 4.2 Отключение документации

Если нужно отключить интерфейс документации в продакшене:

    app = FastAPI(
        docs_url=None,
        redoc_url=None,
        openapi_url=None
    )

## 5. Метаданные и дополнительные описания

### 5.1 Заголовок, описание, версия API

При создании `FastAPI(...)` можно указать:

    app = FastAPI(
        title="Мой магазин",
        description="API для управления товарами и заказами.",
        version="2.1.0"
    )

Swagger UI покажет эту информацию в верхней части страницы.

### 5.2 Теги (Tags)

Используйте теги, чтобы группировать конечные точки (эндпоинты). Это облегчает навигацию в Swagger UI.

    @app.get("/users", tags=["users"])
    def list_users():
        ...

    @app.get("/orders", tags=["orders"])
    def list_orders():
        ...

В результате в Swagger UI появятся разделы **users** и **orders**, каждый со своими методами.

### 5.3 Перенос методов в раздел с описанием

Можно задавать более развернутое описание:

    @app.get("/items", tags=["items"], summary="Получить список товаров", description="Возвращает все товары из базы.")
    def read_items():
        return ["item1", "item2"]

- `summary` — краткое описание маршрута.

- `description` — детальная информация, которую Swagger UI покажет при раскрытии.
