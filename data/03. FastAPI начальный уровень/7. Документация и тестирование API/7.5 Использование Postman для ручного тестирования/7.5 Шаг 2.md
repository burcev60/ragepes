## Работа с параметрами и телом запроса

### 3.1 Query-параметры

- Во вкладке **Params** можно задать query-параметры. Postman сформирует их и добавит к URL.

**Пример**: `/search?q=apple&limit=5`

- Введите ключи: `q`, `limit`, значения: `apple`, `5`.

### 3.2 Headers

- Во вкладке **Headers** задавайте заголовки: `Content-Type`, `Authorization`, и др.

### 3.3 Body

- Для POST / PUT запросов укажите тип тела запроса:

  - **raw** + **JSON** — для JSON-данных.

  - form-data — если загружаете файлы.

  - x-www-form-urlencoded — если имитируете форму.

**Пример**: хотите отправить JSON с полями `name` и `price`:

    {
      "name": "Laptop",
      "price": 999.99
    }

Установите:

- Body -> raw

- Выберите JSON в выпадающем списке.

- Введите JSON в текстовом поле.

## 4. Authorization и Bearer Tokens

1. Вкладка **Authorization** даёт возможность выбрать тип аутентификации.

2. **Bearer Token** — один из самых популярных при работе с JWT.

3. **Basic Auth** — логин и пароль.

4. **Digest Auth**, **OAuth 2.0** и др.

**Пример**: Если сервер требует токен Bearer

- Выберите **Bearer Token**.

- Введите ваш токен.

- Postman добавит заголовок `Authorization: Bearer <token>` при каждом запросе.
