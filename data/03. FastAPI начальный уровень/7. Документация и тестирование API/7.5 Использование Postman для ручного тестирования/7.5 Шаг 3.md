## Управление коллекциями

1. Создавайте **Collections**, чтобы хранить наборы запросов по конкретному сервису.

2. Вы можете создавать под-папки внутри коллекций, разделяя тесты по модулям ("Users", "Items").

3. Под каждую коллекцию можно настраивать **общие переменные** (environment variables), например, `base_url`.

### 5.1 Environment (Окружения)

- Переменные окружения позволяют быстро переключаться между DEV / STAGE / PROD.

- Например, задаём `{{base_url}} = http://127.0.0.1:8000` для локальной разработки, а потом меняем на `https://api.myapp.com` при тестировании продакшена.

- Везде в запросах используем `{{base_url}}/items`.

## 6. Просмотр ответов и журнал запросов

1. **Body** показывает содержимое ответа (JSON, HTML и т.д.).

2. **Cookies** — если сервер устанавливает куки, Postman отследит их.

3. **Headers** — заголовки, которые вернул сервер.

4. **Test Results** — если вы пишете тесты на языке JavaScript прямо в Postman.
