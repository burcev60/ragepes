### Использование Postman для ручного тестирования

**Postman** — один из самых популярных и удобных инструментов для ручного тестирования API. Он позволяет отправлять запросы различных типов (GET, POST, PUT, DELETE), задавать заголовки, параметры, тело запроса и многое другое. В этом уроке мы рассмотрим, как использовать Postman для тестирования веб-приложений, в том числе тех, которые работают на FastAPI.

## 1. Установка и обзор Postman

1. **Установка**: Скачайте Postman с официального сайта и установите на свою операционную систему.

2. **Запуск**: Запустите Postman, у вас откроется главное окно с инструментами для создания запросов.

3. **Вкладка "Collections"**: позволяет группировать запросы по тематике.

4. **Вкладка "History"**: автоматический список всех отправленных запросов.

## 2. Отправка первого запроса

### Шаги:

1. Нажмите **New** (или +), чтобы создать новый запрос.

2. В левом верхнем углу выберите метод: GET / POST / PUT / DELETE / PATCH.

3. Введите URL-адрес (например, `http://127.0.0.1:8000/items`).

4. Нажмите **Send**.

#### Результат:

- В нижней части окна Postman вы увидите ответ от сервера (код, тело JSON, заголовки).

- В верхней части можно переключаться на **Params**, **Authorization**, **Headers**, **Body** и т.д.
