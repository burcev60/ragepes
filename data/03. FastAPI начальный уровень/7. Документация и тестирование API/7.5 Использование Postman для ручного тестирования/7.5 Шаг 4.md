## Поддержка тестов в Postman

Postman позволяет писать небольшие **скрипты** на JS, которые выполняются после получения ответа:

    pm.test("Статус = 200", function() {
      pm.response.to.have.status(200);
    });

    pm.test("Тело содержит поле 'name'", function() {
      var jsonData = pm.response.json();
      pm.expect(jsonData).to.have.property('name');
    });

Это упрощает автоматизацию регрессионных тестов.

## 8. Экспорт и импорт запросов

1. **Export**: Сохранённую коллекцию можно экспортировать в JSON-файл и отправить коллегам.

2. **Import**: Аналогично, можно импортировать чужие коллекции.

3. Это удобно, когда в команде несколько человек, и им нужно общее окружение для тестирования.

## 9. Практический пример

Допустим, у нас есть эндпоинты в FastAPI:

    @app.post("/login")
    def login(data: dict):
        if data["username"] == "admin" and data["password"] == "1234":
            return {"token": "abcd1234"}
        raise HTTPException(status_code=401, detail="Invalid creds")

    @app.get("/users/me")
    def get_me(token: str = Header(None)):
        if token == "abcd1234":
            return {"user_id": 1, "name": "Admin"}
        raise HTTPException(status_code=403, detail="Forbidden")

**Шаги в Postman**:

1. Создайте коллекцию "MyApp".

2. Добавьте запрос `POST /login`:

  - Body -> raw (JSON): `{ "username": "admin", "password": "1234" }`.

3. Отправьте, получите `{"token": "abcd1234"}`.

4. Сохраните токен в переменную окружения `{{token}}`.

5. Создайте запрос `GET /users/me`:

  - Headers -> `token: {{token}}`.

6. Отправьте, получите `{"user_id":1, "name":"Admin"}`.

Теперь в два клика можно проверять логику авторизации и тестировать сценарии "верный"/"неверный" пароль.
