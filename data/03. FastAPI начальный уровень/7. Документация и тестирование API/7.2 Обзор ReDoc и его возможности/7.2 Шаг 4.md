## Продвинутая кастомизация ReDoc

FastAPI (вернее, Starlette) позволяет указать собственный HTML-шаблон для ReDoc:

    from fastapi.openapi.docs import get_redoc_html

    @app.get("/redoc-custom", include_in_schema=False)
    def redoc_custom():
        return get_redoc_html(
            openapi_url=app.openapi_url,
            title="Моя документация",
            redoc_js_url="https://cdn.jsdelivr.net/npm/redoc@next/bundles/redoc.standalone.js",
            # можно указать свои стили, скрипты, etc.
        )

Таким образом, вы сможете внедрить дополнительные элементы интерфейса или изменить стили.

## 8. Сравнение с другими инструментами

- **Redoc** vs **Swagger UI**:

  - Redoc: структурированный интерфейс, ориентирован больше на чтение и понимание API.

  - Swagger UI: упор на тестирование из браузера ("Try it out").

- **Redoc** зачастую предпочтительнее для продакшен-документации, т.к. выглядит аккуратнее.

## 9. Пример применения ReDoc

    from fastapi import FastAPI
    from pydantic import BaseModel

    app = FastAPI(
        title="Shop API",
        description="Документация по магазинам и товарам",
        version="1.0",
        redoc_url="/docs-redoc"
    )

    class Shop(BaseModel):
        name: str
        location: str

    @app.get("/shops", tags=["Shops"], response_model=Shop)
    def get_shop():
        return Shop(name="Central Shop", location="City Center")

Теперь по адресу `http://127.0.0.1:8000/docs-redoc` вы получите ReDoc-интерфейс, который покажет:

- Заголовок: "Shop API"

- Версию: "1.0"

- Описание: "Документация по магазинам и товарам"

- Раздел "Shops" с эндпоинтом `/shops`

- Модель `Shop` с описанием полей.
