## Создание подробных описаний и примеров

### 5.1 Описание моделей

В Pydantic-модели можно использовать `Field` для добавления описаний, примеров:

    from pydantic import BaseModel, Field

    class Item(BaseModel):
        name: str = Field(..., description="Название товара", example="Laptop")
        price: float = Field(..., description="Цена товара", example=999.99)

ReDoc отобразит эти описания и примеры при просмотре модели.

### 5.2 schema_extra

Альтернативный способ:

    class User(BaseModel):
        name: str
        age: int

        class Config:
            schema_extra = {
                "example": {
                    "name": "Alice",
                    "age": 25
                }
            }

## 6. Работа с тегами

ReDoc группирует эндпоинты по тегам, аналогично Swagger UI:

    @app.get("/users", tags=["Users"])
    def list_users():
        ...

    @app.post("/users", tags=["Users"])
    def create_user():
        ...

Все методы, у которых указан тег `"Users"`, будут собраны в общий блок.
