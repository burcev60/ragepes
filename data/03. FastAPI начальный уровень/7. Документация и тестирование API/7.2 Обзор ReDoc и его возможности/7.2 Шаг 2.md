## Как настроить ReDoc в FastAPI

### 3.1 Изменение URL

Вы можете поменять URL для ReDoc при создании приложения:

    from fastapi import FastAPI

    app = FastAPI(
        redoc_url="/api-docs",
    )

Теперь ReDoc будет доступен по `http://127.0.0.1:8000/api-docs`.

### 3.2 Отключение ReDoc

Если не хотите, чтобы ReDoc был доступен, установите `redoc_url=None`:

    app = FastAPI(redoc_url=None)

## 4. Основные особенности интерфейса ReDoc

1. **Навигация слева**: список всех разделов и эндпоинтов. Категории формируются тегами (`tags`) в FastAPI.

2. **Раздел "Introduction"**: берёт информацию из `title`, `description` и `version` при инициализации `FastAPI`.

3. **Таблица свойств (models)**: Детализированная структура Pydantic-моделей, типы полей, обязательность, описания.

4. **Примеры**: Если в моделях Pydantic заданы поля `example` или `schema_extra`, ReDoc может отображать их в виде примера.
