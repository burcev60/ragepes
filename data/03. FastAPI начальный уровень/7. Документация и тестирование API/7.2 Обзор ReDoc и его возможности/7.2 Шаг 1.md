### Обзор ReDoc и его возможности

Помимо Swagger UI, FastAPI автоматически генерирует документацию в формате **ReDoc**, которая также базируется на спецификации OpenAPI. ReDoc предлагает несколько удобных функций, выделяясь своим оформлением и структурой. В этом уроке мы подробно рассмотрим, в чём особенность ReDoc и как с ней работать.

## 1. Что такое ReDoc?

**ReDoc** — это инструмент для визуализации API на базе OpenAPI. Он:

1. Предоставляет лаконичный и современный дизайн.

2. Располагает описание эндпоинтов в виде удобного "дерева" слева и подробного описания — справа.

3. Умеет автоматически генерировать примеры запросов на основе схем.

4. Позволяет легко переключаться между моделью данных, описанием полей и примерами.

По умолчанию, после запуска FastAPI, ReDoc доступен по адресу:

    http://127.0.0.1:8000/redoc

## 2. Отличия от Swagger UI

1. **Дизайн и структура**:

  - ReDoc использует трёхпанельный интерфейс (список методов, описание, схема).

  - Swagger UI показывает эндпоинты в виде сворачиваемых блоков.

2. **Фокус на описании**:

  - ReDoc делает акцент на наглядной документации моделей.

  - Позволяет автоматически генерировать "примеры" на базе JSON Schema.

3. **Интерактивное тестирование**:

  - Swagger UI даёт возможность сразу вызвать запрос ("Try it out").

  - ReDoc ориентирован больше на просмотр и изучение, а не на тестирование.

Если нужен инструмент для "живого" запроса, чаще используют Swagger UI. Если требуется удобно упорядочить документацию, ReDoc вносит дополнительную ясность.
