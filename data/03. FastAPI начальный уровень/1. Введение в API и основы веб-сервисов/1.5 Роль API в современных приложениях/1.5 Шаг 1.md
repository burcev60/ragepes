## Введение

### 1.1 Что такое API в контексте современных приложений

- **API (Application Programming Interface)** — это способ, с помощью которого различные компоненты приложения (или разные приложения) могут «общаться» друг с другом по заранее оговорённым правилам.
- В контексте современных приложений API является «точкой входа» к функционалу и данным, скрывая внутреннюю реализацию и обеспечивая удобный интерфейс для разработчиков и внешних сервисов.


### 1.2 Почему тема актуальна

- Мир IT всё более «распределён»: приложения состоят из множества сервисов, которые связаны между собой.
- Пользователям важно получать данные быстро и из множества источников — соцсети, платёжные системы, геосервисы и т.д.
- Без API полноценная интеграция становилась бы крайне сложной (необходимы прямые, часто небезопасные «лазейки» в базу или сложные самописные решения).
