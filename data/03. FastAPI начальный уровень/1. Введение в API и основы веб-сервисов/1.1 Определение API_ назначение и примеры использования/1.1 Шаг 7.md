## Виды API (без технических деталей)

Хотя **подробный обзор типов** обычно рассматривается в следующих темах, кратко перечислим виды с точки зрения доступности и назначения (не вдаваясь в REST, GraphQL, SOAP и т. д.):

1. **Публичные (открытые)**
  - Доступны всем желающим, хотя обычно требуют регистрации и получения ключа (API Key).
  - Пример: карты, соцсети, погода.
2. **Частные (внутренние)**
  - Используются только внутри компании или организации.
  - Пример: внутренний API для связи между отделами.
3. **Партнёрские**
  - Ограничены узким кругом партнёров, которым выдан доступ по договорённости.
  - Пример: финансовые API между банками.
