## Протоколы передачи данных: HTTP и HTTPS

### HTTP

- **HyperText Transfer Protocol** — основной протокол передачи данных в интернете.

- Использует методы (GET, POST, PUT, DELETE, PATCH и др.) для взаимодействия с ресурсами.

- Сообщения клиент-сервер обмениваются заголовками (Headers) и телом запроса/ответа (Body).

### HTTPS

- **HTTP Secure** — это HTTP, защищённый протоколом шифрования SSL/TLS.

- Обеспечивает безопасную передачу данных, защищая от перехвата и подмены.

- Для большинства современных веб-API использование HTTPS — стандарт, а во многих случаях обязательное требование.
