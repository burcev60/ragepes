## Форматы данных: JSON и XML

### JSON (JavaScript Object Notation)

- Наиболее популярный формат для современных веб-API.

- Легко читается человеком (в отличие от некоторых двоичных форматов) и легко обрабатывается машинами.

- Структура на основе пар «ключ: значение».

- Пример:

    {
      "user": {
        "id": 123,
        "name": "Иван",
        "roles": ["admin", "editor"]
      }
    }

### XML (eXtensible Markup Language)

- Ранее был основным форматом данных для веб-сервисов (до популяризации JSON).

- Структура, основанная на тегах, аналогична HTML.

- Более «тяжёлый» формат, требует больше места для хранения и передачи, чем JSON.

- Пример:

-

    <user>
      <id>123</id>
      <name>Иван</name>
      <roles>
        <role>admin</role>
        <role>editor</role>
      </roles>
    </user>
