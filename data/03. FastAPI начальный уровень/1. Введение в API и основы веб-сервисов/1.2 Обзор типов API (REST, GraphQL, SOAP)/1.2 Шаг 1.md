## Введение в веб-API

### Понятие «веб-API»

Веб-API (иногда упоминается как Web Service) — это программный интерфейс, к которому можно обращаться через протоколы, работающие поверх сети (обычно **HTTP** или **HTTPS**). Если в предыдущей теме мы разобрали общее определение API, то теперь фокусируемся именно на веб-API.

### Ключевые особенности веб-API

1. **Сетевое взаимодействие**: Доступ к методам API осуществляется по URL-адресам.

2. **Стандартная передача данных**: Чаще всего используется JSON или XML.

3. **Структурированные методы**: Чётко описанные «эндпоинты» (конечные точки запроса).

4. **Статус-коды ответов**: Применяются стандартные коды HTTP (200, 201, 400, 404, 500 и т.д.).
