## Кастомизация формата через Pydantic-модели

Pydantic-модели позволяют управлять тем, как данные сериализуются.

### Поля, исключаемые из вывода

    class User(BaseModel):
        id: int
        username: str
        password: str

        class Config:
            orm_mode = True
            fields = {
                'password': {'exclude': True}
            }

Таким образом, поле `password` не попадёт в сериализованный JSON.

### Альтернативный способ исключения

В самом методе маршрута можно использовать `dict(exclude={...})`:

    @app.get("/users/{user_id}")
    def get_user(user_id: int):
        user = User(id=user_id, username="Alice", password="secret")
        return user.dict(exclude={"password"})

Результат не будет содержать поле `password`.

## Обработка дат и времени

Pydantic автоматически превращает объекты типа `datetime`, `date`, `time` в ISO-8601 строки. Если вам нужно другое форматирование, можно использовать **валидаторы** или **custom encoder**.

### Пример c валидатором

    from datetime import datetime
    from pydantic import BaseModel, validator

    class Event(BaseModel):
        name: str
        timestamp: datetime

        @validator('timestamp', pre=True)
        def format_timestamp(cls, value):
            # Если приходит строка, преобразуем её
            if isinstance(value, str):
                return datetime.strptime(value, "%d-%m-%Y %H:%M")
            return value

Если в запросе дата придёт в формате `"25-12-2025 14:30"`, она будет корректно конвертирована и при сериализации отобразится в стандартном формате ISO.

### Custom encoders

Можно прописать кастомные функции для преобразования типов при сериализации:

    from pydantic.json import ENCODERS_BY_TYPE

    ENCODERS_BY_TYPE[datetime] = lambda v: v.strftime("%d/%m/%Y %H:%M")

Тогда при возврате `datetime` в JSON будет использоваться формат `"DD/MM/YYYY HH:MM"`.
