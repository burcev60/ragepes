## Сложные ответные структуры

1. **Вложенные модели**: например, если у товара есть поле `category` — это объект.

    class Category(BaseModel):
        name: str

    class ItemResponse(BaseModel):
        id: int
        name: str
        category: Category

1. **Списки**: если возвращаем список товаров.

    from typing import List

    @app.get("/items", response_model=List[ItemResponse])
    def list_items():
        return [
            {"id": 1, "name": "Book", "price": 9.99},
            {"id": 2, "name": "Pen", "price": 1.99}
        ]

## 5. Различные модели для разных кодов ответа

FastAPI позволяет указать несколько моделей ответа в декораторе, если приложение может вернуть разные коды:

    from pydantic import BaseModel
    from fastapi import HTTPException

    class SuccessResponse(BaseModel):
        id: int
        detail: str

    class NotFoundResponse(BaseModel):
        error: str

    @app.get("/items/{item_id}", responses={
        200: {"model": SuccessResponse},
        404: {"model": NotFoundResponse}
    })
    def get_item(item_id: int):
        if item_id == 1:
            return {"id": 1, "detail": "Item found"}
        else:
            raise HTTPException(status_code=404, detail="Item not found")

- При успехе (`200 OK`) ожидается `SuccessResponse`.

- При ошибке `404 Not Found` возвращаем структуру `NotFoundResponse`.

В Swagger UI это автоматически отобразится, показывая возможные варианты ответа.
