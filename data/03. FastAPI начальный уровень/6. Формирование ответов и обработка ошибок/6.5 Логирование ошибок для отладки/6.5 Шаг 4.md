## Дополнительные заголовки ответов (headers)

Помимо cookies, в HTTP-ответ можно добавлять любые заголовки, информирующие клиента о способах кэширования, языке, типе контента и т.д.

### Ручное добавление заголовков

    from fastapi.responses import JSONResponse

    @app.get("/custom_headers")
    def custom_headers():
        data = {"msg": "Пример заголовков"}
        response = JSONResponse(content=data)
        response.headers["X-My-Header"] = "SomeValue"
        response.headers["Cache-Control"] = "no-store"
        return response

- `X-My-Header` — пользовательский заголовок.

- `Cache-Control` — управляет кэшированием ответа.

### Управление статусом

    @app.get("/response_status")
    def response_status():
        content = {"info": "Всё хорошо"}
        return JSONResponse(status_code=201, content=content)

## Кратко о CORS (Cross-Origin Resource Sharing)

Когда фронтенд (JS) запрашивает ресурсы с другого домена, браузер использует механизм CORS. FastAPI имеет `CORSMiddleware` для настройки заголовков `Access-Control-*`.

    from fastapi.middleware.cors import CORSMiddleware

    origins = ["http://localhost:3000"]
    app.add_middleware(
        CORSMiddleware,
        allow_origins=origins,
        allow_credentials=True,
        allow_methods=["*"],
        allow_headers=["*"]
    )

Теперь ответы от сервера будут содержать необходимые заголовки CORS, и браузер позволит отправлять запросы с указанного домена.
