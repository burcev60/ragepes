## Установка cookies на стороне сервера

Чтобы ответ содержал cookie, можно изменить заголовки ответа:

    from fastapi import FastAPI, Response

    app = FastAPI()

    @app.get("/set_cookie")
    def set_cookie(response: Response):
        response.set_cookie(
            key="session_id",
            value="abc123",
            max_age=3600,       # сколько секунд cookie будет действовать
            httponly=True,      # запрещает доступ к cookie из JavaScript
            secure=True,        # требует HTTPS
            samesite="strict"  # запрещает отправку cookie при переходах с других сайтов
        )
        return {"msg": "Cookie установлена"}

### Разбор кода

1. `response.set_cookie(...)` — метод, упрощающий работу с заголовком `Set-Cookie`.

2. `key` — имя cookie, `value` — значение.

3. Дополнительные параметры:

  - `max_age` или `expires` — срок действия.

  - `httponly` — запрет на чтение куки из JavaScript (повышает безопасность).

  - `secure` — требует HTTPS.

  - `samesite` — защита от CSRF-атак.
