## Коды, связанные с аутентификацией и авторизацией

- **401 Unauthorized**: когда отсутствует авторизация или неверные учётные данные.

  - Клиент может повторить запрос, но с корректной авторизацией.

- **403 Forbidden**: клиент авторизован, но не имеет прав на доступ к ресурсу.

  - Например, пользователь не имеет нужных ролей.

Пример:

    @app.get("/admin")
    def admin_section(user=Depends(get_current_user)):
        if not user.is_admin:
            raise HTTPException(status_code=403, detail="Forbidden. Admins only.")
        return {"msg": "Welcome, admin."}

## Коды, связанные с конфликтами и отсутствием ресурсов

- **404 Not Found**: когда запрашиваемый ресурс (объект, страница) отсутствует.

- **409 Conflict**: например, при создании сущности, которая уже существует.

    @app.post("/users")
    def create_user(user: User):
        if db.exists(user.username):
            raise HTTPException(status_code=409, detail="Username already taken.")
        # иначе создаём
        db.add(user)
        return user

## Серверные ошибки

- **500 Internal Server Error**: используется, если произошло что-то непредвиденное на стороне сервера — баг, исключение.

- **503 Service Unavailable**: при перегрузке сервера или в случае техобслуживания.

FastAPI обычно сам обрабатывает необработанные исключения и возвращает 500. Если нужно, вы можете переопределить поведение через `exception_handler`.
