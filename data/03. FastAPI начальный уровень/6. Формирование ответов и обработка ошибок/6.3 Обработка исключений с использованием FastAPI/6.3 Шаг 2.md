## Возвращение изображений и другого контента

При отправке изображений формата PNG, JPEG, GIF и т.д., важно указывать корректный `media_type`. Например:

    from fastapi.responses import FileResponse

    @app.get("/image")
    def get_image():
        return FileResponse("images/picture.png", media_type="image/png")

**Совет:**

- Указывайте MIME-тип (`image/png`, `image/jpeg`), чтобы браузеры и клиенты корректно обрабатывали файл.

- Вы можете также использовать `Content-Disposition` заголовки для управления режимом открытия/скачивания.

## Стриминговые ответы (StreamingResponse)

Иногда нужно отдавать данные постепенно (в потоковом режиме), особенно при работе с большими файлами или генерацией контента на лету.

### Простой пример

    from fastapi import FastAPI
    from fastapi.responses import StreamingResponse

    app = FastAPI()

    def iter_data():
        # Пример: генерируем данные построчно
        yield "Hello, "
        yield "this is a "
        yield "streamed response!"

    @app.get("/stream")
    def stream_data():
        return StreamingResponse(iter_data(), media_type="text/plain")

Здесь:

1. `iter_data()` — генератор, по одному возвращающий куски данных.

2. `StreamingResponse` оборачивает этот генератор, и клиент начнёт получать данные по мере их генерации.

3. `media_type="text/plain"` сообщает клиенту, что содержимое — текст.

### Работа с большими файлами

Если вы отдаёте большой файл, а не хотите загружать его целиком в память:

    def file_iterator(file_path, chunk_size=1024):
        with open(file_path, "rb") as f:
            while True:
                chunk = f.read(chunk_size)
                if not chunk:
                    break
                yield chunk

    @app.get("/bigfile")
    def stream_file():
        return StreamingResponse(
            file_iterator("huge_video.mp4"),
            media_type="video/mp4"
        )

Такой подход позволяет передавать данные по частям, снижая нагрузку на память сервера.
