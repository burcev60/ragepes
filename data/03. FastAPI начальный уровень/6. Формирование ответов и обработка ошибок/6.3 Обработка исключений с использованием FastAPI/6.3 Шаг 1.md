В предыдущих уроках мы рассмотрели форматы JSON-ответов и использование моделей Pydantic для описания структуры данных. Однако бывают сценарии, когда нужно не просто вернуть JSON, а, например, отправить файл, передавать поток данных (streaming), отдавать изображения или загружать большие файлы по кусочкам. В этом уроке мы подробно разберём различные виды ответов, отличающихся от классического JSON.

## 1. Возвращение статических файлов

Хотя FastAPI не ориентирован на полноценную работу со статическими файлами (как, например, Django), мы можем отдавать файлы с помощью специальных методов.

### 1.1 `FileResponse`

Чтобы вернуть файл из функции-обработчика, используйте `FileResponse`:

    from fastapi import FastAPI
    from fastapi.responses import FileResponse

    app = FastAPI()

    @app.get("/download")
    def download_file():
        file_path = "path/to/report.pdf"
        return FileResponse(
            path=file_path,
            filename="report.pdf",
            media_type="application/pdf"
        )

**Особенности:**

- `path` – физический путь к файлу.

- `filename` – то, как файл будет называться при скачивании.

- `media_type` – MIME-тип, указывающий, как интерпретировать содержимое (PDF, JPEG и др.).

При обращении к эндпоинту `GET /download` клиент получит скачиваемый файл.

### 1.2 `StaticFiles` (для раздачи папки с файлами)

Если нужно раздавать целую директорию статических файлов (например, картинки, CSS, JS), используйте **StaticFiles**:

    from fastapi import FastAPI
    from fastapi.staticfiles import StaticFiles

    app = FastAPI()
    app.mount("/static", StaticFiles(directory="static"), name="static")

Теперь, все файлы в папке `static` доступны по URL `http://127.0.0.1:8000/static/<имя_файла>`.
