## Пример: возвращение PDF в браузере

Если хотим, чтобы браузер напрямую открыл PDF, указываем `media_type="application/pdf"`:

    @app.get("/show-pdf")
    def show_pdf():
        return FileResponse(
            "files/manual.pdf",
            media_type="application/pdf"
        )

Чтобы браузер сразу не открывал, а скачивал, добавьте заголовок:

    response = FileResponse("files/manual.pdf", media_type="application/pdf")
    response.headers["Content-Disposition"] = "attachment; filename=manual.pdf"
    return response

## Сочетание моделей Pydantic и файловых ответов

Иногда требуется вернуть микс: часть — JSON, часть — файл. Например, сначала проверяем в БД существование файла, если нет — возвращаем ошибку (JSON), иначе отдаём файл.

    @app.get("/export")
    def export_data(file_name: str):
        file_path = f"exports/{file_name}.xlsx"
        if not os.path.exists(file_path):
            return {
                "error": "File not found",
                "file_requested": file_name
            }
        return FileResponse(file_path, media_type="application/vnd.ms-excel")

Или используйте разные коды ответов:

    @app.get("/export", responses={
        200: {"description": "File returned"},
        404: {"description": "File not found"}
    })
    def export_data(file_name: str):
        # ...

## Советы по безопасности и оптимизации

1. **Не отдавайте** приватные файлы или конфиденциальные данные напрямую. Желательно использовать аутентификацию и авторизацию.

2. **Будьте осторожны** с путями, передаваемыми пользователями (избегайте directory traversal).

3. **Используйте streaming** при больших файлах, чтобы не перегружать память.

4. **Кешируйте** часто запрашиваемые файлы, если это возможно.
