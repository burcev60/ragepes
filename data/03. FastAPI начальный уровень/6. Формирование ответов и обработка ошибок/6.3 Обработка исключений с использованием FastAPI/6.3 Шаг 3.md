## Настройка заголовков и кодировки

При работе с `StreamingResponse`, `FileResponse` и другими классами ответов, вы можете добавлять заголовки (headers) или менять статусный код (status code). Пример:

    @app.get("/custom-video")
    def custom_video():
        response = StreamingResponse(
            file_iterator("movie.mp4"),
            media_type="video/mp4"
        )
        response.headers["Content-Disposition"] = "attachment; filename=movie.mp4"
        response.status_code = 200  # можно изменить код
        return response

Если файл должен скачиваться (Download), а не отображаться в браузере, используется заголовок `Content-Disposition: attachment`.

## Варианты возвращаемых типов в FastAPI

Помимо `FileResponse`, `StreamingResponse`, `JSONResponse`, есть и другие:

1. **HTMLResponse** — если нужно сгенерировать HTML-страницу.

2. **PlainTextResponse** — когда отдаёте чистый текст.

3. **RedirectResponse** — для перенаправлений.

4. **ORJSONResponse** — ускоренная JSON-сериализация.

Вы можете явно указать нужный класс ответа через параметр `response_class`:

    from fastapi.responses import HTMLResponse

    @app.get("/html", response_class=HTMLResponse)
    def get_html():
        return "<html><body><h1>Hello!</h1></body></html>"
