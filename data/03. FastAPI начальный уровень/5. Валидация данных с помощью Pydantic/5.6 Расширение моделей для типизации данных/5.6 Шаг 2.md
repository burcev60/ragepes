## Работа с коллекциями и вложенными структурами

### 2Списки, наборы, словари

    from typing import List, Set, Dict
    from pydantic import BaseModel

    class Inventory(BaseModel):
        items: List[str]
        unique_items: Set[str]
        meta_data: Dict[str, str]

- `items` — список строк.

- `unique_items` — множество (не допускает повторений).

- `meta_data` — словарь, где ключи и значения — строки.

При валидации Pydantic проверяет, что данные соответствуют этим типам. Если, например, передать вместо списка число, будет вызвана ошибка.

## Специализированные типы

### EmailStr

    from pydantic import BaseModel, EmailStr

    class UserContact(BaseModel):
        email: EmailStr

Если вы передадите неправильно отформатированный email, Pydantic вернёт ошибку.

### SecretStr

Для работы с конфиденциальными данными (например, паролями), есть тип `SecretStr`. Он скрывает значение при отображении:

    from pydantic import BaseModel, SecretStr

    class Credentials(BaseModel):
        username: str
        password: SecretStr

    creds = Credentials(username="admin", password="12345")
    print(creds)  # password=SecretStr('**********')

### HttpUrl

Для валидации URL:

    from pydantic import BaseModel, HttpUrl

    class Link(BaseModel):
        url: HttpUrl

    Link(url="https://example.com")  # OK
    Link(url="not_a_valid_url")      # Ошибка

## Опции типов из модуля `typing`

### Union

`Union` позволяет указать, что значение может быть одного из нескольких типов.

    from typing import Union
    from pydantic import BaseModel

    class MixedFieldModel(BaseModel):
        value: Union[int, str]

    m1 = MixedFieldModel(value=42)  # OK
    m2 = MixedFieldModel(value="42")  # OK
    m3 = MixedFieldModel(value=4.2)  # Ошибка

### Literal

`Literal` позволяет ограничить поле конкретными значениями.

    from typing import Literal

    class PaymentMethod(BaseModel):
        method: Literal["cash", "card"]

    p1 = PaymentMethod(method="cash")  # OK
    p2 = PaymentMethod(method="crypto")  # Ошибка

## Типизация для параметров пути, запросов, заголовков

FastAPI позволяет аннотировать параметры для пути, query, headers — всё это тоже подлежит валидации.

    from fastapi import FastAPI, Path, Query

    app = FastAPI()

    @app.get("/items/{item_id}")
    def get_item(
        item_id: int = Path(..., ge=1),
        search: str = Query("default", min_length=3)
    ):
        return {"item_id": item_id, "search": search}

- `item_id: int` — строго целое число.

- `search: str` — строка с минимальной длиной 3.
