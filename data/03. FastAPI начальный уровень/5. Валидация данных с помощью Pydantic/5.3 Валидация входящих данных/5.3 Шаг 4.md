## Кастомные валидаторы

Pydantic предлагает **@validator** для написания пользовательских проверок:

    from pydantic import BaseModel, validator

    class UserCreate(BaseModel):
        username: str
        email: str

        @validator('email')
        def check_email(cls, value):
            if "@" not in value:
                raise ValueError("Invalid email")
            return value

Если поле `email` не содержит `@`, будет выброшено исключение `ValueError`, которое превратится в ошибку валидации на уровне API.

## Сложная валидация (Regex, Enum, DateTime)

Pydantic и FastAPI позволяют использовать более сложные типы и ограничения:

- **regex** (регулярные выражения):

    from fastapi import Body
    from pydantic importBaseModel, constr

        class PhoneModel(BaseModel):
        phone: constr(regex=r'^\\+?\\d{7,15}$')  # от 7 до 15 цифр, опциональный +

    @app.post("/phones")
    def create_phone(data: PhoneModel):
        return data

- **Enum**: создайте перечисление для ограничения набора значений.

- **DateTime** (datetime, date, time): позволяет проверять формат даты и времени.

## Обработка ошибок валидации

Если данные не проходят проверку, FastAPI возвращает код **422** (Unprocessable Entity) и тело ответа с деталями:

    {
      "detail": [
        {
          "loc": ["body", "phone"],
          "msg": "string does not match regex \"^\\\\+?\\\\d{7,15}$\"",
          "type": "value_error.str.regex"
        }
      ]
    }

Это даёт клиенту точную информацию о том, что пошло не так.
