## Использование Path, Query и Body для валидации

**Path**- и **Query**-параметры также поддерживают валидацию:

    from fastapi import FastAPI, Path, Query

    app = FastAPI()

    @app.get("/items/{item_id}")
    def get_item(
        item_id: int = Path(..., ge=1, le=9999),
        q: str = Query(None, min_length=3, max_length=50)
    ):
        return {"item_id": item_id, "q": q}

- `ge`, `le` — ограничение «больше или равно», «меньше или равно» для `item_id`.

- `min_length`, `max_length` — проверка длины строки `q`.

Если пользователь передаст `item_id=0` или `item_id=12345`, FastAPI вернёт ошибку валидации.
