## Базовая валидация с помощью моделей Pydantic

Наиболее распространённый способ валидации — использование **моделей Pydantic**. Когда вы принимаете данные в теле запроса через объект-модель, FastAPI автоматически проверяет:

- Типы полей (числа, строки, списки, и т.д.)

- Обязательные поля

- Формат JSON

### Пример

    from fastapi import FastAPI
    from pydantic import BaseModel

    app = FastAPI()

    class UserCreate(BaseModel):
        username: str
        password: str

    @app.post("/users")
    def create_user(user: UserCreate):
        return {"msg": "User received", "user": user}

При получении запроса FastAPI:

- Автоматически прочитает JSON из тела.

- Попробует преобразовать данные в `UserCreate`.

- Вернёт ошибку **422 Unprocessable Entity**, если данные не соответствуют ожидаемому формату.

    {
      "detail": [
        {
          "loc": ["body", "username"],
          "msg": "field required",
          "type": "value_error.missing"
        }
      ]
    }
