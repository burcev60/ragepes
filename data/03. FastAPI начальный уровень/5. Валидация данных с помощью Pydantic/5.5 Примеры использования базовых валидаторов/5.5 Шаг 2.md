## Пример: проверка длины строки

Часто нужно ограничить длину строки. Допустим, нужно сделать так, чтобы поле `username` было длиной от 3 до 10 символов.

    from pydantic import BaseModel, validator

    class User(BaseModel):
        username: str

        @validator('username')
        def username_length(cls, value):
            if not (3 <= len(value) <= 10):
                raise ValueError("Username length must be between 3 and 10")
            return value

    # Примеры
    user1 = User(username="Bob")          # OK, длина 3
    user2 = User(username="B")            # Ошибка: слишком коротко
    user3 = User(username="SuperBobCat")  # Ошибка: слишком длинно

**Когда условие не выполняется**, Pydantic автоматически генерирует ошибку валидации. Пример ответа при работе с FastAPI:

    {
      "detail": [
        {
          "loc": ["body", "username"],
          "msg": "Username length must be between 3 and 10",
          "type": "value_error"
        }
      ]
    }
