## Пример: валидация нескольких полей сразу (always=True)

Бывает, что нужно сравнивать поля между собой. Например, проверить, что `password` и `password_confirm` совпадают.

    class PasswordCheck(BaseModel):
        password: str
        password_confirm: str

        @validator("password_confirm", always=True)
        def check_passwords_match(cls, v, values):
            # v - значение поля "password_confirm"
            # values - словарь с другими полями (уже провалидированными)
            if 'password' in values and v != values['password']:
                raise ValueError("Passwords do not match")
            return v

    p = PasswordCheck(password="1234", password_confirm="1234")  # OK
    p = PasswordCheck(password="1234", password_confirm="4321")  # Ошибка

**Особенности:**

- `always=True` означает, что валидатор будет вызываться всегда, даже если `password_confirm` не предоставлено.

- `values` хранит поля, прошедшие валидацию или имеющие значения по умолчанию.
