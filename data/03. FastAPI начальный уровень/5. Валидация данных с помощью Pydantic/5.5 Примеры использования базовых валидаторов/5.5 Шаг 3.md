## Пример: проверка числового диапазона

Допустим, мы хотим гарантировать, что возраст (поле `age`) находится в диапазоне от 0 до 120.

    class Person(BaseModel):
        name: str
        age: int

        @validator('age')
        def valid_age(cls, value):
            if value < 0 or value > 120:
                raise ValueError("Age must be between 0 and 120")
            return value

    # Примеры
    p1 = Person(name="Alice", age=25)   # OK
    p2 = Person(name="Bob", age=-1)     # Ошибка: отрицательный возраст
    p3 = Person(name="Clark", age=150)  # Ошибка: слишком большой возраст

**Обратите внимание:**

- При возникновении ошибки FastAPI вернёт HTTP 422, а при чистом использовании Pydantic в Python будет выброшено исключение `ValidationError`.
