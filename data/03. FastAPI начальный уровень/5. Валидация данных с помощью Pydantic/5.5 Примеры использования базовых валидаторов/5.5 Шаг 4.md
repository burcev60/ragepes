## Пример: проверка email-адреса

В приложениях часто нужно убедиться, что строка действительно выглядит как email. В Pydantic есть встроенный тип `EmailStr`, который автоматически проверяет формат.

### 4.1 Использование `EmailStr`

    from pydantic import BaseModel, EmailStr

    class UserContact(BaseModel):
        email: EmailStr

    user = UserContact(email="admin@example.com")  # OK
    user = UserContact(email="not-an-email")       # Ошибка

Если `email` не соответствует формату, получим ошибку:

    {
      "detail": [
        {
          "loc": ["body", "email"],
          "msg": "value is not a valid email address",
          "type": "value_error.email"
        }
      ]
    }

### 4.2 Собственный валидатор email

Если хотите более гибкую проверку (например, поддерживать особые домены), можно написать валидатор вручную:

    from pydantic import BaseModel, validator

    class UserContact2(BaseModel):
        email: str

        @validator('email')
        def check_email(cls, value):
            if "@" not in value:
                raise ValueError("Not a valid email")
            # Дополнительная логика проверки...
            return value
