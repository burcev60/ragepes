## Возвращение изменённого значения

Иногда нужно не только проверить, но и изменить входные данные, например, приводить строки к нужному формату.

    class Category(BaseModel):
        name: str

        @validator('name')
        def lowercase_name(cls, v):
            # Превращаем название в нижний регистр
            return v.lower()

    cat = Category(name="BOOKS")
    print(cat.name)  # "books"

Это удобно, если вы хотите унифицировать регистр всех строк или обработать пробелы.

## Использование `root_validator` для нескольких полей

`root_validator` даёт возможность проверять корректность набора полей целиком. Например, мы хотим, чтобы общее кол-во `quantity * price` было разумным.

    from pydantic import BaseModel, root_validator

    class Order(BaseModel):
        item: str
        quantity: int
        price: float

        @root_validator
        def check_total_price(cls, values):
            qty = values.get('quantity')
            prc = values.get('price')

            if qty <= 0:
                raise ValueError("Quantity must be positive")
            if prc <= 0:
                raise ValueError("Price must be positive")

            total = qty * prc
            if total > 100000:
                raise ValueError("Order total is too large")

            # Возвращаем весь словарь, иначе данные "пропадут"
            return values

**Пояснения:**

- Внутри `root_validator` вы имеете доступ ко всем полям сразу.

- Возвращать нужно объект `values` целиком, так как это итоговый результат валидации.

## Резюме

Валидаторы в Pydantic — гибкий и мощный инструмент, с помощью которого можно:

1. **Проверять** отдельные поля на диапазоны значений, соответствие форматам, длину строки и т.д.

2. **Сравнивать** несколько полей между собой (например, пароли).

3. **Автоматически изменять** входные данные (к примеру, переводить в нижний регистр).

4. **Валидировать** весь объект целиком с помощью `root_validator`.

В результате получаете чистые, предсказуемые данные в своём приложении, а также упрощённую и более безопасную логику обработки. При возникновении ошибок Pydantic генерирует исключения, которые в связке с FastAPI автоматически превращаются в понятные ответы для клиента.
