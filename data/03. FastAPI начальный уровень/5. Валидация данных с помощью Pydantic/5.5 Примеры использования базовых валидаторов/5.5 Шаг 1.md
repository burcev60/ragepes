### Примеры использования базовых валидаторов Pydantic (Расширенная версия)

В Pydantic валидаторы позволяют проверять и преобразовывать входящие данные до или после основной обработки. Это мощный инструмент, упрощающий контроль над значениями и повышающий надёжность вашего приложения.

## 1. Общая структура валидаторов

    from pydantic import BaseModel, validator

    class MyModel(BaseModel):
        field: str

        @validator('field')
        def validate_field(cls, value):
            # Проверка значения
            # Если всё хорошо, вернуть value
            # Если нужно выбросить ошибку:
            #   raise ValueError("Сообщение об ошибке")
            return value

**Ключевые моменты:**

1. `@validator('field')` указывает, что метод `validate_field` обрабатывает поле `field`.

2. `cls` — ссылка на класс (в примере это `MyModel`).

3. `value` — значение, которое пришло для поля `field`.

4. Если значение корректно, метод должен вернуть `value` (или модифицированную версию). Если нужно отклонить данные, выбросьте `ValueError` или `TypeError`.

Таким образом, вы можете выполнять дополнительные проверки, изменять формат строки, проверять диапазоны чисел и многое другое.
