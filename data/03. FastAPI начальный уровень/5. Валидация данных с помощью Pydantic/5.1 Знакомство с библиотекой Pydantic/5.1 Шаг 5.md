### Работа с вложенными моделями

**Описание:**  
Понимание использования вложенных моделей в Pydantic.

1. Создайте модель `Address` с полями:

  - `city` (строка)

  - `zipcode` (строка)

2. Создайте модель `Person`, включающую поля:

  - `name` (строка)

  - `address` (объект типа `Address`)

3. Маршрут `/person` принимает объект типа `Person` через тело POST-запроса и возвращает данные.

**Пример запроса:**  
POST `/person`

     

`{ "name": "John", "address": { "city": "New York", "zipcode": "10001" } } `

**Пример ответа:**

     

`{ "name": "John", "address": { "city": "New York", "zipcode": "10001" } }`
