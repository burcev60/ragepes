## Создание первой модели

Создадим простейшую модель данных:

    from pydantic import BaseModel

    class User(BaseModel):
        id: int
        name: str
        email: str

Здесь:

- `BaseModel` — основной класс для создания моделей Pydantic.

- Аннотации типов (`id: int`, `name: str`) указывают типы полей, которые будут автоматически проверяться.

## Валидация данных

Создадим экземпляр модели, чтобы проверить работу Pydantic:

    user = User(id=1, name="John Doe", email="john@example.com")
    print(user)

Если данные переданы корректно, вы получите объект User:

    id=1 name='John Doe' email='john@example.com'

Попробуем передать некорректные данные:

    user = User(id="not-an-int", name="John Doe", email="john@example.com")

Pydantic автоматически выдаст ошибку валидации:

    pydantic.error_wrappers.ValidationError: 1 validation error for User
    id
      value is not a valid integer (type=type_error.integer)
