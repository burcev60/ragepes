## Встроенные типы и возможности валидации

Pydantic поддерживает множество встроенных типов:

- Базовые типы (`int`, `str`, `float`, `bool`)

- Дата и время (`datetime`, `date`, `time`)

- Сложные типы (`List`, `Dict`, `Union`, `Optional`)

Пример:

    from typing import List, Optional
    from pydantic import BaseModel

    class Item(BaseModel):
        name: str
        description: Optional[str] = None
        price: float
        tags: List[str]

    item = Item(name="Book", price=12.99, tags=["education", "literature"])
    print(item)

## Работа с вложенными моделями

Модели могут содержать вложенные структуры:

    class Address(BaseModel):
        street: str
        city: str

    class User(BaseModel):
        id: int
        name: str
        address: Address

    user = User(
        id=1,
        name="John Doe",
        address={"street": "Main Street", "city": "New York"}
    )

    print(user)

## Дополнительные возможности

### Значения по умолчанию

Можно задавать значения по умолчанию:

    class User(BaseModel):
        name: str
        age: Optional[int] = None

    user = User(name="John")
    print(user)

### Пользовательские методы валидации

Pydantic позволяет задавать собственные правила валидации:

    from pydantic import validator

    class User(BaseModel):
        name: str
        age: int

        @validator('age')
        def check_age(cls, v):
            if v < 0:
                raise ValueError('Age cannot be negative')
            return v

## Сериализация и десериализация

Модели Pydantic легко преобразуются в словари или JSON:

    user = User(name="Alice", age=30)
    print(user.json())  # JSON-строка

Обратная операция (десериализация):

    user_dict = {"name": "Alice", "age": 25}
    user = User(**user_dict)

## Использование Pydantic в FastAPI

В FastAPI модели Pydantic используются для описания входных и выходных данных в маршрутах:

    @app.post("/users")
    def create_user(user: User):
        return user

FastAPI автоматически проверяет входные данные запроса и генерирует документацию.
