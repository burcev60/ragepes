## Кастомизация ошибок валидации

Часто стандартного формата ошибок (422) достаточно, но иногда нужно возвращать более специфическую структуру или текст. Для этого можно:

1. **Обработать исключение** `RequestValidationError`, которое бросается при ошибках валидации.

2. Использовать специальный декоратор для обработки ошибок:

    from fastapi import FastAPI, Request
    from fastapi.responses import JSONResponse
    from fastapi.exceptions import RequestValidationError
    from starlette.status import HTTP_422_UNPROCESSABLE_ENTITY

    app = FastAPI()

    @app.exception_handler(RequestValidationError)
    async def validation_exception_handler(request: Request, exc: RequestValidationError):
        # Здесь можно сконструировать свой ответ
        return JSONResponse(
            status_code=HTTP_422_UNPROCESSABLE_ENTITY,
            content={
                "error": "Validation Failed",
                "details": exc.errors()
            },
        )

- `exc.errors()` возвращает список детальных ошибок, аналогичных тому, что вы обычно получаете по умолчанию.

- `RequestValidationError` — исключение, выкидываемое при неудачной валидации.
