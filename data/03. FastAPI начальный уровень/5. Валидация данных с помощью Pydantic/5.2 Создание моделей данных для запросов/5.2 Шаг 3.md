## Использование типов и дополнительных возможностей Pydantic

Pydantic предоставляет мощные средства описания и проверки данных:

### 3.1 Дополнительные типы

- **Optional** (из `typing`) — указывает, что поле может отсутствовать.

- **List, Dict, Set, Tuple** — для коллекций.

- **Enum** — для перечислений фиксированных значений.

- **Datetime** и другие типы для дат.

    from typing import Optional, List
    from pydantic import BaseModel

    class UserCreate(BaseModel):
        name: str
        age: Optional[int] = None  # возраст может отсутствовать
        tags: List[str] = []       # список интересов

### 3.2 Валидаторы

С помощью декораторов `@validator` можно добавлять собственные проверки:

    from pydantic import BaseModel, validator

    class UserCreate(BaseModel):
        name: str
        email: str

        @validator('email')
        def validate_email(cls, v):
            if "@" not in v:
                raise ValueError("Invalid email")
            return v

Если email не будет содержать символ `@`, Pydantic вернёт ошибку валидации.
