### Модель для создания товара

**Описание:**  
Использование сложных моделей для передачи данных о товаре.

1. Определите модель `CreateItem` с полями:

  - `title` (строка)

  - `description` (строка)

  - `price` (число)

2. Маршрут `/item` принимает объект типа `CreateItem` через POST и возвращает созданный товар.

**Пример запроса:**  
POST `/item`

`{ "title": "Smartphone", "description": "High-quality smartphone", "price": 299.99 } `

**Пример ответа:**

`{ "title": "Smartphone", "description": "High-quality smartphone", "price": 299.99 } `
