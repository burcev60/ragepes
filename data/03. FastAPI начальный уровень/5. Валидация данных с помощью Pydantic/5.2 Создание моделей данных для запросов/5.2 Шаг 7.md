## **Создание моделей данных для запросов**

### Задача 1: Модель для регистрации пользователя

**Описание:**  
Создайте модель данных для регистрации пользователя.

1. Определите модель `RegisterUser` с полями:

  - `username` (строка, обязательное)

  - `password` (строка, обязательное)

2. Маршрут `/register` принимает объект типа `RegisterUser` через тело POST-запроса.

3. Верните сообщение об успешной регистрации.

**Пример запроса:**  
POST `/register`

`{ "username": "user1", "password": "securepassword" } `

**Пример ответа:**

`{ "message": "User registered successfully" } `
