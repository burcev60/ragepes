## Вложенные модели

Иногда нужно описывать более сложные структуры. Например, у пользователя может быть адрес (улица, город, индекс), и мы хотим принимать всё это сразу.

    class Address(BaseModel):
        street: str
        city: str
        postal_code: str

    class UserCreate(BaseModel):
        name: str
        email: str
        address: Address  # Вложенная модель

При запросе к `/users` мы можем отправлять тело:

    {
      "name": "Bob",
      "email": "bob@example.com",
      "address": {
        "street": "Main St.",
        "city": "Boston",
        "postal_code": "02115"
      }
    }

Pydantic будет валидировать не только поля пользователя, но и структуру адреса.
