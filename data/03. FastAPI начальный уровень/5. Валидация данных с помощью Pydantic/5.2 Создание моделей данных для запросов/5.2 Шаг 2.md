## Базовый пример модели для запроса

Предположим, мы хотим принимать данные для создания нового пользователя (имя, возраст, email). Для этого:

    from fastapi import FastAPI
    from pydantic import BaseModel

    app = FastAPI()

    class UserCreate(BaseModel):
        name: str
        age: int
        email: str

    @app.post("/users")
    def create_user(user: UserCreate):
        # Здесь мы можем сохранить нового пользователя в БД
        return {"success": True, "user": user}

### Разбор кода:

- **UserCreate** — модель, наследованная от `BaseModel` Pydantic.

- Поля `name`, `age`, `email` описывают структуру данных, которую клиент должен отправить.

- **create_user** — маршрут, который получает объект `UserCreate` как аргумент.

При вызове `/users` с телом запроса

    {
      "name": "Alice",
      "age": 30,
      "email": "alice@example.com"
    }

сервер проведёт автоматическую валидацию и, если всё корректно, передаст обработчику объект `user` со всеми данными.
