#### Вложенные зависимости

Зависимости могут сами пользоваться другими зависимостями. Например:

    from fastapi import FastAPI, Depends

    app = FastAPI()

    def dep_a():
        return "A"

    def dep_b(a_value: str = Depends(dep_a)):
        return f"B + {a_value}"

    @app.get("/nested")
    def nested_example(b_value: str = Depends(dep_b)):
        return {"message": b_value}

FastAPI проанализирует, что `dep_b` зависит от `dep_a`, сначала вызовет `dep_a`, а затем подставит результат в `dep_b`.

#### 7. Дополнительные возможности

##### 7.1. Передача `Request` в зависимость

В случае, когда необходимо напрямую работать с объектом `Request`, например для чтения тела запроса или мидлварной логики, вы можете указать `Request` в качестве параметра:

    from fastapi import FastAPI, Depends, Request

    app = FastAPI()

    def read_request_info(request: Request):
        client_host = request.client.host
        user_agent = request.headers.get("User-Agent")
        return {
            "host": client_host,
            "user_agent": user_agent
        }

    @app.get("/info")
    def get_info(info: dict = Depends(read_request_info)):
        return {"info": info}

##### 7.2. Контекстные зависимости с `yield`

Иногда важно «закрыть» ресурс после использования: закрыть соединение с БД, освободить файлы и т.д. Для этого в зависимости используется `yield`.

    from fastapi import FastAPI, Depends

    app = FastAPI()

    def get_db():
        db = create_db_session()
        try:
            yield db
        finally:
            db.close()

    @app.get("/items")
    def read_items(db_session = Depends(get_db)):
        items = db_session.query(Item).all()
        return {"items": items}

Когда запрос завершён, управление вернётся в блок `finally`, и вы сможете корректно освободить ресурс.

##### 7.3. Классы как зависимости

Помимо функций, в FastAPI можно передавать целые классы. Например, если у вас есть сервис, инкапсулирующий бизнес-логику:

    class MyService:
        def __init__(self, prefix: str):
            self.prefix = prefix

        def process(self, data: str) -> str:
            return f"{self.prefix}: {data}"

    def get_service():
        # Можно делать инициализацию, чтение настроек и т.д.
        return MyService(prefix="Service")

    @app.get("/use_service")
    def use_service(service: MyService = Depends(get_service)):
        return service.process("some data")

##### 7.4. Переопределение зависимостей в тестах

Для тестирования можно использовать `app.dependency_overrides`. Это позволяет подменить реальную зависимость тестовой или мок-зависимостью:

    from fastapi.testclient import TestClient

    # Предположим, есть реальная зависимость:

    def get_token():
        return "real-token"

    app = FastAPI()

    @app.get("/token")
    def read_token(token: str = Depends(get_token)):
        return {"token": token}

    # В тесте переопределяем:

    def test_read_token():
        def fake_token():
            return "fake-token"

        app.dependency_overrides[get_token] = fake_token

        client = TestClient(app)
        response = client.get("/token")
        assert response.json() == {"token": "fake-token"}

        app.dependency_overrides.clear()  # важно очищать после теста

Так вы можете тестировать логику своих обработчиков, не завися от реальных внешних сервисов или данных.

#### 8. Основные преимущества простых зависимостей:

1. **Повторное использование**: Единожды написав функцию-зависимость, можно вызывать её во множестве обработчиков.

2. **Удобство тестирования**: В тестах можно переопределять зависимость или мокать её. Это значительно упрощает написание юнит-тестов.

3. **Ясная структура**: Когда у каждого эндпоинта есть список зависимостей, из кода чётко видно, какие данные нужны для корректной работы.

4. **Валидация входных данных**: Зависимости могут включать валидацию параметров, что упрощает отладку и повысит надёжность.

5. **Управление жизненным циклом ресурсов**: Благодаря `yield` можно аккуратно освобождать или закрывать внешние ресурсы (подключения к БД, файлы и т.д.).
