#### Синхронные и асинхронные зависимости

FastAPI поддерживает и синхронные (обычные) функции, и асинхронные (async) функции в качестве зависимостей. Если зависимость работает с асинхронными операциями (например, с async драйвером БД), указывайте `async def`:

    async def async_dependency(x: int) -> str:
        # Здесь может быть асинхронная логика
        # await some_async_task()
        return f"Результат: {x}"

    @app.get("/async_example")
    async def async_example(result: str = Depends(async_dependency)):
        return {"message": result}

#### 5. Пример с дополнительной логикой

Допустим, у нас есть зависимость, которая:

- Читает заголовок `X-Token`,

- Валидирует его,

- Возвращает либо информацию о пользователе, либо выбрасывает ошибку.

    from fastapi import FastAPI, Depends, Header, HTTPException

    app = FastAPI()

    async def get_current_user(x_token: str = Header(...)):
        # Допустим, мы ждём, что x_token должен быть равен "mysecrettoken"
        if x_token != "mysecrettoken":
            raise HTTPException(status_code=401, detail="Неверный токен")
        return {"username": "user1"}

    @app.get("/profile")
    async def read_profile(user: dict = Depends(get_current_user)):
        return {"user_profile": user}
