### Создание простых зависимостей в FastAPI

Инъекция зависимостей в FastAPI позволяет передавать общие параметры и объекты в различные части приложения без необходимости вручную создавать их в каждом обработчике. Простые зависимости — это функции, которые могут принимать параметры и возвращать значения для использования в конечных точках (endpoints).

#### 1. Что такое простые зависимости

Простая зависимость — это обычно синхронная или асинхронная функция, которая может:

- Принимать параметры запроса (Query, Path, Body и т.д.),

- Выполнять какую-то подготовительную логику (например, проверка данных, получение информации из БД),

- Возвращать результат, который нужен конечному обработчику.

Вместо того, чтобы копировать и вставлять один и тот же код в нескольких местах, мы пишем функцию-зависимость один раз и подключаем её к различным обработчикам через специальный объект `Depends`.

#### 2. Базовый синтаксис

    from fastapi import FastAPI, Depends

    app = FastAPI()

    def dependency_function():
        # Здесь любая нужная логика
        return "Значение из зависимости"

    @app.get("/")
    def root(value: str = Depends(dependency_function)):
        return {"message": value}

- `dependency_function` — это наша простая зависимость. Когда в конечном обработчике мы пишем `Depends(dependency_function)`, FastAPI понимает, что перед тем, как вызвать `root`, нужно вызвать `dependency_function` и передать результат в параметр `value`.

#### 3. Передача параметров в зависимость

Часто зависимость принимает параметры запроса (Query, Path, Body, Cookie, Header и т.д.) или дополнительные опции. Например, мы можем использовать типизацию и аргументы FastAPI:

    from fastapi import FastAPI, Depends, Query

    app = FastAPI()

    def greeting(name: str = Query("Гость", min_length=1, max_length=50)):
        return f"Привет, {name}!"

    @app.get("/hello")
    def say_hello(greet: str = Depends(greeting)):
        return {"message": greet}

Здесь:

- `greeting` — функция-зависимость, которая использует параметр `name` из `Query`.

- `say_hello` принимает аргумент `greet`, полученный с помощью `Depends(greeting)`.

- При запросе `GET /hello?name=Алексей` функция `greeting` вернёт `"Привет, Алексей!"`, и этот текст попадёт в `greet`.
