#### Зависимости на уровне всего приложения

Аналогичным образом можно объявить зависимости для всего приложения:

    from fastapi import FastAPI, Depends

    app = FastAPI(dependencies=[Depends(check_auth)])

    @app.get("/")
    def root():
        return {"message": "Root"}

    @app.get("/hello")
    def hello():
        return {"message": "Hello World"}

Теперь **любой** маршрут в приложении будет проходить через `check_auth`. Это полезно, если у вас есть глобальная логика (например, логгирование или универсальная аутентификация), которую нужно применить ко всем запросам.

#### 4. Передача различных зависимостей в один маршрут

Вы можете комбинировать несколько зависимостей в одном методе:

    from fastapi import FastAPI, Depends

    app = FastAPI()

    def dependency_a():
        return "A"

    def dependency_b():
        return "B"

    @app.get("/combo")
    def combo_endpoint(
        dep_a: str = Depends(dependency_a),
        dep_b: str = Depends(dependency_b),
    ):
        return {"result": f"{dep_a} + {dep_b}"}

FastAPI вызовет `dependency_a`, `dependency_b`, а затем передаст их результаты в `combo_endpoint`.

#### 5. Вложенные и комбинированные зависимости

Зависимости могут зависеть друг от друга (вложенные зависимости). Пример:

    def dep_c():
        return "C"

    def dep_b(c_value: str = Depends(dep_c)):
        return f"B -> {c_value}"

    def dep_a(b_value: str = Depends(dep_b)):
        return f"A -> {b_value}"

    @app.get("/nested")
    def nested(a_value: str = Depends(dep_a)):
        return {"message": a_value}

- `dep_a` зависит от `dep_b`, `dep_b` зависит от `dep_c`. FastAPI сам разрулит порядок их вызова.
