### Применение зависимостей в маршрутах в FastAPI

Когда мы говорим о «применении зависимостей», мы имеем в виду способ подключения готовых функций-зависимостей к маршрутам (endpoints), чтобы упростить повторное использование кода и обеспечить более организованную архитектуру.

#### 1. Объявление зависимостей через параметры функции

Самый прямой и очевидный способ — это указать `Depends(...)` в сигнатуре функции-обработчика.

    from fastapi import FastAPI, Depends

    app = FastAPI()

    def simple_dependency() -> str:
        return "Some data"

    @app.get("/items")
    def read_items(data: str = Depends(simple_dependency)):
        return {"data": data}

- При каждом запросе к `/items`, FastAPI вызывает `simple_dependency`, а её результат передаётся в параметр `data` функции `read_items`.

- Вы можете объявить несколько зависимостей, просто добавив больше параметров с `Depends(...)`.

#### 2. Зависимости, объявленные на уровне `APIRouter`

В FastAPI можно группировать маршруты (endpoints) в отдельный `APIRouter` и объявлять зависимости для всех маршрутов сразу. Например:

    from fastapi import APIRouter, Depends

    router = APIRouter(
        prefix="/users",
        dependencies=[Depends(some_common_dependency)],
    )

    @router.get("/")
    def read_users():
        # Этот маршрут автоматически использует some_common_dependency
        return {"result": "All users"}

    @router.get("/{user_id}")
    def read_user(user_id: int):
        return {"result": f"User {user_id}"}

- Здесь `dependencies=[Depends(some_common_dependency)]` говорит FastAPI, что каждый маршрут внутри `router` будет использовать заданную зависимость.

- Если у вас есть много эндпоинтов, которым нужна одна и та же зависимость (например, проверка токена, подключение к БД), это удобно, чтобы не повторять `Depends(...)` в каждом методе.
