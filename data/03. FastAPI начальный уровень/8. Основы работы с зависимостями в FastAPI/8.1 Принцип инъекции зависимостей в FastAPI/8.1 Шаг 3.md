## Обработка контекста (пример с БД)

Один из самых популярных кейсов — это работа с базой данных (session). Обычно нужно:

1. Открыть соединение (или создать сессию).

2. Выполнить запросы.

3. Закрыть/освободить ресурсы.

В FastAPI это можно сделать через зависимость, которая создаёт и отдаёт сессию, а затем при завершении запроса корректно «опускает» соединение. Пример с SQLAlchemy:

    from fastapi import FastAPI, Depends
    from sqlalchemy.orm import Session
    from .database import SessionLocal  # предположим, что это ваш локальный синглтон сессии

    app = FastAPI()

    def get_db():
        db = SessionLocal()  # создаём сессию
        try:
            yield db  # возвращаем сессию на время запроса
        finally:
            db.close()  # по окончании запроса закрываем сессию

    @app.get("/users")
    def get_users(db: Session = Depends(get_db)):
        return db.query(User).all()

- При каждом запросе FastAPI вызовет `get_db()`, создаст сессию и вернёт её (через оператор `yield`).

- Когда запрос обработается, управление вернётся обратно к `get_db()`, и сессия будет закрыта в блоке `finally`.

- Таким образом, обработчик (endpoint) получает уже готовую сессию: он не знает и не «заботится», откуда она взялась.

## 4. Сложные зависимости и вложенные зависимости

В FastAPI можно «встраивать» одну зависимость в другую. Например, одна зависимость может использовать в качестве параметра другую зависимость, и FastAPI корректно всё разрешит:

    from fastapi import FastAPI, Depends

    app = FastAPI()

    def dependency_a():
        return "A"

    def dependency_b(a_value: str = Depends(dependency_a)):
        return f"B + {a_value}"

    @app.get("/")
    def root(b_value: str = Depends(dependency_b)):
        return {"message": b_value}

Алгоритм такой:

1. FastAPI видит, что для вызова `root` нужен `b_value = Depends(dependency_b)`.

2. Для `dependency_b`, в свою очередь, нужен `a_value = Depends(dependency_a)`.

3. Сначала вызывается `dependency_a`, результат передаётся в `dependency_b`.

4. Результат `dependency_b` идёт в `root`.

Так можно строить целые «деревья» зависимостей, что упрощает многократное использование кода и организацию сложной логики.
