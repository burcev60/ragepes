## Пример с аутентификацией / авторизацией

Допустим, вам нужно проверять JWT-токен в заголовках. Вы можете сделать отдельную зависимость, которая:

1. Извлекает заголовок `Authorization`.

2. Валидирует и декодирует JWT.

3. Возвращает объект пользователя или выбрасывает ошибку `HTTPException` при отсутствии/некорректности токена.

Примерно так:

    from fastapi import FastAPI, Depends, HTTPException, status
    from fastapi.security import OAuth2PasswordBearer

    oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")
    app = FastAPI()

    def get_current_user(token: str = Depends(oauth2_scheme)):
        # В реальном мире: проверить валидность токена,
        # вытащить user_id, достать юзера из БД и т.д.
        # Если токен некорректен, кидаем ошибку
        if token != "secret-token":
            raise HTTPException(
                status_code=status.HTTP_401_UNAUTHORIZED,
                detail="Invalid authentication credentials",
            )
        return {"username": "testuser"}

    @app.get("/profile")
    def read_profile(current_user: dict = Depends(get_current_user)):
        return {"profile_data": f"Private data for {current_user['username']}"}

 

- `OAuth2PasswordBearer(tokenUrl="token")` — стандартная схема FastAPI, которая автоматически вытащит токен из заголовка «Authorization: Bearer ...».

- В `get_current_user` мы уже работаем с самим токеном, проверяем его, и если всё ок — возвращаем информацию о пользователе.

- В итоге, в обработчике `read_profile` мы напрямую работаем с «текущим пользователем», не думая о том, откуда он взялся.
