## Классовые зависимости

Если вы хотите упаковать логику в класс (допустим, у вас есть сервис, который должен уметь делать несколько вещей), вы можете объявить класс и использовать инъекцию зависимостей, обращаясь к методам класса:

    from fastapi import FastAPI, Depends

    app = FastAPI()

    class SomeService:
        def __init__(self, prefix: str):
            self.prefix = prefix
  
        def do_something(self, value: str) -> str:
            return f"{self.prefix} - {value}"

    def get_service():
        # Возможно, здесь более сложная инициализация
        return SomeService(prefix="ServicePrefix")

    @app.get("/")
    def root(value: str, service: SomeService = Depends(get_service)):
        return {"result": service.do_something(value)}

- Класс `SomeService` описывает какую-то бизнес-логику.

- В `get_service()` мы можем создавать экземпляр класса (или возвращать готовый) и внедрять его в endpoint.

- Сам endpoint (`root`) просто вызывает нужный метод — то есть не беспокоится о том, как создаётся `SomeService`или где берётся `prefix`.
