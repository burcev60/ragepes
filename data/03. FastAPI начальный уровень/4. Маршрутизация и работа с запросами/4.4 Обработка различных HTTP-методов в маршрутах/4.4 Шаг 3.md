## GET-запросы: работа с Path и Query parameters

**GET**-запросы традиционно используют Path и Query-параметры для передачи данных.

    @app.get("/users/{user_id}")
    def read_user(user_id: int, detail: bool = False):
        if detail:
            return {"user_id": user_id, "info": "Detailed user data"}
        return {"user_id": user_id}

- `user_id` берётся из **Path** (часть URL), например `/users/5`.

- `detail` передаётся как **Query**-параметр, например `/users/5?detail=true`.

- GET-запрос не имеет тела, а все данные передаются через URL.

## POST-запросы: создание новых ресурсов

**POST**-запрос чаще всего сопровождается передачей данных в теле запроса (body). FastAPI позволяет автоматически преобразовывать JSON в модель Pydantic или словарь.

    from pydantic import BaseModel

    class Item(BaseModel):
        name: str
        price: float

    @app.post("/items")
    def create_item(item: Item):
        # Здесь мы имеем доступ к полям через item.name, item.price
        return {"status": "Item created", "data": item}

Если клиент отправляет POST на `/items` с JSON телом:

    {
      "name": "Laptop",
      "price": 999.99
    }

Сервер возвращает подтверждение, что ресурс создан. Если поля не соответствуют типам (например, `price` — строка "abc"), FastAPI автоматически вернёт ошибку валидации.

## PUT и PATCH: полное и частичное обновление

### PUT (полное обновление)

**PUT** предполагает, что вы присылаете все поля объекта целиком. Пример:

    @app.put("/items/{item_id}")
    def update_item(item_id: int, item: Item):
        return {
            "status": "Item fully updated",
            "item_id": item_id,
            "updated_data": item
        }

Если объект имел поля `name` и `price`, а клиент не передал одно из них, обычно считается, что значение обнуляется или становится пустым — в зависимости от логики.

### PATCH (частичное обновление)

**PATCH** даёт возможность изменить только некоторые поля объекта. Например:

    from typing import Optional

    class PartialItem(BaseModel):
        name: Optional[str]
        price: Optional[float]

    @app.patch("/items/{item_id}")
    def partial_update_item(item_id: int, item_data: PartialItem):
        return {
            "status": "Item partially updated",
            "item_id": item_id,
            "updated_fields": item_data
        }

Если клиент хочет изменить только `price`, он может отправить JSON:

    {
      "price": 899.99
    }

Тогда `name` не будет затронуто. Это упрощает работу, если нужно менять лишь часть полей.

## DELETE: удаление ресурсов

**DELETE** обычно используется, чтобы удалить ресурс по его ID:

    @app.delete("/items/{item_id}")
    def delete_item(item_id: int):
        return {"status": "Item deleted", "item_id": item_id}

Клиент отправляет DELETE-запрос по адресу `/items/10`, а сервер выполняет логику удаления (например, удаляет запись из базы данных) и отвечает сообщением.
