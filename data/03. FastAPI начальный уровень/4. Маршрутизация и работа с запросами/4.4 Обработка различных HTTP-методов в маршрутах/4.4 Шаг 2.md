## Как FastAPI обрабатывает методы?

В FastAPI для каждого метода есть отдельный декоратор:

- `@app.get("/...")`

- `@app.post("/...")`

- `@app.put("/...")`

- `@app.patch("/...")`

- `@app.delete("/...")`

Каждый из них регистрирует маршрут и «привязывает» его к соответствующему методу. Если мы используем `@app.get`, то обработчик вызовется только при GET-запросе.

### Пример: один маршрут – несколько методов

    from fastapi import FastAPI

    app = FastAPI()

    @app.get("/items")
    def get_items():
        return {"status": "All items returned"}

    @app.post("/items")
    def create_item(item: dict):
        return {"status": "Item created", "item": item}

- При отправке GET-запроса на `/items` функция `get_items()` вернёт список или сообщение.

- При отправке POST-запроса на `/items` с телом (JSON), функция `create_item()` создаст новый элемент.
