## Обязательные и необязательные параметры, использование типа Optional

Query-параметры в FastAPI могут быть как **обязательными**, так и **необязательными**. Обязательные параметры требуют, чтобы клиент в каждом запросе передавал соответствующее значение, иначе будет сгенерирована ошибка (422 Unprocessable Entity), указывающая на то, что необходимые данные не переданы.

### Обязательные параметры

Если не указать значение по умолчанию (или использовать `...` из модуля `Query`), параметр будет расцениваться как обязательный. Например:

    from fastapi import FastAPI, Query

    app = FastAPI()

    @app.get("/search")
    def search_items(keyword: str = Query(...)):
        return {"keyword": keyword}

Здесь параметр `keyword` обязательный. Любая попытка обратиться к `/search` без `?keyword=...` приведёт к ошибке валидации.

### Необязательные параметры

Когда указывают значение по умолчанию, параметр становится необязательным. Например, `keyword: str = ""` или с модулем `typing`:

    from typing import Optional

    @app.get("/search")
    def search_items(keyword: Optional[str] = None):
        if keyword:
            return {"keyword": keyword}
        return {"keyword": "not specified"}

В этом случае при запросе без параметра `keyword` функция получит `None` и вернёт `"not specified"` (или любое другое поведение, которое вы опишете). Если же клиент укажет `keyword=python`, ответ будет содержать именно эту строку.
