### Передача параметров через URL (Query parameters) в FastAPI

Веб-приложения на FastAPI могут принимать данные не только из тела запроса (JSON, форму, файл) или из пути (Path parameters), но и через так называемые query-параметры. Эти параметры следуют в URL после знака `?` и позволяют гибко настраивать фильтрацию, поиск, пагинацию и многие другие аспекты работы с данными.

## 1. Общие сведения о Query-параметрах

Query-параметры упрощают взаимодействие между клиентом и сервером, а их значения вписываются в строку запроса в виде `?ключ=значение`, с дополнительными параметрами, разделёнными символом `&`. Например: `/items?category=books&limit=10`.

Когда пользователь отправляет такой запрос, FastAPI «считывает» все указанные ключи и значения и передаёт их в вашу функцию в качестве аргументов. Например, если определить обработчик следующим образом:

    from fastapi import FastAPI

    app = FastAPI()

    @app.get("/items")
    def read_items(category: str, limit: int = 10):
        return {"category": category, "limit": limit}

- Аргумент `category: str` будет получать строку из параметра `?category=...`.

- Аргумент `limit: int = 10` означает, что параметр `limit` необязательный и имеет значение по умолчанию `10`. Если клиент не укажет `limit`, будет использовано 10; если же укажет, например, `?limit=5`, то функция получит `limit=5`.

Таким образом, Query-параметры прекрасно подходят для управления тем, как сервер будет обрабатывать и возвращать данные. Например, `category` может определять фильтрацию (книги, электроника), а `limit` ограничивать количество возвращаемых элементов.
