## Создание маршрута с параметрами пути

Рассмотрим базовый пример создания маршрута с использованием Path parameters:

    from fastapi import FastAPI

    app = FastAPI()

    @app.get("/users/{user_id}")
    def get_user(user_id: int):
        return {"user_id": user_id}

**Разбор кода:**

- `FastAPI()` – создание экземпляра приложения.

- `@app.get("/users/{user_id}")` – регистрация маршрута с переменной частью `{user_id}`.

- Функция `get_user(user_id: int)` получает значение из URL и возвращает его клиенту.

- FastAPI автоматически конвертирует переданный в URL идентификатор в тип `int` и возвращает JSON-ответ.

Если отправить запрос на `/users/10`, ответ будет:

    {"user_id": 10}
