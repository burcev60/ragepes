## Поддерживаемые типы Path parameters

FastAPI автоматически преобразует типы и проверяет их корректность при передаче данных через Path parameters. Поддерживаемые типы:

- **int** – целочисленные значения (`/items/{item_id}`).

- **str** – строковые данные (`/users/{username}`).

- **float** – числа с плавающей точкой (`/products/{price}`).

- **UUID** – универсальные уникальные идентификаторы (`/resources/{resource_uuid}`).

Пример использования типа UUID:

    from fastapi import FastAPI
    from uuid import UUID

    app = FastAPI()

    @app.get("/resources/{resource_uuid}")
    def read_resource(resource_uuid: UUID):
        return {"resource_uuid": resource_uuid}

FastAPI гарантирует, что переданный параметр является корректным UUID, иначе вернет ошибку.
