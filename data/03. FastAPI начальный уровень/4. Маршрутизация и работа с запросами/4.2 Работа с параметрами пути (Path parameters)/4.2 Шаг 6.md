## Сложная валидация с использованием регулярных выражений

FastAPI позволяет использовать регулярные выражения для точной валидации параметров пути:

    from fastapi import FastAPI, Path

    app = FastAPI()

    @app.get("/validate/{phone_number}")
    def validate_phone(
        phone_number: str = Path(
            ...,
            regex="^\\d{10}$",
            description="Phone number exactly 10 digits"
        )
    ):
        return {"phone_number": phone_number}

**Что происходит:**

- Параметр `phone_number` строго проверяется по регулярному выражению (ровно 10 цифр).

- Если номер телефона не соответствует шаблону, сервер отправит ошибку валидации.
