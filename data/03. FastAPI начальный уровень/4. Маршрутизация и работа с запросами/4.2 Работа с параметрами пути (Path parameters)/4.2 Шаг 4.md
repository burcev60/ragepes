## Продвинутая валидация и ограничения параметров пути

Для более строгого контроля параметров пути FastAPI предоставляет класс `Path`, позволяющий задавать дополнительные условия и ограничения:

    from fastapi import FastAPI, Path

    app = FastAPI()

    @app.get("/products/{product_id}")
    def get_product(
        product_id: int = Path(
            ...,
            title="Product ID",
            description="The ID of the product to get",
            ge=1,
            le=1000
        )
    ):
        return {"product_id": product_id}

**Пояснение:**

- `title` и `description` – описание параметров, используемое в документации.

- `ge=1` – минимально допустимое значение параметра (greater or equal).

- `le=1000` – максимально допустимое значение параметра (less or equal).

- `...` – обязательный параметр, не допускает пустых значений.

Если значение выходит за рамки указанных ограничений, FastAPI автоматически возвращает ошибку HTTP 422 с пояснением.
