## Множественные методы для одного маршрута

Вы можете привязать к одному URL несколько методов запросов, создавая отдельные обработчики:

    @app.get("/resource")
    def get_resource():
        return {"method": "GET request received"}

    @app.post("/resource")
    def post_resource():
        return {"method": "POST request received"}

## Тестирование маршрутов через встроенную документацию

FastAPI генерирует подробную документацию автоматически, позволяя легко проверять работоспособность ваших маршрутов без необходимости писать дополнительный клиентский код.

- **Swagger UI** доступен по адресу: `http://127.0.0.1:8000/docs`

- **ReDoc** доступен по адресу: `http://127.0.0.1:8000/redoc`

Эти интерфейсы помогут отправлять запросы к вашим маршрутам и проверять ответы прямо в браузере.

Теперь вы подробно знаете, как создавать и настраивать маршруты с разными методами HTTP-запросов в FastAPI, как использовать параметры пути и управлять ответами. Попробуйте создать различные маршруты, используя описанные выше техники, и проверьте их работу с помощью встроенной документации FastAPI.
