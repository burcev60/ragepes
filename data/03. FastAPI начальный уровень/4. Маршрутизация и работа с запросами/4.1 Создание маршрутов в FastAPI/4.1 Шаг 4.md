## Регистрация маршрутов через методы

Кроме использования декораторов, маршруты можно регистрировать вручную с помощью функции `add_api_route()`:

    def get_items():
        return ["item1", "item2", "item3"]

    app.add_api_route("/items", get_items, methods=["GET"])

Это полезно, когда маршруты регистрируются в других модулях или динамически.

## Управление HTTP-ответами

FastAPI позволяет явно указывать код и содержание HTTP-ответов:

    from fastapi import Response, status

    @app.post("/create")
    def create_item(item: dict):
        return Response(content="Item created", status_code=status.HTTP_201_CREATED)

Здесь мы явно возвращаем ответ с HTTP-статусом 201 (создано).
