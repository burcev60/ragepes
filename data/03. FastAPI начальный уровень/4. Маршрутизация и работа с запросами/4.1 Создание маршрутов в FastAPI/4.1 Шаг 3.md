## Статические и динамические маршруты

Маршруты в FastAPI могут быть как статическими (фиксированными), так и динамическими (переменными).

- **Статический маршрут**:

    @app.get("/users")
    def get_users():
        return ["user1", "user2", "user3"]

Данный маршрут всегда будет возвращать один и тот же список пользователей.

- **Динамический маршрут (использование path-параметров)**:

    @app.get("/users/{user_id}")
    def get_user(user_id: int):
        return {"user_id": user_id}

Здесь `{user_id}` является переменной, которая будет передаваться в функцию из URL запроса. FastAPI автоматически выполнит проверку и конвертацию типа.
