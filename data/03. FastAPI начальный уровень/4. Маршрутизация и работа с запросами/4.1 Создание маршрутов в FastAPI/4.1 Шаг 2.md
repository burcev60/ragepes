## Создание простого маршрута

Минимальный пример создания маршрута с использованием FastAPI выглядит следующим образом:

    from fastapi import FastAPI

    app = FastAPI()

    @app.get("/")
    def hello():
        return {"message": "Hello World!"}

Здесь:

- `from fastapi import FastAPI` – импортируем основной класс FastAPI.

- `app = FastAPI()` – создаём экземпляр приложения.

- `@app.get("/")` – декоратор, обозначающий, что функция ниже будет обрабатывать GET-запросы на корневой URL `/`.

- `def hello()` – обработчик маршрута, возвращает словарь, который FastAPI преобразует в JSON.

При отправке запроса браузером или Postman на этот маршрут (`http://127.0.0.1:8000/`) мы получим:

    {"message": "Hello World!"}

## 3. Использование различных HTTP-методов

FastAPI поддерживает все распространенные HTTP-методы:

- **GET** – получение информации.

- **POST** – создание новой записи.

- **PUT** – обновление всей записи.

- **PATCH** – частичное обновление данных.

- **DELETE** – удаление записи.

Пример обработки POST-запроса:

    @app.post("/items")
    def create_item(item: dict):
        return {"item": item, "status": "created"}

Здесь мы принимаем данные в виде словаря и возвращаем статус о создании элемента.
