## Множественные динамические сегменты

Один маршрут может содержать несколько переменных:

    @app.get("/users/{user_id}/orders/{order_id}")
    def get_user_order(user_id: int, order_id: int):
        return {
            "user_id": user_id,
            "order_id": order_id,
            "info": "Detail info about user's order"
        }

- При обращении к `/users/10/orders/5`, функция получит `user_id=10` и `order_id=5`.

- Подобная структура часто встречается, когда нужно указать вложенные ресурсы (у пользователя может быть несколько заказов).

Разумеется, количество динамических сегментов не ограничено, но старайтесь сохранять читаемость адресов.

## 5. Валидация параметров пути с помощью Path

FastAPI предоставляет специальный класс `Path` для более тонкой настройки:

    from fastapi import FastAPI, Path

    @app.get("/items/{item_id}")
    def get_item(item_id: int = Path(
        ...,    # Означает, что параметр обязателен
        ge=1,    # Значение должно быть >= 1
        le=1000, # И <= 1000
        title="Item ID",
        description="Номер товара в каталоге"
    )):
        return {"item_id": item_id}

- `...` (Ellipsis) говорит о том, что параметр `item_id` не может быть пропущен.

- `ge`, `le` и другие параметры (`gt`, `lt`) позволяют накладывать ограничения на числовое значение.

- `title` и `description` — метаданные, которые будут отображаться в автодокументации (/docs и /redoc).

Если пользователь обратится к `/items/0` или `/items/1001`, сервер ответит ошибкой валидации, не вызывая логики функции.
