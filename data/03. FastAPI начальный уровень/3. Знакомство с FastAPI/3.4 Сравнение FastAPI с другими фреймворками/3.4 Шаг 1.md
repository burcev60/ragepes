## Сравнение с Flask

### Общая информация

- **Flask** — один из самых популярных фреймворков, особенно для небольших приложений и прототипов.

- Имеет минималистичный ядро с модульной структурой, куда можно подключать расширения (Flask-Login, Flask-WTF и др.).

- Синхронный по природе (хотя и можно использовать async в отдельных сценариях, но это нестандартная практика).

### Сходства

1. **Минимализм**: Flask и FastAPI позволяют быстро стартовать с небольшим базовым кодом.

2. **Расширяемость**: оба фреймворка дают возможность подключать плагины и сторонние библиотеки.

### Отличия

1. **Асинхронность**:

  - Flask изначально не ориентирован на `async/await`. Для асинхронной обработки нужны дополнительные костыли (например, `gevent`, `eventlet`).

  - FastAPI поддерживает асинхронность «из коробки».

2. **Валидация данных**:

  - Flask не имеет встроенной системы валидации запросов.

  - FastAPI автоматизирует валидацию через Pydantic.

3. **Автогенерация документации**:

  - Flask не предоставляет готовый инструмент для Swagger/OpenAPI, но есть расширения.

  - FastAPI создает документацию автоматически.

4. **Производительность**:

  - Flask работает на WSGI и часто медленнее при больших нагрузках.

  - FastAPI с Uvicorn (ASGI) обеспечивает более высокую пропускную способность.

### Когда выбрать Flask?

- Когда нужен простой прототип, без особых требований к асинхронности.

- Если есть существующая экосистема Flask-плагинов, которой вы активно пользуетесь.

- При поддержке старого проекта, где уже нет смысла переходить на новый фреймворк.
