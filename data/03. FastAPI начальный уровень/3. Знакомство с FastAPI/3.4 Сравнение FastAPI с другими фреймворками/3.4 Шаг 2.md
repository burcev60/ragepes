## Сравнение с Django

### Общая информация

- **Django** — полноценный «монолитный» фреймворк с MVC-архитектурой, ORM, админкой, встроенным аутентификационным механизмом и т.д.

- Очень популярен для больших проектов, требующих много функциональности из коробки.

- Имеет синхронную архитектуру, но начиная с версии 3.0 появилась экспериментальная поддержка ASGI.

### Сходства

1. **Поддержка Python 3**: и Django, и FastAPI ориентированы на последние версии Python.

2. **Широкое сообщество**: оба решения имеют большую базу пользователей.

### Отличия

1. **Подход к разработке**:

  - Django «навязывает» структуру проекта, даёт собственную ORM.

  - FastAPI предоставляет гибкость в выборе ORM и архитектуры (обычно используют SQLAlchemy).

2. **Монолит vs. микросервисы**:

  - Django подходит для классических монолитных приложений.

  - FastAPI активно используется для микросервисов и REST API.

3. **Производительность**:

  - Django исторически медленнее, так как он «тяжелее» и ориентирован на широкую функциональность.

  - FastAPI быстрее в контексте high-load REST API.

4. **Автогенерация документации**:

  - Django Rest Framework (DRF) может генерировать документацию, но это отдельный пакет.

  - FastAPI встраивает документацию по умолчанию.

### Когда выбрать Django?

- Нужно быстро поднять полноценный сайт/панель администрирования.

- Требуются встроенные механизмы аутентификации, ORM, шаблонизатор.

- Команда уже знакома с Django, и перенос на FastAPI не оправдан.
