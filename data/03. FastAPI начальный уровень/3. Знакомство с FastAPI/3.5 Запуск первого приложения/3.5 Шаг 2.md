1. **Создание минимального приложения**

  В корне вашего проекта создайте файл `main.py`. В нём объявим объект приложения `FastAPI` и один маршрут (endpoint):

    # main.py
    from fastapi importFastAPI

        # Создаём экземпляр приложенияapp = FastAPI()

        # Определяем маршрут по адресу "/"
    @app.get("/")
    def read_root():
        return {"message": "Hello, FastAPI!"}

  Здесь мы:

  - Импортируем класс `FastAPI` из модуля `fastapi`.

  - Создаём объект `app`, к которому можно «привязывать» маршруты.

  - Используем декоратор `@app.get("/")` для описания GET-запроса на корневой URL ("/").

  - Функция `read_root()` возвращает словарь Python, который автоматически сериализуется в JSON.

2. **Запуск приложения и проверка работы**

  1. **Запустите сервер**:

    uvicorn main:app --reload

    - `main:app` указывает Uvicorn, что надо запустить приложение (`app`) из файла `main.py`.

    - Параметр `--reload` активирует автоматическую перезагрузку при изменении кода. Очень удобно в процессе разработки.

  2. **Проверьте консоль**: Если всё успешно, вы увидите примерно следующие сообщения:

    INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
    INFO:     Started reloader process [XXXX]
    INFO:     Started server process [XXXX]

      Это значит, что ваш сервер запущен локально и доступен по адресу `http://127.0.0.1:8000`.

  3. **Откройте браузер** и перейдите по адресу `http://127.0.0.1:8000`.

    - Если всё настроено правильно, вы увидите ответ в виде JSON:

    {
      "message": "Hello, FastAPI!"
    }

    - Это подтверждает, что маршрут `"/"` успешно возвращает ответ.
