- **Подготовка виртуального окружения и установка необходимых пакетов** Прежде чем запускать ваше первое приложение на FastAPI, важно работать в виртуальном окружении, чтобы избежать конфликтов с другими проектами и системными библиотеками. Предположим, что вы уже создали папку для проекта и активировали виртуальное окружение:

    # Пример для Windows:python -m venv venv
    venv\Scripts\activate

        # Пример для macOS/Linux:
    python3 -m venv venv
    source venv/bin/activate

  После активации окружения убедитесь, что установлены пакеты FastAPI и Uvicorn — веб-сервер, который будет исполнять ваше приложение:

    pip install fastapi uvicorn
> **FastAPI** — это фреймворк для создания веб-приложений и REST API. **Uvicorn** — это высокопроизводительный сервер ASGI, с помощью которого ваше FastAPI-приложение будет обрабатываться.
