1. **Просмотр автоматически сгенерированной документации**

  FastAPI автоматически создаёт спецификацию OpenAPI и предоставляет удобные интерфейсы для тестирования:

  - **Swagger UI**: `http://127.0.0.1:8000/docs`

  - **ReDoc**: `http://127.0.0.1:8000/redoc`

  Перейдите по любой из этих ссылок в браузере:

  - В Swagger UI вы увидите интерактивную документацию, где можно «потрогать» ваш API: отправить запросы прямо из браузера и посмотреть ответы.

  - ReDoc — это другой формат документирования, с подробным описанием схем и моделей.

2. **Что происходит под капотом?**

  - **FastAPI** анализирует ваши функции-обработчики (эндпоинты), типы аргументов и возвращаемое значение.

  - На базе этого генерируется спецификация OpenAPI, которая используется для создания документации.

  - **Uvicorn** выступает в роли сервера ASGI, управляя сетью и асинхронным исполнением запросов.

3. **Дополнительные возможности**

  - **Смена порта**: Если хотите запустить сервер на другом порту, можно использовать опцию `--port`. Например: `uvicorn main:app --reload --port 8080`.

  - **Просмотр логов**: Во время работы приложения в консоли выводятся логи, где отображаются входящие запросы, коды ответов и время обработки.

  - **Остановка**: Чтобы остановить сервер, нажмите в терминале `Ctrl + C`.
