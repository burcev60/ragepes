## Примеры, гайды и рекомендуемые внешние ресурсы

### 3.1. GitHub-репозиторий FastAPI

- **URL**: <https://github.com/tiangolo/fastapi>

- Исходный код фреймворка, открытый для контрибуции.

- Раздел **Issues** содержит обсуждения багов и предложений новых функций. Перед тем как задать вопрос, проверьте, не обсуждалось ли это раньше.

- **Pull requests** дают возможность увидеть актуальное развитие проекта и понять, как принимаются решения сообществом.

- Есть примеры развертывания в папке `examples/` или ссылки на связанные репозитории с демо-кодом.

### 3.2. Stack Overflow

- **URL**: <https://stackoverflow.com/questions/tagged/fastapi>

- Отличный ресурс для поиска решений конкретных задач.

- Всегда проверяйте, под каким тегом (fastapi, python, uvicorn) задаётся вопрос.

- При написании своего вопроса указывайте версию FastAPI, используемый Python, важные детали окружения.

### 3.3. YouTube

- Существует несколько каналов, посвящённых Python и FastAPI. Ключевые поисковые запросы: "FastAPI tutorial", "FastAPI deployment", "FastAPI best practices".

- Есть ролики, где авторы пошагово создают REST API, подключают БД и выкладывают приложение в продакшен.

- Набирают популярность стримы, где разработчики в реальном времени пишут код на FastAPI.

### 3.4. Medium, DEV.to, Habr и т.п.

- Обширное количество статей по FastAPI на русском языке можно найти на Хабре (Habr). Часто авторы дают свои практические рекомендации.

- На Medium и DEV.to много англоязычных статей, где делятся опытом по настройке, интеграции с Docker, SQLAlchemy, PostgreSQL.

- Обращайте внимание на даты публикаций: FastAPI быстро развивается, некоторые статьи могут быть частично устаревшими.

### 3.5. Другие ресурсы

- **Awesome FastAPI** (GitHub-репозиторий со списком полезных библиотек и расширений): <https://github.com/mjhea0/awesome-fastapi>.

- **Курсы на Udemy, Coursera**: платные и бесплатные курсы, которые могут содержать структурированные лекции, домашние задания.

- **Gitter / Telegram / Slack / Discord-чаты**: сообщества, где программисты оперативно обмениваются короткими вопросами.
