## Основные разделы документации и их назначение

Ниже перечислены главные разделы, с которыми стоит детально ознакомиться, чтобы эффективно работать с FastAPI.

1. **Tutorial - User Guide**

  - Объясняет фундаментальные понятия: маршрутизация, обработка HTTP-запросов, валидация данных (через Pydantic-модели), автогенерация документации OpenAPI.

  - Показывает, как работать с формами, JSON, файлами, заголовками запросов.

  - Демонстрирует подход к созданию иерархии маршрутов и структурированию приложения.

2. **Advanced User Guide**

  - Раскрывает тему асинхронности и concurrency более глубоко: отличия `async`/`await`, взаимодействие с базой данных в асинхронном режиме.

  - Описывает продвинутые схемы авторизации, использование OAuth2, JWT-токенов и других методов безопасности.

  - Даёт советы по интеграции с внешними сервисами и написанию middleware (фильтрация запросов, логирование и т.д.).

3. **Deployment**

  - Рассматривает варианты упаковки и запуска приложения: Docker-образы, настройка конфигурации для Uvicorn/Gunicorn, настраиваемые Dockerfile.

  - Есть примеры развёртывания на популярных хостингах (Heroku, AWS, Google Cloud).

  - Объясняет отличия среды разработки и окружения в продакшене (prod) и как оптимизировать параметры запусков.

4. **Security**

  - Подробно рассказывает о разных способах защищать API (Basic Auth, OAuth2, API-ключи).

  - Даёт шаблоны настройки аутентификации и авторизации, какие HTTP-заголовки нужны, как работать с куками.

  - Детально описывает валидацию и хранение паролей, способ их шифрования.

5. **Testing**

  - Описывает установку Pytest, настройку тестового окружения.

  - Даёт примеры написания юнит-тестов для маршрутов: проверка кодов ответов, тела ответа, заголовков.

  - Рассказывает о практике TDD (Test-Driven Development) в связке с FastAPI.

6. **Дополнительные руководства**

  - **Работа с базами** (использование ORM, Pydantic-моделей для чтения/записи).

  - **Фоновые задачи** (background tasks) для выполнения долгих операций без блокировки основного потока.

  - **GraphQL**, **WebSockets** и другие расширенные возможности.
