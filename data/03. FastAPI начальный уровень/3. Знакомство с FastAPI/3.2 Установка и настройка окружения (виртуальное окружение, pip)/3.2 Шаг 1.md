## Установка Python (при необходимости)

FastAPI требует установленной среды Python версии 3.7 или выше. Если Python ещё не установлен:

1. Загрузите установщик [с официального сайта Python](https://www.python.org/downloads/).

2. Запустите установку.

3. В окне установщика обязательно поставьте галочку **Add Python to PATH** (или выберите соответствующую опцию при установке).

Узнать, установлен ли Python, а также его версию, можно в консоли (PowerShell, cmd в Windows или терминал на macOS и Linux), выполнив:

    python --version

## Создание и активация виртуального окружения

Для локальной разработки проектов на Python желательно использовать **виртуальные окружения**. Это помогает изолировать зависимости разных проектов друг от друга.

### Windows

    # Создать виртуальное окружение (вместо myenv можно указать любое название)
    python -m venv myenv

    # Активировать виртуальное окружение
    myenv\Scripts\activate

После активации виртуального окружения в начале строки консоли будет отображаться `(myenv)`.
> **Примечание:** чтобы деактивировать виртуальное окружение, введите команду `deactivate`.

### macOS и Linux

    # Создать виртуальное окружение
    python3 -m venv myenv

    # Активировать виртуальное окружение
    source myenv/bin/activate

После этого название окружения (например, `(myenv)`) появится в начале вашей командной строки.
> Аналогично Windows, чтобы деактивировать окружение, выполните `deactivate`.
