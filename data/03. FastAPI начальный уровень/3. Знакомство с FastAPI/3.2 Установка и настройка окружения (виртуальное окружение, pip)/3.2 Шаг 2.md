## Установка и использование pip

**pip** — это стандартный менеджер пакетов в Python. С его помощью можно устанавливать, обновлять и удалять сторонние библиотеки.

### Установка pip

Если у вас установлен Python 3.7+ из официального дистрибутива, pip уже, как правило, встроен. Можно проверить версию pip командой:

    pip --version

Если команда `pip` не обнаружена, попробуйте выполнить `python -m ensurepip --upgrade`.

### Основные команды pip

- Установка пакета:

    pip install <название_пакета>

- Установка конкретной версии:

    pip install <название_пакета>==<версия>

- Обновление пакета:

    pip install --upgrade <название_пакета>

- Удаление пакета:

    pip uninstall <название_пакета>

- Создание файла зависимостей (обычно `requirements.txt`):

    pip freeze > requirements.txt

- Установка всех зависимостей из `requirements.txt`:

    pip install -r requirements.txt
> **Совет:** Все команды устанавливают пакеты внутри активированного виртуального окружения, если оно запущено.
