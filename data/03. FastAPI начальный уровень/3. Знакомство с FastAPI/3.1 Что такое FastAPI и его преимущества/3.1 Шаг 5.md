### Минимальный пример кода

Чтобы увидеть, насколько просто стартовать, создадим небольшой «Hello, World!» при помощи FastAPI.

    # файл main.py
    from fastapi import FastAPI

    app = FastAPI()

    @app.get("/")
    async def root():
        return {"message": "Hello FastAPI!"}

    # Запуск:
    # uvicorn main:app --reload

- **Импорт**: берём `FastAPI` из библиотеки `fastapi`.

- **Инициализация**: `app = FastAPI()` — наше приложение.

- **Маршрут**: декоратор `@app.get("/")` говорит, что при GET-запросе на корень (`"/"`) будет вызвана асинхронная функция `root()`.

- **Ответ**: возвращаем словарь (в JSON-формате).

- **Запуск**: командой `uvicorn main:app --reload` мы поднимаем локальный сервер. `--reload` перезагружает сервер при изменении кода.

При открытии `http://127.0.0.1:8000/docs` вы сразу увидите документацию, сгенерированную Swagger.

### Итоги

**FastAPI** — это гибкий, быстрый и удобный фреймворк на Python для создания современных API-сервисов. Его сильные стороны:

1. **Производительность** (близкая к Node.js и Go);

2. **Автоматическая документация** (Swagger/OpenAPI);

3. **Валидация данных** с помощью Pydantic;

4. **Асинхронная архитектура** (ASGI);

5. **Простота и лаконичность** кода.
