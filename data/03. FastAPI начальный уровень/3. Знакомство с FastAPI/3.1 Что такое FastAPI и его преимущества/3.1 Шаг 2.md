### Основная идея и назначение FastAPI

1. **Создание HTTP API**: Позволяет быстро писать RESTful или RPC-style эндпоинты для обмена данными через JSON, XML и другие форматы.

2. **Асинхронное программирование**: Благодаря ключевым словам `async`/`await` и протоколу ASGI, приложение может обрабатывать многие запросы параллельно (конкурентно), не блокируя процесс.

3. **Автоматическая документация**: Использует OpenAPI (Swagger) и JSON Schema для генерации документации «из коробки»:

  - Вы можете открыть `/docs` или `/redoc` для просмотра автоматизированной, интерактивной документации.

4. **Валидация данных**: На базе Pydantic предоставляет удобный способ описывать структуру входных данных и проверять их корректность (JSON-схемы, типы, ограничения). Это сокращает вероятность ошибок и повышает надёжность.
