### Краткий справочник кодов

| **Код** | **Класс** | **Название** | **Смысл** |
| --- | --- | --- | --- |
| 200 | 2xx | OK | Запрос успешно обработан |
| 201 | 2xx | Created | Успешно создан ресурс |
| 204 | 2xx | No Content | Успешно, но без тела |
| 301 | 3xx | Moved Permanently | Постоянный редирект |
| 302 | 3xx | Found (Moved Temporarily) | Временный редирект |
| 304 | 3xx | Not Modified | Ресурс не изменился |
| 400 | 4xx | Bad Request | Ошибка запроса |
| 401 | 4xx | Unauthorized | Требуется аутентификация |
| 403 | 4xx | Forbidden | Доступ запрещён |
| 404 | 4xx | Not Found | Ресурс не найден |
| 405 | 4xx | Method Not Allowed | Метод не разрешён |
| 409 | 4xx | Conflict | Конфликт (например, дубликат данных) |
| 500 | 5xx | Internal Server Error | Общая внутренняя ошибка |
| 502 | 5xx | Bad Gateway | Ошибка прокси или шлюза |
| 503 | 5xx | Service Unavailable | Сервис недоступен |
| 504 | 5xx | Gateway Timeout | Прокси не дождался ответа |

Конечно, есть и другие коды, но эти — наиболее часто встречающиеся в повседневной веб-разработке.
