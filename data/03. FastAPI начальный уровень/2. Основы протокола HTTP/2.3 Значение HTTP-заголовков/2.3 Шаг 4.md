### Важные заголовки запроса

Рассмотрим некоторые заголовки, которые **обычно** встречаются в HTTP-запросах:

#### Host

- **Значение**: имя хоста (домен) и (иногда) порт, к которому идёт запрос.

- **Пример**: `Host: example.com`.

- **Зачем нужен**: HTTP/1.1 требует этот заголовок для правильной маршрутизации, особенно если сервер обслуживает несколько сайтов (virtual hosting).

#### User-Agent

- **Значение**: информация о клиенте (браузере, приложении).

- **Пример**: `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)...`

- **Зачем нужен**: сервер может анализировать тип клиента (версию браузера), предоставлять совместимый контент.

#### Accept

- **Значение**: какие типы контента клиент готов принять.

- **Пример**: `Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8`

- **Зачем нужен**: сервер может выбрать **формат** ответа, если доступно несколько вариантов (HTML, JSON, XML).

#### Accept-Language

- **Значение**: какие языки предпочитает клиент.

- **Пример**: `Accept-Language: en-US,en;q=0.9,ru;q=0.8`

- **Зачем нужен**: сервер может вернуть контент на подходящем языке.

#### Accept-Encoding

- **Значение**: какие алгоритмы сжатия (gzip, deflate, br) клиент поддерживает.

- **Пример**: `Accept-Encoding: gzip, deflate`

- **Зачем нужен**: сервер может сжимать контент перед отправкой.

#### Authorization

- **Значение**: данные для аутентификации пользователя (Basic, Bearer token, и т.д.).

- **Пример**: `Authorization: Basic QWxhZGRpbjpvcGVuIHNlc2FtZQ==`

- **Зачем нужен**: чтобы сервер мог идентифицировать и авторизовать пользователя.

(Существует множество других заголовков, но эти — наиболее распространённые.)
