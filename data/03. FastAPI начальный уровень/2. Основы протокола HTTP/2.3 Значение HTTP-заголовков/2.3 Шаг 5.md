### Важные заголовки ответа

При формировании **HTTP-ответа** сервер обычно отправляет несколько важных заголовков:

#### Server

- **Значение**: информация о ПО сервера.

- **Пример**: `Server: nginx/1.18.0`

- **Зачем нужен**: информирует о типе/версии веб-сервера, хотя зачастую этот заголовок маскируют из соображений безопасности.

#### Content-Type

- **Значение**: тип содержимого (MIME-тип) и, возможно, кодировку.

- **Пример**: `Content-Type: text/html; charset=UTF-8`

- **Зачем нужен**: чтобы клиент (браузер) понимал, как интерпретировать тело ответа (HTML, JSON, изображение, и т.д.).

#### Content-Length

- **Значение**: размер тела ответа в байтах.

- **Пример**: `Content-Length: 342`

- **Зачем нужен**: чтобы клиент знал, когда закончился ответ (если не используется chunked-передача).

#### Set-Cookie

- **Значение**: задаёт cookie-файл в браузере.

- **Пример**: `Set-Cookie: session_id=abc123; Path=/; HttpOnly`

- **Зачем нужен**: для механизма сессий, отслеживания состояния пользователя.

#### Cache-Control

- **Значение**: правила кэширования.

- **Пример**: `Cache-Control: max-age=3600, must-revalidate`

- **Зачем нужен**: чтобы сообщить клиенту/промежуточным кэшам, как долго можно хранить контент.

#### Content-Encoding

- **Значение**: указывает метод сжатия (gzip, deflate, br).

- **Пример**: `Content-Encoding: gzip`

- **Зачем нужен**: чтобы сообщить клиенту, как «распаковывать» тело ответа.
